# 5E Hub — 패밀리 런처 시안

## 방향
기존 5E의 남색 이탤릭 워드마크와 실제 앱 아이콘을 유지하는 브랜드 확장이다. 교사가 도구의 이름 대신 자신의 작업으로 진입하도록 네 서비스와 목적별 필터를 첫 화면에 둔다. 소개는 짧게, 네 도구는 동일한 비중으로 보인다.

## 토큰
- 바탕 `#fafbfd`, 종이 `#ffffff`, 본문 `#182238`, 보조 본문 `#566176`, 경계 `#dde3ed`.
- 5E `#315dcc` / `#eef3ff`; OurDocs `#7353ac` / `#f3effa`; ExamLibrary `#8d601b` / `#f9f3e8`; DocFinder `#24765e` / `#edf6f1`.
- 본문 Pretendard(기존 저장소의 글꼴), 브랜드 Georgia italic(기존 5E 심벌 계승).
- 최대 너비 1240px; 데스크톱 네 열, 태블릿 두 열, 휴대전화 한 열의 가로형 서비스 행.
- 의미 있는 기능·주소 글자는 최소 11px, 주요 버튼은 최소 높이 44px.
- 서비스 반경 14px, 1px 경계; 액션 반경 7px. 그림자 대신 서비스 배경과 경계를 사용한다.

## 가족 아이콘
저장소의 `assets/apple-touch-icon.png`는 변경하지 않는다. `hub/assets/5e-original.png`는 출처를 기록한 PNG 텍스트 메타데이터를 포함하며 원본 픽셀을 동일하게 보존한다. 네 SVG에는 원본 `assets/apple-touch-icon.png`의 바이트를 그대로 내장한다. 같은 128×128 좌표계에 112×112 원본, 우하단 43×43 서비스 배지, 흰색 2px 기능 기호를 더했다. 연필 / 겹친 문서 / 열린 책 / 돋보기로 색을 구분하기 어려워도 서비스를 식별한다. 원본이 내장된 독립 SVG로 전달한다.

## 동작과 내용
- 서비스 링크: 사용자가 지정한 도메인의 `/`, `/ourdocs/`, `/examlibrary/`, `/docfinder/`.
- 작업 필터: 전체 / 그림 만들기 / 함께 쓰기 / 자료 찾기. 기본 HTML은 모든 도구를 보여주고 JS가 동작할 때 필터를 켠다.
- 필터는 버튼의 `aria-pressed`, 결과는 라이브 상태 영역으로 전달한다.
- 장식 링크는 키보드 순서에서 제외하고 카드의 주 액션을 사용한다.
- 마우스 호버에는 아이콘을 4px 올리는 작은 피드백; reduced-motion에서는 제거한다.
- DocFinder는 기존 독립 서비스로 이동해 로그인·쿠키·문서 권한 처리를 그 서비스에서 유지한다.

## 범위
새 `/hub/` 화면, 별도 패밀리 아이콘 시안, `/docfinder/` 진입점만 추가한다. 기존 편집기와 공동작성·기출 서비스의 UI와 아이콘은 변경하지 않는다. 현재 공개 배포의 모든 파일을 해시로 보존해 새 경로만 덧붙인다.
