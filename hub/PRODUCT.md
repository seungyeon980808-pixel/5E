# 5E Hub

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
교사와 수업·평가 자료 제작자가 5E 시리즈의 용도를 확인하고 원하는 서비스로 이동한다.

## Product Purpose
사용자가 링크나 서비스 이름을 기억하지 않아도 하나의 주소에서 제작·공동작성·기출 탐색·문서 검색 도구를 찾을 수 있게 한다.

## Capabilities and Constraints
- 허브 주소: https://www.5e.ai.kr/hub/
- 사용자 지정 서비스 경로: /, /ourdocs/, /examlibrary/, /docfinder/.
- 5E: 과학 시험용 그림·그래프·이미지 편집.
- OurDocs: 함께 쓰는 한글 문서. 기존 서비스의 공동작성 경로를 연결한다.
- 기출 탐색기: 기출문항 검색과 원본 확인. 기존 /examlibrary/ 경로를 연결한다.
- DocFinder: PDF·HWP·HWPX의 파일명·본문 검색. 새 도메인 경로에서 기존 서버로 이동한다.
- 기존 홈페이지·문서·검색 서비스와 인증 동작을 유지한다.

## Brand Commitments
기존 남색 둥근 사각형과 흰색 이탤릭 5E 글자를 유지한다. 가족 아이콘은 원본 아이콘 위에 서비스별 색과 기능 기호를 더한다.
