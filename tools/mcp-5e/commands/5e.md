mcp-5e(`mcp__5e__*`) 도구를 사용해서 요청을 처리한다. **브라우저 콘솔·내부 모듈 호출 같은
뒷길 금지 — 반드시 mcp__5e 도구만 쓴다.**

## 정본 문서 (규칙이 헷갈리면 여기부터)

- 호출 규약: `<5E-폴더>\tools\mcp-5e\CONVENTIONS.md`
- 그리기 규칙(바이블): `<5E-폴더>\docs\FIGURE_DESIGN_PRINCIPLES.md`
  — 특히 §17(선 굵기·점선 명칭), §19(그림 분해), §15(물체=사각형·원), §16(면 접촉 스냅)

## 표준 호출 순서

1. `app_status` — 연결 확인. 안 됐으면 안내문을 그대로 사용자에게 보여준다.
2. `set_page {page:"이름", create:true}` — **그림 하나 = 페이지 하나.** 기존 그림 위에 겹쳐 그리지 않는다.
   `set_artboard` — 눈대중(한 패널 90×60, 두 패널 150×50~60). 실측하지 않는다.
3. 필드가 필요하면 `describe_schema {type}` 확인 후 `add_objects`/`add_circuit`/`add_graph`
   — `path` 생략(그래야 화면에 바로), 한 그림은 objects 배열로 **한 번에**.
4. 고치는 요청이면 먼저 `read_app`으로 화면 상태를 읽는다.
5. `export_image`로 눈 확인 → 수정은 `remove_objects` 후 다시. 목표 2회 이내.
6. **저장은 사용자의 Ctrl+S.** 파일을 직접 만들거나 덮지 않는다.

## 자주 틀리는 규칙 요약 (바이블 압축)

- **선 굵기**: 전부 0.35mm, 그래프 계열만 0.4mm. 원본에서 재지 않는다.
- **점선 용법**: 기준선·궤적·치수보조선 = 1.0/0.3 · 가상선(이동 후 위치 도형) = 1.3/0.9 ·
  숨은선·영역 경계선 = 0.5/0.3 · 그래프 안내선 = `annGuides`(자동) · 제2계열 파선 = 1.9/0.9
- **라벨은 주인 객체에 붙인다** (제일 중요):
  - 상자 안 물리량/이름 → `labelInner` + `labelInnerType`("quantity"=이탤릭·첨자 / "label"=정체)
  - 상자 밖 → `labelOuter` + `labelOuterType` + `labelOuterPos`(above/below/left/right)
  - 실·용수철·회로 소자 → 그 객체의 `label`
  - 주인이 없는 글자만 독립 `text`(한글 돋움) / `formula`(물리량 이탤릭)
- **수식 표기는 소스 그대로**: `theta_1`, `R_1`, `v_0/3` → 앱이 θ₁·R₁ 등으로 변환. 유니코드로 미리 바꾸지 말 것.
  로마숫자 영역은 `{roman1}`~`{roman12}`.
- **이어진 면(바닥+경사)은 polyline 하나**. 경사 위 블록·마찰 띠는 면 접촉 계산으로 붙이고
  회전각 = 경사각 (오르막 −, 내리막 +).
- **물체는 사각형(블록)과 원(공·입자)**. 창작이면 블록은 정사각형, 기출 재현이면 원본 비율.
- **움직임 화살표는 표준 5mm** (`lineMode:"arrow"`), 길이 표시는 치수선
  (`lineMode:"lengthArrow"` + `dimensionLabel`).
- **그래프는 전부 `add_graph` 한 호출**: 축·문자 눈금(`tickLabelMode:"text"` + `tickTextX/Y`)·
  수선의 발(`annGuides`)·불연속 연결(`guideLines`)·꺾은선(`series:[{points:[[x,y],…]}]`)·
  함수 곡선(`functions:[{expr}]`). 축·눈금·꺾은선을 line으로 따로 긋지 않는다.

## 기출 문제 참고 (요청에 "몇 학년도/몇 월/과목/몇 번"이 나오면)

레퍼런스는 `<5E-폴더>\assets\exam-library\images`, 색인은 같은 폴더 `manifest.json`.
**파일명 접두사로 과목을 추측하지 말고** manifest로 찾는다
(`b1`=생명1, `p1`=물리1, `c1`=화학1, `e1`=지구1 — 직관과 다르다).

```bash
python -c "
import json
d = json.load(open(r'<5E-폴더>\assets\exam-library\manifest.json', encoding='utf-8'))
hit = [i for i in d['items'] if i['subjectLabel']=='물리1' and i['year']==2027 and i['month']==6 and i['no']==4]
print(hit)
"
```

이미지를 Read로 한 번 보고 **다시 그리는 것**(픽셀 복사 아님). 기출 재현이면 주요 배치
(원점·칸 크기·상대 위치)는 대략이라도 재고 시작한다 — 눈대중 배치는 실패한다.

## 다 그린 뒤 — 자체 검토 (토큰 아끼려고 조건부로만)

1. `read_app`(텍스트, 저비용)은 항상 — 객체 개수·타입이 의도와 맞는지.
2. `export_image`는 한 번 — 겹침·잘림·라벨 위치를 본다.
3. 원본 이미지를 다시 여는 건 명백히 이상할 때만. "혹시 몰라서" 재열람 금지.
4. 사용자가 "정확도 최우선"이라고 하면 그때는 원본 대조까지 한다.
