## 장면 3 — 그래프
28. 03 / 그래프
29. 그래프 사진이 / 식으로 고치는 그래프로.
30. 「그래프 복원」을 누르면 축과 눈금, 곡선을 읽어 다시 그립니다. 원본 사진 위에 겹쳐 맞춰 보고, 곡선은 y = 2/√x 같은 식으로 고칩니다. 식의 값을 바꾸면 곡선이 바로 움직입니다.
31. 단계: 그래프 복원 / 원본 위에 겹쳐 보기 / 곡선을 식으로 / 값 바꾸면 곡선이 움직임

  - S3-2 「그래프 복원」을 누르면
  - S3-3 축·눈금부터 읽고
  - S3-4 곡선·점을 찾아 편집할 수 있는 그래프로 (실제 약 1분)
  - S3-5 복원 결과를 원본 사진 위에 겹쳐
  - S3-6 손잡이가 지나가면 5E가 다시 그린 그래프
  - S3-7 편집기 ② 함수 — A는 식 y = 4/√x, B는 아직 자유곡선 19점
  - S3-8 B를 해석적 함수 y = 2/√x 로
  - S3-9 겹쳐 비교 — 두 곡선 모두 원본과 꼭 맞습니다

186. Q 어떤 컴퓨터에서 되나요? / A 웹은 크롬 · 사파리 같은 브라우저, 설치판은 Mac(Apple 칩 · 인텔)과 64비트 Windows입니다. 넓은 화면(PC) 기준입니다.
187. Q 휴대폰이나 태블릿에서도 되나요? / A 지금은 넓은 화면(PC) 기준입니다. 좁은 화면과 모바일은 다음 버전에서 다룹니다.
188. Q 내 Mac이 Apple 칩인지 인텔인지 모르겠어요 / A 왼쪽 위 사과 메뉴 › 「이 Mac에 관하여」에 「칩」이 보이면 Apple 칩, 「프로세서」가 보이면 인텔입니다.
189. Q Mac에서 「손상되었기 때문에 열 수 없습니다」가 떠요 / A 1.7.1부터 설치 파일 전체를 임시 서명으로 묶어 이 창이 뜨지 않습니다. 처음 열 때 막히면 응용 프로그램 폴더에서 5E를 Control-클릭 → 열기.
190. Q Windows에서 「PC 보호」 창이 떠요 / A 설치 파일에 아직 코드 서명이 없어서입니다. 추가 정보 → 실행을 누르세요.
191. Q 받은 설치 파일이 맞는지 확인하려면? / A 릴리스에 함께 올린 SHA256SUMS.txt로 확인할 수 있습니다.
192. Q 새 버전은 어떻게 받나요? / A 웹은 열 때마다 최신입니다. 설치판은 시작 창에 「1.7.1 → 1.7.2 [받기]」처럼 알려 주고, 받기 · 설치는 직접 합니다.
193. Q 자동 업데이트가 되나요? / A 아니요. 설치판은 새 버전을 알려 주기만 하고, 받기 · 설치는 직접 합니다. 인터넷이 없으면 조용히 지금 모습 그대로입니다.
194. Q 내 시험지는 어디에 저장되나요? / A 웹은 브라우저 안 보관함에 두고 「저장(.5e)」으로 파일을 내려받습니다. 설치판은 처음 저장할 때 자리를 고르고(처음 자리 「문서」), ~/Documents/5E/출제 에도 자동 저장합니다.
195. Q .5e 파일은 무엇인가요? / A 그림 · 한글 시험지 · 문항 · 시험지를 모두 담는 5E 파일 하나입니다. 어느 프로그램에서 열든 맞는 프로그램으로 넘겨 엽니다.
196. Q 웹에서 만든 것을 설치판으로 옮기려면? / A 웹과 설치판의 출제 자료는 따로 저장됩니다. .5e로 저장해서 다른 쪽에서 여세요.
197. Q 예전 버전에서 만든 파일이 열리나요? / A 1.6.3 · 1.7.0에서 만든 파일은 그대로 열립니다. 1.7.0의 .exampool도 열립니다.
198. Q 자동 백업은 얼마나 남나요? / A 설치판은 10분마다 백업하고, 최근 24개와 최근 30일 동안 날마다 마지막 하나를 남깁니다. 나머지는 바로 지우지 않고 휴지통으로 옮깁니다.
199. Q .5e 파일을 두 번 눌러 열 수 있나요? / A 설치판에서 됩니다. 이미 5E가 떠 있으면 그 창에서 엽니다.
200. Q 엑셀로 주고받을 수 있나요? / A 문항 목록은 「엑셀로 내보내기」로 내보내고, 「불러오기」로 엑셀도 엽니다.
201. Q 한글(한컴오피스)이 없어도 되나요? / A 됩니다. 5E_hwp가 한글 프로그램 없이 HWP · HWPX를 열고, 고치고, 저장합니다.
202. Q 시험지를 한글 파일로 받을 수 있나요? / A 시험지를 HWPX로 저장하거나 5E_hwp로 보내 인쇄 전 조판을 마칩니다.
203. Q 한글 단축키를 그대로 쓸 수 있나요? / A 5E_hwp는 한컴 한글 Windows 키 조합과 같은 단축키를 씁니다.
204. Q 5E_hwp는 무엇을 하나요? / A 「인쇄 전 조판(모양만)」을 맡습니다. 시험지 머리 · 문항 간격 · 단 채우기 · 용지 · 쪽 번호 · 〈보기〉 · ㄱㄴㄷ 선지 · 인쇄 · PDF. 문항 내용은 5E_exam이 맡습니다.
205. Q 5E_hwp 모드는 무엇이 있나요? / A 세 가지입니다 — ⌥⌘4 기본 · ⌥⌘5 집중 · ⌥⌘6 없음.
206. Q 학교 시험지 양식을 쓸 수 있나요? / A 원안지 한글 파일을 등록하면 머리 표 · 꼬리말 · 단 · 쪽 번호를 그대로 두고 그 위에 문항을 조판합니다.

209. Q 어떤 문항 유형을 만들 수 있나요? / A 합답형 · 정답형 · 짝 고르기 · 대화·발표 · 서술형. 고르면 평가원 문항 틀로 시작합니다.
210. Q 〈보기〉 정답은 어떻게 정하나요? / A ㄱ · ㄴ · ㄷ에 ○ · ×를 정하면 정답 선지가 정해지고, 기출에서 자주 쓰인 조합으로 선지를 채웁니다.

216. Q 어떤 기출이 들어 있나요? / A 라이브러리에 평가원 · 학평 · 교과서가 있습니다. 학평 과학탐구도 들어 있습니다.
217. Q 기출을 낱말로 찾을 수 있나요? / A 라이브러리에서 낱말로 찾으면 그 낱말이 든 기출만 원본 위에 형광으로 보여 줍니다.
218. Q 기출 변형은 오래 걸리나요? / A 미리 변환해 둔 문항은 1초 안에 열리고, 원본은 근거로 자동 연결됩니다.
219. Q 교과서 그림을 시험용 그림으로 바꿀 수 있나요? / A 라이브러리에서 교과서 쪽을 찾아 잘라 넣고 「변환하기」를 누르면 흑백 선화로 다시 그리고, 글자는 고칠 수 있는 라벨로 얹습니다.
220. Q 기출 그림의 글자를 고칠 수 있나요? / A 라벨 복원(베타)이 글자를 지우고 원본 크기 · 위치 그대로 고칠 수 있는 라벨로 다시 얹습니다.
221. Q 그래프 사진을 고칠 수 있게 되나요? / A 「그래프 복원」이 축 · 눈금 · 곡선을 읽어 편집할 수 있는 그래프로 다시 그립니다. 곡선은 식으로 고칠 수 있습니다.
222. Q 그림의 일부만 고칠 수 있나요? / A 부분 수정이 원본 · 지금 그림 · 지정한 영역을 함께 읽고 그 부분만 고칩니다.
223. Q 그림만 따로 받을 수 있나요? / A PNG로 저장하거나 이미지 복사로 가져갈 수 있습니다.
224. Q AI를 쓰려면 무엇이 필요한가요? / A 로그인한 ChatGPT 계정의 기능과 이용 한도 안에서 실행됩니다.
