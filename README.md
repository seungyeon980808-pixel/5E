# 5E — 과학 교육을 위한 평가 문항 편집기

**sciEnce Educational Evaluation Exam Editor**

5E는 과학 교사가 시험 문항을 처음부터 끝까지 한 곳에서 만드는 프로그램입니다.
교과서·기출에서 그림을 가져와 시험용 그림으로 다듬고(5E_image), 문항 카드로 문항을 쓰고 학교 시험지로 묶고(5E_exam), 한글 파일로 조판해 인쇄합니다(5E_hwp).

- 웹에서 바로 쓰기: <https://www.5e.ai.kr/>
- 설치판(Windows · Mac): [GitHub 릴리스](https://github.com/seungyeon980808-pixel/5E/releases/latest)
- 이번 버전 변경 내용: [1.7.0 릴리스 노트](docs/RELEASE_NOTES_v1.7.0.md)
- 문제 신고: <https://www.5e.ai.kr/bug/>

현재 버전 **1.7.0** · 라이선스 AGPL-3.0

---

## 왜 5E인가요

교사의 도구는 강사의 도구와 달라야 합니다. 학교 시험은 문제를 많이 만드는 일이 아니라, 성취기준 안에서 근거를 남기며 한 부를 바르게 만드는 일입니다. 5E는 그 과정 — 그림 준비, 문항 쓰기, 근거 연결, 시험지 묶기, 한글 조판, 인쇄 전 점검 — 을 한 흐름으로 잇습니다.

## 세 프로그램

| 프로그램 | 하는 일 |
|---|---|
| **5E_image** | 시험용 그림. 교과서·기출 그림을 AI로 평가원식 흑백 선화로 바꾸고, 라벨을 붙이고, 그래프를 복원하거나 새로 만듭니다. |
| **5E_exam** | 문항과 시험지. 문항 카드로 문항을 쓰고, 기출을 찾아 「변형」하고, 학교 양식으로 시험지를 묶습니다. |
| **5E_hwp** | 한글 조판과 인쇄. 한글(HWP·HWPX) 문서를 열어 고치고, 정답표·분류표·학생용 사본·PDF를 만듭니다. |

맨 위 이름 줄로 세 프로그램을 오가며, 세 프로그램이 함께 쓰는 **5E 클립보드**(⌘C · ⌘X · ⌘V, 어디서든 ⇧⌘V)로 그림·그래프·표를 옮깁니다.

## 출제 흐름

1. **라이브러리에서 찾기** — 평가원 · 학평 · 교과서 자료를 과목·단원·연도·낱말로 찾습니다. 문항은 정답 선지 형광펜과 함께 보이고, 별표로 모아 둡니다.
2. **그림 준비(5E_image)** — 필요한 그림을 잘라 AI 이미지 변환으로 흑백 선화로 바꾸고, 원본 글자를 고칠 수 있는 라벨로 다시 얹습니다. 그래프는 원본에서 복원하거나 대화로 새로 만듭니다.
3. **문항 쓰기(5E_exam)** — 유형과 자료 구조를 골라 평가원 문항 틀로 시작합니다. 카드에 쓰는 대로 오른쪽에 실제 한글 조판이 그려집니다. 기출을 「변형」해 편집 가능한 문항으로 가져올 수도 있습니다.
4. **시험지 묶기** — 문항을 담고 학교 양식(원안지)을 고르면 실제 한글 쪽으로 배치됩니다. 순서·여백을 정하고 점검합니다.
5. **조판·인쇄(5E_hwp)** — 한글 파일로 보내 다듬고, 인쇄 전 점검을 거쳐 PDF·HWPX로 저장합니다. 정답표·이원목적분류표·학생용 사본이 자동으로 따라옵니다.

## 기능

### 5E_image — 시험용 그림

- **AI 이미지/그래프 작업대**: 이미지 변환 · 이미지 생성 · 그래프 복원 · 그래프 생성을 한 창에서. 여러 작업을 동시에 걸어 두고, 끝나면 위쪽 줄에 알림이 뜹니다.
- **라벨 복원**: 기출 그림의 글자를 원본 크기·위치 그대로 고칠 수 있는 5E 라벨로(물리량 기울임, 숫자·단위 바로 세움, 한글·영어·수식 글꼴 구분).
- **부분 수정**: 고칠 곳에 점이나 영역 코멘트를 남기면 그 부분만 고칩니다.
- **AI 창 안 라벨 편집**: 글자 · 크기(pt) · 위치 · 지시선.
- **그래프**: 원본 그래프 복원(눈금 글자 크기·화살표를 원본에서 재어 맞춤), 함수로 그래프 생성, 그래프 위에서 축 이름·원점·눈금 바로 고치기.
- **캔버스**: 도형 · 글 · 수식 · 화살표 · 실험 장치 · 과학 오브젝트 · 에셋 라이브러리 · 레이어 · 안내선. PNG · SVG · `.5e` 프로젝트로 저장.
- 화면 색 세 가지(다크네이비 · 그라파이트 · 화이트), 기능 검색(⌘K / Ctrl+K).

### 5E_exam — 문항과 시험지

- **문항 카드**: 지문 · 자료 · 발문 · 〈보기〉 · 선지를 시험지 순서대로. 자료 칸 네 가지(그림 · 그래프 · 표 · 자료 상자), 〈보기〉 ○·×로 정답 자동, 자주 쓰는 조합으로 선지 채우기, 표를 한글처럼(F5 · M · S), 수식 입력(⌘E).
- **실시간 한글 조판**: 카드 옆 미리보기가 실제 HWP 조판입니다. 구조 잠금, 조판 부호(고정 띄어쓰기 · 내어쓰기 · 여백), 조판 설정(기본 수능 틀: B4 단 폭 112mm · 11.5pt).
- **기출 「변형」(AI 없음)**: 원본 PDF를 편집 가능한 한글 문항으로(1,440문항 시험 95.7% 제자리 복원). 원본은 근거로 자동 연결.
- **아이디어 판 · 문항 목록**: 출제 아이디어를 판에 모으고, 문항 목록은 열 있는 표로 줄 세우고 거릅니다.
- **시험지**: 담기 → 학교 양식으로 배치 → 여백·순서 → 점검(배점 합계 · 정답 분포 · 목표와 차이) → 이원목적분류표 · B형 · 인쇄 · HWPX · 5E_hwp로 보내기.
- **학교 양식**: 학교 원안지 한글 파일을 등록하면 그 양식 위에 그대로 조판. 대왕중 · 해송고 · 육민관고 원안지 기본 제공.
- **시험지 파일(.exampool)**: 문항 · 그림 · 학교 양식 · 조판 기준을 한 파일로 저장하고 엽니다. 시험이 끝난 시험지는 읽기 전용으로 잠급니다.
- **AI 출제 대화**: 대화로 문항을 다듬고 교육과정 범위·정답·그림을 검토합니다. 변경안은 「적용」을 눌러야 들어갑니다.
- 엑셀로 내보내기·가져오기.

### 5E_hwp — 한글 조판과 인쇄

- 한글(HWP·HWPX) 문서를 한글 프로그램 없이 열고 고치고 저장합니다.
- 모드 세 가지(기본 · 집중 · 없음), 왼쪽 문항 목록, 오른쪽 인스펙터(글자·문단 · 표 · 그림 · 쪽), 구조 잠금.
- 문항 사이 빈칸을 누르고 엔터 → 쪽 모양은 그대로 두고 새 줄.
- **교사용 줄**(`[정답]` `[해설]` `[성취기준]` …): 정답을 한 번 쓰면 정답표 · 나형 정답 · 정답 분포 · 정답·해설지 · 분류표 · 정답 QR이 따라가고, 학생용 사본에서는 빠집니다.
- 문항 틀 14종 · 조합 선지 · 배점 한 번에 · 정답 한 번에 · 가·나형 · 쪽 번호 · 머리말.
- **인쇄 전 점검**: 넓은 그림 · 번호 빠짐 · 배점 합계 · 글꼴 섞임 · 수식 크기 · 숫자·단위 띄어쓰기 · 정답 분포 치우침을 찾아 한 번에 고칩니다.
- 학습지 틀 · 빈칸 학습지 · QR 코드 · 화학식 첨자 한 번에.
- 한컴 한글 단축키(Windows 키 조합 기준). [전체 목록](docs/HWP_EXAM_SHORTCUTS.md)

### 라이브러리

- 5E 제공 자료: **평가원 · 학평 · 교과서**. 과학탐구 기출(물리·화학·생명·지구 Ⅰ·Ⅱ)을 과목 · 단원 · 연도 · 본문 낱말로 찾습니다.
- 문항 미리보기와 정답 선지 형광펜, 검색어 형광펜, 별표 폴더.
- 그림 영역 자르기 → 작업대·문항 카드·클립보드로.
- 설치판은 내 PDF 폴더도 연결할 수 있습니다.

## 시작하기

### 웹에서 바로

1. <https://www.5e.ai.kr/> 을 엽니다. 설치는 필요 없습니다.
2. 시작 화면에서 **image**(그림) · **exam**(시험지) · **hwp**(한글 파일 열기) 중 하나를 고릅니다.
3. AI 기능은 AI 창에서 ChatGPT 계정으로 기기 로그인한 뒤 씁니다. AI 없이도 그리기 · 문항 쓰기 · 조판 · 점검은 모두 됩니다.

### 설치판

[GitHub 릴리스](https://github.com/seungyeon980808-pixel/5E/releases/latest)에서 내려받습니다.

| 운영체제 | 파일 |
|---|---|
| Windows (64비트) | `5E-1.7.0-windows-x64.exe` |
| Mac (애플 실리콘) | `5E-1.7.0-macos-arm64.dmg` |
| Mac (인텔) | `5E-1.7.0-macos-x64.dmg` |

설치 파일에는 아직 코드 서명이 없습니다. Windows에서 「Windows의 PC 보호」 창이 뜨면 「추가 정보 → 실행」, Mac에서 처음 열 때 막히면 응용 프로그램 폴더에서 5E를 Control-클릭 → 「열기」를 누릅니다.

1.7.0 이전 설치판의 최신 릴리즈 <strong>v1.5.8</strong>은 [v1.5.8 릴리즈 페이지](https://github.com/seungyeon980808-pixel/5E/releases/tag/v1.5.8)에 남아 있습니다.

설치판은 출제 자료를 `~/Documents/5E/출제`에도 자동 저장·백업하고, 내 컴퓨터에 로그인된 Codex로 AI를 쓰며, 근거 검색을 할 수 있습니다.

### AI 연결

| 환경 | 연결 방식 |
|---|---|
| 웹 | AI 창에서 ChatGPT 계정으로 기기 로그인 |
| 설치판 | 내 컴퓨터에 로그인된 Codex 사용 |

5E는 ChatGPT 비밀번호를 받지 않습니다. AI 기능은 로그인한 계정의 기능과 이용 한도를 따릅니다.

## 자주 묻는 질문

<details>
<summary><b>비용이 드나요?</b></summary>

5E 자체는 무료입니다. AI 기능은 로그인한 ChatGPT 계정의 기능과 이용 한도 안에서 실행됩니다. 기출 변형 · 조판 · 점검은 AI를 쓰지 않습니다.
</details>

<details>
<summary><b>한글 프로그램이 있어야 하나요?</b></summary>

아니요. 5E_hwp가 한글 문서를 직접 열고 저장합니다. 내보낸 HWPX는 한컴 한글에서도 열립니다. 한컴 글꼴이 없는 컴퓨터에서는 비슷한 글꼴로 보일 수 있습니다.
</details>

<details>
<summary><b>학교 시험지 양식을 쓸 수 있나요?</b></summary>

네. 시험지 만들기에서 학교 원안지 한글 파일을 등록하면 머리 표 · 꼬리말 · 단을 그대로 두고 그 위에 문항을 조판합니다.
</details>

<details>
<summary><b>기출 「변형」 결과는 원본과 같나요?</b></summary>

눈으로 보아 어색하지 않은 수준을 목표로 합니다(1,440문항 시험 95.7% 제자리 복원). 시험지에 넣기 전에 원본과 비교해 확인하세요.
</details>

<details>
<summary><b>작업은 어디에 저장되나요?</b></summary>

브라우저(또는 설치판) 안에 자동 저장됩니다. 웹과 설치판, 브라우저마다 저장 공간이 다르므로 옮길 때는 그림은 프로젝트 파일(`.5e`), 시험지는 시험지 파일(`.exampool`)을 쓰세요.
</details>

<details>
<summary><b>교과서·기출 그림을 써도 되나요?</b></summary>

교과서·기출 자료는 각 저작권자의 이용 조건을 따릅니다. 라이브러리에 자료가 보인다는 것이 이용 권리를 확인했다는 뜻은 아닙니다.
</details>

## 내 데이터는 어디로 가나요

| 데이터 | 어디에 저장되나 | 밖으로 나가나 |
|---|---|---|
| 그림 작업 | 브라우저 IndexedDB 자동 저장 | 나가지 않습니다 |
| 문항 · 시험지 | 브라우저 IndexedDB(설치판은 `~/Documents/5E/출제`에도 자동 저장·백업) | 나가지 않습니다 |
| 프로젝트 · 시험지 파일 | 내가 저장한 `.5e` · `.exampool` 파일 | 직접 옮길 때만 |
| AI 작업 | 브라우저 IndexedDB | 실행할 때 원본과 요청만 AI 연결 서버로 |
| 웹 AI 로그인 | 브라우저 탭의 sessionStorage에 5E 세션 토큰 하나 | ChatGPT 인증 정보는 서버 임시 공간에만, 30분 동안 쓰지 않으면 끝 |
| 설치판 AI | 내 컴퓨터의 Codex 로그인 | 내 컴퓨터에서 AI 서비스로 바로 |
| 문제 신고 | 문제 신고 게시판 서버 | 공개를 고른 내용만 공개 |

## 개발

```bash
npm ci
npm run exam        # 로컬 서버로 열기
npm run desktop     # 설치판(Electron)으로 열기
npm test            # 단위 검사
npm run test:browser
```

Node 24.21.0 · Electron 44.4.5. 한글 조판 엔진은 `vendor/rhwp-studio`(rhwp)를 씁니다.
