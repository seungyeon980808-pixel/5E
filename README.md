**5E**(sciEnceEducationalExamEasyEditor)는 과학 교사가 자신의 PDF·이미지에서 필요한 영역을 골라
**시험문제용 도판**을 만들고 캔버스에서 마무리하는 도구입니다. 직접 그리는 SVG 편집기와
지원되는 그래프를 편집 가능한 오브젝트로 만드는 보조 흐름도 함께 제공합니다.
웹 편집기는 설치 없이 사용할 수 있고, 만든 프로젝트는 기본적으로 내 컴퓨터에만 남습니다. Windows 데스크톱판의 AI 이미지 기능을 사용자가 직접 실행한 경우에만 입력한 설명과 첨부 이미지가 로컬 Codex를 통해 해당 계정의 AI 서비스로 전달됩니다.

- **대상** — 과학(물리·화학·생명·지구과학) 교사, 시험지·학습지 제작자
- **스택** — 바닐라 JS + SVG, 빌드 없음. GitHub Pages 정적 배포
- **저장** — 프로젝트 JSON · 전체 백업 ZIP · 브라우저 자동 저장
- **Windows 배포** — 설치 파일은 GitHub Releases에서 제공하며 [코드 서명 정책](docs/CODE_SIGNING_POLICY.md)을 공개합니다.

## 5분 둘러보기

<img src="docs/images/release-v1.0.0/01-workspace.png" alt="5E 화면 구성 — 상단 툴바, 좌 오브젝트 패널, 가운데 캔버스, 우 속성 패널, 하단 페이지 탭" width="820" />

화면은 네 구역입니다.

1. **위쪽 툴바** — 프로젝트 저장·불러오기, 내보내기와 화면 설정
2. **왼쪽 패널** — 기본 그리기 도구, 내가 저장한 오브젝트와 고급 편집 도구
3. **가운데 캔버스** — 실제 그림이 놓이는 아트보드. 휠로 확대, 스페이스+드래그로 이동
4. **오른쪽 패널** — 선택한 것의 속성(굵기·색·글씨·좌표…). 선택한 종류에 따라 항목이 달라집니다
5. **아래 탭** — 페이지(문항) 목록. 문항 하나에 페이지 하나씩 쓰면 편합니다

전형적인 작업 흐름은 이렇습니다.

```
내 PDF·이미지 연결 → 검색·영역 선택 → 도판 만들기 → 원본 비교 → 캔버스 삽입
```

이미지 없이 요청을 입력해 만들거나, 캔버스에서 처음부터 직접 그릴 수도 있습니다.

## ① 시험문제용 도판 만들기

캔버스 아래의 **시험문제용 도판 만들기**를 열면 다음 순서로 작업합니다.

1. 개별 이미지는 **이미지 추가**로 바로 넣습니다.
2. PDF나 이미지 폴더는 **자료 연결 → 내 PDF·이미지 폴더 선택**으로 연결합니다.
3. 이미지 이름 또는 PDF 원문을 검색합니다. PDF 결과를 열면 **문항 전체**·**도판 영역** 제안을
   고른 뒤 경계를 직접 고치고 확대 미리보기에서 확인할 수 있습니다. 제안은 자동 확정되지 않으며,
   별도 변환 버튼을 누른 크롭만 다음 단계로 전달됩니다. 페이지 전체·수동 영역 지정도 지원합니다.
4. 요청을 입력하고 **도판 만들기**를 누릅니다.
5. 확정한 원본이 있으면 **원본과 비교**한 뒤 결과를 캔버스에 삽입합니다.

자료 연결은 사용자가 직접 고른 로컬 폴더를 대상으로 합니다. Windows 데스크톱판에서 AI 기능을
실행한 경우에만 확정한 자료와 요청이 해당 계정의 AI 서비스로 전달됩니다.

**고급 설정**에는 모델·추론·속도, 그림 복잡도, 라벨, 여러 장 변환, 작업 탭과 화면 캡처가
접혀 있습니다. 기본 출력은 **시험문제용 도판**이며, **편집 가능한 그래프**는 지원되는 그래프를
위한 보조 출력입니다.

자주 쓰는 캔버스 오브젝트는 **오브젝트 저장**으로 개인 저장소에 넣어 다시 사용할 수 있습니다.

## ② 그래프와 함수

시험지 그림의 절반은 그래프입니다. 그래서 그래프는 **전용 창**에서 만듭니다. 툴바의 `좌표/함수 생성`(<kbd>F</kbd>).

창은 세 단계로 나뉩니다.

```
① 좌표 — 축·격자·눈금을 만들고
② 함수 — 그 위에 곡선을 얹고
③ 표시 — 점·화살표·안내선·범례를 붙인다
```

### ① 좌표 — 축 만들기

<img src="docs/images/release-v1.2.0/10-axis-detail.png" alt="비대칭 좌표축과 네 끝 여백 지정" width="820" />

- **모양** — ㄴ자 / ㅏ자 / 십자 중 선택
- **비대칭 범위** — x·y의 음/양 방향 칸 수를 따로 지정. 왼쪽 2칸 · 오른쪽 5칸 같은 축이 만들어집니다
- **칸 범위 / 간격** — 축이 덮는 값과 격자 간격을 따로. 간격을 0.5로 주면 눈금이 촘촘해집니다
- **눈금 라벨** — 없음 / 숫자 / 배수(a, 2a, 3a…) / 직접 입력. 숫자는 **끌어서 위치를 옮길 수** 있습니다
- **고급 옵션** — 화살표 여백과 격자 튀어나옴을 네 끝 각각, 축 이름·눈금 글씨 크기, 라벨 이동 잠금

<img src="docs/images/readme/14-tick-labels.png" alt="눈금 라벨 네 가지 방식 비교" width="820" />

눈금 숫자가 곡선이나 다른 라벨에 가려지면 끌어서 옆으로 비켜 놓습니다.

### ② 함수 — 곡선 얹기

세 가지 방식이 하위 탭으로 나뉩니다.

| 탭 | 무엇 |
|---|---|
| **해석적 함수** | 수식을 입력해 그립니다. `sin`, `log`, 분수, 지수 모두 됩니다 |
| **직선·꺾은선** | 점을 찍어 잇습니다 |
| **자유곡선** | 마우스로 죽 끌어 그립니다 |

<img src="docs/images/release-v1.1.0/02-range.png" alt="사각형을 끌어 정의역과 치역을 한 번에 지정" width="820" />

- **정의역·치역** — 값으로 입력하거나, 미리보기 위에 **사각형을 끌어 한 번에** 잡습니다. 그래프의 일부만 보여주는 문항에 씁니다
- **여러 함수** — 한 평면에 겹쳐 넣고, 선 종류(실선·파선·점선)와 굵기를 따로 줍니다
- **끝 라벨** — 곡선 끝에 이름을 붙입니다

<img src="docs/images/release-v1.1.0/01-bezier.png" alt="자유곡선을 그린 뒤 앵커와 베지어 핸들로 다듬는 과정" width="820" />

자유곡선은 **대충 끌어 그린 뒤 다듬는** 방식입니다. 그린 즉시 성긴 앵커로 정리되고, 앵커를 끌어 모양을 잡거나 베지어 핸들로 곡률을 조절합니다. 앵커 개수도 늘리고 줄일 수 있습니다(우클릭으로 삭제).
찍은 점은 **정확히 통과**합니다 — 점 사이에서 제멋대로 부풀지 않습니다.

### ③ 표시 — 점과 안내선 붙이기

<img src="docs/images/release-v1.2.0/02-annot-after.png" alt="빈 좌표평면에 표시점·수선의 발·안내 점선·범례를 올린 모습" width="620" />

함수와 **무관하게** 얹는 층입니다. 함수가 없는 빈 평면에도 놓입니다.

- **표시점** — 까만 점
- **수선의 발** — 찍은 점에서 두 축까지 점선
- **화살표** — 곡선 위를 클릭하면 그 자리 접선 방향으로
- **가이드라인** — 두 점을 이어 안내 점선
- **범례 박스** — 선 견본 + 설명. 줄을 늘리고 자유롭게 옮깁니다
- **라벨러 표시점** — 아래

<img src="docs/images/release-v1.2.0/04-labelpt-after.png" alt="점 주위를 15도씩 도는 이름표" width="520" />

**라벨러 표시점**은 클릭한 순서대로 A·B·C 이름표가 붙고 점과 함께 움직입니다.
찍는 즉시 선택되어 <kbd>PageUp</kbd> <kbd>PageDown</kbd>으로 이름표 방향을 **15°씩** 돌립니다. 거리와 글씨 크기도 점마다 따로.

### 그 밖에

- **데이터 표 붙여넣기** — 엑셀에서 복사한 표를 붙이면 좌표평면 위 산점도가 됩니다
- **평가원 화살촉** — 축과 직선 끝의 화살촉을 실제 기출 지면에서 윤곽을 따 재현했습니다

<img src="docs/images/release-v1.2.0/07-arrowhead-after.png" alt="뒤쪽이 오목한 평가원 스타일 화살촉" width="360" />

## ③ 그리기 도구

### 선

| 도구 | 키 | 설명 |
|---|---|---|
| 직선 | <kbd>L</kbd> | 끝에 화살표를 달 수 있습니다 |
| 꺾은선 | <kbd>P</kbd> | 클릭으로 꼭짓점 추가, 우클릭으로 완성 |
| 곡선 | <kbd>C</kbd> | 찍은 점을 지나는 매끄러운 곡선 |
| 자유 그리기 | <kbd>D</kbd> | 마우스로 죽 끌어 그리기 |

<img src="docs/images/readme/01-lines.png" alt="직선·꺾은선·곡선·자유 그리기 네 가지 비교" width="820" />

**언제 쓰나** — 눈금 없는 개념도의 축은 직선, 실험 장치의 실·줄은 꺾은선, 그래프 개형은 곡선, 지형이나 자기력선처럼 규칙 없는 모양은 자유 그리기.

모든 선은 **선 종류·굵기·색**을 따로 주고, 나중에 앵커를 옮겨 고칠 수 있습니다.

<img src="docs/images/readme/02-stroke.png" alt="선 종류(실선·파선·점선)와 굵기 단계, 화살촉과 치수선" width="820" />

### 도형

타원 <kbd>O</kbd> · 사각형 <kbd>S</kbd> · 직각삼각형 <kbd>Y</kbd>. 채움과 테두리를 따로 정합니다.

<img src="docs/images/readme/03-shapes.png" alt="타원·사각형·직각삼각형과 채움/테두리 조합" width="820" />

**언제 쓰나** — 물체·용기·블록처럼 그림의 몸통이 되는 것들. 채움을 옅게 주면 뒤에 있는 격자나 배경이 비쳐 보입니다.

### 텍스트와 수식

- **자유 텍스트** <kbd>T</kbd> — 글꼴·크기·정렬. 시험지 지면에 맞춘 **자간·장평** 조절
- **라벨러** <kbd>Shift</kbd>+<kbd>T</kbd> — 지시선 + 이름표. 대상을 옮기면 지시선이 따라옵니다
- **수식** — LaTeX 문법. 팔레트 버튼으로 기호를 넣고, 첨자·분수·근호·그리스 문자를 씁니다. 수식 글꼴은 LM Roman을 번들해 어느 PC에서나 같게 나옵니다
- **원문자** — ㉠㉡㉢㉣㉤ 등 시험지에 자주 쓰는 기호를 팔레트에서

<img src="docs/images/readme/04-labeler.png" alt="지시선과 이름표가 대상을 따라 움직이는 라벨러" width="820" />

라벨러는 **지시선과 이름표가 한 몸**입니다. 대상을 옮기면 함께 따라오므로, 나중에 배치를 바꿔도 선을 다시 긋지 않습니다. 이름표 자리에는 수식도 들어갑니다.

<img src="docs/images/readme/05-formula.png" alt="LaTeX 수식 예시와 시험지 기호 팔레트" width="820" />

<img src="docs/images/release-v1.2.0/13-text-spacing.png" alt="자간과 장평을 다르게 준 같은 문장" width="820" />

### 표시·측정

- **각도 호** <kbd>A</kbd> / **직각 표시** <kbd>Shift</kbd>+<kbd>A</kbd> — <kbd>Tab</kbd>으로 전환
- **점** <kbd>N</kbd>
- **길이 표시(치수선)** — 두 점 사이 거리에 라벨
- **자 · 각도기** — 화면 위에 올려놓고 각도와 길이를 재는 가이드. 그림에는 안 나갑니다

<img src="docs/images/readme/06-measure.png" alt="각도 호·직각 표시·점·치수선" width="820" />

<img src="docs/images/readme/07-gauge.png" alt="그림 위에 올려놓고 재는 자와 각도기" width="820" />

**언제 쓰나** — 자·각도기는 기출 지면을 흉내 낼 때 각도가 맞는지 눈으로 확인하는 용도입니다. 내보내기에는 포함되지 않으니 켜 둔 채 작업해도 됩니다.

### 자르기 <kbd>E</kbd>

가위로 오브젝트를 자릅니다. **자유곡선으로 자르고**, <kbd>Shift</kbd>를 누르면 직선, <kbd>Shift</kbd>+<kbd>Ctrl</kbd>은 각도 스냅.
채움이 있는 도형을 자르면 **채움을 유지한 채 둘로** 나뉩니다.

<img src="docs/images/readme/08-cut.png" alt="채움이 있는 도형을 곡선으로 잘라 둘로 나누는 과정" width="820" />

**언제 쓰나** — 단면을 보여줘야 하는 그림(잘린 관, 반쪽 렌즈, 지층 단면)에서 도형을 새로 그리는 대신 잘라 씁니다. 잘린 조각은 각각 따로 옮기고 회전합니다.

## ④ 캔버스 오브젝트와 개발용 레거시 자료

왼쪽 패널의 기본 심볼과 **퍼스널 오브젝트**는 캔버스 편집 보조 도구로 계속 사용할 수 있습니다.
직접 만든 도해는 **오브젝트 저장**으로 개인 저장소에 넣어 다시 배치할 수 있습니다.

이와 별개인 번들 기출·부품 라이브러리의 버튼, 단축키, 커맨드 팔레트 항목과 튜토리얼은 일반 실행에서
노출하지 않습니다. 저장소의 기존 자산은 Phase 1에서 삭제하지 않았고, 명시적인 개발용 게이트가
켜진 로컬 환경에서만 레거시 UI를 점검할 수 있습니다. 새 사용자 흐름은 ①의 내 PDF·이미지 연결을
사용합니다.

## ⑤ 이미지 다루기

### 이미지 객체화 (고급·실험)

불러온 이미지(스캔·캡처)를 **편집 가능한 벡터 객체로** 바꿉니다. 필요한 부분만 남기거나 선을 고쳐 쓸 수 있습니다.
이 기능은 고급·실험 편집 도구이며, 모든 입력의 구조와 글자를 정확히 복원한다고 보장하지 않습니다.
일반 작업은 먼저 **시험문제용 도판** 흐름을 사용하고, 개별 선·면 편집이 꼭 필요할 때 객체화를 시도하세요.

- 인식 강도를 조절합니다 — 묶음 거리 · 최소 크기 · 글자 판정 크기 · 곡선 단순화
- 미리보기에서 원치 않는 조각을 **클릭해 빼냅니다**
- 글자는 남기거나 · 지우거나 · 텍스트 객체로 바꿉니다
- 격자·눈금선만 걸러낼 수 있습니다

<img src="docs/images/readme/10-objectify.png" alt="스캔 이미지를 벡터 조각으로 바꾸는 과정과 인식 옵션" width="820" />

옵션 네 가지가 각각 무엇을 바꾸는지는 이렇습니다.

| 옵션 | 올리면 | 내리면 |
|---|---|---|
| **묶음 거리** | 끊어진 선을 하나로 이어 봅니다 | 조각이 잘게 나뉩니다 |
| **최소 크기** | 점·잡티를 무시합니다 | 작은 표시점까지 살립니다 |
| **글자 판정 크기** | 더 큰 것까지 글자로 봅니다 | 글자를 그림으로 봅니다 |
| **곡선 단순화** | 점이 줄어 가벼워집니다 | 원본 모양에 더 충실합니다 |

바꾼 뒤에는 평범한 벡터 객체라, 선 하나하나를 고치고 색·굵기를 그림 전체와 맞출 수 있습니다.

### 그 밖의 이미지 기능

- **여러 장 불러오기** — 한 페이지에 모으거나, 페이지마다 하나씩
- **원본 비교** — 그린 오브젝트와 원본 이미지를 좌우로 놓고 대조
- **인쇄 비교 배경** — 실제 지면을 반투명 배경으로 깔고 그 위에 맞춰 그립니다
- **영역 지우기** — 사각형·자유 영역으로 이미지의 일부를 지웁니다(되돌리기 가능)
- **붙여넣기** — 클립보드 이미지를 <kbd>Ctrl</kbd>+<kbd>V</kbd>로 바로

## ⑧ 저장과 백업

- **프로젝트 저장** <kbd>Ctrl</kbd>+<kbd>S</kbd> — JSON 한 파일. 파일을 캔버스에 끌어다 놓으면 바로 열립니다

브라우저에서 `http://localhost:8000`. Windows에서는 저장소에 있는 `run-server.bat`을 더블클릭해도 됩니다.

## 저장 파일 형식

프로젝트 JSON은 스키마 `0.17`을 쓰며 **페이지 단위**로 `objects`, `guides`, `layers`, `artboard`와 문항 메타를 담습니다(`pages[]`).
되돌리기 히스토리·선택 상태·화면 배율은 저장되지 않습니다.
구버전 파일은 열 때 자동 마이그레이션되고, 페이지 개념이 없던 파일은 한 페이지로 감싸 열립니다.
