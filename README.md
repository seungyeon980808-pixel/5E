# 5E

**과학교사를 위한 시험·학습지 그림 편집 도구입니다.**

있는 그림을 가져와 고치고, 글자와 라벨을 붙여 이미지로 저장하세요. 직접 그리기와 그래프 제작도 지원합니다.

**숫자가 다른 이유:** 기존 웹 배포 복원 후 Windows 릴리즈와 웹 소스가 갈라졌고, Preview는 별도 스냅샷으로 추가됐습니다. README의 과거 `v1.5.0` 안내는 최신판 안내가 아니었습니다. 이번 정비는 배포판을 실제 상태대로 구분하며, 설치 파일을 새로 빌드한 것으로 표시하지 않습니다. 자세한 출처와 정책은 [배포 안내](docs/RELEASE_CHANNELS.md)를 참고하세요.

> 중요한 작업은 프로젝트 파일로 따로 저장하세요. Preview의 브라우저 저장 공간은 기존 웹판과 분리돼 있으며 자동으로 작업이 옮겨지지 않습니다.

## 사용 흐름

1. 기출 그림이나 이미지를 불러옵니다.
2. 필요한 부분을 남기고, 객체화 또는 편집 도구로 정리합니다.
3. 글자·기호·지시선을 붙입니다.
4. 이미지로 내보내고, 재편집할 작업은 프로젝트 파일로 저장합니다.

Preview에는 PDF 읽기·검색·페이지 렌더링 코드가 포함돼 있습니다. 다만 **PDF 가져오기부터 변환·라벨링·저장까지 이어지는 단일 화면의 기본 제품 경험은 아직 정식 제공 상태가 아닙니다.** 현재 브라우저/설치판에서 이용 가능한 진입점과 연동 범위가 다릅니다.

## 5E와 고급 편집기

앞으로 **5E**는 `PDF → 그림 추출 → 변환 → 라벨 → 저장` 흐름을 중심으로 정리하고, **5E Pro**는 직접 그리기·그래프 등 전체 도구를 제공하는 고급 작업 공간으로 구분할 계획입니다.

현재 공개 소스의 `Pro/Lite`는 **화면 표시 모드**이며 요금제가 아닙니다. 기본 진입점도 아직 Pro입니다. 이번 문서 정비만으로 새로운 기본 화면이 구현됐다고 보장하지 않습니다.

- **고급 도구:** 도형·곡선, 좌표/함수, 라벨·수식, 자르기, 페이지와 오브젝트 재사용
- **과목 범위:** 물리 부품 팔레트 중심. 화학·생명과학·지구과학 팔레트의 일부 분류는 비어 있습니다.
- **상세 설명:** [기존 웹 편집기 사용 안내](docs/LEGACY_README_GUIDE.md)

## 파일과 개인정보

- 일반 편집 작업은 브라우저 저장소와 사용자가 저장한 프로젝트 파일을 중심으로 처리합니다. 브라우저 데이터 삭제는 자동 저장 데이터도 지울 수 있습니다.
- AI 기능을 명시적으로 실행하면 설명·첨부 이미지가 로컬 Codex를 거쳐 해당 계정의 외부 AI 서비스로 전송될 수 있습니다. **완전 오프라인 AI라고 안내하지 않습니다.**
- 웹 Preview는 Windows 전용 로컬 폴더·화면 캡처·AI 연결 기능을 모두 대체하지 않습니다.
- 시험 원문·교과서·기출 자료를 가져올 때는 해당 자료의 이용 권한을 확인하세요. 코드의 AGPL-3.0 라이선스가 모든 이미지의 재배포 권한을 뜻하지 않습니다.
- [코드 서명 및 배포 정책](docs/CODE_SIGNING_POLICY.md) · [Windows 사용·개발 안내](docs/DESKTOP_WINDOWS.md)

## 개발과 검증

웹앱은 바닐라 JavaScript와 SVG 기반 정적 앱입니다. 저장소 루트를 정적 HTTP 서버로 제공하면 `/`와 `/preview/`를 각각 확인할 수 있습니다. Windows 셸은 Electron을 사용합니다.

Node.js 20 이상에서:

```sh
npm run check:release
npm run test:release
npm test
```

- `check:release`: 배포 채널 표, 패키지·잠금 파일·화면 표기를 검사합니다.
- `test:release`: 잘못된 버전·태그·문서 연결을 검사기가 거부하는지 확인합니다.
- `npm test`: 기존 `desktop/*.test.cjs` 검사입니다. **전체 웹 UI·PDF 변환·내보내기 품질을 보증하는 E2E 검사가 아닙니다.**
- Windows 릴리즈는 태그와 패키지 버전이 다르거나 해당 릴리즈 노트가 없으면 빌드를 중단합니다.
