# 메모

휴대폰과 컴퓨터 사이에서 링크와 짧은 생각을 빠르게 옮기는 공유 작업판. `5e.ai.kr/memo/`로 바로 접근하며 공개 작업판에는 로그인이 필요 없다.

선택 제목, 링크 열기와 복사, 자유롭게 붙이고 편집하는 포스트잇, 기기 간 동기화를 제공한다. 최초 작성 후 24시간이 지나면 지정한 Google 주인장만 보관함에서 볼 수 있다. 디자인은 컴팩트한 데스크톱 메모 도구와 주변 포스트잇, 어두운 보라·남색의 정적인 공간감을 유지한다.

GitHub Pages 화면에 Cloudflare Workers·D1 저장소와 지정한 주인장 Google 로그인을 연결한다. 로컬 시험 결과를 실서버 연결 성공으로 표시하지 않는다.
