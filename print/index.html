    프롬프트가 완성되었습니다

    브리프(고른 내용)는 프롬프트 안에 들어 있고, AI가 시작하면서 폴더의 작업/print-브리프.md로 저장합니다.

    붙여 넣는 곳

    Claude · Claude Code

    Claude 데스크톱 앱 → 왼쪽 Code 탭 → 폴더 고르기에서 폴더를 열고, 아래 입력창에 프롬프트를 붙여 넣어 보냅니다.

    처음이라 Claude Code가 없다면

    앱은 claude.ai/download에서 받습니다. 터미널을 쓰려면 아래 명령을 한 번 붙여 넣으세요.

    GPT · Codex

    Codex 앱에서 폴더를 프로젝트로 열고 프롬프트를 붙여 넣어 보냅니다. 터미널이면 그 폴더에서 codex를 실행해 붙여 넣습니다.

    처음이라 Codex가 없다면

    ChatGPT 계정으로 로그인해 씁니다. 터미널을 쓰려면 아래 명령을 한 번 붙여 넣으세요.

    둘 중 어느 쪽에 붙여 넣어도 똑같이 만들어집니다. 필요한 다른 프로그램(Typst · Python · 글꼴)은 AI가 알아서 설치합니다. claude.ai나 ChatGPT 웹 채팅 창에서는 폴더를 열 수 없어 안 됩니다.

    다 만들면 폴더는 이렇게 됩니다

    
    
    파일 이름: 날짜_과목명_학습지(또는 시험지)_버전 · 그림: 날짜_과목_버전_문항번호_문항 안 번호. 고칠 때마다 v2, v3 … 새 파일로 만들고 이전 판은 그대로 둡니다. 문항표(엑셀)는 늘 함께 만들어집니다.
    

    
    만든 뒤에는
    
    
    
    
    
      
    AI가 이 교재의 작업 규칙(브리프 · 폴더 · 이름 규칙)을 이미 익힌 상태라, 같은 대화에서 말로 하면 됩니다. 고칠 때마다 새 버전(v2, v3 …)이 생기고 이전 판은 남습니다.
    
      
    
        
    문항 하나만 바꾸고 싶어요
    「7번 문항을 새 문항으로 바꿔 줘」, 「3번 선지 ④를 더 헷갈리게」처럼 번호를 넣어 말하세요. 바꾼 뒤 그 쪽만 다시 보여 줍니다.
    
        
    난이도를 올린(내린) 버전을 하나 더 만들고 싶어요
    「어려움 비율을 40%로 올린 버전 하나 더」라고 하면 같은 범위로 새 버전을 만듭니다. 원래 판은 그대로 남습니다.
    
        
    문항을 더 넣거나 빼고 싶어요
    「서술형 3문항 추가」, 「계산 문항 2개 빼고 개념 문항으로」처럼 말하면 문항표(엑셀)와 정답 · 해설까지 함께 고칩니다.
    
        
    그림이 마음에 안 들어요
    「5번 그림 다시」, 「5번 그림의 화살표를 오른쪽으로」처럼 말하세요. 그림 파일은 작업/원본/ 안에 문항 번호가 붙은 이름으로 있어 직접 바꿔 끼워도 됩니다.
    
        
    대화창을 닫았어요. 이어서 하려면요?
    같은 폴더를 다시 열고 「작업/print-브리프.md대로 이어서 해 줘」라고 하세요. 브리프와 작업 파일이 폴더에 다 남아 있어 처음부터 다시 하지 않습니다.
    
        
    Claude로 만들다가 Codex로(또는 반대로) 이어도 되나요?
    됩니다. 규칙과 작업 파일이 모두 폴더에 있어서, 다른 AI에서 폴더를 열고 위처럼 「이어서 해 줘」라고 하면 됩니다. 사용량이 다 떨어졌을 때 유용합니다.
    
        
    사용량이 다 떨어졌어요
    지금까지 만든 것은 폴더에 그대로 있습니다. 사용량이 다시 차면 「이어서 해 줘」, 또는 다른 AI(Claude ↔ Codex)에서 이어 가세요.
    
      
    
    
    
    
    
      
    폴더 맨 위의 「편집기 열기」 파일을 더블클릭하면 편집기가 브라우저에 열립니다. 왼쪽은 원본, 오른쪽은 조판된 쪽입니다.
    
      
    
        
    편집기는 어떻게 여나요?
    맥은 편집기 열기.command, 윈도우는 편집기 열기.bat을 더블클릭합니다. 맥에서 「확인되지 않은 개발자」 경고가 뜨면 파일을 오른쪽 클릭 → 열기를 한 번 하면 됩니다. 창(터미널)은 편집하는 동안 켜 두세요.
    
        
    글자 · 정답 · 배점은 어디를 고치나요?
    왼쪽 원본에서 문항 번호를 찾아 글을 고치면 오른쪽 쪽이 바로 다시 조판됩니다. 정답은 answer:, 배점은 points: 줄입니다. 저장은 ⌘S(Ctrl+S)입니다. 오른쪽 쪽을 누르면 그 쪽을 AI에게 부탁하는 글이 만들어집니다.
    
        
    고친 것을 PDF로 다시 뽑으려면요?
    편집기 위쪽의 PDF 저장을 누르면 결과/에 다음 버전 이름으로 저장됩니다(예: v1 → v2). 이전 판은 지워지지 않습니다.
    
        
    엑셀 문항표만 고치면 되나요?
    아니요. 문항표는 결과를 정리한 표라서, 고쳐도 PDF에 반영되지 않습니다. 원본(편집기 왼쪽)을 고친 뒤 AI에게 「문항표 다시 만들어 줘」라고 하세요.
    
        
    고치다가 망가졌어요
    되돌리기(⌘Z / Ctrl+Z)를 먼저 해 보고, 안 되면 결과/의 이전 버전 PDF와 작업/의 원본이 남아 있으니 AI에게 「v1으로 되돌려 줘」라고 하면 됩니다.
    
        
    한글(HWP) 파일로 옮기려면요?
    지금은 PDF와 엑셀로 만듭니다. 한글로는 엑셀 문항표를 5E에 불러와 조판하는 방법을 준비 중입니다. 급하면 한컴오피스에서 PDF를 열어 변환할 수 있지만 수식 · 그림이 깨질 수 있습니다.
    
        
    편집기가 안 열려요
    AI에게 「편집기 열어 줘」라고 하면 필요한 프로그램(Python · Typst)을 확인하고 대신 띄워 줍니다.
