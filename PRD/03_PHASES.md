# 5E 튜토리얼(따라하기) — Phase 분리 계획

> 한 번에 9개 코스를 다 만들면 엔진 문제가 생겼을 때 9곳을 고쳐야 합니다.
> 엔진을 먼저 코스 3개로 검증하고, 나머지는 내용만 채웁니다. (인터뷰 Q20 확정)

---

## Phase 1: 엔진 + 첫걸음 + 주제 코스 2개 (MVP)

### 목표
처음 온 교사가 첫 방문 배너 → 첫걸음 코스 → "기출 검색" 또는 "그리기 도구" 코스까지, 문서 없이 5E의 대표 흐름을 완주할 수 있다.

### 기능
- [ ] 연출 엔진 (`js/tutorial.js`) — 흐림+구멍+테두리(SVG 마스크), 코치 창 자동 배치, [이전][다음][그만], wait 이벤트 감지, action 실행, 창 크기 변경 대응
- [ ] 코스 선택 화면 — 코스 목록 + 소요 시간 + 완료 표시 + 이어하기
- [ ] 첫 방문 제안 배너 (1회, 거절 기억)
- [ ] Pro 자동 전환 + 종료 시 원래 모드 복원
- [ ] 연습용 페이지 자동 생성 + 종료 시 삭제 여부 확인
- [ ] **캔버스 위 안내 영역** — 그릴 자리를 world mm 좌표로 점선 표시(확대·이동 따라감). state.objects 를 건드리지 않아 저장·내보낸 그림에 남지 않는다
- [ ] **가상 커서 시연** — 어디를 눌러 어디까지 끄는지 유령 커서가 반복 재생. Shift·Ctrl 보조키를 칩으로 표시하고, 사용자가 마우스를 누르면 비켰다가 조용해지면 돌아온다
- [ ] 코스 ① 첫걸음 — 화면 4구역 + 검색→불러오기→수정→내보내기 (12단계)
- [ ] 코스 ② **빗면 그림 하나 완성하기** (13단계) — 바닥 직선 → '수평면' 글자 → 빗면(그린 뒤 Shift 스냅으로 바닥에 붙이기) → 물체(Shift 정사각형 → 라벨 → Shift 스냅으로 빗면에 얹기). **띄워 그린 뒤 붙이는 순서**가 핵심이라 스냅을 몸으로 익힌다
- [ ] 코스 ③ 기출 검색→고쳐쓰기 — 압축 코드·드롭다운·의미 검색, 참고 창
- [ ] 코스 ④ 그리기 도구 — 선·도형·텍스트·측정·자르기 기본기
- [ ] 진입점: 상단 메뉴 "도움말 → 따라하기" + 커맨드 팔레트

### 데이터
- Course/Step (내장), Progress (localStorage 키 3개)

### "진짜 제품" 체크리스트
- [ ] 실제 5E 화면 요소를 짚는다 (가짜 스크린샷 X)
- [ ] wait 단계가 실제 사용자 조작으로만 넘어간다 (자동 넘김 X)
- [ ] 튜토리얼 종료 후 사용자 작업물이 시작 전과 동일하다
- [ ] GitHub Pages 배포 후 첫 방문 시나리오를 시크릿 창으로 검증한다

### Phase 1 시작 프롬프트
```
이 PRD를 읽고 5E 튜토리얼 Phase 1을 구현해주세요.

- js/tutorial.js (연출 엔진) + js/tutorial-courses.js (코스 3개) + css/tutorial.css
- 첫 방문 배너, 코스 선택 화면, Pro 전환·복원, 연습 페이지 생성·정리

반드시 지켜야 할 것:
- 04_PROJECT_SPEC.md의 "절대 하지 마" 목록 준수
- 기존 파일 수정은 진입점 연결(메뉴·커맨드 팔레트·index.html 스크립트 태그) 최소한으로
- 버전 문자열·?v= 쿼리는 올리지 않는다

Do not ask clarifying questions. Make reasonable assumptions and proceed.
```

## Phase 2: 나머지 주제 코스 + 도움말 사전

### 전제 조건
- Phase 1 코스 3개가 배포되어 실제 화면에서 안정 동작 (특히 wait 감지·마스크 연출)

### 목표
9개 영역 전체가 코스로 커버되고, 따라하기가 못 담는 세부는 도움말 사전에서 찾을 수 있다.

### 기능
- [ ] 코스 ④ 그래프와 함수 (좌표·함수·표시 3단계)
- [ ] 코스 ⑤ 과목별 오브젝트 (역학·전기·파동)
- [ ] 코스 ⑥ 이미지 객체화 (붙여넣기→벡터화·따내기)
- [ ] 코스 ⑦ 페이지와 내보내기 (문항별 페이지·폴더 일괄 저장)
- [ ] 코스 ⑧ 저장과 백업 (자동 저장·JSON·ZIP)
- [ ] 코스 ⑨ 편집 가속 (스냅·그룹·속성 복사·전체 통일)
- [ ] 도움말 사전 (`js/help-content.js` + 목록 창, 검색 포함)
- [ ] 완료 후 다음 코스 추천 연결 그래프 완성

### 추가 데이터
- HelpTopic 배열

### 통합 테스트
- Phase 1 코스 3개가 여전히 정상 동작하는지, 코스 9개 완료 표시·이어하기가 뒤섞이지 않는지
