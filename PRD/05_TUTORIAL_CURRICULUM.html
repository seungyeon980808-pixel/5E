과제당 4~6분, 전부 하면 약 45분 — 완주 의무 없음. 각 과제는 서로 다른 도구 조합을 쓰도록 설계해, 열 개를 돌면 5E의 주요 기능을 한 번씩 다 만져 보게 된다. 상세 표는 문서 하단.

모든 코스에 적용되는 공통 원칙

  • 읽기 설명만 있는 단계 — [다음]으로 진행. 실습 사용자가 직접 하는 단계 — 동작이 감지되면 자동 진행. 자동 프로그램이 대신 해 주는 단계 — [자동으로 하기] 버튼 하나만 누르면 됨.
  • 타이핑 금지 — '수평면', 'm' 같은 글자는 전부 자동으로 넣는다. 사용자가 키보드로 치는 일은 없다.
  • 언제든 [이전] — 되돌아간 단계는 실습을 다시 요구하지 않는 읽기 모드. [다음]으로 언제든 복귀.
  • 가이드라인 표기 — 눌러야 할 버튼은 테두리 강조 + 안내문에 위치를 말로도 쓴다 (예: "왼쪽 도구 3번째 줄 맨 왼쪽, 사선 모양"). 그릴 자리는 점선 영역, 클릭 순서는 ①② 번호, 드래그는 경로 점선.
  • 가상 커서 — 실습 단계마다 커서가 동작을 반복 시연. 시인성 강화: 크기 1.4배, 진한 그림자, 이동 속도 지금의 60% (부드러운 감속). 사용자가 마우스를 잡으면 즉시 비켜남.
  • 설명 창 — 본문 15px→16px, 제목 17px→18px, 창 너비 360px. 어느 화면 배율에서도 같은 크기로 읽힘.
  • 연습 페이지 — 실습 코스는 '따라하기 연습' 페이지를 자동 생성. 사용자의 원래 작업물은 절대 건드리지 않고, 끝나면 삭제 여부를 물음.
