# 5E 튜토리얼(따라하기) — 프로젝트 스펙 (AI 행동 규칙)

> AI가 코드를 짤 때 지켜야 할 규칙. 구현을 시킬 때마다 이 문서를 함께 공유하세요.

---

## 기술 스택

| 영역 | 선택 | 이유 |
|------|------|------|
| 언어/프레임워크 | 바닐라 JS (빌드 없음) | 5E 본체와 동일 — 새 의존성·빌드 도입 금지 |
| 연출(흐림+구멍) | SVG `<mask>` 또는 CSS `clip-path`를 쓴 전체 화면 오버레이 | 5E가 SVG 기반이라 익숙한 기술. 구멍 파기는 캔버스 dim보다 SVG 마스크가 단순 |
| 코치 창 | 일반 DOM + `position: fixed`, 자동 배치 계산 | 라이브러리(driver.js 등) 불필요 — HwpPalette 설계를 직접 이식하는 편이 통제 쉬움 |
| 저장 | localStorage (`5e.tutorial.*`) | 서버 없는 정적 앱. 기존 자동 저장(idb-store)과 분리해 충돌 방지 |
| 배포 | GitHub Pages (기존 그대로) | 추가 인프라 없음 |

## 새 파일 구조 (기존 트리에 추가)

```
5E_main/
├── js/
│   ├── tutorial.js          # 연출 엔진 (마스크·코치 창·진행 제어·진행 기록)
│   ├── tutorial-courses.js  # 코스 내용만 (문구·target·wait 정의)
│   └── help-content.js      # 도움말 사전 내용 (Phase 2)
├── css/
│   └── tutorial.css         # 오버레이·코치 창 스타일
└── PRD/                     # 이 문서들
```

기존 파일 수정은 다음으로 **한정**한다:
- `index.html` — 스크립트/CSS 태그 추가
- `js/top-menu.js` — "도움말 → 따라하기" 항목 추가
- `js/command-palette.js` — "따라하기" 명령 등록
- `js/main.js` — 첫 방문 배너 호출 1줄

## 절대 하지 마 (DO NOT)

- [ ] 외부 라이브러리(driver.js, intro.js, shepherd 등)를 넣지 마 — 5E는 의존성 0 원칙
- [ ] 기존 툴팁(tool-hint.js)·기존 도움말 문구를 수정하지 마 — 튜토리얼은 독립 모듈 (인터뷰 Q14)
- [ ] 버전 문자열·`?v=` 캐시버스트를 올리지 마 — 사용자 명시 지시가 있을 때만
- [ ] 사용자의 기존 페이지·오브젝트·설정을 변경하지 마 — 실습은 연습용 페이지에서만
- [ ] wait 단계를 setTimeout으로 자동 통과시키지 마 — 실제 조작 이벤트로만 진행
- [ ] 튜토리얼 코드가 꺼진 상태에서 렌더 루프·이벤트에 개입하게 하지 마 — 실행 전엔 리스너 0개
- [ ] 진행 기록 외의 어떤 데이터도 브라우저 밖으로 보내지 마 (분석·로그 수집 금지)

## 항상 해 (ALWAYS DO)

- [ ] 코스 문구는 `tutorial-courses.js`에만 — 엔진에 문구 하드코딩 금지
- [ ] target 선택자는 실행 시점에 평가하고, 요소가 없으면 그 단계를 건너뛰며 콘솔 경고를 남겨라 (죽은 짚기 방지)
- [ ] [그만]·ESC·페이지 이탈 시 오버레이·리스너·연습 상태를 전부 정리해라 — HwpPalette에서 "겹친 흐림 패널" 버그가 실제 있었다 (tutorial.py 주석)
- [ ] 튜토리얼 시작 시 화면 모드(Lite/Pro)와 현재 페이지를 기억했다가 종료 시 복원해라
- [ ] 창 크기 변경·패널 접힘 시 구멍·코치 창 위치를 다시 계산해라
- [ ] 문체는 HwpPalette help_content를 따라라: 존댓말, 짧은 단락, 글머리표 `·`, 표 금지, "물감·팔레트"식 일상 비유
- [ ] 색·글꼴은 5E 기존 토큰을 써라 (시그니처 `#0969da`, IBM Plex Sans KR) — 그라데이션·큰 그림자 금지
- [ ] 섹션 주석 (`// ===== SECTION =====`) 필수

## 테스트 방법

```bash
# 로컬 실행 (5E_main에서)
python -m http.server 8270
```

- 시크릿 창으로 열어 "첫 방문 배너 → 첫걸음 완주 → 새로고침 → 완료 표시 유지"를 확인
- 코스 중간에 [그만] → 재실행 → 이어하기 확인
- 튜토리얼 중 창 크기를 바꿔 구멍·코치 창이 따라오는지 확인
- 종료 후: 화면 모드 복원, 연습 페이지 삭제 선택 반영, 기존 페이지 무손상 확인

## 배포 방법

기존과 동일 — main에 push하면 GitHub Pages 자동 반영. 커밋은 `feat: 튜토리얼(따라하기) …` (Conventional Commits).
