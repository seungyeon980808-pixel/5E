## 1. 제품 개요

### 한 줄 요약
5E를 처음 여는 과학 교사가 아무 문서도 읽지 않고, 실제 화면 위에서 하나씩 짚어주는 "따라하기"만으로 기출 검색부터 내보내기까지 스스로 해낼 수 있게 하는 인앱 튜토리얼.

### 해결하는 문제
5E는 기출 검색·그래프·그리기·과목 오브젝트·이미지 객체화 등 9개 영역을 가진 큰 도구다. 지금은 README를 읽어야 전모를 알 수 있는데, 처음 온 교사는 README를 읽지 않는다. 화면만 보고는 "그래서 뭐부터 누르지?"에서 막힌다.

### 핵심 가치
- **실제 화면 위에서 배운다** — 문서가 아니라, 지금 보고 있는 그 버튼에 파란 테두리가 생기고 옆에 설명이 뜬다. "아 저거구나"가 즉시 된다.
- **직접 해봐야 넘어간다** — 핵심 단계는 사용자가 실제로 클릭/드래그해야 진행된다. 손에 익는다.
- **검증된 레퍼런스** — 같은 사용자가 만든 HwpPalette의 따라하기(halo + coach + 흐림 구멍 방식)에서 실사용 검증된 설계를 웹으로 옮긴다.

### 디자인·구현 레퍼런스
- `31_hwp_palette/tutorial.py` — 연출 엔진(halo, 흐림+구멍, coach 창, wait 단계, action 준비, 다중 위젯 짚기)
- `31_hwp_palette/help_content.py` — 도움말 사전의 내용/UI 분리 구조, 문체(존댓말·비유·짧은 단락)
- 레퍼런스는 방향 합의용이며, 산출물에 재게시하지 않는다.

## 2. 사용자

### 주요 사용자
- **누구**: 5E를 처음 접하는 과학 교사 (컴퓨터 숙련도 다양, 파워포인트 수준의 도구 경험)
- **상황**: 시험 기간에 급하게 시험지 그림이 필요해서 링크를 타고 들어옴. 배울 시간이 5~10분밖에 없음
- **목표**: 오늘 안에 그림 한 장을 완성해서 한글 문서에 붙이는 것

### 보조 사용자
- **기존 사용자** — 안 써 본 영역(예: 이미지 객체화)을 배우고 싶을 때 해당 코스만 골라 실행

### 사용자 시나리오
1. 교사가 5E를 처음 열면 "따라하기로 시작해 볼까요?" 배너가 뜬다
2. 수락하면 연습용 페이지가 자동으로 만들어지고, 화면 4구역 안내 → 기출 검색 → 불러오기 → 수정 → 내보내기를 한 바퀴 체험한다 (약 5분)
3. 끝나면 "다음은 '그리기 도구' 코스를 추천해요"가 뜨고, 코스 목록에 완료 표시가 남는다
4. 나중에 막히면 상단 메뉴의 도움말 사전에서 기능별 짧은 설명을 찾아 읽는다

## 4. 사용자 흐름 (User Flow)

### 핵심 흐름 (첫걸음 코스)
```
첫 방문 배너 → 수락 → Pro 전환·연습 페이지 생성 → 화면 4구역 투어(보기)
→ 기출 검색 열기(실습) → 문항 불러오기(실습) → 속성 수정(실습)
→ 내보내기 안내(보기) → 완료 + 다음 코스 추천 → 연습 페이지 삭제 여부 확인
```

### 상세 흐름
1. **발동**: 최초 접속 시 배너 제안(1회). 이후엔 상단 메뉴 "도움말 → 따라하기"와 커맨드 팔레트에서 수동 실행
2. **준비(action)**: 코스 시작 시 Pro 모드 전환 + 연습용 페이지 생성. 사용자의 기존 페이지는 건드리지 않는다
3. **보기 단계**: 대상에 테두리 + 코치 창. [다음]으로 진행
4. **실습 단계(wait)**: "직접 눌러보세요" — 대상 요소의 클릭/조작 이벤트를 감지하면 자동으로 다음 단계로
5. **이탈**: [그만]은 언제든 가능. 진행 위치가 저장돼 다음에 "이어하기" 제안
6. **종료**: 완료 축하 + 다음 코스 추천 + 연습 페이지 삭제 여부 확인 + 원래 화면 모드 복원

## 5. 성공 기준

- [ ] 5E를 처음 보는 사람이 README 없이 첫걸음 코스만으로 "기출 검색 → 수정 → 내보내기"를 완주할 수 있다
- [ ] 첫걸음 코스 소요 시간이 5분 안팎이다 (단계 수 15개 이내)
- [ ] 튜토리얼 종료 후 사용자의 기존 작업물(페이지·오브젝트·설정)이 시작 전과 완전히 동일하다 (연습 페이지 제외)
- [ ] [그만] 후 재실행하면 그만둔 단계부터 이어서 진행된다
- [ ] 튜토리얼이 꺼진 상태에서는 기존 5E 동작·성능에 어떤 영향도 없다 (독립 모듈)

## 6. 안 만드는 것 (Out of Scope)

> 이 목록에 있는 건 이번 작업에서 만들지 않습니다.

- **동영상 튜토리얼** — 이유: 제작·유지 비용이 크고, 화면 위 따라하기가 더 직접적
- **새 기능(버전 업데이트) 안내 코스 체계** — 이유: 인터뷰에서 범위 밖으로 확정 (Q16). 필요해지면 별도 기획
- **기존 툴팁(tool-hint)·도움말 문구의 통합/수정** — 이유: 독립 모듈 원칙 (Q14). 기존 코드는 손대지 않는다
- **터치 전용 문구 분기** — 이유: 데스크톱 우선 (Q17). 터치에서 깨지지만 않게 한다
- **튜토리얼 진행 통계 수집** — 이유: 5E는 서버 없는 정적 앱. 데이터는 브라우저 밖으로 나가지 않는다
