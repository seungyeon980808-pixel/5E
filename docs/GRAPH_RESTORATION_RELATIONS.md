# 관계를 유지하는 편집 가능한 복원

2026-10-08 실행 변경. 모델은 `gpt-6.1-sol / medium`이며 자동 대체나
무제한 재시도를 추가하지 않는다. 원문 응답, 계산 후 자동 결과, 사람이 수정한
결과를 구분한다. `.5e`의 함수식은 편집 원본이고 샘플 점은 렌더링용이다.

## 보조선과 표시 점

보조선의 `x/y/to`는 실제 그려진 범위다. `seriesId/pointIndex` 또는
`anchorX`는 별도 접점이며 선분 내부에 있을 수 있다. 계수 계산은 연결된
곡선 점에서 기준점을 수집하고, 관계 검사는 접점과 유한 선분의 거리를
비교한다. 수식으로 변환해도 독립적인 보조선 길이를 줄이지 않는다.

연속 곡선의 표시 점과 구간 화살표는 수식화를 금지하는 조건이 아니다.
표시 점은 같은 계열의 `anchorX`에 연결된 point 표기로, 진행 화살표는
식의 x 접점과 방향으로 옮긴다. 빈 점/채운 점, 농도, 개별 크기, 선폭을
유지한다. 산점도, 불연속, 수동 핸들과 닫힌 경로는 임의로 함수화하지 않는다.
`candidateFamily:none`은 AI 후보 부재이지 프로그램의 계산 금지가 아니다.

## 궤적과 짧은 수식

서로 다른 입자는 별도 계열로 관찰하도록 요청한다. 기존 응답에서 합쳐진
궤적은 표시된 내부 점의 접선 불연속과 양쪽 외곽의 독립적인 초기 방향
화살표가 함께 있을 때 분리한다. 각 부분은 독립적으로 검증하며 실패한
부분도 관찰점으로 유지한다.

`physicsModel:{kind:'tangent-quadratic',orientation:'horizontal'|'vertical',
tangentAt:'start'|'end',otherOrientation?:'vertical',tangentSpeed?:number}`는 끝점과 축 방향 접선으로
계산하는 저차원 도형 모델이다. 반대 끝의 수직 접선은 관찰된 모양의 조건이며
문항의 물리 법칙을 인증하는 값이 아니다. 눈금과 원점에 가까운 기준점은
해당 표기 관계에 맞추고 전체 곡선의 표시 공간 거리, 방향, 극값을 다시 측정한다.
실제 최초 응답과 원래 좌표는 별도 기록에 남는다.

직접 결정되는 단순 모델이 관찰과 맞지 않으면, 수직 초기 접선의 매개변수
속도 항 하나를 관찰에서 추정할 수 있다. 끝점은 고정하고 초기 방향을
검증한다. 상대 멱함수도 필요할 때 제한된 지수 후보와 오프셋을 끝점 및
관찰에서 검증한다. 이 계수의 출처는 `endpoint-tangent-observations` 또는
`process-endpoints-observed-exponent`로 구분한다.

예를 들어 단위가 L인 O=(0,0), q=(2,3), p=(4,4) 궤적은 관찰 조건에 따라
`3*sqrt(x/2)`와 `4-(1-sqrt((x-2)/2))^2`로 표현할 수 있다.
숫자나 문항 ID를 제품 코드에 넣지 않으며 기준점과 방향에서 계산한다.
기존 파서는 `sqrt`를 지원하므로 새 매개변수 편집기를 만들지 않는다.

수치 없는 반비례와 P-V 과정은 상대 그림 좌표의 끝점 비에서 멱지수를
계산할 수 있다. `a*(x/x0)^p`의 지수는 관계를 유지할 정밀도로 저장하며
긴 log 식 대신 계산한 계수를 보여 준다. 이것은 과정 종류나 실제 단위의
확정이 아니다. 사인파는 표시된 극값 높이와 눈금에 맞는 영점들에서
진폭·중심·주기·위상을 함께 계산하고 잘못된 AI 식은 채택하지 않는다.

## 실패와 초안

구조/출처가 유효한 계획은 관계 오류가 있어도 편집 가능한 결과를 제공한다.
`quality.status`, critical 관계 오류, 수식화 미완료 검수 항목을 작업 상태,
네이티브 객체 메타데이터와 저장 파일에 남긴다. 품질 오류 때문에 정상
계열을 버리거나 전체 결과를 숨기지 않는다.

안전하지 않은 JSON, 다른 원본 바인딩, 계산할 수 없는 축·좌표와 잘못된
네이티브 참조는 여전히 구조 오류다. 해당 자료를 정상 결과로 가장하지 않는다.
생성·관계·스타일·수식화·편집·저장 성공은 각각 따로 평가한다.

단일 수평 축은 원본 계약 `frame.variant:'x'`를 기존 네이티브 `single`로
매핑한다. 무테두리의 빈 표기 견본 한 행은 원래 선 위치를 사용한다.
관찰 범례에 기본 박스·배경을 추가하지 않으며 명시적 `frame:true`와
일반 수동 그래프의 기존 박스는 유지한다.

표시 원이나 기타 정상 관찰이 플롯 프레임 밖에 있어도 원본 이미지 안에
있으면 함께 캘리브레이션한다. 출처와 캘리브레이션이 없는 임의의 데이터
범위 초과는 허용하지 않는다. 표시 원점과 눈금에 맞는 축 접점도 식의
독립 기준점이다. 원점의 수학 서식과 한 픽셀 이내의 축 접촉 잉크를
해석하되 실제 큰 범위 초과는 여전히 거부한다.

최종 교차 검사에서 실패한 새 수식만 관찰점으로 되돌린다. 보조선 접점,
표시 점과 진행 화살표의 연결을 복원하며 다른 정상 계열은 버리지 않는다.
축 절단 도형은 전역 상대 물리 좌표로 승격하지 않아 원래 관찰 기하와
축 절단을 편집할 수 있다.

## 검증 도구

- `tools/replay-graph-responses.mjs`: 저장 응답을 AI 요청 없이 재계산하고
  구조·관계·네이티브 생성과 수식 목록을 기록한다.
  최초 무호출 게이트는 엄격하며, 최종 평가의 `--allow-quality-review`는
  관계 실패를 별도 기록하면서 구조적으로 유효한 편집 초안을 제공한다.
- `tools/verify-restored-graphs.cjs`: 저장된 자동 결과를 WebKit에서 렌더링,
  기존 편집기 적용/수식 변경, undo/redo, 실제 다운로드와 재열기로 검증한다.
  `automatic.5e`와 `manual-edit-test.5e`를 구분한다. 후자는 UI 검사용 수정이며
  자동 복원 품질이나 수동 보정 성과에 합산하지 않는다.
- `tools/evaluate-physics-graphs.mjs`: 고정 모델의 최초 실제 응답을 원본별
  한 번만 요청한다. 이번처럼 명시적으로 요청한 기존 표본 반복은
  `priorSubmissionExpected:true`, 새 표본은 제출 이력 검토를 기록한다.

단위/브라우저 검사 통과는 원본과 완전한 시각 일치 또는 물리 법칙 인증이 아니다.
최신 표본별 판정과 파일은 로컬 `outputs/graph-restoration-20261008/`에 제공한다.

## 2026-10-09 · 관계 고정 후 해석식 복원
수식 복원은 `눈금 좌표 변환 → 독립 궤적/과정 분리 → 엄격한 물리 관계 모델 → 제한된 관계 제약 근사 → 교차 검증` 순서로 실행합니다. 이미 검증된 식은 재해석하지 않습니다. 새 `relation-analytic-fit.js`는 선형·이차·평행이동/반사 무리함수·역수/역제곱·지수·로그·사인파·삼각함수 제곱의 작은 후보군을 비교합니다. AI의 family는 선호이며 잘못된 분류가 다른 검증된 식을 금지하지 않습니다. 실제 `candidateExpression`도 독립 측정으로 검증합니다.

확정 접점 등식은 먼저 소거해 고정하고, 부족한 나머지 계수를 관찰에서 추정합니다. `coefficientSource:relation-constrained-observations`는 물리 관계와 관찰 추정이 섞인 모델, `relative-display-relations-estimated`는 실제 단위가 미확정인 상대 그림입니다. 두 경우 모두 `certainty:observed`, `provenance:image-fit`를 유지합니다. 기준점만으로 계수 전부를 결정한 기존 `relation-anchors`와 구분해 표시합니다. 높은 차수의 점별 보간식을 생성하지 않습니다.

반복 봉우리뿐 아니라 눈금에 정렬된 골짜기 간격을 이용하여 주기와 위상을 결정합니다. 실제 저장된 파동은 반올림된 봉우리 간격 1.9999를 사용해 실패했으나, 확정 바닥 접점 x=1,3을 이용하면 주기 2를 얻습니다. 상한 높이는 관찰 추정입니다. 양쪽 유리함수 가지는 대응하는 ±기준점과 같은 발산/추세가 확인될 때만 공통 극점 0과 배경 상수를 함께 계산합니다. 독립 곡선을 family 이름만 보고 합치지 않습니다.

보조선의 원래 x/y/to는 유지하고 접점 연결만 anchorX로 옮깁니다. 표시점과 진행 화살표도 원래 접점과 방향을 유지합니다. 최종 교차 검증이 새 식을 거부하면 해당 단계의 원래 점·표시점·화살표·연결 주석을 함께 복구합니다. 공동 유리함수 모델은 두 가지를 함께 되돌립니다. 다른 정상 곡선은 유지합니다. 2점 직선 기본 요소, 산점도, 닫힌 경로, 불연속, 수동 핸들, 축 생략은 기존 기하로 남깁니다.

저장 메타데이터는 독립적으로 식·접점·모델·오차·표시점·방향을 재계산합니다. 손상된 메타데이터는 검증 실패로 반환하며 예외로 전체 복원을 중단하지 않습니다. 생성/검증 접점 한도와 256개 주석 제한을 같은 기준으로 검사합니다. 기존 거리 한도(정규화 최대 4%, RMS 1.5%)는 넓히지 않았으며 강한 접점 오차 한도는 1e-7입니다.

프롬프트 버전은 `graph-observation-v24-relation-analytic`, 파이프라인 캐시에는 새 fitter 버전을 포함합니다. 새 복원 작업에서 변경이 적용됩니다. 저장한 점 경로 .5e를 열기만 해서는 자동으로 식이 바뀌지 않습니다. 누적 HTML에는 동일한 저장 응답 20개의 재계산과 별도 브라우저 회귀를 나누어 기록합니다. 이번 검증은 실제 AI 추가 호출 없이 수행했으므로 새 프롬프트의 모델 인식률 향상은 별도 실측이 필요합니다.

### 연결 보조선 편집 회귀 (2026-10-09)

함수식 또는 관찰점의 접점이 이동할 때, 수평 보조선의 반대쪽 y와 수직 보조선의 반대쪽 x도 같은 이동량을 적용한다. 축 쪽 끝점의 길이 방향 좌표와 연장 범위는 유지한다. 실제 두 끝점이 축과 평행한 경우만 적용하며 대각선, 지시선, 화살표의 독립 반대쪽 끝점은 이동하지 않는다. 스타일만 변경하거나 점 좌표가 그대로인 경우 원래 측정 좌표를 보존한다. `test-graph-guide-rebinding.mjs` 11개 회귀와 실제 편집 `+0.05` → 방향 확인 → 원식 복구 → 저장·재열기 두 브라우저 엔진 검증으로 확인한다.
