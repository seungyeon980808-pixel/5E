# 5E 문항 카드 작업실 시안

2026-10-15. 주소: `/assets/exampool/concept/index.html`. 기존 문항 시트와 실제 한글 엔진의 저장소를 대체하지 않는 별도 클릭형 시안이다.

## 화면 구성

5E 본체의 Cool Slate 토큰을 따른다. 도구 영역 `#161b22`, 경계 `#30363d`, 밝은 글자 `#e6edf3`, 파란 강조 `#2f81f7`. 문항 대시보드와 편집 바탕은 본체의 `#0d1117`이며, 셀과 시험지 본문은 흰색이다. 푸터는 기존 한 줄을 유지한다.

왼쪽 분류는 **출제한 문항 / 점검할 문항 / 완성한 문항 / 시험지 구성**이다. 세 문항 상태는 사용자가 지정한다. 빈칸 검사 결과와 작업 상태를 혼동하지 않는다. 완성 상태의 내용·서식을 변경하면 점검 상태로 돌아간다. ‘전체 보기’로 상태와 검색 조건을 해제할 수 있다.

카드를 열면 왼쪽은 선택한 문항 한 열의 실제 데이터 시트, 오른쪽은 같은 데이터의 출력 모양이다. 별도의 지문·발문·선지 입력 폼과 상단 탭을 없앴다. A열 항목명, 행 번호, 실제 문항의 열 문자, 셀 선택·범위와 입력줄은 전체 시트와 동일하다. 내용 길이에 따라 행 높이를 맞추고 긴 내용은 셀 안에서 스크롤한다. 자료·사진·표 선지는 더블클릭/F2 또는 ‘셀 자세히’로 아래 상세 영역을 열고 구조를 유지해 편집한다. 단원·성취기준·정답·해설도 같은 열의 셀로 관리한다. ‘문항 내용’, ‘출제 정보’ 버튼은 해당 행으로 이동하는 바로가기다.

편집 영역은 데스크톱에서 최대 1100px(넓은 화면 1160px), 종이 본문은 CSS 기준 86mm, 좌우 여백은 각 12px이다. 문항 길이에 따라 높이가 늘어나며 한 페이지로 제한하지 않는다. 좁은 화면에서는 문항 시트와 출력 모양을 탭으로 전환한다.

## 카드·시트·엑셀 연결

카드, 세로 시트, 내용 입력과 오른쪽 편집은 하나의 문항 모델을 사용한다. 한 문항은 한 열, 항목은 행이다. 시트에서는 모든 상태의 문항을 표시하므로 범위 편집 중 상태 변화로 열이 사라지지 않는다.

기존 `sheet/grid.js`, `vertical.js`, `excel.js`를 재사용한다. 방향키와 범위 선택, F2·더블클릭, Tab/Enter 역방향 이동, Alt+Enter, Home/End, 전체 선택, 복사·잘라내기·붙여넣기, 지우기와 수식 입력줄을 지원한다. 표·사진처럼 복합 구조를 가진 셀은 문항의 자료 상세 편집으로 연다.

전체 시트·선택 문항 시트·다운로드 XLSX에서 동일한 주소를 사용한다. 헤더가 1행이므로 발문은 9행이며, 6번째 문항은 G열이다. 시트 내부의 쓰기 인덱스는 기존 ROWS 인덱스를 유지하고 표시 주소에만 행/열 오프셋을 적용한다. 오른쪽 문단을 누르면 대응 셀과 입력줄이 선택되며, 입력 즉시 같은 셀 값이 갱신된다. 반대로 셀 선택 시 오른쪽 대응 부분을 크기에 영향을 주지 않는 배경·outline으로 표시한다. 셀 입력 중에는 복제한 모델로 출력 모양만 미리 보여 주고 Enter/이동으로 확정한다. Esc는 저장된 모델의 출력 모양으로 복원한다. 잘못된 값은 확정 시 반영하지 않는다. 본문 편집 시 커서 위치를 유지한다. 계산식을 실행하지 않는다.

- 실제 XLSX를 내려받고 다시 올릴 수 있다. 내려받은 항목/구성/표/자료 양식에 맞춰 작성한다.
- 같은 문항 ID는 가져온 값으로 갱신하고 새 ID는 추가한다. 파일에서 빠진 기존 문항은 삭제하지 않는다.
- 표 병합·그림·참고자료와 숨김 구조는 기존 importer/exporter가 처리한다. ID와 시트 구조를 임의로 바꾸지 않는다.
- 잘못된 붙여넣기 범위는 복제본 전체를 검증한 후 반영한다. 마지막 셀이 잘못되어도 앞 셀이 일부 수정되지 않는다.
- 변경 이력 30개를 메모리에 보관한다. 연속 입력은 750ms 이내에서 묶는다. 문항 내용·서식·상태·복제·시험지 순서·가져오기를 되돌릴 수 있다. 페이지를 새로 열면 이력은 초기화된다.
- 저장 키는 기존 `5e-card-workspace-concept-v2`를 유지한다. 사용자가 추가한 문항과 입력 내용을 재생성하지 않는다. 저장은 현재 브라우저에만 적용된다.

## 조판 도구와 단축키

`기능·단축키`에서 모든 기능의 조작과 지원 범위를 확인할 수 있다. Mac의 ⌘와 Windows의 Ctrl을 함께 안내한다.

현재 작동: 양쪽 본문·과정·보기·표 셀·글 선지 수정, 문항 전체의 크기·자간·줄 간격, 선택한 문단의 굵게/기울임/밑줄·정렬·내어쓰기(Shift+Tab), 표 셀 정렬(가운데 기본), 표 끝에 행·열 추가와 병합 풀기, 그림/그림 선지 업로드·교체와 본문 그림 폭 조정, 선지의 자동/한 줄/3+2/2+2+1/세로 배치. 짧은 조합 선지는 기본적으로 3+2로 묶어 4+1로 어색하게 흐르지 않도록 한다. 서식은 블록/항목 ID별로 저장한다. 문항 복제 시 서식 경로도 새 ID에 맞춰 연결한다. 문단 서식은 선택한 부분 글자에 한정되는 기능이 아니다.

공통: 저장 ⌘/Ctrl+S, 복제 ⌘/Ctrl+Shift+D, 카드 화면 찾기 ⌘/Ctrl+F, 화면 전환 Alt+1/2/3, 기능 안내 F1. 조판 문단 안에서 ⌘/Ctrl+B/I/U와 Shift+Tab. 시트 안에서는 셀 단축키가 우선한다.

시험지 구성은 선택 카드 담기, 드래그·버튼 순서 변경, 제거와 번호 다시 부여, A4 1단/2단의 개념 미리보기다.

## 실제 한글 연결 전인 범위

오른쪽은 **HTML contenteditable 편집 시안**이다. 실제 HWPX와의 양방향 매핑은 아직 없다. ‘기존 한글 도구’ 링크는 기존 예제로 실제 엔진을 열며 이 시안의 문항을 전달하지 않는다. 기존 네이티브 본문 변경 방지 장치는 제거하지 않았다.

기능 안내에 빠짐없이 연결 과제로 명시: 부분 글자 서식/서식 복사/글꼴/장평, LaTeX·한글 수식 객체, 위아래첨자, 표 범위 병합·분할·테두리·여백, 개체 어울림·글자처럼 취급·자르기, 찾아바꾸기·특수문자·탭 위치, 쪽·단 나누기·묶음 유지·머리/꼬리말, HWPX 저장·재열기·출력 비교 검수. 연결 전 기능을 작동하는 버튼처럼 표시하지 않는다.

참고자료 상세 영역의 원문 뷰어도 통합 전이다. 점검은 누락과 현재 HTML 가로 넘침만 확인하며, 물리적 타당성·정답 검증·네이티브 조판 무결성을 보증하지 않는다. 실제 시험지 페이지 나누기와 일괄 HWPX 출력은 다음 단계다.

## 5E · 엑셀 · 한글 시각 구분 (2026-10-15)

- 본체의 어두운 패널·얇은 경계·32px 버튼·파란 선택색을 헤더·분류·카드 관리에 적용했다. 카드의 문항 자체만 흰색으로 표시한다.
- 왼쪽은 엑셀식 녹색 제목줄과 셀 선택, 회색 행열 머리글, 이름 상자와 fx 입력줄, 워크시트 탭을 사용한다. 입력줄을 시트 안으로 옮기면서 원래 DOM 노드와 단일 grid 컨트롤러를 유지한다. 전체 시트·개별 문항 전환 후에도 같은 셀 주소와 입력 기능을 사용한다.
- 오른쪽은 한글식 파란 제목줄, 바탕글/바탕 표시, 크기·자간·문단 서식 도구, 실제 본문 86mm와 일치하는 cm/mm 눈금자, 회색 바탕과 흰 문항 용지다. 바탕글/바탕은 현재 서식 표시이며 미지원 글꼴 선택 버튼을 만들지 않았다. 제목줄에 ‘편집 시안’을 표시한다.
- 눈금자는 문항 내용 밖에 위치한다. 전체 보기에서는 종이와 같은 배율로 축소한다. 본문 글자 크기·폭·표·보기 배치는 바꾸지 않았다. 820px 이하에서는 탭 전환으로 도구 겹침을 방지한다.

## 차분한 분할 작업실 (2026-10-15 15:42)

- 사용자 지정 taste-skill 저장소의 redesign/minimalist/soft 문서를 읽고 기존 vanilla 구조에 적용했다. 큰 색상 제목줄·파란 버튼을 없애고, 5E의 어두운 외곽 안에 흰 시트와 회색 한글 도구를 작은 모서리·약한 그림자로 구분한다. 셀·문항·카드에 전환/움직임을 넣지 않았다. 상단은 한 줄, 문항 상태·복제·시험지 담기는 상태 메뉴, 파일 조작은 파일 메뉴에 모았다.
- 가운데 경계는 마우스·터치 드래그, 방향키(2%)·Shift+방향키(10%)로 조절한다. Enter·두 번 클릭으로 기본 너비, 드래그 중 Esc로 취소한다. 문항/시험지 각각의 비율을 별도 키 `5e-card-workspace-view-v1`에 저장한다. 기존 문항 저장 키·스키마는 유지한다.
- 본문 86mm와 글자 크기·표 폭은 고정이다. 화면 배율은 변환과 별도 프레임 크기로 처리해 패널 너비 조절 중 내용 줄바꿈이 달라지지 않게 했다. `너비 맞춤 / 전체 보기 / 100%`를 제공한다. 820px 이하는 문항 시트/문항·시험지 탭을 사용한다.
