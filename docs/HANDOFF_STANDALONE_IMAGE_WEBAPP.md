# 평가원식 이미지 변환 웹앱 새 세션 핸드오프

## 목표

5E·ExamPool 통합은 이번 범위에서 제외한다. 사용자가 설명, 참고 이미지, 손그림 또는 일반 과학 그림을 입력하면 라벨 없는 평가원식 흑백 선화 PNG를 생성하고 내려받을 수 있는 독립 웹앱을 기획·구현한다.

## 먼저 확정해야 할 배포 트랙

설치 없는 모바일·PC 웹앱을 최우선으로 한다. 다만 개인 Codex 구독을 일반 웹사이트가 직접 사용하는 구조는 브라우저 보안과 인증 제약 때문에 채택하지 않는다. 새 세션에서는 아래 두 방식만 비교한다.

1. ChatGPT 안에서 실행되는 Custom GPT/앱 형태: 별도 설치와 API 종량제 없이 사용할 수 있지만 독립 URL 웹앱의 자유도는 낮다.
2. 독립 호스팅 웹앱: 모바일과 PC에서 설치 없이 사용할 수 있지만 서버 측 모델 호출과 비용·인증 구조가 필요하다.

사용자의 현재 우선순위는 `설치 없음 > 휴대폰 지원 > 독립 웹앱 UX > 완전 자동 5E 연결`이다. API 종량제 금지 조건과 충돌하면 구현에 들어가기 전에 그 충돌을 명확히 보고하고, Custom GPT/ChatGPT 앱 트랙을 기본안으로 제안한다.

## 입력 방식

- 그림 설명만 입력
- 설명과 참고 이미지 입력
- 설명과 손그림 입력
- 이미지만 입력하고 평가원식으로 변환

## 출력 모드

초기 버전은 `그림형`만 구현한다.

- 문자, 숫자, 기호, 라벨, 지시선, 화살표 없음
- 흰 배경과 검은 선
- 회색은 물리적 의미가 있는 영역에만 최소 사용
- PNG 다운로드
- 생성 프롬프트와 구조 명세 JSON 함께 보관

완성형 라벨 생성과 5E 자동 연결은 후속 범위다.

## 반드시 읽을 기존 자산

1. `5E_main/docs/EXAM_SCIENTIFIC_DIAGRAM_STYLE.md`
2. `5E_main/docs/IMAGE_CONVERSION_ENGINE_VALIDATION.md`
3. `5E_main/docs/IMAGE_CONVERSION_MANIFEST.schema.json`
4. `5E_main/tools/normalize-exam-lineart.py`
5. `outputs/image_conversion/luna_benchmark_*/SUPERVISOR_EVALUATION.md`

교과서·기출 원본 크롭은 내부 검증용이며 공개 배포 자산으로 복제하지 않는다. 공개 예시는 직접 제작했거나 배포 권리가 확인된 자료만 사용한다.

## 새 세션 첫 작업

1. 현재 저장소를 읽기 전용으로 조사한다.
2. 설치 없는 모바일 웹앱에서 가능한 인증·모델 실행 경로를 공식 OpenAI 문서로 검증한다.
3. `Custom GPT/ChatGPT 앱`, `독립 호스팅 웹앱`, `로컬 설치형`의 기능·비용·제약을 비교한다.
4. API 종량제 금지 조건에서 실제 구현 가능한 권장안을 하나 선택한다.
5. 권장안의 사용자 흐름, 화면 구성, 데이터 계약, 개인정보·저작권 처리, 배포 절차를 작성한다.
6. 사용자의 승인 전에는 대규모 구현이나 외부 배포를 하지 않는다.
