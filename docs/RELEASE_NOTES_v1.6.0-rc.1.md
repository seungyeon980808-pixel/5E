# v1.6.0-rc.1 — 비공개 Windows 안정화 후보

이 문서는 1.6.0 정식 배포 전에 오류와 배포 절차를 점검하기 위한 로컬 릴리스 후보의 기록입니다. 이 후보는 공개 배포본이 아닙니다.

사람에게 후보를 인계할 때의 SHA-256 확인, 예상 서명 경고, 보류 UAT와 승격 조건은 [비공개 RC 인계 문서](RC_HANDOFF.md)를 따릅니다.

## 후보 상태

- 설치 파일: `5E-Setup-1.6.0-rc.1-windows-x64.exe`
- 코드 서명: 하지 않음(비공개 RC 검증용)
- 태그 이름 규칙: `v1.6.0-rc.1`(문서상 규칙만 확정, 태그 미생성)
- 원격 push 및 GitHub Release: 수행하지 않음

## 이번 후보의 목적

- 웹앱과 Windows 데스크톱 앱의 버전 및 설치 파일 식별자를 하나로 맞춤
- 로컬 테스트, 패키지 감사, 설치 파일 생성과 증거 기록을 재현 가능한 순서로 검증
- 공개 안정판 `v1.5.8`의 릴리스 기록은 변경하지 않고 현재 후보의 상태를 별도로 관리

## 정식 1.6.0 전에 남은 확인

- 로그인된 실제 계정을 사용하는 이미지 생성 UAT
- 깨끗한 Windows 환경에서 설치·실행·제거 UAT
- 위 확인에서 발견된 문제 수정 및 최종 서명·공개 여부 결정

실제 계정 사용량과 외부 시스템 변경을 피하기 위해 위 두 UAT는 이 비공개 RC 제작 단계에서는 보류합니다.
