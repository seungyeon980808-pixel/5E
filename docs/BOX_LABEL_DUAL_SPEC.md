# 상자 라벨 — 안쪽·바깥 동시 사용 (명세)

> 2026-07-30 교사 결정. **구현 완료** — 렌더러·인스펙터·마이그레이션 모두 이 문서대로 들어갔다.
> 설계 결정과 근거는 `DESIGN.md` 2-4(스키마) · 13-6(UI)로 옮겨 두었다.
> 첫 실사용: 물리1 2027-06 10번 재현(`exam-figures/p1_2027_06.json` 10번 페이지).

## 왜 필요한가

기출 도판에서 상자 하나가 **두 가지 글자**를 동시에 갖는다.

```
  A ⎡ 3m  ⎤        ⎡ m_B ⎤ B
    └─────┘        └─────┘
    바깥  안쪽      안쪽   바깥
```

- **안쪽**: 그 물체의 **물리량**(`m_B`, `3m`) 또는 이름
- **바깥**: 그 물체의 **이름표**(A, B, C)

지금은 라벨 슬롯이 하나뿐이라 둘 중 하나만 된다. 그래서 재현할 때 바깥 이름표를 `formula`
독립 객체로 따로 얹었는데, **상자를 옮기면 라벨이 안 따라오는** 문제가 생겼다.

## 규칙

| 슬롯 | 위치 | 서체 | 비고 |
|---|---|---|---|
| **안쪽** | 항상 상자 중앙 (선택 불필요) | **물리량 / 이름표 중 선택** | 물리량이면 이탤릭 + **아래첨자 렌더링** |
| **바깥** | **위·아래·왼쪽·오른쪽 중 선택** | **물리량 / 이름표 중 선택** (기본 이름표) | 물리량이면 이탤릭 + 아래첨자 |

> **2026-07-31 개정**: 바깥 슬롯은 원래 "언제나 이름표"였다. 17번(2027-06 물리1)이 그 반대다 —
> 상자 **안**이 이름(A·B)이고 **바깥**이 질량(*m*·2*m*, 이탤릭)이다. 이 규칙이면 질량을
> `formula` 로 따로 얹어야 하고, 그러면 상자를 옮길 때 안 따라온다(1장 실패의 재발).
> 그래서 **두 슬롯 모두 서체를 고른다**로 바꿨다. 기본값은 이름표라 기존 그림은 그대로다.

- 두 슬롯은 **각각 켜고 끌 수 있다**(체크박스). 둘 다 끄면 라벨 없는 상자.
- 바깥 라벨은 상자에서 `gap`(글자 크기 × 0.85)만큼 떨어진다 — 지금 `withBoxLabel` 규칙 그대로.
- 회전(`rotation`)해도 글자는 수평을 유지한다 — 지금 동작 유지.

## 데이터 필드

```js
labelInner      // 문자열. 비면 안쪽 라벨 없음
labelInnerType  // "quantity"(물리량·이탤릭·첨자) | "label"(이름표·정체)
labelOuter      // 문자열. 비면 바깥 라벨 없음
labelOuterType  // 같은 두 값. 부재 = "label" (옛 파일 호환)
labelOuterPos   // "above" | "below" | "left" | "right"
```

`labelSize` · `labelBg` · `haloRatio` 는 두 슬롯이 공유한다.

### 기존 파일 호환 (project-io.js 마이그레이션)

옛 파일은 `label` / `labelPos` / `labelType` 하나만 갖고 있다. 열 때 이렇게 옮긴다.

- `labelPos === "center"`(또는 없음) → `labelInner = label`, `labelInnerType = labelType`
- 그 외(above/below/left/right) → `labelOuter = label`, `labelOuterPos = labelPos`

옮긴 뒤 옛 필드는 지우지 않고 남겨 둔다(구버전 앱에서 열어도 최소한 하나는 보이게).

## 완료 기준 (2026-07-30 전부 실측 확인)

- [x] 앱에서 상자를 만들어 **안쪽 `m_B` + 바깥 `B`** 를 넣으면 둘 다 보인다
- [x] 안쪽 `m_B` 의 **B 가 아래첨자로** 렌더된다
- [x] 바깥 라벨 위치를 위·아래·왼쪽·오른쪽으로 바꿔 보면 그대로 움직인다
- [x] **상자를 드래그하면 두 라벨이 함께 따라온다** (x +20mm 이동 → 두 라벨 정확히 +20mm)
- [x] 옛 프로젝트 파일을 열어도 기존 라벨이 그대로 보인다 (`migrate()` 직접 호출로 확인)
- [x] 회전시켜도 글자는 수평 (rotation 30° 확인)

### 구현하며 추가로 정한 것

- **인스펙터도 렌더러와 같은 해석 함수를 쓴다.** `boxLabelSlots` 를 `render.js` 에서 내보내고
  패널이 그걸 쓴다. 첫 편집에서 새 두 슬롯으로 굳힌다(안쪽만 건드려 바깥 라벨이 사라지는 것 방지).
- **슬롯 끄기 = 글자 비우기.** 표시 여부 필드는 만들지 않았다. 껐다 켤 때 되돌릴 값은
  세션 동안만 기억한다(저장 파일에는 남지 않는다). → `DESIGN.md` 13-6
- **바깥 슬롯은 4방향뿐**이라 원본이 대각선일 때는 가장 가까운 방향을 골라 기록한다.
  → `docs/FIGURE_DESIGN_PRINCIPLES.md` 1장
