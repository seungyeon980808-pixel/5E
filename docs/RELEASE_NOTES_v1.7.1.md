# 5E v1.7.1 — 덜어내고 고친 판

**새 기능 없이, 덜어내고 고친 판입니다.**

1.7.0을 내고 직접 출제해 보며 찾은 결함을 고치고, 쓰지 않는 기능을 코드째 지웠습니다. 파일 형식은 `.5e` 하나로 모았고, 설치판은 `.5e` 파일을 두 번 눌러 열 수 있습니다.

[웹에서 시작하기](https://www.5e.ai.kr/) · [README](../README.md) · [문제 신고](https://www.5e.ai.kr/bug/)

---

## 하이라이트

- **파일은 `.5e` 하나** — 그림·한글 시험지에 이어 문항·시험지도 `.5e`로 저장합니다. 어느 프로그램에서 열든 맞는 프로그램으로 넘겨 엽니다.
- **설치판에서 두 번 눌러 열기** — Windows·Mac에서 `.5e` 파일을 두 번 누르면 5E가 열립니다. 이미 떠 있으면 그 창에서 엽니다.
- **Mac 설치 파일 「손상됨」 해결** — 설치 파일 전체를 무료 임시 서명으로 묶어, 받은 뒤 「손상되었기 때문에 열 수 없습니다」가 뜨지 않습니다.
- **Mac 설치판 편집 키** — 글 칸과 5E 클립보드에서 ⌘A·⌘C·⌘V·⌘X·⌘Z가 됩니다.
- **덜어내기** — 튜토리얼, MCP 연결, 5E_hwp 교사용 기능(정답·배점·분류표·학생용 사본·가·나형·QR·학습지 틀)을 지웠습니다.
- **그림은 따로 받기** — 쪽 미리보기와 기출 그림을 그림 서버(Cloudflare)에서 받습니다. 설치 파일이 약 120MB 가벼워졌습니다.

| | 1.7.0 | 1.7.1 |
|---|---|---|
| 문항·시험지 파일 | `.exampool` | `.5e` (1.7.0 `.exampool`도 그대로 열림) |
| 설치판 파일 열기 | 프로그램 안에서만 | `.5e` 두 번 눌러 열기 |
| Mac 설치 파일 | 서명이 깨져 「손상됨」 | 번들 전체 임시 서명 → 「그래도 열기」로 열림 |
| 쪽 미리보기 그림 | 설치 파일 안 | 그림 서버에서 받음 |

## 지운 것

1.7.1은 「쓰지 않는 기능은 숨기지 않고 코드까지 지운다」는 원칙으로 덜어냈습니다.

**튜토리얼** — 5E_image 맨 위 「튜토리얼」 단추, 기능 검색(⌘K)의 「튜토리얼」 항목, 첫 방문 환영 창이 없어졌습니다.

**MCP 연결** — 바깥 AI 도구를 5E에 잇던 실험 기능(주소에 `?mcp=1`을 붙일 때만 보이던 「MCP」 단추)을 지웠습니다.

**5E_hwp 교사용 기능** — 5E_hwp는 「인쇄 전 조판(모양만)」을 맡고, 문항 내용은 5E_exam이 맡습니다. 그래서 내용을 다루던 기능을 지웠습니다.
- 「문항」: 정답(정답 한 번에), 해설, 분류, 배점(배점 한 번에)
- 「학습지」: 빈칸 표시·표시 지우기·굵은 글씨→빈칸, 학생용·정답지 내려받기, 정답 모아 넣기, 학습지 틀, QR 코드
- 「판짜기」: 정답·해설지, 분류표, 정답표 칸, 가·나형
- 「점검」: 정답 분포 고르게, 배점 합계·배점 빠진 문항·정답 분포 치우침·같은 정답 연속
- 왼쪽 문항 목록의 정답 표시

남은 것: 시험지 머리, 문항 간격, 단 채우기, 1단·2단, 용지, 쪽 번호·머리말, 발문, 〈보기〉, ㄱㄴㄷ 선지, 번호 다시, 고른 문항만 새 파일로, 문항 그림 내보내기, 상자·답란·평가 기준표, 인쇄·PDF, 모드 세 가지(⌥⌘4 기본 · ⌥⌘5 집중 · ⌥⌘6 없음).
문서에 이미 들어 있는 `[정답]`·`[해설]` 줄은 지우거나 오류로 잡지 않고 그대로 둡니다.

**그 밖** — 아무 데서도 불러오지 않던 파일 14개, 옛 미리보기 사본(/preview/), 쓰지 않는 옛 소개 그림을 지웠습니다. 화면에서 보이는 차이는 없습니다.

## `.5e` 하나로

- 5E_exam 「저장 (.5e)」(⌘S): 시험지 안이면 그 시험지를, 아니면 보관함 전체를 `.5e` 하나로 저장합니다. 문항·그림·학교 양식·조판 기준이 함께 들어갑니다.
- 「불러오기…」(⌘O): 파일 이름이 아니라 안쪽 내용으로 종류를 가립니다. `.5e`, 1.7.0 `.exampool`, 엑셀(이름이 바뀐 엑셀도)을 모두 엽니다. 엑셀은 「엑셀로 내보내기」로 따로 냅니다.
- 5E_image에서 문항·시험지 `.5e`를 열면 5E_exam으로, 5E_exam에서 그림이나 한글 시험지 `.5e`를 열면 맞는 프로그램으로 넘겨 엽니다.
- 5E_hwp의 파일 고르기 창은 `.5e`만 보여 줍니다. 옛 형식 파일은 1.7.1 동안 끌어 놓으면 열립니다.
- 설치판은 처음 저장할 때 이름과 자리를 고르게 하고, 처음 자리는 「문서」 폴더입니다.
- 1.6.3·1.7.0에서 만든 파일은 그대로 열립니다.

## 고친 것

**설치판**
- 5E_exam 「시험지 파일로 저장」이 설치판에서 「저장할 수 없는 파일 종류」로 실패하던 것.
- Mac: 편집 메뉴가 없어 글 칸의 ⌘A·⌘C·⌘V·⌘X·⌘Z와 캔버스의 5E 클립보드 ⌘C·⌘V·⌘X가 아무 일도 하지 않던 것.
- 출제 자동 백업이 끝없이 쌓이던 것: 최근 24개와, 최근 30일 동안은 날마다 마지막 하나만 남기고 나머지는 휴지통으로 옮깁니다(바로 지우지 않음).
- Mac Pro 화면에서 라이브러리 제목이 창 단추(빨강·노랑·초록) 자리에 걸리던 것.
- 시작 창에 새 버전이 있으면 「1.7.1 → 1.7.2 [받기]」처럼 알려 줍니다. 누르면 릴리스 페이지가 열리고, 받기·설치는 직접 합니다(자동 업데이트 아님). 인터넷이 없으면 조용히 지금 모습 그대로입니다.

**Lite**
- Lite인데 5E_hwp 조판 창·5E_exam 출제 칸이 열리던 길을 막았습니다. 막힌 기능을 누르면 「정식판에서 됩니다」 안내와 「Pro로 바꾸기」가 뜨고, 바꾸면 하던 일을 이어서 합니다.

**5E_exam**
- 문항 카드: 자료 칸에서 Delete는 그림만 비웁니다(칸·이름·크기는 남고 ⌘Z로 되돌림). 칸째 지우기는 휴지통 단추.
- 문항 카드: 합답형 선지 칸이 좁으면 「ㄷ」이 칸 밖으로 떨어지던 것.
- 보관함 「배점 · 정답」을 ①~⑤로 보여 주고, ①을 「정답 없음」으로 잘못 보던 것.
- 카드 쪽 그리기가 실패하면 늘 이유를 함께 보여 줍니다.
- 「불러오는 중… 00:00」 시간이 화면이 바쁠 때 멈춰 있던 것.
- 조판 설정의 간격 칸이 B4·A3 문항에서도 그 용지의 실제 mm로 보입니다(이미 조판된 문항은 바뀌지 않음).
- 왼쪽 메뉴 접기·펴기가 뚝 끊기지 않고 부드럽게 움직입니다.
- 한글 파일(HWPX)로 내보낼 때 수식을 한글 수식 문법으로 바꿔 넣습니다. 한글 수식에 없는 기호(⇌ ħ ⊥ ∥ 등)는 글자 그대로 넣습니다.
- 기본 학교 원안지 3개에서 학교 이름을 지우고 「중학교 원안지(A4)」 「고등학교 원안지(B4)」 「고등학교 원안지 2(B4)」로 이름을 바꿨습니다. 조판 모양은 같습니다.

**5E_hwp**
- 판 구조(문항 하나가 표 하나) 시험지에서 문항을 지우면 표가 남아 다음 문항과 겹치던 것.
- 한글 되돌리기를 한 뒤 그림을 고치면 되돌리기 전 원본이 열리던 것.
- 그림 배치 중 Esc(취소)·Enter(확정)가 먹지 않던 것.
- Safari에서 그림 자르기를 확인한 뒤 배치 칸이 뜨지 않던 것.
- 시험지가 없을 때 「먼저 시험지를 여세요」 같은 경고로 끝나지 않고, 파일 메뉴(새 시험지·열기)를 펼쳐 이어서 하게 합니다.
- 조각 편집 막대가 「파일」 단추와 모드 탭을 덮던 것. 넓은 창에서는 맨 위 줄 안에, 좁은 창에서는 그 바로 아래 한 줄에 놓입니다.

**5E_image · AI · 그래프**
- 그래프·과학 오브젝트 라벨에서 영문·괄호 앞뒤 띄어쓰기가 사라지던 것(「경과 시간」이 「경과시간」으로 붙던 것).
- AI 그래프 복원에서 축 이름이 「주기주기(일)」처럼 두 번 쓰이던 것.
- 글 상자 수식에서 한글 수식 말(LEQ·GEQ·NEQ·sqrt·root·approx·inf)과 `<=` `>=` `!=`를 받습니다.
- AI 일괄 실행이 「변환하기」와 같은 요청 글을 써서, 같은 작업은 다시 요청하지 않고 앞 결과를 씁니다.
- AI 창 왼쪽 위 연결 줄(↳ 문항 카드 · …)이 두 줄까지 보입니다.

**라이브러리**
- 검색 형광이 글자에서 어긋나던 것: 학평은 거의 모두 제자리, 평가원도 가로·세로를 더 맞췄습니다.
- 「보내기」 메뉴가 단추 옆이 아니라 칸 오른쪽 위에 뜨던 것.

**공통**
- 닫힌 「5E 프로그램」 목록이 Esc를 가로채 지우개 설정·배치 칸이 Esc로 닫히지 않던 것.
- Safari에서 시작 직후 클립보드 판이 Esc를 가로채 메뉴·글자 칸·확대 칸이 Esc로 닫히지 않던 것.

## 설치

| | 파일 |
|---|---|
| Windows | `5E-1.7.1-windows-x64.exe` |
| Mac · 애플 실리콘 | `5E-1.7.1-macos-arm64.dmg` (또는 `.zip`) |
| Mac · 인텔 | `5E-1.7.1-macos-x64.dmg` (또는 `.zip`) |

설치 파일은 아직 정식 코드 서명·공증을 받지 않았습니다.
- Windows: 「PC 보호」 창이 뜨면 **추가 정보 → 실행**.
- Mac: 처음 열 때 「Apple이 확인할 수 없습니다」가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 맨 아래 **그래도 열기**를 누릅니다. 한 번 열면 다음부터는 그냥 열립니다.

내려받은 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다. 설치판의 사용자 자료 폴더는 1.7.0과 같아서, 덮어 설치해도 작업이 그대로 남습니다.

## 알아 두실 것

- 쪽 미리보기와 기출 그림은 그림 서버에서 받으므로 인터넷이 필요합니다(설치판도 같음). 과학 부품 그림은 설치판 안에 그대로 있습니다.
- 한글 수식 변환은 HWPX 내보내기에만 들어갔습니다. `.hwp`로 내보낼 때는 수식이 지금처럼 나가며, 1.7.2에서 다룹니다.
- 시험지를 파일 하나씩 열고 저장하는 구조는 1.7.2에서 다룹니다. 1.7.1은 확장자만 `.5e`로 모았습니다.
- 1.7.1에서 저장한 문항·시험지 `.5e`는 1.7.0에서 열리지 않습니다(「지원하지 않는 파일」로 거절하고, 파일은 망가뜨리지 않습니다).
- 그래프·오브젝트 라벨의 띄어쓰기를 살리면서, 띄어쓰기가 있는 라벨은 조금 넓어집니다(글자 4mm 기준 「경과 시간」 9.97 → 10.72mm). 띄어쓰기 없는 라벨은 그대로입니다.
- 이미 기본 학교 양식을 등록해 둔 기기에는 옛 양식 이름이 그 기기 안에 남습니다. 조판 기준은 바뀌지 않습니다.
- 넓은 화면(PC) 기준입니다. 좁은 화면과 모바일은 다음 버전에서 다룹니다.
- AI 기능은 로그인한 ChatGPT 계정의 기능과 이용 한도 안에서 실행됩니다.
