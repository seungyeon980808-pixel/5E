사용자가 뜻한 교과서는 국내 중학교 2학년 과학 교과서다. 이전 OpenStax Physics 10개는 이 범위에 맞지 않아 새 비교 보고서에서 제외했다. 이전 자료는 과거 실행 증거로 보존했다.

## 원본과 실행

2022 개정 천재교과서 『중학교 과학 2』(임성숙 외)의 공식 공개 교과서 미리보기에서 실제 수록 좌표 그래프 10개를 선정했다. 표지와 차례, 해당 본문 페이지를 렌더링해 직접 확인했다. 공식 출처는 https://text.tsherpa.co.kr/mid/book.html?bookcode=text-mid-science-lss 이다.

PDF를 Poppler로 렌더링한 뒤 그래프 영역만 잘랐다. 곡선·눈금·라벨 픽셀은 수정하지 않았다. 인쇄 쪽수, PDF 페이지, 자르기 범위, PDF·렌더·입력 이미지의 SHA256은 `textbook-manifest.json`에 남겼다. 전체 교과서 PDF나 요청 첨부를 Git에 추가하지 않았다.

새 교과서 10개만 실제 제품 작업대에서 `gpt-6.1-sol`, `medium`, `graph-observation-v21-physics-processes`로 각각 한 번 실행했다. 모델 대체·자동 재시도·수동 계획 보정은 없었다. 제품 코드는 수정하지 않았다.

기존 물리 10개, 화학·생명과학·지구과학 각 5개는 재요청하지 않았다. 총 25개의 원본·첫 응답·계획·SVG·PNG·5E·검증 파일이 기존 보고서와 바이트 단위로 같음을 검사했다. 검증 해시는 `reused-exam-evidence.json`에 남겼다. 통합 보고서의 요청 35회는 이번 새 요청 10회와 기존 요청 25회를 합한 수치다.

10개 중 생성 8개, 편집·저장·재열기 통과 4개, 미생성 2개다. 함수식을 생성한 그래프는 0개다. 생성된 8개 중 3개는 정상 직선·꺾은선이고 5개는 데이터 곡선이 점 경로로 남았다. 직선·꺾은선을 함수화 실패로 집계하지 않았다. 새로운 식이 없으므로 새 교과서의 ② 함수 입력 수정 검사는 대상이 없으며 통과로 주장하지 않는다. 기존 기출에서 생성된 식 8개의 두 브라우저 검증은 이전 증거를 유지했다.

사인 파동은 수학적으로 식 표현이 가능하다. 이번 실패 원인은 시간축 수치가 없는 경우 상대 단위를 설정하는 단계가 부족하다는 것이다. 광합성 개념 곡선도 상대 좌표 근사 함수로 편집 가능하게 할 여지가 있지만 이번 응답에서는 구현되지 않았다. 실측 용해도 곡선의 근사식을 고유한 물리 법칙이라고 확정해서는 안 된다.

형태·기준점 관계와 편집 가능성은 별개다. 녹는점의 수평 구간과 직선 기울기 관계는 대체로 보존됐으나 글자가 커지고 겹침·줄바꿈 변화가 발생했다. 소리 파동과 광합성 곡선도 형태는 유사하지만 함수식으로 변형할 수 있는 결과는 아니다. 네 개의 라벨 적용 실패는 그대로 기록했으며 원인 진단이나 제품 수정으로 성공을 덮어쓰지 않았다.

## 검증과 재현

- 새 입력 10개의 고유 해시, 출처·쪽수, 고정 모델·effort, 실제 요청 1회씩을 검사했다.
- 원본·변환본의 같은 영역을 비교 PNG로 만들었다. 미생성 2개를 포함해 새 교과서 10개와 기존 기출 25개의 이미지 총 35개가 HTTP 200으로 열리는지 확인했다.
- Safari에서 새 비교 페이지가 실제 표시되는 것을 접근성 트리와 스크린샷으로 확인했다. 첫 화면은 중2 교과서 10개만 보이며 분류에서 기존 기출을 선택할 수 있다.
- `tools/prepare-middle2-science-graphs.py`: 공식 PDF의 지정 그래프 영역과 출처를 고정하고 기존 기출 증거를 재사용한다.
- `tools/report-science-graphs.mjs`: 출판사·책명·쪽수와 이번 요청/기존 요청을 구분하여 첫 응답 증거를 집계한다.
- `tools/create-science-image-gallery.py`: 결과 데이터 변경 없이 원본·변환 비교 PNG와 분류 페이지를 만든다.

이번 작업은 교과서 범위 정정과 실제 재평가다. 자동 복원의 완성도 개선으로 보고하지 않는다. 다음 개선 대상은 상대 축 함수화, 생략 표시 처리, AI 응답 규격, 편집 적용 차단, 글자·선 크기다.
