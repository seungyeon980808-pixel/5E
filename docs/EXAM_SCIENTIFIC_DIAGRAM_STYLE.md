# 평가원식 과학 도식 이미지 스타일 가이드

## 목적

물리·화학·생명과학 기출문항에 사용할 2D 과학 도식을 제작할 때, 생성 이미지와 SVG 자산이 동일한 인쇄 도판 느낌을 유지하도록 하는 기준이다.

## 핵심 방향

- 과학 장치의 사실적인 제품 그림이 아니라 문제 풀이용 도식으로 그린다.
- 장식보다 위치·관계·상태·운동 경로가 먼저 보이게 한다.
- 정면도, 측면도, 단면도와 단순한 사선 도식을 우선한다.
- 등각 투시, 카탈로그형 3D 렌더링, 과도한 입체 표현은 피한다.

## 선 규칙

- 외곽선은 내부 구조선보다 굵게 한다.
- 내부 구조선은 얇고 단순하게 유지한다.
- 선 끝과 꺾임은 지나치게 장식적으로 처리하지 않는다.
- 실선은 실제 구조물·경계·현재 상태에 사용한다.
- 점선은 기준 위치, 이전 위치, 가상 위치, 보이지 않는 구조에 사용한다.
- 화살표는 이미지에 포함하지 않는다. 운동·힘·빛·전자·전류 등의 화살표는 사용자가 별도로 조판한다.
- 치수선·지시선·라벨선은 본체 외곽선과 구분되도록 얇게 한다.

## 색과 명암

- 기본은 흰 배경과 검은 선이다.
- 전체 면의 대부분은 흰색으로 남긴다.
- 회색은 물리적으로 의미가 있는 영역에만 제한적으로 사용한다.
  - 액체·용액
  - 전자선·광선의 진행 영역
  - 단면으로 드러난 재료
  - 핵·세포질·특정 기관
  - 장치 내부의 구분이 필요한 한두 영역
- 금속·유리·플라스틱을 회색 농도 차이만으로 사실적으로 묘사하지 않는다.
- 그라디언트, 광택, 반사광, 그림자, 입체 조명은 사용하지 않는다.
- 해칭·점묘는 단면이나 재료 구분에 꼭 필요할 때만 최소한으로 사용한다.
- 회색은 장식이 아니라 정보 전달 수단이어야 한다.

## 구조와 배치

- 하나의 부품보다 문항에서 사용되는 실험 장면과 관계를 우선한다.
- 장치의 모든 세부를 묘사하지 않고 문제 풀이에 필요한 부분만 남긴다.
- 나사, 다이얼, 받침, 연결부는 식별에 필요할 때만 표현한다.
- 본체 주변에 충분한 여백을 두되, 실제 문항처럼 비대칭 배치도 허용한다.
- 바닥·수평면·경사면·기준선은 장면의 운동 관계가 드러나도록 배치한다.
- 물체의 이전 위치나 가상 위치는 점선, 실제 현재 위치는 실선으로 구분한다.
- 같은 물체의 반복 위치가 있으면 크기·방향·비율을 일관되게 유지한다.

## 라벨과 기호

- 이미지 생성 단계에서는 한글 라벨을 넣지 않는다.
- 라벨·지시선·문자·수식은 가능한 한 후처리나 프로그램 조판으로 넣는다.
- 라벨이 없어도 본체와 물리적 관계가 식별되어야 한다.
- 기호도 이미지에 포함하지 않는다. 필요한 기호는 사용자가 별도로 조판한다.
- 화살표도 이미지에 포함하지 않는다. 필요한 화살표는 사용자가 별도로 조판한다.

## 운동·상태 표시

- 출발 위치, 중간 위치, 도착 위치를 선 종류로 구분한다.
- 실제 위치는 실선 외곽과 선명한 구조로 그린다.
- 과거·가상·예상 위치는 점선 외곽으로 그린다.
- 마찰 구간은 별도의 띠나 제한된 질감으로 표시하되, 바닥 전체를 과도하게 채우지 않는다.
- 경사면의 높이 차이와 수평 이동 구간이 한눈에 보이도록 한다.

## 금지 사항

- 과도한 회색 명암
- 금속의 사실적인 광택
- 전 제품을 3D로 렌더링하는 방식
- 장식용 해칭과 그림자
- 불필요한 기계 부품 추가
- 생성 모델이 만든 부정확한 한글 텍스트
- 생성 모델이 만든 부정확한 문자·기호·수식
- 생성 모델이 만든 화살표와 방향 표시
- 본체와 라벨이 겹쳐 구조가 가려지는 배치
- 점선과 실선의 의미가 뒤섞이는 표현

## 최종 검수 질문

1. 흰색과 검은 선만 보아도 문제의 구조가 이해되는가?
2. 회색 영역마다 물리적 의미가 있는가?
3. 실선과 점선의 상태 구분이 명확한가?
4. 물체의 운동 경로와 높이 차이가 한눈에 보이는가?
5. 불필요한 제품 묘사나 장식이 제거되어 있는가?
6. 라벨을 나중에 추가할 여백이 남아 있는가?

## 참조 이미지 재현 절차

1. 참조를 본체, 반복 부품, 연결선, 삽입도, 인물·자연물로 분해한다.
2. 제거할 문자·기호·수치·화살표는 이름뿐 아니라 차지하는 좌표 영역까지 표시한다.
3. 실루엣, 부품 수, 연결 관계, 상대 배치, 선 위계, 회색 사용을 각각 검수한다.
4. 저해상도 혼합 장면은 전체 생성하지 않고 개별 물체를 확대 크롭하여 제작한다.
5. 단순 기하 장치는 반복 개수, 접점, 중심축, 캔버스 점유율을 수치로 고정한다.
6. 생성 결과가 원본 요소를 익숙한 다른 물체로 치환하면 즉시 실패로 판정한다.
7. 같은 구조 오차가 두 번 반복되면 좌표 기반 SVG 또는 분리 자산 조합으로 전환한다.
8. 통과 판정은 제거 대상의 의도적 차이를 제외한 구조 일치율 95% 이상일 때만 내린다.

## 개념 유사성과 구조 일치의 구분

- 같은 실험 목적이나 같은 교과 개념을 나타내더라도 용기 종류, 패널 수, 부품 수, 연결 방식이 달라지면 재현 실패다.
- 둥근 플라스크를 비커로, 두 상태 비교를 하나의 광선도로, 개별 부유물을 일반 입자층으로 바꾸는 재해석을 허용하지 않는다.
- 사진을 선화로 단순화할 때 삭제할 수 있는 것은 색, 광택, 그림자, 배경, 조판 요소뿐이다. 문제 풀이에 관여할 수 있는 물체의 외형과 상대 위치는 삭제하거나 일반화하지 않는다.
- 자체평가에서 `핵심 개념이 유지됨`, `대체로 유사함`은 통과 근거가 아니다. 원본과 생성본의 폐쇄 객체 목록을 항목별로 대응시켜야 한다.
- 구조 점수 40점은 객체 종류·개수·연결·패널 상태가 모두 일치할 때만 만점을 준다. 이 중 하나라도 바뀌면 총점 95점 이상을 부여하지 않는다.
- 원본에 있던 화살표를 제거하는 것은 허용되지만, 생성 모델이 광선·운동선·지시선·화살표를 새로 추가하면 즉시 실패다.

## 회색 면적 제한

- 장식 목적의 회색은 0%를 원칙으로 한다.
- 자연물의 물·얼음·지층처럼 구별이 필요한 장면도 회색 총면적을 캔버스의 10% 이내로 유지한다.
- 장치 단면은 한두 단계의 평면 회색만 사용하며 연속 농담이나 가장자리 번짐을 허용하지 않는다.

## 제작 레이어 분리

- 기하 구조: 5E 또는 SVG 객체로 제작한다.
- 삽화 전경: 인물·손·차량처럼 기본 도형으로 정체성이 사라지는 요소만 검증된 기출 크롭 자산을 사용한다.
- 조판: 문자·기호·수치·화살표는 이미지 자산에서 제외하고 사용자가 프로그램에서 추가한다.
- 한 장면 안에서도 위 세 종류를 한 번에 생성하지 않고 독립 레이어로 조합한다.

## 프로그램 객체 제작 검수

- 자동 라벨이나 기본 수치가 강제로 들어가는 템플릿은 무라벨 자산에 사용하지 않는다.
- 저장 전에 모든 객체의 경계가 아트보드 안에 있는지 검사한다.
- 반복 부품은 하나의 마스터 자산에서 복제하여 크기·선 굵기·방향을 일치시킨다.
- 코일처럼 외피와 내부 반복 구조가 함께 있는 장치는 두 레이어를 모두 그린다.
- 마찰 구간은 검은 굵은 선이 아니라 제한된 옅은 회색 띠로 표현한다.
- 패널별 광선·줄·도선은 시작점과 종료점을 독립 목록으로 관리해 다른 패널의 선을 재사용하지 않는다.

## 삽화 부품 정제 규칙

- 사람·손·차량처럼 기하 도형만으로 정체성이 사라지는 대상은 검증된 기출 삽화를 독립 부품으로 분리할 수 있다.
- 원본 전체를 한 장의 이미지로 넣지 않는다. 물체별로 분리하고, 바닥·도선·받침·용기 같은 구조는 5E/SVG 선 도형으로 다시 조립한다.
- 분리한 부품에 포함된 문자·기호·수식·화살표·지시선·점선 치수선은 모두 제거한다.
- 부품 주변에 문자 조각이나 지시선 잔여가 한 픽셀이라도 보이면 자산으로 승인하지 않는다.
- 사진식 연속 명암은 검정·흰색과 최대 두 단계의 평면 회색으로 단순화한다.
- 회색 단계 변환 뒤에도 사람의 얼굴, 손가락, 바퀴살처럼 식별에 필요한 내부선은 보존한다.
- 회색 면을 생성할 때는 RGB 세 채널을 같은 값으로 지정한다. 단일 정수 색상값을 넣어 빨강 등 유채색으로 해석되는 오류를 금지한다.
- 삽화 부품을 사용한 결과와 순수 벡터 재현 결과는 평가 기록에서 구분한다. 부품 추출의 높은 일치율을 벡터 생성 성능으로 간주하지 않는다.

## 좌표 기반 장치 재현 규칙

- 경사면·레일·도르래 줄처럼 방향성이 있는 구조는 그리기 전에 원본의 시작점과 끝점 높이를 숫자로 기록한다.
- 좌우로 반복되는 패널은 첫 패널을 통째로 복제하지 않는다. 공통 구조만 복제하고 물체 위치와 줄 연결은 패널별 좌표 목록으로 관리한다.
- 용수철 생성 함수는 수평·수직·경사 방향에서 각각 시험한다. 끝단 감쇠식이 중간 진폭까지 0으로 만드는지 반드시 확인한다.
- 용수철은 반복수가 맞더라도 전체 폭, 리드선 길이, 코일 중심 간격이 원본과 다르면 통과시키지 않는다.
- 회색 사진을 선화로 바꿀 때 단순 임계값만 적용하면 풍력 터빈 날개처럼 가는 회색 선이 사라질 수 있다. 외곽선 검출 레이어와 명암 축약 레이어를 결합한다.
- 원형 장치는 외원·내원·중심점·관통 축을 각각 독립 객체로 만들고 중심 좌표를 공유한다.
- 곡면 궤도는 시작 경사, 최저점, 수평 접속점의 세 좌표를 먼저 고정한 뒤 곡선을 보간한다.
- 평가 전에는 원본과 재현물의 경사 부호, 패널 순서, 좌우 방향을 먼저 비교한다. 방향이 반대면 세부 묘사와 관계없이 실패다.

## 혼합 장면의 자산 경계 규칙

- 삽화 부품의 크롭 경계는 물체 외곽에서 끝내며, 옆에 있는 문자·말풍선·신호선·운동선까지 넓게 포함하지 않는다.
- 크롭 직후 흰 배경 위에 단독으로 배치해 네 방향 경계에 잔여 픽셀이 있는지 검사한다.
- 문자와 물체가 겹쳐 있어 단순 사각 마스크가 물체를 훼손하면 해당 크롭을 사용하지 않고 선 도형으로 다시 만든다.
- 전화 신호, 빛, 운동선처럼 원본에서 기호 역할을 하는 선은 사용자 조판 대상이다. 본체 자산에는 넣지 않는다.
- 화살표를 제거할 때 경로 자체가 물리적 구조를 설명하면 선만 남기고, 방향만 나타내는 선이면 전체를 제거한다.
- 직접 추출, 순수 벡터, 혼합 제작을 학습 로그에서 명시하고 세 방식의 점수를 따로 해석한다.
- 여러 삽화가 나란히 있는 장면은 각 삽화를 독립 부품으로 분리해 정렬하며, 원본 전체 이미지를 한 번에 명암 변환한 결과는 재편집 가능한 자산으로 간주하지 않는다.
- 회로·층상 구조·매질 단면은 문자 없이도 층, 접점, 폐회로 연결이 식별되어야 한다.

## 복합 기계 장치의 골격 규칙

- 복합 장치는 외곽 실루엣을 먼저 그린 뒤 중심축, 지지대, 작동부, 검출부, 외부 연결부 순서로 조립한다.
- 원심분리기·전자현미경처럼 중심축이 중요한 장치는 모든 대칭 부품이 같은 축 좌표를 공유해야 한다.
- 화면·계기판·전광판·휴대전화 화면에 원본 문자가 있으면 내용을 모사하지 않고 빈 내부 사각형으로 남긴다.
- 장치에 붙은 안내판과 상호 표시는 장치 외곽의 일부가 아니므로 빈 패널 외곽만 보존한다.
- 지시선이 기계 내부를 가로지르는 참조는 지시선을 구조선으로 오인하지 않는다. 가려진 구조는 반대편 대칭이나 인접 윤곽으로 복원한다.
- 복합 장치의 평가는 외곽 일치뿐 아니라 부품 개수, 중심축, 접속 순서, 지지 관계를 따로 확인한다.
- 투시 장면은 소실점 하나와 바닥 기준선을 먼저 고정하고 차량·문·기둥을 같은 투시계에 배치한다.
- 일상 장면의 사진식 배경은 핵심 물체 식별에 필요한 경우에만 남기며, 넓은 하늘·바닥 명암은 흰색 또는 한 단계 회색으로 축약한다.
- 여러 패널 아래의 패널 기호와 캡션은 그림 자산에서 제거한다. 패널 테두리와 내부 삽화만 남긴다.

## 부품 목록과 연결 위상 검수

- 복합 장면을 그리기 전에 `본체·지지대·가동부·연결선·부착물·반복부품`으로 분해한 목록을 작성한다.
- 재현 후에는 원본 목록의 부품 개수와 생성 객체 개수를 대조한다. 누락된 부품이 있으면 실루엣이 유사해도 통과시키지 않는다.
- 회로는 소자 모양보다 연결 위상을 먼저 복원한다. 각 폐회로를 따라가며 소자 순서와 분기점 수를 기록한다.
- 전지·스위치·저항처럼 직렬로 놓인 소자의 좌우 순서가 달라지면 구조 오류로 판정한다.
- 교차하는 두 선은 접점 표시가 있을 때만 연결한다. 접점이 없는 교차선은 서로 다른 레이어로 유지한다.
- 도르래 장면은 도르래 수, 줄 수, 줄의 시작·종료 물체, 각 물체가 접한 면을 표로 관리한다.
- 반복 블록은 크기만 맞추지 않고 줄 또는 도선이 들어오고 나가는 면까지 원본과 일치시킨다.
- 문자 제거 후에도 소자 종류가 몸체 형상으로 구분되도록 전지의 장·단판, 저항의 지그재그, 스위치의 열린 접점을 보존한다.
- 굵은 유체 관로는 외곽선 두 줄과 내부 유체 띠를 별도 레이어로 만들며, 관 두께가 곡률에 따라 갑자기 변하지 않게 한다.

## 반복 간격·회전각·곡률 규칙

- 같은 레인이나 축 위의 반복 위치는 개별 픽셀 좌표가 아니라 0~1의 정규화 위치값으로 저장한다.
- 투시 레인의 사선 경계는 공통 소실점을 공유해야 하며, 각 경계선을 따로 눈대중으로 기울이지 않는다.
- 반복 블록의 현재 위치와 가상 위치는 같은 마스터 도형을 사용하고 실선·점선 속성만 바꾼다.
- 좌우 대칭 우주선은 한쪽을 단순 좌우 반전하지 않는다. 엔진 방향·선수·내부 창 위치를 패널별로 다시 검수한다.
- 굴곡 궤도는 접속점에서 위치뿐 아니라 접선 방향도 연속이어야 한다.
- 원호 영역은 중심점과 반지름 배열을 공유하며, 각 원호의 시작각·끝각을 숫자로 기록한다.
- 지레와 저울은 받침점, 매다는 점, 끝점을 하나의 1차원 축 좌표로 관리한다.
- 인물에 문자가 붙어 분리할 수 없으면 부정확한 문자 크롭을 유지하지 않고 무라벨 선화 실루엣으로 교체한다.
- 교체한 실루엣의 점수는 원본 삽화 정제 점수와 구분하며, 자세·관절·접촉 관계가 단순화된 정도를 감점한다.
- 복잡한 배선의 꺾임점은 직교 경로 목록으로 관리하고, 스위치와 전지 주변에서 불필요한 대각선을 만들지 않는다.

## 계기·스프링·반복 패널 규칙

- 같은 문제 안의 저울·계기·블록은 하나의 마스터 도형을 복제하고 바늘 각도나 물체 높이처럼 상태를 나타내는 값만 바꾼다.
- 아날로그 눈금은 중심·반지름·시작각·끝각·눈금 수를 수치로 고정하며, 패널마다 눈금을 새로 그리지 않는다.
- 디지털 표시창은 숫자나 단위를 넣지 않은 빈 흰색 패널로 남기고, 버튼의 개수와 간격만 원본 구조에 맞춘다.
- 용수철은 전체 길이, 코일 폭, 회전 수, 양끝 직선부 길이를 한 묶음으로 기록한다. 여러 상태에서는 코일 폭보다 피치와 전체 길이 변화를 우선 비교한다.
- 반복 패널의 공통 기준선과 물체 중심은 동일한 좌표 배열을 공유하고, 힘 화살표·문자·수치는 생성 자산에 포함하지 않는다.
- 우주선은 외곽 선체, 내부 창, 엔진, 선수의 네 영역으로 나누어 비율을 검수한다. 내부 인물은 창 중심축과 바닥 접촉 위치를 먼저 맞춘다.
- 사실적인 명암이 포함된 원본 장치도 재현 자산에서는 흰색·한두 단계의 평면 회색으로 축약한다. 광택과 입체 그라디언트는 형태 일치 점수와 별개로 제거한다.
- 작은 코일이나 나선은 축 방향 외곽선과 반복 고리의 피치를 분리해 관리하며, 고리 수를 줄여 장식적으로 단순화하지 않는다.

## 다분야 도판과 학습 원본 선별 규칙

- 목표 스타일이 흑백 선화인 경우, 원본의 핵심 정보가 사진 질감·흐림·광택에만 의존하는 도판은 학습 원본에서 제외한다. 선과 평면 영역으로 구조를 설명할 수 있는 원본으로 교체한다.
- 여러 상태의 피스톤·용기 도식은 용기 외곽을 공통 마스터로 두고 피스톤 높이, 침전물 유무, 액면 위치만 상태값으로 관리한다.
- U자관과 연결 용기는 외벽과 내벽을 별도 연속 경로로 만들고, 액체 영역이 벽 경계를 침범하지 않도록 채움 다각형을 검수한다.
- 도르래 장면은 줄의 접선, 도르래 중심, 경사면 방향, 블록 접촉면을 먼저 맞춘다. 문자 제거 후에도 줄이 어느 물체와 연결되는지 식별되어야 한다.
- 회로의 소자명이 제거되어도 소자 외형, 직렬·병렬 연결, 스위치 접점, 전지 극판 길이 차이는 유지한다.
- 인물 삽화를 무라벨 실루엣으로 교체한 결과는 장치 도식과 같은 기준으로 통과 처리하지 않는다. 손의 접촉 대상, 무릎·발의 지지 상태, 시선 방향이 단순화된 만큼 별도로 감점한다.
- 염색체·염색분체는 동원체 위치, 팔 길이, 짝의 수, 회색 농도만 사용해 구분한다. 원형 세포 경계 안에서 중심과 회전각을 수치로 관리한다.
- 원본에서 화살표가 상태 전환만 설명하는 경우 화살표를 제거하되, 패널 순서와 상태 차이가 외형만으로 읽히도록 배치한다.

## 참조 이미지 직접 생성 재현 규칙

- 이 학습 과정은 MCP·캔버스 조작이나 벡터 코드 작성을 평가하지 않는다. 기출 원본을 이미지 생성 모델의 참조 이미지로 입력하고 별도의 래스터 이미지로 재현한 결과만 평가한다.
- 프롬프트에는 원본의 객체 수, 접촉 관계, 패널 수, 좌우 순서, 주요 실루엣을 먼저 명시한다. 스타일 형용사는 그다음에 적는다.
- 작은 저해상도 장치 이미지는 모델이 익숙한 제품 형태로 확대·재해석하기 쉽다. 다음 생성 전 원본 객체가 화면 대부분을 차지하도록 무문자 영역을 확대해 참조한다.
- `그라디언트 금지`만으로는 회색 면의 부드러운 명암이 완전히 사라지지 않는다. `각 회색 영역은 하나의 완전히 균일한 농도`라고 반복하고, 최종 자산은 회색 단계 수를 검사한다.
- 원본 물체 내부의 문자는 제거 지시를 해도 다시 생성될 수 있다. 첫 생성에서는 구조 보존을 우선하고, 남은 문자만 지우는 정밀 편집을 한 번 별도로 수행한다.
- 정밀 편집 프롬프트에는 `문자 영역만 변경`과 함께 보존할 인물·장치·배치·선 굵기를 명시한다. 전체 장면을 다시 생성하지 않는다.
- 인물 중심 도판은 자세·시선·손 접촉을 구체적으로 적으면 원본 선화 밀도에 가깝게 재현된다. 이름표와 말풍선은 별도의 제거 대상으로 적는다.
- 회로와 반복 생물 도식은 부품 수와 연결 위상 또는 개체 수와 회전각을 명시하면 안정적이다. 소자 내부는 `완전한 빈칸`으로 요구한다.
- 생성 모델이 저해상도 장치를 다른 종류의 기계로 확장한 경우 선화 품질이 높더라도 구조 일치 실패로 판정한다.
- 이미지 생성 결과와 코드 기반 재현 결과는 같은 번호 체계나 평균에 섞지 않고 별도의 학습 로그로 관리한다.

## 이미지 생성 반복 구조와 회색 보정 규칙

- 저해상도 참조 이미지는 내용 변경 없이 긴 변이 약 1200~1600픽셀이 되도록 확대하면 모델이 장치 종류를 다른 사물로 재해석하는 비율이 낮아진다.
- 확대는 원본에 없던 정보를 복원하지 않는다. 장치 정체성은 좋아져도 작은 나사·지지대·구멍의 정확도는 별도 감점한다.
- 반복 패널은 전체 장면을 한 문장으로 설명하지 않고 `패널 1의 위쪽 객체·아래쪽 객체`, `패널 2의 위쪽 객체·아래쪽 객체`처럼 패널별 객체 목록을 작성한다.
- 모델은 문자 제거 뒤 서로 다른 두 스프링이나 두 장치를 하나의 연속 객체로 합칠 수 있다. 문자 제거 전후의 객체 수가 동일한지 반드시 다시 센다.
- 복잡한 인물 장면과 실제 제품 삽화는 원본의 자세·실루엣·세부 밀도를 잘 보존하는 편이므로, 장치 구조보다 인물의 손 접촉과 시선을 프롬프트에 우선 적는다.
- `균일한 단일 회색`을 생성 프롬프트와 정밀 편집 프롬프트에 모두 반복해도 이미지 생성 모델이 부드러운 명암을 남길 수 있다.
- 회색 평탄화 정밀 편집이 두 번 연속 실패하면 더 이상 생성 모델에 반복 요청하지 않는다. 구조가 확정된 뒤 별도의 결정적 후처리 단계에서 회색 단계 수를 줄이는 대상으로 기록한다.
- 화면·휴대전화·모니터처럼 텍스트가 많은 평면은 `완전히 빈 화면`으로 요구하면 구조 손실 없이 비교적 안정적으로 제거된다.
- 고정된 장치의 여러 상태는 공통 마스터를 직접 요구하고, 상태 차이는 바늘 각도·피스톤 높이처럼 변경 항목만 열거한다.

## 반복 객체와 생물 단면 직접 재현 규칙

- 반복 입자·세포·구멍이 8개를 넘으면 `총 10개`처럼 총수만 적지 않는다. 화면을 위·가운데·아래 또는 좌·중·우 구역으로 나누고 구역별 개수와 객체 종류를 함께 적는다.
- 서로 다른 종류의 입자가 섞인 경우 전체 개수와 함께 조합별 개수를 분리한다. 예: 흰색-회색 쌍, 회색-회색 쌍을 각각 센다.
- 문자와 점선 경계가 겹친 원본은 `문자·기호만 제거하고 점선 상자와 모든 모서리는 유지`를 불변 조건으로 둔다. 문자 제거 뒤 경계 수를 다시 센다.
- 생물 단면은 기관명을 먼저 붙이지 않는다. 외곽 주머니 수, 관 수, 내부 격벽 수, 방사형 분기 수, 밀집 조직의 위치를 구조 목록으로 작성한 뒤 필요한 경우에만 기관명을 보조 설명으로 쓴다.
- 생물 내부의 물결선·세포·관 다발은 질감이 아니라 구조다. 모델이 장식적 해칭으로 대체하지 않도록 시작점·종점·분기 방향을 명시한다.
- 동물 삽화는 머리 방향, 목과 척추의 굽힘, 부리·손·발의 접촉점, 지면에 닿은 발 수를 우선 고정한다. 주변 식물과 지면 선은 그다음에 기술한다.
- 복합 우주 장치와 기계는 큰 부품 계층을 `주 구조물 → 지지대 → 하부 본체 → 펼쳐진 막` 순으로 적으면 세부가 많아도 실루엣과 연결이 안정적이다.
- 이미지 생성 점수는 구조 일치와 회색 평탄도를 분리해 기록한다. 구조가 통과해도 회색 그라디언트가 남으면 최종 자산 단계에서는 별도 후처리 대상으로 표시한다.

## 반복 개체 슬롯과 연결망 명세 규칙

- 9개 이상의 반복 개체는 총수만 적지 않고 위치 슬롯으로 기술한다. 3×3 배열이면 `상단 좌·중·우, 중앙 좌·중·우, 하단 좌·중·우`처럼 각 자리의 점유 여부를 모두 적는다.
- 불규칙 군집은 화면을 3행 또는 4개 사분면으로 나누고 구역별 개수를 적는다. 생성 후에도 같은 구역 기준으로 다시 세어 하나라도 다르면 구조 실패로 판정한다.
- 분자 격자와 세포 연결망은 원자·세포 수와 함께 각 노드의 연결 차수를 구분한다. 끝점, 두 갈래 노드, 세 갈래 노드의 개수를 별도로 기록한다.
- 점선 결합과 실선 결합이 함께 있으면 두 선을 단순한 스타일 차이가 아니라 별도 연결 종류로 취급한다. 각 점선의 시작·종료 객체를 프롬프트에 쓴다.
- 굵은 혈관·가지·배선과 가는 말단 구조가 함께 있으면 `주 분기 → 2차 분기 → 말단 고리` 순으로 계층을 기술한다. 모든 말단을 한꺼번에 질감으로 묘사하지 않는다.
- 동일 동물이나 장치의 전후 상태는 첫 상태의 실루엣을 공통 마스터로 명시하고, 실제로 달라지는 접촉점·내부 객체 수·회전각만 상태별로 적는다.
- 전자기 장치와 회로는 배선 수를 먼저 고정하고 각 배선에 `시작 단자 → 종료 단자`를 부여한다. 두 선이 화면 중간에서 합쳐져 하나가 되면 실패다.
- 원본 화살표가 제거된 뒤에도 단계 구분이 필요한 경우, 화살표 자리에 빈 여백을 남기고 객체를 서로 붙이지 않는다.

## 소형 핵심 객체 확대 참조 규칙

- 전체 원본에서 긴 변의 약 8%보다 작은 객체가 문항의 핵심이면 전체 이미지 한 장만 참조하지 않는다. 원본 전체와 해당 객체 확대 크롭을 두 장의 참조로 함께 제공한다.
- 첫 번째 이미지는 `전체 구도와 객체 위치 참조`, 두 번째 이미지는 `첫 번째 이미지 속 동일 객체의 세부 구조 참조`로 역할을 분명히 적는다.
- 확대 크롭은 객체 외곽만 자르지 않고 접촉하는 지지대·배선·표면을 조금 포함한다. 객체 정체성보다 접점 위상을 먼저 보존하기 위해서다.
- 작은 객체는 `회색 덩어리`, `샘플`, `부품`처럼 추상적으로 부르지 않는다. 외곽을 원·반원·갈고리·평판 등 기본 형상으로 분해하고 겹침 순서를 적는다.
- 확대 참조가 있어도 전체 장면에서 객체 크기와 위치는 첫 번째 원본을 따른다. 두 번째 크롭의 확대 비율을 장면에 그대로 적용하지 않는다.
- 사진 기반 원본을 선화로 바꿀 때는 사진 질감을 복원하지 않는다. 외곽 실루엣, 큰 내부 구획, 손·도구·바닥과의 접촉점만 선으로 옮긴다.
- 차량과 제품의 문자·로고를 제거한 자리는 빈 흰색 또는 균일한 회색 패널로 두고, 문자 대신 임의의 장식선을 만들지 않는다.
## 확대 참조 사용 시 전체 배율 보존 규칙

- 첫 번째 참조 이미지는 전체 구도·점유율·중심 좌표·여백의 유일한 기준이다.
- 두 번째 확대 이미지는 같은 객체의 국소 형상·접점·겹침 순서만 보충한다. 확대본의 객체 크기를 전체 결과에 적용하지 않는다.
- 확대 참조를 쓰기 전에 원본에서 본체 경계 상자의 좌우·상하 점유율을 기록한다. 생성본의 본체도 같은 비율 범위 안에 둔다.
- 라벨·화살표·지시선을 삭제한 빈 공간을 메우기 위해 본체를 확대하거나 재배치하지 않는다.
- 접점이나 굽힘이 원본 전체에서 이미 식별되는 단순 도판에는 확대 참조를 사용하지 않는다.
- 확대본에는 형상뿐 아니라 필요한 접촉면과 지지 구조를 포함하되, 원본 전체에서의 배율은 별도로 고정한다.

## 선 밀도와 사진 기반 도판의 선화 변환 규칙

- 사진을 선화로 바꿀 때 원본의 검은 면적 비율과 단위 면적당 주요 선 개수를 먼저 맞춘다.
- 섬모·털·염색체처럼 반복되는 미세 구조는 더 또렷하게 보이도록 임의로 늘리지 않는다.
- 외곽선은 내부선보다 약간만 굵게 한다. 작은 생물 단면에 굵은 만화식 외곽선을 사용하지 않는다.
- 사람은 얼굴 묘사보다 머리 방향, 몸통 기울기, 관절 각도, 손·발·도구의 접촉점을 우선한다.
- 복합 장면은 사람 수와 장치 수뿐 아니라 각 객체의 경계 상자, 가림 순서, 지지면 접촉을 함께 고정한다.
## 라벨 제거 후 객체 확대 방지 규칙

- 라벨이 넓은 면적을 차지하는 원본은 라벨을 지운 뒤에도 물리 객체의 원래 경계 상자를 유지한다.
- 단독 생물이나 단독 인물은 원본 캔버스 기준 경계 상자의 왼쪽·위쪽·오른쪽·아래쪽 좌표를 0~1 정규화 값으로 기록한다.
- `원래 위치와 여백을 유지한다`라는 문장만으로 충분하지 않으면 `본체는 화면 너비의 약 35%, 높이의 약 55%만 차지한다`처럼 점유율을 수치로 명시한다.
- 객체가 작게 보이는 것이 원본의 특징이라면 선명도를 높이기 위해 객체를 확대하지 않는다.
- 여러 객체가 있는 도판은 행별 객체 수, 빈 칸의 위치, 객체 사이 간격을 함께 고정한다.

## 의미 보충 화살표 억제 규칙

- 입자·기체·유체·생물 이동처럼 운동이 암시되는 장면은 모델이 원본 화살표를 다시 만들기 쉽다.
- 화살표를 제외할 때는 `화살표 금지`뿐 아니라 `방향 선 0개`, `입자만 표시`를 함께 명시한다.
- 첫 생성에 화살표가 남으면 전체 프롬프트를 바꾸지 않고 해당 방향 표시 제거만 단일 수정 항목으로 재생성한다.
- 단계 도판에서 전환 화살표를 제거한 공간은 비워 두며, 앞뒤 패널을 가까이 붙이지 않는다.

## 정규화 경계 상자 적용 보강 규칙

- 객체마다 원본 캔버스 기준 중심 좌표, 폭, 높이를 0~1 값으로 기록한다.
- 허용 경계 상자만 제시하지 않고, 상자 밖에서 반드시 비어 있어야 하는 금지 점유 영역을 함께 명시한다.
- 라벨을 제거한 자리는 새 부품·연장선·장식으로 채우지 않는다. 해당 여백 자체를 원본 구성 요소로 본다.
- 객체가 여러 개면 전체 경계 상자와 개별 객체 경계 상자를 모두 기록한다. 전체 상자만 맞고 내부 간격이 달라지는 결과는 실패로 판정한다.
- 생성 결과의 객체 폭·높이가 목표값에서 8% 넘게 벗어나면 구조가 맞더라도 배치 실패로 기록한다.

## 세부 밀도 상한 규칙

- 자연물·동물·사진 기반 도판은 원본보다 더 많은 비늘, 털, 발톱, 지면선, 미세 균열을 추가하지 않는다.
- 반복 무늬는 원본에서 대표 행 또는 대표 구역의 개수를 세어 상한으로 명시한다.
- 높은 선명도는 선 개수 증가가 아니라 외곽선의 끊김 제거와 주요 접점 보존으로 확보한다.
- 원본이 작은 도감형 삽화이면 생성물도 같은 점유율과 선 밀도를 유지하며, 화면을 채우는 일러스트레이션으로 확대하지 않는다.

## 의미선 완전 제거 규칙

- 화살촉이 없는 광선·전자선·전류선·운동 경로도 의미선으로 분류한다.
- 의미선을 제거할 때는 `화살표 0개`와 별도로 `광원과 표적 사이 선분 0개`, `입자 사이 연결선 0개`처럼 시작점과 끝점을 지정해 수량을 0으로 고정한다.
- 물리적인 전선·줄·관과 의미선을 혼동하지 않도록 유지할 연결은 시작 부품과 종료 부품을 함께 적는다.
- 의미선 제거 뒤 생긴 공간에는 새 전선이나 장치 외곽을 연장하지 않는다.

## 사람과 줄이 있는 역학 도판의 안전 문맥 규칙

- 실제 원본이 안전한 교실 시범이면 학생이 발판에 서 있고 손으로 줄 끝을 잡는다는 접점을 명시한다.
- 줄이 목·머리·몸을 감싸지 않고 옆으로 충분히 떨어져 있다는 사실을 명시한다.
- 매달림·추락·구속·상해가 없는 정적 역학 시범임을 분명히 하며, 원본에 없는 위험한 자세를 추가하지 않는다.
- 안전 문맥을 추가하더라도 원본의 손 위치, 도르래 위치, 발판 연결 구조를 변경하지 않는다.

## 불규칙 층 경계 앵커 규칙

- 지질·지구 내부 단면의 불규칙 경계는 이름이 아니라 경계가 만나는 외곽선·층 경계·중심선의 접점 좌표로 기록한다.
- 각 불규칙 영역에 대해 왼쪽 끝, 오른쪽 끝, 최고점, 최저점과 인접 층 접점의 정규화 좌표를 고정한다.
- 동심층 수가 맞더라도 불규칙 영역의 면적이나 접점이 크게 달라지면 구조 실패로 판정한다.

## 넓은 회색 면 평탄도 검사

- 액체·도로·단면처럼 넓은 회색 면은 내부 밝기 변화가 거의 없는 단일 농도인지 확인한다.
- 동일 재료 영역 안에 광원 방향을 암시하는 그라디언트가 생기면 생성 성공과 별개로 보정 대상으로 표시한다.
- 서로 다른 재료를 구분할 때만 2~3단계의 평면 회색을 사용하며, 한 재료 내부에는 농도 단계를 추가하지 않는다.

## 사진형 피사체 점유율 강제 규칙

- 사진형 원본은 피사체 전체 경계 상자뿐 아니라 피사체의 검은 선·회색 면이 캔버스에서 차지하는 면적 비율을 기록한다.
- 피사체와 캔버스 네 변 사이의 최소 여백을 각각 0~1 정규화 값으로 고정한다.
- 라벨 제거 뒤 남는 여백이 넓으면 `빈 영역`이 아니라 `금지 점유 영역`으로 지정하고 최소 폭을 수치로 명시한다.
- 작은 동물·제품·장면을 선명하게 보이게 한다는 이유로 확대하지 않는다. 원본 점유율보다 8% 이상 커지면 형태가 좋아도 배치 실패다.
- 사진을 선화로 변환할 때 영웅 구도, 도감 삽화, 제품 중심 구도로 재구성하지 않는다.

## 분리 액체 영역 규칙

- 연결관·염다리·밸브로 연결된 여러 용기는 물리적 연결과 액체 영역의 분리를 따로 기록한다.
- 용기 수, 액체면 수, 서로 닿지 않아야 하는 액체 영역 수를 각각 명시한다.
- 독립 용기 사이에는 원본과 같은 흰 간격의 최소 폭을 지정한다.
- 연결 부품 아래나 주변에서 회색 액체 면이 이어져 하나의 넓은 면으로 보이면 위상 실패로 판정한다.

## 빈 부품 면 유지 규칙

- 라벨을 제거한 계기 화면, 스크린, 전극, 전원 상자, 용기 면은 완전히 빈 물리적 면으로 유지한다.
- 빈 면에 눈금·문자 비슷한 선·점·광점·반사 무늬를 보충하지 않는다.
- 빈 면의 외곽과 연결 단자는 보존하되 내부 정보는 0개로 지정한다.

## 교과서 사진·복합 조판 변환 규칙

- 입력 크롭에 본문, 표, QR 코드, 안전 아이콘이 함께 남아 있어도 크롭 전체를 장면으로 해석하지 않는다. 생성 전에 `남길 과학 대상`을 명시적인 폐쇄 목록으로 작성하고 목록 밖 요소는 모두 제거한다.
- 사진 실험 장치는 제품 외형보다 `받침 → 지지대 → 고정부 → 작동부 → 용기 또는 시료`의 물리적 지지 관계를 먼저 보존한다.
- 사진 배경을 제거한 뒤에도 장치의 원래 좌우 순서와 수직 정렬을 유지한다. 빈 공간을 새 받침, 케이블, 장식선으로 채우지 않는다.
- 사진형 자연물은 원본의 모든 질감을 선으로 옮기지 않는다. 외곽 실루엣과 문제 풀이에 필요한 대표 내부 특징만 남긴다.
- 공동·균열·반점처럼 불규칙 특징이 핵심이면 전체 개수 범위, 회색으로 채울 개수, 보조 윤곽선 수를 각각 숫자로 제한한다.
- 인물이 장치를 관찰하는 장면은 얼굴 묘사보다 눈높이, 시선 방향, 몸의 기울기, 손과 지지면의 접촉을 우선한다.
- 인물과 장치가 함께 있을 때 장치가 지나치게 작아지지 않도록 각 객체의 화면 점유율을 별도로 고정한다. 인물은 머리·어깨·필요한 손만 남기는 축약 표현을 허용한다.
- 사진에서 선화로 변환한 넓은 면은 생성 결과와 무관하게 최종 단계에서 `검정·단일 회색·흰색` 3단계 팔레트로 정규화한다.
- 3단계 정규화 뒤 물·단면·깊은 공동처럼 의미가 있는 회색이 사라지면 해당 영역만 명세에서 회색 허용 대상으로 다시 지정한다.
- 동일 객체의 수정본은 이전 결과를 보존하고 `v1`, `v2`로 기록한다. 최종 비교판에는 채택한 최신 결과만 넣는다.

## 생물 구조·상태 비교 규칙

- 확대 계층도는 단계 수와 단계별 객체 수를 고정하고, 각 단계가 다른 장기로 오인되지 않도록 `외곽 실루엣 + 절단면 수 + 대표 내부 구조`를 함께 지정한다.
- 관형 기관의 절단도는 관의 양쪽 끝, 내강, 내벽 주름이 동시에 보여야 한다. 위처럼 닫힌 주머니형 실루엣으로 바뀌면 구조 실패다.
- 반복 융털·폐포·세관은 대표 개수 또는 허용 범위를 명시한다. 반복 무늬를 배경 질감처럼 무한히 늘리지 않는다.
- 두 상태 비교는 객체 수, 시점, 크기, 정렬을 완전히 동일하게 두고 변화 대상만 크기·위치·곡률로 구분한다.
- 폐 상태 비교에서는 폐 외곽과 가로막 곡선이 주 정보다. 늑골과 척추는 이를 가리지 않는 얇은 보조선으로 제한한다.
- 여러 기관 자산을 한 판에 놓을 때 `문자·숫자·기호·화살표·지시선 0개`를 각 셀에 독립적으로 적용한다.
- 해부 단면의 회색은 피질·수질·내강처럼 문제 풀이에 필요한 한두 영역만 허용한다. 장기 전체를 입체 명암으로 채우지 않는다.

## 전기·자기 장치 규칙

- 회로는 부품 목록보다 `단자 수·접점 상태·분기 수·케이블 시작점과 종단`을 먼저 고정한다.
- 전선은 장치 뒤에서 임의로 사라지지 않게 하며, 각 선의 양끝이 어느 단자에 닿는지 검수한다.
- 같은 회로의 상태 비교는 전원·전구·저항·지지대 형상을 동일하게 유지하고 스위치 접촉 상태만 변경한다.
- 검전기 반복 그림은 용기, 마개, 금속판, 금속 막대의 크기와 시점을 고정하고 금속박 각도만 상태 변수로 둔다.
- 코일은 일정 간격의 반복선으로 단순화하되 시작 단자와 끝 단자를 보존한다.
- 나침반과 계기 바늘은 화살촉 없는 양끝 막대로 그린다. 방향 정보는 사용자가 후처리하므로 N·S 문자와 방향 화살표를 넣지 않는다.
- 전원 장치와 계기 화면은 빈 사각 면으로 두고 눈금, 숫자, 파형, 문자형 흔적을 생성하지 않는다.
- 여러 상태판에서는 장치의 공통 형상을 복제 수준으로 맞추고 자석 위치, 스위치 접점, 바늘 각도처럼 지정된 변수만 바꾼다.

## 참조 이미지 의미 고정 규칙

- 생성 전에 참조 크롭 자체를 시각 확인하고 `실제로 보이는 핵심 객체`, `객체 수`, `배치`, `삭제 대상`을 기록한다.
- PDF 쪽수, 인쇄 쪽수, 파일명, 단원 제목만으로 목표 대상을 추론하지 않는다.
- 프롬프트가 참조 크롭과 다른 대상을 설명하면 그림의 완성도와 무관하게 변환 실패다.
- 복합 페이지는 남길 영역을 먼저 자르거나, 남길 객체를 폐쇄 목록으로 제한한다.
- 천체 사진의 검은 배경과 별빛은 제거하고 흰 배경 위에 천체 외곽, 띠, 고리, 대표 표면선만 옮긴다.
- 암석·지층 사진은 층리선과 주요 균열의 허용 개수를 명시하며, 사진의 모든 질감을 선으로 복제하지 않는다.
- 우주 장비는 태양 전지판 수, 안테나 종류, 바퀴 수, 지지 다리 수처럼 실루엣을 결정하는 부품만 보존한다.

## 화학 입자·용액 규칙

- 입자 모형은 상태 수, 입자 종류 수, 각 종류의 개수, 결합 여부를 생성 전에 기록한다.
- 전후 비교에서 중간 상태를 임의로 추가하지 않으며, 변하지 않는 입자는 위치와 개수를 고정한다.
- 입자 종류는 흰색과 단일 회색 또는 외곽 모양으로만 구분하고 원소 기호·전하 기호는 넣지 않는다.
- 액체 회색은 용기 경계 안에서 하나의 수평면 아래에만 존재해야 한다.
- 원본에 없는 가열판, 시약병, 센서, 전선 등 표준 실험 부품을 문맥상 추정해 추가하지 않는다.
- 확대 입자 삽화는 실제 물체와 분리된 원형 자산으로 두며 연결 화살표는 생성하지 않는다.

## 빛·파동 장면 규칙

- 거울, 수면, 스크린은 경계선이 우선이며 넓은 장식 회색을 사용하지 않는다.
- 반사·굴절 장면의 광선은 사용자가 후처리하므로 기본 그림형에서는 생성하지 않는다.
- 파면이 대상 자체인 경우에만 화살촉 없는 일정 간격 곡선을 제한된 개수로 허용한다.
- 자산판의 셀 번호와 캡션도 숫자·기호 금지 대상이다.
- 사람은 관찰 방향, 손과 장치의 접촉, 수면에 대한 위치처럼 물리 관계에 필요한 자세만 남긴다.
- 반복 거울 상태는 거울과 물체 크기를 고정하고 물체 거리와 반사상 크기만 변경한다.

## 지질·자연 경관 규칙

- 층리, 절리, 공동, 균열, 자갈은 허용 개수 또는 범위를 명시해 사진 질감의 무한 복제를 막는다.
- 암석 식별에 필요한 결정립, 층상 구조, 기공, 유리질 파단 중 해당 특징만 남긴다.
- 전경·중경·배경은 회색 농도 차이보다 외곽 겹침, 기준 수면, 지표선으로 구분한다.
- 수면은 하나의 수평 경계와 단일 회색 영역으로 제한하며 반사광을 넣지 않는다.
- 지층 단면은 넓은 띠 수를 제한하고, 띠 내부에 추가 명암이나 무늬를 채우지 않는다.
- 장 표지 사진은 목표 삽화가 아니다. 최종 참조 미리보기에서 목표 객체가 실제로 보이는지 확인한다.
- 최종 후처리 팔레트는 검정·중간 회색·흰색의 3단계 (`0, 176, 255`)로 고정한다. 흰색 강제 기준은 밝기 242 이상이다.

## 반복 상태·액체층·사진 동작 보존 규칙

- 반복 상태 도판은 첫 용기의 외곽, 크기, 액면 높이를 공통 형상으로 고정한 뒤 실제로 변하는 요소만 바꾼다.
- 서로 다른 입자 종류는 회색 농도에 의존하지 않고 크기, 채움 여부, 윤곽 모양 중 하나로 구분한다.
- 입자 수가 의미를 가지면 종류별 허용 개수 또는 증가·감소 관계를 생성 전에 기록한다.
- 흰색 액체층도 빈 공간과 구분되도록 상면과 하면의 경계를 모두 닫아 그린다.
- 여러 액체층이 있는 용기는 빈 머리 공간과 각 액체층을 별도 영역으로 세어 검수한다.
- 사진 속 손과 사람은 얼굴이나 의복의 사실성보다 도구를 잡는 위치, 접촉점, 힘을 가하는 방향이 드러나는 자세를 보존한다.
- 전자 장치의 화면·버튼·눈금판은 본체 형상만 남기고 모든 문자와 숫자를 제거한 무표기 면으로 만든다.
- 관·전선·실은 시작점, 접속부, 굽힘 구간, 종단 위치가 하나의 끊기지 않은 구조인지 검수한다.
- 원본 자르기에 본문·표·말풍선이 포함되면 생성 전에 보존할 과학 대상과 제거할 조판 요소를 각각 명시한다.
## 잘린 구도·자연물·해부 그림 보존 규칙

- 참조에서 물체 일부가 화면 밖으로 잘린 구도는 의도된 구성으로 취급한다. 이를 완전한 원형·전신·제품 전체 모습으로 복원하지 않는다.
- 생성 전에 주요 물체마다 참조 화면 기준 경계 상자와 잘린 변을 기록한다.
- 꽃, 줄기, 잎 무리, 암석, 혈구, 입자처럼 반복되는 독립 객체는 허용 개수 또는 허용 범위를 기록한다. 빈 배경을 장식하기 위해 개수를 늘리지 않는다.
- 인체 그림은 사람 실루엣과 장기를 별도 객체로 기록한다. 주요 장기 덩어리와 몸통·갈비뼈·피부 단면 등 문제 해석에 필요한 주변 맥락을 일반적인 해부 아이콘으로 대체하지 않는다.
- 확대 원, 확대 삽화, 별도 상세 패널이 과학 구조를 설명하면 라벨이 제거되더라도 해당 상세 영역 자체는 보존 대상이다.
- `알아볼 수 있음`은 통과 기준이 아니다. 객체 개수, 경계 상자, 잘림, 연결 위상 중 하나가 크게 다르면 구조 실패다.
## 색상 정보 제거와 희소 표식 보존 규칙

- 참조의 색을 제거하기 전에 각 색이 단순 장식인지 과학적 범주·상태·종류를 구분하는 정보인지 판정한다.
- 색이 범주를 구분하면 흑백 변환에서 `채운 도형/빈 도형`, `서로 다른 외곽 모양`, `단일 평면 회색/흰색` 중 하나로 대응시킨다. 서로 다른 범주를 같은 빈 원으로 합치지 않는다.
- 별, 점, 입자, 전자처럼 작은 표식이 과학 데이터라면 강조색 표식만 세지 말고 전체 표식의 개수와 위치를 보존한다.
- 원샷 결과에 남은 유채색, 광휘, 방사형 그라디언트, 번짐은 정규화 전 단계의 실패다. 정규화로 제거되더라도 원샷 통과로 바꾸지 않는다.
- 천체 밝기는 원의 크기, 평면 채움, 한 단계 회색 중 필요한 최소 수단으로만 구분한다. 빛무리, halo, bloom, soft glow를 사용하지 않는다.
- 희소 선 도식은 선분을 장식이 아니라 연결 위상으로 본다. 생성 전에 각 선의 시작 객체와 끝 객체를 edge list로 기록한다.
- 인쇄 카드, 이름 칸, 설명 상자는 제거할 수 있다. 제거한 영역을 질감·점묘·장식선으로 채우지 않는다.
## 범주 구분용 흑백 패턴 제한

- 색으로 구분된 범주를 흑백으로 옮길 때 우선순위는 `채움/비채움`, `외곽 모양`, `검정·평면 회색·흰색` 순서다.
- 점묘, 사선 해칭, 교차 해칭을 넓은 광선·액체·기관 영역의 범주 구분 수단으로 사용하지 않는다.
- 여러 범주가 겹치는 장면은 겹침 영역을 추가 무늬로 채우기보다 경계선과 최대 두 단계 평면 회색으로 구분한다.
- 범주 정보 보존 검사와 평가원식 스타일 검사는 별도 게이트다. 범주가 맞아도 과도한 무늬를 사용하면 통과하지 않는다.
- 자연 표면의 구멍·반점·요철은 형태를 결정하는 큰 영역만 제한적으로 남기고 모든 사진 질감을 폐곡선으로 추적하지 않는다.
## 설명 상자와 고범주 색상 도식 처리

- 라벨 문자와 함께 존재하는 설명 상자, 말풍선, 지시선용 빈 프레임은 문자를 제거할 때 함께 제거한다.
- 화면, 계기판, 용기, 물리적 경계가 아닌 빈 사각형을 장치 부품처럼 남기지 않는다.
- 스펙트럼처럼 색 범주가 많아 검정·회색·흰색만으로 안정적인 대응이 어려우면 생성 전에 범주별 선 종류·간격·외곽 모양 대응표를 만든다.
- 대응표 없이 여러 색 띠를 동일한 검은 띠로 합치지 않는다. 범주 보존이 불가능하면 자동 통과 대상에서 제외한다.
- 분자·입자 군집은 전체 원형 외곽보다 범주별 개수와 인접 관계를 우선해 보존한다.
