1. 튜토리얼의 목표

사용자가 실제 작업 화면 위에서 “어디를 누르고, 어디에서 그리고, 어떤 결과를 만들어야 하는지”를 단계별로 확인하고 따라 하게 한다.

단계 안내→대상 강조→동작 시연→사용자 실행→완료 피드백

3. 핵심 효과 상세 정의

효과언제 표시하는가어떻게 보이는가사용자에게 말할 문장상태
대상 강조선
tut-halo		target으로 실제 UI를 찾았을 때클릭 대상 주위 파란 테두리·광택. 창 크기와 스크롤을 따라 재배치“파란 대상 강조선이 표시된 직선 도구를 클릭하세요.”구현됨
보조키 안내 배지
tut-modkey		demo.mod가 있을 때Ctrl 누른 채를 작업 영역 위 파란 캡슐로 표시. 위가 좁으면 아래로 이동“보조키 안내 배지를 보고 Ctrl을 누른 채 두 점을 클릭하세요.”구현됨
목표 형상 가이드
guide.shape		최종 오브젝트의 모양·크기·비율이 중요한 캔버스 단계사각형·원·삼각형·꺾은선·경사면·치수선·화살표의 반투명 실루엣“유령 커서의 경로를 따라 목표 형상의 크기와 비율에 맞춰 완성하세요.”신규 구현
핵심 구분: 대상 강조선은 “어디를 클릭할지”, 작업 위치 가이드선은 “어디로 움직일지”, 목표 형상 가이드는 “무엇을 완성할지”를 보여준다. 보조키 안내 배지는 버튼이 아니라 입력 조건 표시다.

4. 한 단계의 동작 기준

순서질문판정 기준
1무엇을 설명하는가?코치창에 제목·본문·실행 안내를 표시한다.
2어디를 조작하는가?target으로 DOM을 찾고 대상 강조선을 표시한다.
3어떻게 조작하는가?demo로 유령 커서, mod로 보조키 배지를 표시한다.
4캔버스에서는 어디에 하는가?guide로 작업 위치 가이드선을 표시한다.
5어떤 모양을 만드는가?shapeGuide로 목표 형상 실루엣을 표시한다. 추가 구현 대상이다.
6언제 성공인가?wait.click·wait.until 등 실제 동작으로 판정한다.

5. 목표 형상 가이드

유령 커서가 선을 따라 움직이는 것만으로는 최종 결과의 크기·비율·범위를 알기 어렵습니다. 작업 경로와 결과 실루엣을 함께 보여줍니다.

권장 개념: path는 어디로 움직일지, shape는 무엇을 만들지 나타낸다.
요구 범위
  • 직선: 방향·길이·정렬
  • 사각형·원·삼각형: 최종 크기·비율·범위
  • 꺾은선·경사면: 꼭짓점과 연결 순서
  • 치수선·화살표: 기준점·방향·화살촉
  • 이미지 추출·배열: 선택 영역과 결과 배치 영역
제안 데이터

guide: () => ({ path: { pts: [[-20,10],[20,10]] }, shape: { type: "rect", x:-12, y:-8, w:24, h:16 } })

6. 성능 기준

튜토리얼이 꺼져 있을 때는 기존 렌더 루프에 상시 개입하지 않습니다. 실행 중에만 80ms 상태 판정·대상 위치 재계산·필요한 커서 애니메이션이 동작합니다.

  • 가이드선은 저장 객체에 넣지 않아 작업물·내보내기·실행취소에 영향을 주지 않는다.
  • 종료 시 interval·animation frame·이벤트·오버레이를 정리한다.
  • 복잡한 wait.until 객체 순회와 그래프/이미지 단계의 DOM 측정을 확인한다.

7. 요청서에 사용할 문장

“클릭해야 하는 UI 요소에는 대상 강조선을 표시하고, Ctrl·Shift 입력이 필요한 단계에는 보조키 안내 배지를 표시한다. 캔버스 작업에는 작업 위치 가이드선과 목표 형상 가이드를 함께 표시하며, 사용자의 실제 동작은 유령 커서로 한 번 시연한다. 단계 설명과 진행 버튼은 코치창에 표시하고, 성공 시 완료 피드백을 보여준다.”

UI 테두리는 대상 강조선, 캔버스 경로는 작업 위치 가이드선, 결과물 윤곽은 목표 형상 가이드로 구분한다.
