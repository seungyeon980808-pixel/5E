# 물리 기출 그래프 실제 평가

## 평가 계약

처음 보는 물리 기출 그래프 20개를 먼저 고정하고 `gpt-6.1-sol / medium`으로 각 1회 요청한다. 기존 제출 원본과 SHA-256으로 중복을 확인한다. 최초 응답, 원본, 네이티브 결과, 실제 토큰 및 실행 시간을 보존한다. 수동 plan 보정이나 자동 재시도로 최초 성공률을 바꾸지 않는다.

먼저 직선·수평 구간, 파동, 실선·점선의 두 계열 3개를 실행해 실제 연결과 제품 작업대를 확인한다. 이 3개를 20개에 포함한다. 나머지는 독립 실행 기록으로 최대 동시 2개를 처리한다. 원본에 함께 있는 장치·문제 본문·패널 번호는 복원 대상에서 제외하지만 원본 전체는 보존한다.

## 실행

`tools/evaluate-physics-graphs.mjs`는 실제 제품 작업대에서 업로드·복원 버튼·드래그 비교·더블클릭·편집·삽입·실행 취소·`.5e` 다운로드와 재열기를 검증한다. 평가용 연결기는 인증된 로컬 Codex App Server에 실제 요청과 이벤트를 전달한다. 합성 응답을 사용하지 않는다. 설치 앱의 Electron IPC와 배포 웹 인증은 별도 검증이다.

필수 환경 변수는 `PHYSICS_GRAPH_REAL=1`, `PHYSICS_GRAPH_MANIFEST`, `EVIDENCE_DIR`다. 재시험은 별도 기록 디렉터리와 `PHYSICS_GRAPH_PASS=2` 또는 `3`으로 표시한다. 최초 성공률에 합산하지 않으며 총 3차를 넘지 않는다. 선택 실행은 `PHYSICS_GRAPH_CASES`에 manifest ID를 쉼표로 지정한다. `PHYSICS_GRAPH_VALIDATE_ONLY=1`은 파일·해시·고정 설정·재실행 가드를 검증하며 모델을 시작하지 않는다. `CODEX_BINARY`, `PLAYWRIGHT_MODULE`, `PREVIEW_URL`은 실행 환경에 맞춰 지정한다. 기존 원본별 실행 디렉터리가 있으면 유료 재실행을 거부한다.

manifest는 모델·effort, 서로 다른 원본 20개, 원본 해시, 과거 제출과의 비중복, 원본별 scope 지시를 포함한다. 소규모 설정 비교는 `expectedCount`를 명시한 1~20개만 허용하며, 생략하면 기존 20개 검증을 유지한다. 추출 프롬프트에 사례별 정답 좌표나 함수식을 넣지 않는다. 검증의 오류 응답도 실패로 보존한다.

`tools/report-physics-graphs.mjs`는 `PHYSICS_GRAPH_EVIDENCE` 아래 실행 기록을 모아 `OUTPUT_DIR`에 같은 원본 좌표의 비교 HTML·PNG, SVG, 편집 문서와 전체 기록을 만든다. 원문 응답을 수정하거나 모델을 호출하지 않는다. `PHYSICS_GRAPH_REFINED`에 재시험 배치 폴더들의 상위 폴더를 지정하면 첫 결과를 유지한 채 재복원을 세 번째 그림으로 표시한다. `refined-review.json`에는 id·evaluationPass와 시각 판정을 기록한다. 그래프 영역을 자른 비교는 화면 표시이며 모델에 보낸 원본과 별도다.

## 판정

- 구조 검증: source 바인딩·JSON 계약·네이티브 객체 생성.
- 편집 검증: 실제 작업대 결과 비교·취소, 네이티브 삽입, 무변경 적용, 표기 수정·undo/redo, 실제 `.5e` 파일 재열기에서 원래 필드 보존.
- 시각 검수: 원본 대비 곡선·정점·극값·교점·평탄/불연속 구간, 축·눈금·표기, 점/선/보조선/화살표·영역.

시각 판정은 `usable`(주요 관계와 필수 표기 보존), `needs-review`(누락·왜곡·스타일 조정 필요), `failed`(응답/구조 실패), `blocked`(표현 제한으로 차단)를 사용한다. 편집 검증 통과를 원본 일치로 집계하지 않는다. 글꼴 서체 차이는 유보하지만 표기 내용·크기·정자 여부는 검수한다.

처리 시간이 짧다는 이유로 품질 합격을 부여하지 않는다. 원본 관찰 좌표는 정확한 물리량 데이터 회수로 주장하지 않는다. 출력 토큰에는 공급자의 추론 토큰이 포함될 수 있으므로 추론 토큰을 별도로 더해 이중 집계하지 않는다. 이 인증은 ChatGPT 플랜 사용량이며 API 요금으로 환산해 실청구액이라고 보고하지 않는다.

## 남은 제품 연결

2026-10-06 관찰에서 셸의 Codex CLI 0.153.2는 Sol 6.1을 목록에 제공하지 않았고 앱에 포함된 0.160.0은 제공했다. 평가는 사용 가능한 후자를 명시해 실행한다. 제품의 고정 모델 미지원 차단은 유지하며, 설치 앱이 실제로 사용하는 CLI와 배포 웹 공급자의 지원 상태도 출시 전에 확인해야 한다. 전역 CLI 설치나 사용자 설정을 평가에서 임의로 변경하지 않는다.

## 2026-10-06 첫 평가와 하네스 보완

실제 20개 요청의 모델/effort 이벤트를 대조했다. 네이티브 결과 및 비교·더블클릭·편집·실행 취소·저장·재열기는 19/20 통과했다. 첫 응답 시각 검수는 사용 가능 14, 조정 필요 5, 표현 제한 1이다. 이는 실행 에이전트의 원본 대조이며 독립 평가나 픽셀 완전 일치가 아니다. 첫 검수에서 물체 A를 축 아래첨자로 오독한 사례는 원본 재대조 후 정정했고 이력도 보존했다.

표현 제한 사례는 물결 표시로 축 구간을 생략한 `axis-break`였다. 모델은 정상 완료하고 제한을 식별했지만 엔진은 삽입을 차단했다. 평가 도구가 차단 문구를 완료로 감지하지 못해 270초를 기다렸으므로 이 기록은 분석 타임아웃으로 해석하면 안 된다. 원본 실행 기록은 유지하고 이후 평가에서 공급자 완료 이벤트와 작업대 종료를 함께 확인하도록 변경했다.

추출 버전 v10은 첨자 보존, 실제 인쇄된 보조선의 범위, 축/보조선 교차점에서의 곡선 접선과 관찰점 추적을 강화한다. 캐시 버전을 올려 이전 추출 결과를 새 결과로 재사용하지 않는다. 일반 대화 요청 대신 기존 JSON-scene 전용 임시 요청을 사용한다. 이전 대화를 재개하거나 이미지 생성 도구를 호출하지 않는다. 모델은 여전히 Sol 6.1 / medium으로 고정한다.

재시험은 조정 필요 5개와 정상 직선 대조군 1개로 구성한다. 별도 2차 기록과 같은 원본 해시를 사용하며 정답 좌표·함수·수정 plan을 제공하지 않는다. 원본 응답에 대한 수동 데이터 보정은 0회다. 입력/출력 토큰·시간과 시각 품질을 첫 응답과 함께 보고한다.

2차 재시험 6개는 네이티브 생성 및 편집/저장/재열기 6/6, 실행 에이전트 시각 대조 6/6 사용 가능으로 판정했다. 최초의 조정 필요 5개에서 교차점 어깨 또는 보조선 연장 차이가 개선됐다. 같은 6개를 비교한 입력 토큰은 144,308 → 115,492(약 20.0% 감소), 평균 요청 시간은 94.3 → 59.6초다. 프롬프트와 요청 프로필을 함께 바꾼 관찰 결과이며 각각의 인과 효과나 향후 보장값은 아니다.

전체 실제 요청은 26회다. 첫 20회 입력 505,064 / 출력 51,547 토큰, 별도 2차 6회 입력 115,492 / 출력 9,071 토큰이다. 26회 모두 실제 공급자 설정 이벤트에서 Sol 6.1 / medium을 확인했다. 세 번째 반복은 추가 문제 근거가 없어 실행하지 않았다. 축 생략은 모델 교체/프롬프트만으로 해결된다고 주장하지 않으며 엔진 지원 확장이 필요하다. 설치 앱 IPC·배포 웹 인증 및 튜닝 후 새로운 미사용 표본 평가도 남는다.

## 추가 개선 2회: 비용 비교와 새로운 표본

2026-10-06 사용자 승인에 따라 두 추가 개선 주기를 완료했다. 과거 제출에서 수집한 52개 원본 해시와 21개 문항 ID를 제외한 물리 기출 10종을 4종/6종으로 나눴다. 이는 로컬 제출 기록에 대한 비중복이며 모델의 학습 여부를 뜻하지 않는다. 사례별 정답 좌표를 주거나 응답 plan을 손으로 고치지 않았다. 실제 요청은 추가 18회이고 사례별 최대 3회다.

1차 주기는 같은 새 원본 4개에 긴 v10과 간결한 v11 필드 참조를 각각 요청했다. 네이티브·편집 결과는 3/4 → 4/4, 시각 사용 가능은 2/4 → 3/4였다. v10의 순환 그래프는 닫힘 화살표가 없는 구간 번호를 가리켜 계약 검증에서 실패했다. 간결 프롬프트는 마지막 닫힘 구간을 실제 점 쌍으로 표현하도록 명시했다. 같은 4개 입력 토큰은 76,913 → 67,961(11.6% 감소), 평균 시간은 55.2 → 55.0초다. 속도 개선으로 해석하지 않는다. 1회씩 비교한 소규모 관찰이며 통계적 우월성이나 미래 비용 보장이 아니다.

## 고정 설정 새 20종과 실제 IPC 후속 (2026-10-06)

로컬 선행 제출 62개 해시 및 기존 문항 ID를 제외한 새 물리 기출 20종을 같은 일반 지시·간결 프롬프트 v16·Sol 6.1 / medium으로 한 번씩 요청했다. 문항별 정답 좌표, 수동 plan 보정, 자동 재시도는 없다. 이는 선행 제출과의 비중복이지 모델의 학습 여부를 의미하지 않는다. manifest의 frozenPromptVersion을 첫 평가에서 검증해 실행 중 설정 변경을 막는다.
