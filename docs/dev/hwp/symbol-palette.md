# 특수기호 팔레트 근거 — 최근 3년 평가원 기출 기호 빈도

팔레트 코드: `js/rhwp-exam-symbols.js`(`SYMBOL_ROW` 첫 줄 16칸, `SYMBOL_TABS` 묶음 탭, `SYMBOL_CHUNKS` 조각, 최근 쓴 기호 8개는 브라우저 localStorage에만). 아래 분석 결과가 **반영됨**.

## 1. 한눈에

- 본문 글자로 쓰인 특수기호는 **69종뿐**(2024~2026학년도 6월·9월 모평·수능 × 물리·화학·생명·지구과학 Ⅰ·Ⅱ = PDF 72개, 1,440문항, 31,027자). 옛 hwpPalette 목록 425개 중 한 번이라도 나온 것은 56개.
- 키보드로 못 치는 본문 기호 14,330자의 약 92%(13,230자)를 **16칸**이 덮는다.
- 옛 목록에 없던 상위 기호: ◦(854회), ～(전각 물결, 821), ＋·－·＝(전각), ㉮㉯㉰, ㎛, ∙ ․ ･. **◦ ⇄ ∙ ․ ･는 완성형(KS X 1001) 밖 글자**라 한글 문자표 「유니코드」 탭을 뒤져야 하므로 팔레트의 가치가 가장 크다.
- 평가원은 ℃ × ○ → ° 그리스 문자를 **대부분 수식 편집기 안에** 넣는다(℃ 282회 중 본문 글자 0회). 수식 없이 글자로 치게 하려면 「과학·단위」 탭에 있어야 한다.

## 2. 센 방법 (재현·판단용)

| 항목 | 내용 |
|---|---|
| 자료 | 평가원 원본 PDF(한글에서 내보낸 것), 문항별 쪽·상자 좌표 카탈로그(8,420문항). 2027-6월 PDF 8개는 참고 열로만 |
| 글자 추출 | PyMuPDF로 글자마다 글꼴·크기·위치. 5E 출제 칸의 기출 글자 자료는 공백이 뭉개지고 글꼴 정보가 없어 쓸 수 없었음 |
| 수식/본문 구분 | 수식 글꼴(`HyhwpEQ`) 글자는 전부 「수식 안」으로 따로 집계. 수식 글꼴은 숫자·로마자·그리스 문자를 사용자 정의 영역(U+E000대)에 두므로 86종을 그림으로 판독 |
| 특수기호 정의 | 본문 글꼴 글자 중 한글 음절·영문·숫자·공백·`. , ? ! : ; ( ) [ ] ' "` 외 전부. ㄱㄴㄷ 낱자는 표지라서 포함 |
| 첨자 | 글자 크기 8.4pt 이하(본문 11.2pt의 75%). 대부분 이온 전하(Na＋) |
| 한계 | 학력평가 미집계, 2027-9월 없음, PDF ToUnicode 대응표를 믿음(◦ ∙ ․ ･는 실제 한글 파일의 글자와 다를 수 있음 → 팔레트에 넣기 전 한글 문자표에서 모양 확인), 그림 속 글자 포함, 문항 상자 밖 약 570자 누락, 표 안 작은 글씨(9.2~9.6pt)는 첨자로 안 침 |

## 5. 한글 입력 난이도 (왜 팔레트가 필요한가)

| 구분 | 기호 | 한글에서 넣는 법 |
|---|---|---|
| 키보드로 바로 | ㄱㄴㄷ, < >, %, /, -, ~, +, = | 그대로 |
| 완성형 안 | ① ~ ⑤, ㉠~㉥, ⓐ~ⓕ, ㉮~㉰, Ⅰ~Ⅵ, ～ ＋ － ＝, ‘ ’, ′, →, ㎛, Ω, °, ℃, ×, ○, …, ※, ∼ | 자음+한자 키·문자표 「한글(KS)」, 2~4번 클릭 |
| **완성형 밖** | ◦ U+25E6(854) · ⇄ U+21C4(32) · ∙ U+2219(23) · ․ U+2024(20) · ･ U+FF65(12) · ⋮ U+22EE(4) · ◯ U+25EF · — U+2014 · ≳ U+2273 | 문자표 「유니코드」 탭에서 블록을 알아야 찾음 → 팔레트 우선 |

옛 목록(425개)에 없던 기출 기호 18종: ◦ ～ ＋ － ＝ ㉮ ∙ ㉯ ․ ㎛ ㉰ ･ ⋮ Ω(U+2126) ＞ ◯ — ≳. 옛 목록엔 ~ ∼ ·는 있었지만 평가원이 실제 쓰는 ～ ◦ ∙ ․는 없었다. Ω는 U+03A9(9회)·U+2126(4회) 두 가지로 나옴.
