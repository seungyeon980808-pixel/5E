# 조판 기준 (Typeset Standard)

문항 카드(내용)와 **조판 기준**(모양)을 나눈다. 조판 기준 = 용지·본문 글자·요소 간격·요소 모양·줄 맞춤·잠금 기본값을 담은 이름 붙은 묶음. 내장 「수능 틀」(고칠 수 없음, 복제 가능) + 학교 양식에서 만든 기준을 저장·불러오기·파일로 주고받는다.

구현 상태: 아래 5단계 모두 구현됨. 코드 `assets/exampool/sheet/` 의 `typeset-standard.js`(기준 데이터·검증·내보내기), `typeset-gaps.js`(간격 보기·조절), `typeset-settings.js`(조판 설정 팝업), `line-fit.js`(자간 맞춤), `standard-from-hwp.js`(양식에서 기준 만들기), `typeset-model.js`(줄 나눔). 단위 검사 `tests/test-typeset-standard.mjs`(수능 틀 출력이 바이트까지 같음을 증명).

## 1. 실험으로 확인한 사실 (rhwp 0.8.7 엔진 직접 호출)
조건: 기출 지문 첫 문단 50개(수식 없음), 단 폭 81mm, 함초롬바탕 11pt·장평 95·자간 −5·양쪽 정렬.

1. **어절 가운데서 끊기는 버그**: `KEEP_WORD`는 엔진(과 rhwp 「바탕글」 = 한컴 기본)에서 **글자 단위**, `BREAK_WORD`가 어절 단위(`koreanBreakUnit=0`). 옛 코드는 어절 단위라며 `KEEP_WORD`로 바꿔 줄 끝 276곳 중 145곳(53%)이 어절 가운데서 끊겼다. 지금은 `KEEP_WORD → BREAK_WORD`(`typeset-model.js`, `LAYOUT_VERSION`으로 저장 조판에 「다시 맞추기」 표시). 한컴 한글에서의 「줄 나눔 기준 = 어절」 표시는 한글이 있는 PC에서 확인 필요.
2. 어절 단위만으로는 양쪽 정렬이 남는 폭을 공백에 몰아 줘 공백이 2배 넘게 벌어진 줄이 145/284.
3. **윗줄부터 자간 맞춤**: 공백 넓은 줄은 자간을 줄여 다음 어절을 끌어올리고, 안 되면 넓혀 채우며, 짧은 끝줄은 윗줄로 흡수하거나 한 어절을 내려보낸다.

| 자간 범위(기본 −5%) | 공백 2배↑ 줄 | 공백 늘어남 중앙값 | 짧은 끝줄 |
|---|---|---|---|
| 맞춤 전 | 145 | 1.03칸 | 5 |
| −8~−2% | 59 | 0.60칸 | 3 |
| **−10~0% (채택)** | **41** | **0.55칸** | **1** |
| −10~+2% | 27 | 0.52칸 | 0 |

   50문단 0.5초(문단당 약 10ms). 문단별 41개 좋아짐·8개 같음·1개 나빠짐 → 「나빠지면 되돌림」 검사를 둠.
4. 엔진 성질: 줄 범위에 자간을 주면 그 줄부터 아래만 다시 나뉜다(윗줄 불변) → 윗줄부터 차례로 맞추면 됨. 자간은 정수 %.
5. 한계: 수식 든 줄(수식은 글 위치에 안 잡힘, 단 학교 양식은 `school` 옵션으로 맞춤)·그림 옆 글 줄은 건너뜀. 〈보기〉·표 칸은 글을 미리 잘라 넣는 방식이라 별도.

## 2. 데이터 구조 (현재 `KICE_STANDARD`)
```json
{ "id":"std_…", "name":"…", "version":1, "base":"kice",
  "source":{"kind":"builtin|hwp|copy|file","file":"…","at":"…"},
  "paper":{"size":"A4","columns":2,"columnGap":8,"margin":{"top":15,"bottom":15,"left":15,"right":15}},
  "print":{"explanation":"none|with"},
  "text":{"font":"함초롬바탕","size":11,"ratio":95,"spacing":-5,"lineSpacing":160,"align":"justify","break":"word"},
  "gaps":{"text":0,"material":0,"bogi":0,"ask":0,"choices":0,"after":1.54,
          "bogiPadTop":1.54,"bogiPadBottom":2.30,"bogiPadSide":2.30,"bogiPadLeft":2.30,"bogiPadRight":2.30,
          "boxPadSide":2.30,"boxPadTop":1.54,"boxPadBottom":1.54},
  "parts":{"number":"n.","bogiTitle":"<보 기>","bogiTitleWidth":12.26,"bogiTitleRow":2.91,"bogiTitlePad":0.38,
           "bogiLineSpacing":150,"tableText":10,"tableLineSpacing":130,"cellPad":0.38,"rule":0.12,
           "choices":"auto","choiceTabs":[16.59,27.65,43.02],"labelSpace":"space","hanging":true,"numberIndent":3.06},
  "fit":{"on":true,"low":-10,"high":0,"shortLastLine":15},
  "lock":true }
```
- 단위: 간격·여백 mm, 글자 pt, 장평·자간·줄 간격 %. 비운 값은 수능 틀 값을 따름(`resolveStandard`가 수능 틀 위에 펼침, 범위 밖 값은 오류).
- `gaps.text/material/bogi/ask/choices`는 지문·자료·〈보기〉·발문·선지 **앞에 더 두는** 간격(수능 틀 0 = 조판이 정한 기본 간격만). 문항 하나만 바꾸는 예외도 같은 칸을 더함.
- 학교 양식에서 읽은 기준은 `parts.numberBold·numberPlus·points`가 더 붙음(수능 틀에는 없어 조판이 예전 그대로).
- 저장: ExamPool IndexedDB `standards` 저장소 + `.5e-typeset.json` 내보내기/가져오기. 문항에는 `standardId`만(없으면 시험지 기준 → 수능 틀). 기준이 바뀌면 그 기준으로 저장한 조판에 「기준 바뀜 · 다시 맞추기」 표시.
- **용지 맞춤**(`standardForPaper`): A4 2단에 맞춘 기준을 B4·A3 문항에 쓸 때 단 폭을 평가원 원본 111.98mm에 맞추고(좌우 여백을 그만큼 조정) 간격·선지 칸·번호 들여쓰기를 단 폭 비율만큼 되돌린다. 〈보기〉 제목 칸은 키우지 않음(위 선이 글자 밑으로 내려가고 양옆이 뜸). 수능 틀은 이때 본문 11.5pt·자간 −3·줄 간격 145%(원본 PDF 실측), 상자 좌우 2.54mm.
- 수능 틀 간격은 평가원 2009-6 모평 한글 원본 실측 × 0.768(5E 단 폭 86 ÷ 원본 111.98)으로 정함. 선 굵기 0.12mm는 줄이지 않음(0.09는 인쇄가 흐림).

## 3. 화면 흐름
- 오른쪽 상세 조판 머리 줄: `조판 기준 · 수능 틀 ▾` · `간격 보기` · 상세 조판 · 크게 보기 · 구조 잠금.
- **간격 보기**: 엔진이 그린 실제 줄·표·그림 위치 + 조판이 기록한 글 소속(지문/발문/〈보기〉/선지)으로 요소 사이에 초록 띠, 단 여백에 보라 띠 + mm. 잠금 켜짐: 보기만. 잠금 풀림: −/+ 0.5mm(0~20), 범위 「이 문항만」(기본) / 「조판 기준에」. 수능 틀을 처음 바꾸면 「수능 틀 (내 설정)」으로 복제. 값을 바꾸면 엔진 문단 간격을 직접 고치지 않고 기준/블록 값을 바꾼 뒤 문항 조판을 다시 만든다(저장 조판과 일치, 1/75 단위 함정 회피).
- **구조 잠금**: 켜짐 = 글자 입력·지우기, 자간·한 줄 맞춤, 굵게·기울임·첨자, 내어쓰기는 허용. 막는 것: 문단 간격·줄 간격, 여백·용지·단, 글꼴·크기·장평(표·그림 틀은 이미 막음). 5E_hwp에도 같은 잠금이 영향(`js/rhwp-exam-layout-lock.js`).
- **기준 메뉴**: 수능 틀 / 저장한 기준들 / 학교 양식(한글 파일)에서 만들기… / 지금 설정을 새 기준으로 저장… / 기준 관리(이름·복제·지우기·내보내기·가져오기).
- **학교 양식에서 만들기**: 양식을 엔진으로 열어 쪽 설정·문항 문단 모양·실측 간격·선지 줄을 읽어 표로 보여 줌(찾음/못 찾음→수능 틀 값), 값 고치기 + 지금 문항 미리보기 + 이름 붙여 저장. 간격은 쓴 값이 아니라 **그려진 위치**로 잰다. 상세 → `typeset/school-forms.md`.

## 5. 구현 차례와 규칙
1. ★ 어절 끊김 버그 → 2. 기준 데이터(하드코딩 값을 「수능 틀」로, **출력 바이트 동일**) → 3. 간격 보기·조절·잠금 → 4. ★ 윗줄부터 자간 맞춤 → 5. 학교 양식에서 기준 만들기. (★ = 조판 결과가 바뀌므로 전후 비교·승인.)
- 조판 규칙을 고치면 `TYPESET_CACHE_VERSION`·`LAYOUT_VERSION`을 올린다(저장된 조판 무효화).
- 기준 값 이동 단계는 수능 틀 출력이 바이트까지 같아야 통과(예제·기출 표본 문항의 section0/header 비교).

## 6. 자간 맞춤과 내어쓰기·머리의 순서
내어쓰기는 「ㄱ. 」「① 」「(가) 」 머리의 **그려진 폭을 엔진에서 재서** 건다. 그래서:
1. 머리(「n. 」「ㄱ. 」「① 」「(가) 」)에는 자간 맞춤을 걸지 않는다(머리 폭이 바뀌면 내어쓰기 선이 어긋남).
2. 순서: 글자 모양(장평·자간 기본) → 내어쓰기 재기·걸기 → 줄 맞춤. 줄 맞춤은 들여쓴 줄 폭 그대로 계산.
3. `parts.labelSpace`(머리 뒤 칸: 보통 공백 `space` / 고정 공백 `fixed`), `parts.hanging`(내어쓰기 켜기)로 양식마다 달라질 수 있게 함.
4. 〈보기〉 글 폭 = 단 폭 − 번호 들여쓰기 − 좌우 안쪽 여백. 좌우 여백을 바꾸면 줄바꿈이 바뀌므로 조판을 다시 만든다.

### 실시간 반영 실측 (rhwp 0.8.7, 헤드리스 크로미움)
| 문서 크기 | 조작 1번 | 한 문단 맞춤 중앙값 | 최대 | 쪽 그리기 |
|---|---|---|---|---|
| 3문단(문항 하나, 짧음) | 0.19ms | 5ms | 23ms | 5ms |
| 12문단(문항 하나, 김) | 0.29ms | 17ms | 32ms | 6ms |
| 40문단(시험지 한 쪽) | 0.94ms | 34ms | 74ms | 14ms |

- 조작 1번이 문서 전체를 다시 배치해 문서가 클수록 느리다. 문단 하나 맞춤에 조작 약 30번.
- 방침: ExamPool 문항(문서 = 문항 하나)은 실시간 가능. 입력이 0.3초 멈추면 고친 문단만 **고친 줄부터 아래로** 맞추고, 한 번의 되돌리기 단계로 묶으며 커서는 그대로 둔다. 자간은 직전 값부터 시험하거나 이분 탐색으로 조작 수를 약 1/3로. 5E_hwp 시험지 전체는 실시간이 아니라 단추·문항 단위.
- 웹킷(사파리)에서 같은 수치인지는 구현 때 브라우저 검사로 확인(위 측정은 크로미움) (확인 필요).

## 7. 열린 항목 (확인 필요)
- 자료 상자·대화 칸·표 칸 안쪽 여백을 기준에 넣는 범위(1차는 〈보기〉만).
- 숫자·단위 띄어쓰기 점검을 ExamPool에도 쓸지.
- 양식의 머리말·꼬리말을 시험지 바탕으로 쓰는 기능.

# 부록 B. 수능 과탐 문제지 실측 (2006학년도 시험지 PDF 8개)
PDF 쪽 크기가 297×420mm(A3)로 실제 시험지(8절)를 키운 것일 수 있어 **절대값보다 비율·차이**를 믿는다. 7개 PDF는 글자가 그림이라 선·상자만 재고, 글자 값은 한컴 PDF 하나(물리Ⅱ 2쪽) 기준이다.

**쪽·단**: 맨 위 굵은 가로줄 31.0~266.0mm(굵기 약 1pt) · 단 구분 세로줄 x 148.5(아주 가는 선) · 왼쪽 단 번호 30.95 ~ 오른쪽 142.8(폭 약 111.9) · 오른쪽 단 153.8 ~ 265.7.

**글자·줄**: 본문 11.22pt(본문·선지·〈보기〉 같음) · 줄 간격 6.07~6.09mm(글자의 약 153%) · 문항 번호 폭 3.98mm(둘째 줄부터 내어쓰기) · 발문 첫 줄 들여쓰기 3.55mm(약 1글자).
