# 학교 양식·아무 양식 자동 조판

목표: 학교가 쓰는 시험지 한글 파일(원안지)만 넣으면 문항을 그 양식에 맞춰 조판하고, 사람은 최종 검수만 한다. 어색한 곳은 표시하고 한 번에 고친다.

코드: `assets/exampool/sheet/` 의 `typeset.js`(양식 묶기), `standard-from-hwp.js`(양식에서 조판 기준 읽기), `typeset-model.js`(`anchorRaisedTables`·`LAYOUT_VERSION`), `equation-script.js`(수식), `handoff.js`, `exam-build.js`, `hancom-file.js`.

## 흐름
| 단계 | 내용 |
|---|---|
| 등록 | 2단계 「조판 확정」: 왼쪽 이름·남길 것·PARTS·쪽·단 설정, 오른쪽 견본 시험지 1·2쪽(`sample-questions.js` 견본 6문항) |
| 가볍게 저장 | 등록 때 문항 자리(첫 문항~꼬리 앞)의 그림·개체(pic·container·ole·도형·글맵시·차트)와 안 쓰는 BinData를 지움(`typeset.slimForm`, hwpx로 저장). 지운 뒤 첫 문항·꼬리·단·머리 표·부분 수가 같아야 쓰고, 아니면 원본. 6MB → 40KB 수준 |
| 기본 양식 | `assets/exampool/forms/`에 학교 원안지 3개(`middle-a4.hwpx` 중학교 원안지(A4), `high-b4.hwpx` 고등학교 원안지(B4), `high-b4-2.hwp` 고등학교 원안지 2(B4); 학교 이름은 ○로 지움)를 넣고 `ensureBuiltinForms`가 처음 시험지 목록을 열 때 뒤에서 한 번 읽어 `typesetForms`(id `form_builtin_*`)·`typesetStandards`(id `std_builtin_*`)에 등록(약 3초). 양식 읽는 규칙이 바뀌면 `BUILTIN_VER`를 올려 다시 등록 |
| 틀 고르기 | 등록을 기다림. 시험지 카드에 양식 이름 표시 |
| 보관함 | 내 문항만. 기출은 「기출문제 열기 →」로 변형만 |
| 규칙 격리 | 학교 양식 전용 규칙은 `String(standard.id).split('@')[0] !== KICE_STANDARD.id`로 가둠 → **수능 틀 출력은 바뀌지 않음**(수능 틀 1,228건 불변 확인) |

## 양식에서 읽는 값 (`standard-from-hwp.js`)
쪽 설정(용지·여백·단), 「1.」 같은 문항 문단에서 가장 많이 쓴 글자·문단 모양, 문항 머리 사이 실측 간격, 선지 줄. 못 찾은 값은 수능 틀 값. 문항 번호는 「1.」「1)」「Q1.」「문 1.」「[1]」, 한글 「문단 번호」(headType Number), 개요 번호(수준 0)도 문항으로 봄. 머리말·꼬리말(학교 이름 등)은 범위 밖.

## 학교 양식 전용 조판 규칙 (수능 틀은 그대로)
| 규칙 | 이유·방식 |
|---|---|
| 수식 스크립트 | 첨자 `{X_a}^b`, 수식 안 한글 빈칸, 한글 든 분수 막대 간격, 화살표·「a∼d」·기울어진 글자 뒤 ¼ 빈칸 |
| 수식 뒤 1pt WJ·줄 맨 앞 수식 보호 | 줄 나눔이 수식 앞에서 어긋나는 것 방지. 단 나누기 앞 1pt WJ는 그림 옆 문항 수식이 한 칸씩 밀리던 결함 때문 |
| 한글 호환 | 한글로 가져가는 HWPX(`forHancom`)에서만 U+2060을 같은 폭 빈칸으로(윈도우 한글에서 「WJ」 점 상자로 보임). 5E 화면·인쇄는 그대로 — 빈칸이면 rhwp가 수식 뒤 줄 높이를 다시 놓침 |
| 띄어쓰기 | 1.2em 넘게 벌어진 문단은 글자 단위 줄 나눔(0.6~1.2em은 어절 안 끊김 1번 이하일 때만, 줄·높이가 늘면 되돌림). 611문항 기준 어절 안 끊김 4.66%(수능 4.3~4.6%) |
| 그림 아래 | 단 폭 전체로. 문항 조판 단계에서(카드·한글 창·시험지·내보내기가 같게). 진짜 어울림(Square)은 rhwp가 깨뜨려 쓰지 않음 |
| 단 폭 50% 넘는 그림 | 글 옆이 아니라 글 아래 가운데 |
| 표 위로 올라감(겹침) | 표만 든 문단에 줄 정보가 없으면 rhwp가 표를 앞 글보다 위에 놓음 → `anchorRaisedTables`가 위로 올라간 표 문단에만 줄 정보를 넣음(연쇄 처리, 단 나누기 계획부터). 〈보기〉 표 바로 뒤 선지 표도 같은 단의 직전 inline 표와 비교(떠 있는 머리표 제외). 회귀 검사 `tests/test-school-form-browser.cjs` |
| 누름틀 | 「선택형 00문항」의 「00」은 빈 누름틀 → 그 자리에 문항 수를 글로 넣음(누름틀 값만 넣고 같은 줄 총점을 부분 수정하면 엔진이 뒤 글자를 빨간 기울임으로 틀어 줄을 한 번에 다시 씀) |
| 자간 맞춤 | `line-fit.js`가 `school` 옵션으로 수식 든 문단도 맞추고, 줄 오른쪽 끝을 문단의 양쪽 정렬 줄 끝으로 잼 |

## 속도
- 학교 양식은 기본 틀 조판을 건너뛰고(20문항 21.8 → 9.7초, 재조판 0.4초), 조판 결과를 IndexedDB `5e-typeset-cache`에 저장(→ `exam/cards-library.md`).
- 32문항 시험지 첫 그리기: 5E 기본 틀 3.9초 / 무거운 양식 15초. 가볍게 저장한 양식은 첫 그리기 약 9초·여백 계산 약 10초(양식 파일에 든 문항 그림 31개·41MB가 묶을 때마다 압축·해제로 느렸던 것을 뺌).

## 검증 방법
- 기출 18묶음 × 양식 6개 = 108건을 실제로 묶어 내보내기해 성공/실패 분류(겹침 외 남은 막힘은 변환 자료 문제·옛 코드에서도 동일).
- 수능 틀 불변 확인: 평가원 틀 비교 하네스 diff, 611문항 회귀, 단위 검사(`npm test`)와 `test-school-form-browser.cjs` 두 엔진 통과.
- 설치판에서 문항·양식을 읽기만 해 와 실제 보내기로 재현하는 검사 `tests/test-exam-send-1106-repro.cjs`(환경 변수가 없으면 건너뜀).

## 알려진 한계 (확인 필요)
- 그림 옆 좁은 줄 띄어쓰기 벌어짐·마지막 낱말만 넘어감(9문항).
- 분수 든 줄 높이(우리 1.75배 vs 수능 1.44배)는 안을 비교판으로 만들었으나 미반영.
- 윈도우 한글에서 열면 화면과 달라지는 부분(번호 앞 점 등)은 한글 설치 PC에서 확인 필요.
- 고등학교 양식 3은 1쪽 본문이 비고 첫 문항이 2쪽부터 시작(`planFormBreaks` firstStart).
- 양식 머리말·꼬리말을 시험지 바탕으로 그대로 쓰는 기능은 범위 밖.
