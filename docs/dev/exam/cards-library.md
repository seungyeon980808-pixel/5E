# 문항 보관함·시험지·문항 카드

코드: `assets/exampool/sheet/` 의 `exams.js`(시험지 API), `pool-views.js`(보관함·시험지 목록·순서 끌기·보내기), `card-editor.js`(문항 카드), `library-view.js`.

## 데이터
| 항목 | 내용 |
|---|---|
| 시험지 | `data.exams=[{id,title,status:'drafting'|'done',items[],…}]` (`exams.js` `newExam`·`normalizeExams`) |
| 문항 보관함 | 어느 시험지에도 안 든 문항. 예전 `examSet`은 첫 실행 때 시험지로 옮김 |
| 문항 단계 | `WORKFLOWS`: 초안 · 검토 중 · 완성. AI 검토 기록은 `q.reviews` |
| 카드 data 속성 | `cv` 접두어(전역 처리기와 겹침 방지) |
| 문항 출처 | `q.origin {kind:'import',file,at,batch}`(불러올 때 기록) / `q.source` 「기출 변형」 / 직접 제작 |
| 시험 종료 시험지 | 문항 읽기 전용(카드·칸·미리보기 고침 막음). 띠에서 「복제해서 작업대로 꺼내기」 / 「출제 중으로 되돌리기」. 조판 자동 저장·상태 바꾸기·복제는 통과 |

## AI 검토 연결
부모 5E로 `postMessage('5e-question-sheet',{action:'review'})` → `window.fiveEReviewHarness.request(packet)`가 `{text, items:[{field,text}], suggestion}`을 돌려줌. 완성 조건: 발문 · 자료(그림/표가 모두 찬 자리) · 보기(합답형) · 선지 · 정답이 모두 차면 검토 요청 가능.

## 카드 조판 주의
빈 칸 뼈대, 본문 엔진 줄바꿈 + `applyQuestionIndent`, 맨 앞 1pt 문단(시험지 빌드가 문단 0을 건너뛰므로 필수), 보기 폭·안쪽 여백.

## 3칸 화면 (확정 방향)
| 항목 | 결정 |
|---|---|
| 칸 | 왼쪽 라이브러리 · 가운데 문항 카드만(머리줄에서 「쪽 전체」로 바꿔 크게 봄) · 오른쪽 **미리보기 + AI**(위 버튼으로 하나씩 전환, 동시에 안 봄) |
| AI 알림 | 새 의견은 버튼에 숫자. 「AI 검토 요청」→ AI, 「미리보기에서 보기」→ 미리보기 |
| 경계 | 칸 사이 경계마다 손잡이 **하나**. 카드는 가운데 칸을 꽉 채움(카드 폭 손잡이 따로 두지 않음) |
| 접기 | 좌우 패널 여닫기는 가운데 머리줄 양 끝 버튼만(접힌 세로 띠 없음). 오른쪽 칸은 미리보기·AI가 함께 접힘 |
| 기본 폭 | 1440px 화면 → 라이브러리 545 · 오른쪽 410, 1920px → 725 · 545 |
| 미리보기 | 실제 조판(한글 엔진). 한 번 조판한 모양을 칸에 맞춰 확대·축소만(폭이 바뀌어도 줄바꿈 불변), 문항 하나를 스크롤 없이. 「쪽 전체」도 HTML 흉내가 아니라 엔진 조판(시험지와 같은 합친 문서 → 쪽마다 SVG) |

## 문항 목록·시험지 (11-15 개편)
| 항목 | 내용 |
|---|---|
| 목록 | 열 있는 표: 번호·발문·출처·자료 구조·단원·배점·완성도·만든 때·마지막 편집. 열 제목으로 정렬, 출처 거르기, 줄 두 번 누르기 → 카드 |
| 범위 | 스위치 「작업대 / 모든 문항」. 모든 문항은 「들어간 시험지」 열, 시험지별·불러온 묶음별·단원별 묶기, 묶음 접기·통째로 휴지통, 고른 문항 막대에서 작업대 복제·별표 |
| 시험지 배치·점검 | 문항 줄·쪽의 문항 두 번 누르기 → 카드, 경로 옆 ‹ n/N ›, 시험지로 돌아가기 |
| 불러오기 | 기본 「시험지로 등록」(양식·틀·목표·여백·단 나누기 유지), 「문항만 작업대로」 선택 가능 |
| 시험지 파일 | 시험지 ⋯ 「시험지 파일로 저장(.exampool)」 = 문항·그림·자료 + 학교 양식(base64)·조판 기준. 불러오면 같은 ID로 양식·기준 등록 |
| 담기 | 다른 시험지에 든 문항을 담으면 복제본(원래 시험지는 그대로) |
| 카드 저장 확인 | 「고친 내용 저장?」 비교에서 typeset·updatedAt은 뺌(넘길 때마다 창이 뜨던 문제) |

## 조판 결과 저장
IndexedDB `5e-typeset-cache`: `q`(문항 조판, slot=id|용지|기준), `a`(묶은 시험지 form|plain + 시험지 id). 열쇠 = `TYPESET_CACHE_VERSION`(`typeset.js`) + contentKey·용지·기준 JSON. **조판 엔진·규칙을 고치면 `TYPESET_CACHE_VERSION`을 올릴 것**(`LAYOUT_VERSION`은 `typeset-model.js`). 효과: 껐다 켠 뒤 32문항 시험지 다시 열기 29초 → 0.7초.
