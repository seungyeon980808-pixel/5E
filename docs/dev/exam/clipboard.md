# 5E 클립보드

| 항목 | 결정 |
|---|---|
| 원칙 | AI로 처리할 것 = 작업대(라이브러리 「AI 이미지/그래프」→공용 작업대·이미지 분류). 그 밖에 옮기는 모든 것 = 클립보드 |
| 옛 서랍 | 클립보드로 합침. 같은 IndexedDB `fivee-drawer`를 쓰므로 옛 항목은 출처 「옛 서랍」으로 그대로 보임 |
| 코드 | `js/clipboard-view.js`(오른쪽 서랍·크게 보기·고르기 모드), `js/drawer.js`(저장소: kind·source·pinned·moving·objects·ref, 고정 안 한 것 50개) |
| 단축키 | ⌘C/⌘X/⌘V, 어디서든 ⇧⌘V로 열기·한 번 더 누르면 크게 보기. Esc는 `escape-layers`에 등록(크게 보기 → 옆 서랍 → 닫기) |
| ⌘X | 「옮기는 중」 표시 — ⌘V로 붙이면 클립보드에서 빠짐 |
| 크게 보기 | 종류·출처 거르기, 찾기, 여러 개 고르기, Space로 한 장 |
| 5E_image | 「서랍」 단추 삭제, 「고급 기능」→「작업 도구」, 맨 위 「클립보드 N」 줄 |
| 5E_exam | 왼쪽 메뉴 「서랍」→「클립보드」. 넣기 = 열린 문항 카드 자료 칸, 없으면 열린 아이디어 판 |
| 5E_hwp | 「내용 넣기 › 클립보드」, 넣기 = 커서 자리 |
| AI 이미지 | 「＋ 메뉴·소스 추가」는 「클립보드에서」 하나. 결과 「이미지 복사」는 클립보드에도 넣음 |
| 설치판 | 창으로 돌아올 때 맥 클립보드 그림을 「밖에서 · 캡처」로 가져옴(⋯ 메뉴에서 끌 수 있음, main의 `clipboard:read-image` IPC). Electron 44의 `clipboard.readImage` 부재로 `clipboard.read()` 사용. **main 프로세스 코드라 앱을 다시 켜야 반영** |
| 항목 이름 | 객체 종류로(「사각형」「사각형 3개」「글 「…」」) |
| 스타일 | 「넣기」는 꽉 찬 파란 단추 대신 은은한 단추 |
| 검사 | `tests/test-clipboard-hub-browser.cjs` |
