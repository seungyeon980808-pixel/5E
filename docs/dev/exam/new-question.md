## 수치(정적 판정이지 실행 성공률이 아님)
- 메뉴로 편집 없이 대응되는 문항: 1,377/1,440 = 95.63%. 과목별로 화학Ⅱ 90.6 · 생명Ⅰ 94.4 · 생명Ⅱ 89.4는 95% 미달 → 「8과목 모두 95% 달성」이라고 쓰지 말 것.
- 「자료 없이 글만」을 넣으면 97.22%, 8과목 모두 95% 이상.
- 자료 3개 + 묶음 속 자료를 합친 확정안 기준으로는 다시 계산하지 않음(묶음 속 자료 100문항은 만든 뒤 묶기 편집이 필요해 수치가 내려감) (확인 필요).

## 평가원 서식(예시·결과가 따르는 모양)
- 표: 가는 검은 선, 머리칸 작은 돋움체, 값 바탕체(변수만 기울임), 촘촘한 줄.
- 실험 상자: 〔실험 과정〕〔실험 결과〕, 과정 내어쓰기, 장치 그림 오른쪽 위 36%, 결과표는 상자 폭 가득.
- 그래프: 축 끝 화살표, 점선 기준선, 기울인 눈금. 그림은 계산으로 그려 이름표가 겹치지 않음.
- 배점 「[3점]」은 앞 낱말과 붙임. 합답형 선지는 한 줄 5개. 대응 선지는 A·B·C 3값 2열, 맨 윗줄 묶음 위에만 열 제목, 제목마다 짧은 밑줄, 테두리 없음.
