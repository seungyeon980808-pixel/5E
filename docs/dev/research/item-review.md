# 출제 하네스·검토·반박 의견서 — 설계 재료 조사 (2.0 계획용)

상태: **조사·설계만, 코드 반영 없음.** 원칙(2.0 결정): AI는 **판정하지 않고 「확인할 곳 + 근거」**를 보여 주며 결정·서명은 교사. 표기: **[확인]** 원문(또는 원문을 옮긴 보도)에서 직접 확인 · **[관찰]** 기출 관찰에 근거한 정리, 공식 문서로 확인 못 함 · **[확인 못 함]**. 교육과정 근거 데이터는 [curriculum-2.0.md](curriculum-2.0.md).

## 0. 핵심 결론

1. 평가원은 과탐 문항 형식 매뉴얼을 공개하지 않는다(공개: 매년 출제 방향 브리핑, 학습 방법 안내의 평가 요소·예시 문항). 형식 분류는 기출 관찰로 만들고 출처를 「관찰」로 표시.
2. 2027학년도 수능부터 평가원이 **문항별 성취기준 등 교육과정 근거를 공개할 예정**(시행기본계획). 5E 메타데이터의 성취기준 칸은 이 형식과 맞추기. 실제 공개 양식은 (확인 필요, 수능 뒤).
3. 학교 시험의 뼈대는 시·도교육청 학업성적관리 시행지침: 문항정보표(영역·내용·성취기준), 공동 출제·검토, 교육과정 범위·수준 이탈 금지, 이의 오류 검증에 외부 전문가 자문 가능. **복수정답 재채점 방식(복수 인정/전원 정답/문항 제외)은 학교 규정에 넘겨져** 교육청 지침에서 확인 못 함 → 5E는 선택지만 제공하고 「학교 규정을 따른다」.
4. 이의심사 판단 축 세 가지: (가) 과학적으로 참/거짓이 갈리는가 (나) 표현이 두 가지로 읽히는가 (다) 조건이 모순되어 답을 고를 수 없는가. 근거: 교육과정·성취기준, 관련 학회 자문, 외부 전문가 심사.
5. 법원 기준(2022 수능 생명과학Ⅱ 20번 1심): 오류가 정답 선택을 불가능하게 하거나 심각한 장애를 줄 정도면 정답 처분 취소. 평가원의 「조건이 불완전해도 성취기준 변별 타당성은 유지」 논리는 받아들여지지 않았다. → 반박 의견서는 「교육과정에 있다」만으론 약하고 **「조건이 성립하고, 의도한 정답 외에는 참이 될 수 없다」**를 보여야 한다.

### 1-2. 발문 유형 코드 제안 [관찰]

| 코드 | 발문 형태 | 선지 |
|---|---|---|
| Q-BOGI-T | (자료)에 대한 설명으로 **옳은 것만을 〈보기〉에서 있는 대로 고른 것은?** — 과탐 최다 | ㄱㄴㄷ 조합 |
| Q-BOGI-F | 옳지 **않은** 것 / 틀린 것(드묾, 부정어 강조 필요) | ㄱㄴㄷ 조합 |
| Q-DIRECT | 빈칸·물리량·개체로 가장 적절한 것 / ㉠, ㉡으로 옳은 것 | ①~⑤ 값·짝 |

### 1-3. ㄱㄴㄷ 선지 조합 규칙 [관찰]과 기계 점검

- 보기 3개에서 가능한 비어 있지 않은 조합 7개 중 **5개를 선지**로 쓴다. 흔한 배열: ① ㄱ ② ㄷ(또는 ㄴ) ③ ㄱ,ㄴ ④ ㄴ,ㄷ ⑤ ㄱ,ㄴ,ㄷ(단일→둘→셋).
- 빠지는 2개 조합 때문에 **「정답 없음」 사고**가 생긴다. 사례: 2023학년도 6월 모평 지구과학Ⅱ 14번 — ㄱ이 거짓이면 참은 ㄴ뿐인데 「ㄴ」 단독 선지가 없어 정답 없음 처리 [확인].
- **기계 점검**: 각 보기의 참/거짓 판정이 하나라도 뒤집히면 그 조합이 선지에 있는가? 있으면 복수정답 위험, 없으면 정답 없음 위험 → 위험 보기를 집중 검토 대상으로 띄운다.
- 정답 번호가 고르게 분포해야 한다는 연구, 정답지 위치가 정답률에 영향을 준다는 연구가 있다(초록 수준 확인).

### 1-4. 자료 제시 방식 [관찰]

그래프(시간-물리량·두 변인), 표(실험 조건·결과), 모식도(장치·세포·지층·천체 배치), 실험 과정 서술, 가계도·유전 자료, 화학 반응식·몰 자료, 지도·일기도·관측 자료. 보통 2~3개를 섞는다. 5E 그림 기능의 분류와 직접 이어진다.

### 1-5. 오답 선지 설계 원리

| 원리 | 설명 | 검토 위험 |
|---|---|---|
| 흔한 오개념 | 학생이 실제로 갖는 오해 | 학계에서는 맞는 말일 수 있음 |
| 조건 일부만 반영 | 자료의 한 조건을 무시하면 참이 되게 | 조건이 문장에 명시돼 있는지 |
| 인과·상관 혼동 | 그래프 경향을 인과로 서술 | |
| 비교 대상 바꾸기 | A↔B, (가)↔(나) | |
| 크기·부호·단위 | 2배↔½배, 증가↔감소 | 반올림·유효숫자 |

일반 원칙: 질문이 모호하면 아는 학생도 틀리고 시비가 난다, 부정형 발문은 밑줄 강조, 정답만 길어지는 편향 주의(선지가 길수록 선택 선호가 높다는 연구).

### 1-6. 학교 시험 지침 (시·도교육청 시행지침의 공통 내용) [확인]

- 문항정보표(영역·내용·성취기준) 등 출제 계획 작성. 같은 과목 2명 이상이면 공동 출제·검토·편집 의무.
- 시판 참고서 등 기출 문항 **전재·선행출제 금지**. 선행교육규제법에 따라 학교 교육과정 범위·수준을 벗어난 출제 금지.
- 출제 범위·평가 목표·문항 유형: 교과협의회 → 학업성적관리위원회 심의 → 학교장 결재. 원안지·문항정보표 5년 보관.
- 이의신청: 절차는 학교 규정, 면밀히 검토, 필요시 외부 전문가 자문. 재심의 요청 시 학부모·외부 전문가 한시 위촉.
- 학교 규정 예(어느 고교 규정): 출제 금지 사례에 「정답에 대한 논란의 여지가 있거나 정답이 없는 문제」, 참고서 전재·일부 변경, 전년도 문제 30% 이상 미수정 재사용을 열거. 이의신청 흐름은 성적 확인 후 **2일 이내** → 교과 담당 → 교과협의회 → 위원회 → 결과 전달 → 재발 방지.
- 답변 서식은 교육청·학교 모두 두지 않음 [확인 못 함] → 공개 사례를 찾지 못했고, 회의록 + 학생 회신문 형태로 추정. 정답 변경은 반드시 위원회 심의·결재 기록이 남아야 한다(결재된 정답과 다르게 채점한 일이 감사에서 지적된 사례).

## 2. 이의 처리 형식과 사례

### 2-1. 평가원 수능·모평 절차 [확인]

접수(수능 약 4~5일, 모평 3~4일) → 정답과 무관·중복 제외 → **이의심사실무위원회**(출제 비참여 외부 전문가 포함) 심사, 필요시 관련 학회·외부 전문가 자문 → **이의심사위원회** 최종 심의 → 결과 공개, 이의가 많은 문항은 문항별 상세 답변. 2022 생명과학Ⅱ 사태 뒤 개선: 외부 위원 확대, 출제위원은 참고인으로만, 소수의견 재검증(2차 실무위) 신설(세부 시행은 확인 못 함). 결과 문구 표준형: 「문제 및 정답에 이상 없음」/「정답 없음(모두 정답)」/「①번 외에 ⑤번도 정답(복수 정답)」.

**설계에 주는 교훈**: 평가원이 진 경우는 모두 「교육과정에 있다/출제 의도는 이렇다」로 버틴 경우. 인정된 경우의 근거는 **과학적 사실 + 학회 의견 + 이중 해석 가능성**. 교과서 서술이라도 최신 사실과 다르면 근거가 안 되고(교과서는 「범위 안」을 보일 뿐 「참」의 근거로는 약함), 정답 없음의 상당수는 ㄱㄴㄷ 조합 선지 누락이다.

평가원 상세 답변 원문의 구조는 직접 못 읽었다 — 보도로 본 구조: 이의 요약 → 쟁점 일부 인정 여부 → 판단 기준(교육과정·성취기준) → 자문·심의 절차 → 결론. 게시판 원문 PDF 확인 (확인 필요).

|---|---|
| A 정답 구조(기계 점검 가능) | 보기별 판정에서 나온 조합이 선지에 정확히 하나 있다 · 판정이 뒤집힐 때 생기는 조합이 선지에 있는지(1-3) · 시험지 전체 정답 번호 분포 쏠림 · 계산형: 반올림·유효숫자·단위가 선지 간격보다 작은 차이를 만들지 않음 |
| B 조건·자료 | 풀이에 필요한 조건이 모두 문장/자료에 있다(단원자·이상기체·마찰 무시 등) · **조건을 모두 만족하는 상황이 존재한다**(음수 개체 수 등) · 그래프 축·단위·눈금이 본문 수치와 맞고 표의 합·비율이 맞다 · 실제 통계·관측값은 기준 연도를 적었다 |
| C 용어·표현 | 교과서·교육과정 용어와 같다(교과서마다 다르면 표시) · 두 가지로 읽히는 말(상태/동작, 포함/불포함, 「항상」「~만」) 없음 · 부정형 발문 강조 |
| D 교육과정 범위 | 연결한 성취기준 안에서 풀린다(상위 과목·예외가 판정을 바꾸지 않음) · 학교 수업 범위(진도) 안 — 선행출제 금지 |
| E 출처·공정 | 시판 문제집·기출 전재가 아님(변형이면 바꾼 내용 기록) · 공동 검토 확인 기록 |

### 3-3. 반박 의견서 템플릿

1. 대상(시험명·과목·문항 번호·접수 날짜/건수) 2. 이의 요지(신청인 주장을 공정하게 요약, 주장하는 정답·근거) 3. 쟁점 정리(무엇이 참이냐에 따라 정답이 갈리는가) 4. 검토 — 4-1 문항 조건 목록과 **조건을 모두 만족하는 상황이 존재함** · 4-2 과학적 판단(의도한 정답 외 조합이 참이 될 수 없음) · 4-3 교육과정 범위(성취기준) · 4-4 용어·표현(다른 해석 여지) · 4-5 신청인 주장이 성립하려면 필요한 전제와 그것이 문항 조건과 맞지 않는 이유 5. 근거 자료(3-4) 6. 결론(이상 없음/복수 정답/정답 없음 처리안) 7. 처리 절차(교과협의회 → 위원회 → 결재, 외부 자문 여부) + 작성·검토자, AI 초안 사용 표시.

5E 동작: 3-1 메타데이터(보기별 이유·의도한 오답·핵심 조건·근거)로 4~5번 칸을 미리 채운 **초안**만 만들고, 교사가 「확인함」을 눌러야 6번 결론 칸이 열린다. **4번 칸(조건 성립 + 다른 정답 불가)은 필수**(「교육과정에 있다」만으로 끝내지 않도록).

### 3-4. 근거 인용 형식

근거 힘 순서: **과학적 사실(학술 자료) > 교과서 다수의 일치 서술 > 교육과정·성취기준(범위 근거) > 출제 의도.**

| 종류 | 형식 |
|---|---|
| 교육과정 | 문서명(고시 번호), 과목, 성취기준 코드·문장 |
| 성취기준 해설 | 문서명, 쪽 |
| 교과서 | 과목·출판사·발행 연도·쪽·해당 서술 짧게(**2종 이상 일치 권장**, 다르면 그대로 밝힘) |
| 학술 자료 | 저자·연도·제목·학술지/책·쪽·DOI |
| 통계·관측 | 기관·자료명·기준 연도·접속일 |
| 자문 | 학회/전문가·회신일·요지 |

인용은 짧게, 쪽 번호 필수. **AI가 찾은 근거는 교사가 원문 쪽을 열어 본 것만** 의견서에 들어가게(근거 날조 방지).
