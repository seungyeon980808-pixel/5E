# 교육과정·성취기준 근거 자료 — 확보·저장 설계 (2.0 계획용)

원칙: AI 결과는 판정이 아니라 「확인할 곳 + 근거」. 근거는 5E 안의 교육과정 자료에서만 인용한다. 표본: [curriculum-sample.json](curriculum-sample.json)(통합과학1 「(2) 물질과 규칙성」 한 영역). 상태: **조사·설계만, 코드 반영 없음**(대량 옮기기는 아래 6절 결정 뒤).

## 1. 공식 출처

| 문서 | 고시 | 형식 | 비고 |
|---|---|---|---|
| 과학과 교육과정(2022 개정) | 교육부 고시 제2022-33호 [별책 9] | PDF 292쪽, HWP | 초3~고3 과학 전체. 표본의 출처. 국가교육과정정보센터(NCIC, ncic.re.kr) > 원문 및 해설서 > 2022 개정 시기 > 고등학교(2022.12) > 과학 |
| 과학 계열 선택 과목(2022 개정) | 같은 고시 [별책 20] | PDF, HWP | 과학고 등 전용. 2.0 범위 밖 가능성 큼 |
| 과학과 교육과정(2015 개정) | 교육부 고시 제2015-74호 [별책 9] | PDF 278쪽, HWP | **PDF 글꼴이 깨져 글자 추출 불가** → HWP에서 뽑아야 함(HWP 추출 환경은 조사 당시 미작동) |

- 내려받기 주소의 파일 번호는 사이트 개편 때 바뀐다 → 5E에는 「NCIC 경로 + 파일 sha256」로 기록하고 「확인한 날짜」를 함께 저장.
- 2022 개정 아래 후속 고시(2024.08, 2026.01)가 있으나 과학 별책은 2022.12판이 최신(조사 시점). 새 고시가 나오면 다시 확인.
- 두 번째 공식 사본 후보: 법제처 국가법령정보센터 행정규칙(과학 별책 첨부 여부 미확인).
- 성취수준(A~E): NCIC 성취수준 게시판에서 과학은 「과학 계열」만 찾음. 통합과학·일반선택 성취수준 자료 위치 (확인 필요) — 검토에서 「어느 성취수준을 겨냥하나」를 다루려면 필요.

## 3. 성취기준 코드 체계

| 개정 | 형식 | 예 |
|---|---|---|
| 2022 | `[학년(군)+과목약칭+영역-번호]` | `[12물리01-03]` |
| 2022(과목명에 숫자) | `[학년+과목약칭+과목번호-영역-번호]` | `[10통과1-02-01]` |
| 2015 | `[학년+과목약칭(로마숫자)+영역-번호]` | `[12물리Ⅰ01-01]` |

2022 개정 고등학교 과학 과목 약칭: 공통 — 통합과학1 `10통과1`, 통합과학2 `10통과2`, 과학탐구실험1·2 `10과탐1`·`10과탐2` / 일반선택 — 물리학 `12물리`, 화학 `12화학`, 생명과학 `12생과`, 지구과학 `12지구` / 진로선택 — 역학과 에너지 `12역학`, 전자기와 양자 `12전자`, 물질과 에너지 `12물에`, 화학 반응의 세계 `12반응`, 세포와 물질대사 `12세포`, 생물의 유전 `12유전`, 지구시스템과학 `12지시`, 행성우주과학 `12행우` / 융합선택 — 과학의 역사와 문화 `12과사`, 기후변화와 환경생태 `12기환`, 융합과학 탐구 `12융탐`. 고등학교 성취기준은 약 270개(초·중 포함 473개 코드).

- **원문 오기**: 과학탐구실험2 해설에 `[10과탐02-01-03]`으로 적힌 곳이 있으나 실제 코드는 `[10과탐2-01-03]`. 5E는 코드를 정규화(공백·전각 괄호·`02`→`2`)해 찾고 원문 표기는 `label_in_source`로 따로 보관.
- 2022 개정 원문의 가운뎃점은 `⋅`(U+22C5). 검색은 `·`(U+00B7)와 같게 취급하되 **인용은 원문 글자 그대로**.

## 4. 원문 항목과 5E에서의 쓰임

| 원문 항목 | 5E 쓰임 |
|---|---|
| 핵심 아이디어(과목 단위로 나열) | 출제 하네스: 문항 의도 설명의 배경 |
| 내용 요소(지식·이해/과정·기능/가치·태도) | 출제 범위 판단: 문항 개념이 내용 요소에 있는가 |
| **성취기준** | 모든 문항의 1차 근거. 문항마다 1개 이상 연결 |
| 탐구 활동 | 자료·실험 상황 문항의 근거 |
| **성취기준 해설** | **검토의 핵심.** 「~에 한정하여 다룬다」「다루지 않는다」 같은 범위 한정 문장으로 범위 이탈을 잡음. 예: 통합과학1 `[10통과1-02-04]` 해설 「각 화학 결합으로 나타나는 성질은 전기 전도성에 한정하여 다룬다.」(79쪽) → 「녹는점을 묻는 선지는 범위 밖」을 근거와 함께 표시 |
| 성취기준 적용 시 고려 사항 | 연계 과목 범위 확인, 의견서의 「교육과정이 이렇게 지도하라고 한다」 |
| 평가의 방향·방법 | 의견서: 「성취기준에 근거한 평가」 일반 원칙 인용 |
| 성격·목표, 교수·학습 방향 | 거의 안 씀 |

## 5. 저장 구조 (`5e-curriculum/0.1`, 표본이 이 형식)

한 파일에 표 6종: `sources` · `curricula` · `subjects` · `domains` · `standards` · `explanations` (+ `considerations`, `inquiry_activities`).

| 규칙 | 이유 |
|---|---|
| `text`는 원문 그대로(줄바꿈만 합침). AI 요약·풀어쓰기는 저장하지 않음(필요하면 화면에서 만들고 「요약」 표시) | 인용 일치 검사의 기준이 흔들리지 않게 |
| 모든 행에 `cite`: `page`(인쇄 쪽, 사람이 원문을 펴서 찾는 번호) + `pdf_page`(뷰어 쪽, 2022 별책은 `page + 6`) | 두 쪽에 걸치면 `page_end` |
| 안정 ID: 성취기준은 `code`, 해설 등은 `exp:10통과1-02-04#1` 꼴 | 문항·의견서가 ID로만 근거를 가리킴 |
| `sha256` 고정, 원문이 다시 고시되면 새 `source` 추가·옛 행 삭제 안 함 | 이미 낸 의견서의 근거가 바뀌면 안 됨 |
| `explanations[].applies_to`는 배열 | `[10통과1-03-01∼02]`처럼 해설이 여러 성취기준을 묶음 |
| 핵심 아이디어는 영역이 아니라 **과목 단위**로 둠. 영역에 붙이면 `"mapping": "추정"` 표시 | 원문이 영역별로 나누지 않음 |
| 다음 단계 필드: `explanations[].limits`(범위 한정 문장 `{text, kind:"exclude"}`), `standards[].label_in_source`, `standards[].achievement_levels` | 검토가 한정 목록을 먼저 봄 |

파일 위치 안: `assets/curriculum/2022/science.json` + 원본 PDF는 저장소 밖(사용자 PC 또는 릴리스 첨부), 해시만 기록.

추출: 2022 개정 PDF는 PyMuPDF `get_text('blocks')`로 성취기준·해설·고려 사항·탐구 활동이 깨끗이 나뉨(표본에서 원문 쪽 그림과 성취기준 6개를 한 글자씩 대조해 일치). 「내용 체계」 표는 칸이 섞여 좌표로 따로 읽어야 하고, 탐구 활동이 성취기준 상자와 떨어져 다음 쪽으로 흐르는 영역이 있어 자동 추출 뒤 영역 경계를 사람이 확인해야 한다.

## 6. 문항·의견서의 인용 방식

문항(엑셀 한 줄/ExamPool 카드)에 근거를 붙인다:

```jsonc
"curriculum_refs": [
  { "standard": "10통과1-02-04", "role": "primary" },
  { "standard": "10통과1-02-03", "role": "related" },
  { "ref": "exp:10통과1-02-04#1", "role": "scope", "quote": "각 화학 결합으로 나타나는 성질은 전기 전도성에 한정하여 다룬다." }
],
"curriculum_check": { "by": "teacher", "status": "confirmed" }
```

- 엑셀에는 코드만 적고(`10통과1-02-04`) 5E가 DB에서 문장·쪽을 옆에 보여 줌. 없는 코드는 빨간 표시.
- AI는 **DB에서 검색한 후보 목록 안에서만** 성취기준을 제안(목록 밖 코드는 버림). 제안은 `suggested`, 교사가 확인해야 `confirmed`.
- `quote`는 저장할 때 DB `text`의 부분 문자열인지 기계 검사 → AI가 문장을 지어내거나 바꾸면 걸러짐.
- 의견서 본문 형식: `「2022 개정 과학과 교육과정」의 성취기준 [코드]는 "원문"이며, 같은 성취기준 해설은 "원문"이라고 밝히고 있다(교육부, 2022, p. 79).` 끝에 출처 목록. 항목(성취기준/해설/고려 사항/평가 방법)을 밝히고 여러 쪽이면 `pp. 79–80`.
- AI 초안에서 DB와 일치하지 않는 인용은 **빨간 줄 + 내보내기 막기**, 근거 없는 주장 문장은 「근거 연결 없음」 표시. 의견서에 쓴 근거는 `curriculum_refs`로 데이터에도 남김.
- 교과서는 본문을 저장·배포하지 않고 위치(출판사·교과서명·연도·쪽·소단원)만. 평가원 기출은 출처만 밝히고 문항을 옮기지 않음. 근거 1순위는 언제나 교육과정 원문, 교과서·기출은 「보조 근거」로 표시를 나눔.
