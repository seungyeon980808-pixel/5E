## 2. 1.8.0 (그림·그래프 생성)

별도 저장소에서 실험 중인 생성 도구를 5E로 가져옵니다. 5E에 기대는 곳(`desktop/ai-direct-image.cjs`, `js/ai-prompt.js` 등)을 설정 하나로 모으고 「받는 것 / 내놓는 것」 경계를 문서로 둡니다. 옛 `.5exam` 해석 코드 삭제도 이때입니다.

### 2-1. 지금 상태 (초안·출시 전)

그림 생성은 새 그림 엔진으로 바꿨고(설치판, 플래그 기본 켬), 그래프 「그림으로 생성」은 플래그 뒤 옵션(기본 끔, 기본은 그래프 객체 생성 그대로)입니다. 붙인 곳·플래그·실패 길은 [image/ai-engines.md](image/ai-engines.md), 사용자용 초안은 `docs/RELEASE_NOTES_v1.8.0.md`. 판 번호·출시 보류 파일은 아직 1.7.1 그대로입니다.

## 3. 1.9.0 (대화형 출제)

새 탭에서 대화로 문항을 만들고, AI 결과는 「판정」이 아니라 **확인할 곳 + 근거(교육과정·성취기준·교과서 위치)**로 보여 줍니다. 근거는 AI 기억이 아니라 5E 안에 넣어 둔 자료에서 인용하고 최종 결정은 교사가 합니다. 새 기능은 처음부터 별도 모듈(폴더)로 만듭니다. `.5e` 안에 AI가 바로 쓰는 글자 원고 형식을 두는 것도 이때 검토합니다.

## 4. 2.0.0 (전부 안에서)

| 단계 | 내용 |

2.0.0 범위는 이 출제 흐름으로 고정하고, 흐름 밖 기능은 손대지 않습니다. 2.0 전에 AI 연결 경로를 하나 더 확보합니다(예: API 키 직접 입력) — 지금은 사용자의 ChatGPT/Codex 로그인에 기대어 정책 변경에 약합니다.

### 모바일 (2.0.0 범위, 설계 확정)

- 구성: 아래 탭 문항 · 시험지 · 사진. 위 막대 48px, 왼쪽 「5E」, 오른쪽 ⇅(컴퓨터와 주고받기).
- 문항 탭: 내 문항 / 기출, 묶음 칩과 ★ 거르기. 문항 보기는 컴퓨터에서 조판한 모양 그대로(보기만) + 별표·메모·글자 고치기·시험지에 담기. 시험지 탭: 순서 끌어 바꾸기·빼기. 사진 탭: 찍기·자르기 → 문항에 붙이기 또는 컴퓨터로 보내기.
- 뺀 것: 엑셀 편집, 조판 설정, 변형, 캔버스 편집, AI 변환, 5E_hwp 전체.
- 컴퓨터가 받을 때: 5E_exam에 「휴대폰에서 고친 N문항」 줄을 두고, 같은 문항을 양쪽에서 고쳤으면 두 글을 나란히 놓고 고름.
- 만드는 순서: 1.7.1 덜어내기가 끝난 뒤 기능 표를 한 번 맞춤 → 잇기(QR·묶음 올리기/받기, `.5e` 형식 사용) → 문항 → 시험지 → 사진 탭 → 옛 `?mobile=1` AI 화면 삭제.
- 컴퓨터 창이 좁을 때(760px 이하) AI 출력 단추가 숨는 문제는 모바일과 따로 아래 출력 줄로 고치는 안으로 정함(시점 미정).
