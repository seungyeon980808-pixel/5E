## 문서 쓰는 규칙

1. **공개 저장소입니다.** 다음은 쓰지 않습니다 — 개인 컴퓨터의 절대 경로(`/Users/…`, `C:\Users\…`), 이메일 주소, 클라우드 드라이브 폴더 경로·문서 ID, 키·토큰 값과 그 파일 위치, 작업용 임시 주소, 실제 학교 이름, 학생 정보, 고치지 않은 보안 취약점의 재현 절차. 경로는 저장소 기준 상대 경로로, 개인 자료는 「원본 자료 폴더」처럼 일반화합니다. `desktop/public-docs-privacy.test.cjs`(단위 검사에 포함)가 이를 검사합니다.
2. **날짜 기록 대신 고쳐 씁니다.** 결정이 바뀌면 새 문서를 더하지 말고 그 문서를 고치고, `decisions.md`에 한 줄 남깁니다.
3. 사용자에게 보이는 글과 커밋 메시지는 한국어로 씁니다.
4. 코드가 문서와 다르면 코드가 맞습니다. 문서를 고칩니다.
5. 문서를 옮기면 그 경로를 적은 곳(`git grep 파일이름`)을 같이 고칩니다.
