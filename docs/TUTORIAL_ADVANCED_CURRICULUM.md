# 튜토리얼 심화 트랙 커리큘럼 (5단계)

작성 2026-08-03 · 브랜치 `fix/tutorial_detail` · 아직 **기획 문서**다(구현 전).

## 왜 다시 짜는가

지금 심화 트랙은 세 코스다 — `기출 그림 다듬기` · `정렬과 간격` · `꺾은선으로 지형 그리기`.
두 가지 문제가 있다.

1. **없는 화면을 시연한다.** `기출 그림 다듬기`는 오른쪽 속성의 `[사각형 영역 지우기]`를
   누르라고 안내하는데, 그 단추는 화면에 나올 수 없다.
   `js/inspector.js:203` 이 그 블록을 켜는 조건이 `s.imageEditSession` 인데,
   그 세션을 시작하는 `startImageEditSession`(`js/image-cutout.js:80`)을 **부르는 곳이
   앱 전체에 하나도 없다.** 코드에는 있지만 도달할 수 없는 UI다.
   → 이미지에 구멍을 뚫는 실제 길은 **지우개 도구(Shift+E, 올가미)**, 선을 잘라내는 길은
     **가위(E)** 다. 둘 다 왼쪽 도구 팔레트에 있고 실제로 동작한다.
2. **기본 트랙과 겹친다.** 지우기·정렬은 기본 3코스에서 이미 손으로 해 본다.

## 설계 원칙

- 기본 3코스가 다루지 않은 것만 넣는다.
- 한 코스가 끝나면 **그림 한 장이 남는다**. 기능 소개가 아니라 결과물을 만든다.
- 처음 쓰는 사람이 따라올 수 있게, 매 단계 짚을 자리와 통과 조건을 둔다.
- 실제로 존재하고 도달 가능한 기능만 쓴다(위 1번을 다시 밟지 않는다).

### 기본 트랙이 이미 가르친 것 (심화에서 반복하지 않는다)

화면 배율 · 다섯 구역 · 화면 고정 · 고르기/옮기기/크기/회전 · 오른쪽 속성 ·
직선 끝점과 화살표 · 직선·글자·삼각형·사각형 그리기 · Shift 스냅 · 그룹(G) ·
기출 라이브러리 검색과 객체화 · 퍼스널 오브젝트 저장과 오브젝트 검색 ·
라벨러와 텍스트 · 이미지로 내보내기

## 심화 1. 가위와 지우개 — 가져온 그림 다듬기 (약 7분)

**왜**: 기출을 가져오면 늘 "이건 빼고 싶다"가 생긴다. 그런데 **지우는 길이 둘**이고,
무엇을 가져왔느냐에 따라 손이 달라진다. 이 차이를 모르면 "지워지지 않는다"고 느낀다.

| 단계 | 짚는 곳 | 하는 일 |
|---|---|---|
| 1 | — | 지우는 길이 둘이라는 것 (선 → 가위 / 그림 → 지우개) |
| 2 | 기출 라이브러리 | 도판 하나를 **이미지 삽입**으로 가져온다(객체화가 아니다) |
| 3 | `[data-tool="ERASE"]` | 지우개(Shift+E)를 켠다 — 대상 위에서 **주황**, 아닌 곳에서 **회색** |
| 4 | 캔버스 | 필요 없는 곳을 올가미로 감싸 진짜 구멍을 뚫는다 |
| 5 | 캔버스 | Ctrl+Z 로 되돌려 보고, 다시 지운다 |
| 6 | 기출 라이브러리 | 같은 도판을 이번엔 **오브젝트 변환**으로 가져온다 |
| 7 | `[data-tool="CUT"]` | 가위(E)를 켜고 선 하나를 가로질러 자른다 |
| 8 | 캔버스 | 잘려 나온 조각을 골라 지운다 |
| 9 | — | 정리: 이미지는 지우개, 선은 가위 |

**결과물**: 같은 기출 도판을 두 방식으로 다듬은 두 장.

## 심화 2. 과목 부품으로 실험 장치 그리기 (약 8분)

**왜**: 저항·전구·스탠드를 낱개 도형으로 그리면 오래 걸리고 매번 다르게 생긴다.
5E에는 과목 전용 부품이 100개 넘게 들어 있다(역학 20 · 회로 16 · 광학 16 · 전자기학 10 ·
실험 기구 10 · 화학/생명/지구 20여). **있는 것을 꺼내 쓰는 법**이 이 코스다.

| 단계 | 짚는 곳 | 하는 일 |
|---|---|---|
| 1 | `#subject-select` | 과목을 바꾸면 왼쪽 목록이 통째로 바뀐다 |
| 2 | `#subject-section` | 과목별 오브젝트 칸을 펼친다 |
| 3 | 캔버스 | 직류전원을 놓는다 |
| 4 | 캔버스 | 저항·전구를 놓는다 |
| 5 | 캔버스 | 도선으로 잇는다(끝점 스냅) |
| 6 | `#object-search-trigger` | 전류계를 **이름으로 검색해서**(Ctrl+F) 꺼낸다 |
| 7 | 오른쪽 속성 | 부품 라벨(R, V)을 단다 |
| 8 | `#parts-library-open` | 이미지 라이브러리에서 도해 한 장을 넣어 본다 |

**결과물**: 전지·저항·전구·전류계가 도선으로 이어진 회로도 한 장.

## 심화 3. 그래프와 좌표평면 (약 8분)

**왜**: 물리 문항의 절반이 그래프다. 손으로 그리면 축·눈금·화살표가 매번 다르고,
눈금 숫자를 글자로 하나씩 놓으면 고치기가 지옥이다.

| 단계 | 짚는 곳 | 하는 일 |
|---|---|---|
| 1 | `#graph-tool-open` | 좌표/함수 생성(F)을 연다 |
| 2 | 좌표 탭 | 축 범위·눈금 간격을 정해 빈 좌표평면을 만든다 |
| 3 | 캔버스 | 만들어진 평면의 크기를 조절한다 |
| 4 | 오른쪽 속성 | 축 이름을 넣는다 — 물리량은 이탤릭(v, t)으로 |
| 5 | 함수 탭 | 식으로 곡선 하나를 얹는다 |
| 6 | 좌표 탭 | 점을 찍어 꺾은선(측정값)을 하나 더 얹는다 |
| 7 | 캔버스 | 특정 값에 점선 안내선을 긋는다 |
| 8 | — | 다 만든 그래프를 퍼스널 오브젝트로 저장해 둔다 |

**결과물**: 축 이름과 안내선이 있는 속도–시간 그래프.

## 심화 4. 여러 개를 한꺼번에 — 정렬·간격·전체 통일 (약 6분)

**왜**: 문항 그림은 "같은 것 여러 개"가 많다(가·나·다 비교 실험). 하나씩 눈대중으로
맞추면 인쇄했을 때 어긋난 것이 보인다.

| 단계 | 짚는 곳 | 하는 일 |
|---|---|---|
| 1 | 캔버스 | 같은 장치를 셋으로 복제한다(Ctrl+C/V) |
| 2 | 캔버스 | 셋을 감싸 고른다(Ctrl+A 또는 드래그) |
| 3 | `#bulk-edit-open` | 전체 통일/수정을 연다 |
| 4 | 모달 | **좌우 정렬** — 세로 위치를 맞춰 한 줄로 세운다 |
| 5 | 모달 | **좌우 간격 통일** — 그 줄 안에서 빈 거리를 고르게 (정렬이 먼저, 간격이 나중) |
| 6 | 모달 | 선 굵기·글씨 크기를 한 번에 통일한다 |
| 7 | 캔버스 | 각각을 그룹(G)으로 묶어 통째로 옮긴다 |
| 8 | 오른쪽 레이어 | 배경과 장치를 레이어로 나눠 둔다 |

**결과물**: (가)(나)(다)가 가지런히 놓인 비교 실험 그림.

## 심화 5. 문항 세트를 한 번에 — 페이지와 일괄 내보내기 (약 7분)

**왜**: 시험지 한 장에 그림이 여러 개다. 한 장씩 만들고 한 장씩 내보내면 파일 이름이
뒤섞이고, 나중에 어느 문항 그림인지 알 수 없게 된다.

| 단계 | 짚는 곳 | 하는 일 |
|---|---|---|
| 1 | 페이지 탭 | 페이지를 추가한다 |
| 2 | 페이지 탭 | 페이지 이름을 문항 번호로 바꾼다(파일 이름이 된다) |
| 3 | 캔버스 | 두 번째 페이지에 그림을 하나 만든다 |
| 4 | 페이지 탭 | 페이지를 오가며 원본이 그대로인지 확인한다 |
| 5 | `#image-export` | 내보내기 창을 연다 |
| 6 | `#export-dir-pick` | **저장 폴더**를 연결한다 (한 번 연결하면 계속 그 폴더) |
| 7 | `#export-all-pages` | 페이지 선택… 으로 내보낼 페이지를 고른다 |
| 8 | 모달 | 한 번에 PNG로 뽑는다 — 파일 이름이 페이지 이름 그대로인지 확인 |
| 9 | `#project-save` | 프로젝트 저장(Ctrl+S)과 이미지 내보내기의 차이 |

**결과물**: 지정한 폴더에 문항 번호로 이름 붙은 PNG 여러 장.
