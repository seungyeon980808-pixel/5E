# 평가원식 이미지 변환 엔진 검증 기록

## 목표

교과서 사진·컬러 삽화·복합 도식을 입력받아 문자, 숫자, 기호, 지시선, 화살표를 제거하고 평가원 문항에 사용할 수 있는 흑백 선화 자산으로 변환한다. 최초 검증 20건에 이어 교과서 전체에서 추가 사례를 선별하여 누적 100건까지 검증한다.

## 모델 운용 결론

- 실제 이미지 변환, 구조 분석, 원본과의 시각 비교에는 시각 추론과 이미지 생성 품질이 높은 상위 모델을 사용한다.
- Luna가 빠른 경량 모델이라는 전제에서는 후보 페이지 탐색, 크롭 좌표 산출, 파일 관리, 정량 검사, 기록 정리에 사용한다.
- 출력 테스트도 최종 출력 품질을 검증하는 작업이므로 Luna만으로 수행하지 않는다.
- 권장 구성은 `상위 모델: 구조 명세·생성·수정 판단`, `Luna: 작업 오케스트레이션·자동 검사·로그 작성`이다.

## 변환 파이프라인

1. 원본에서 목표 자산의 경계와 주변 제거 대상을 분리한다.
2. 본체, 지지대, 연결부, 반복 부품, 내부 경로를 구조 목록으로 작성한다.
3. 부품 수, 접속 순서, 좌우·상하 배치, 겹침 순서를 고정한다.
4. 문자·숫자·기호·지시선·화살표를 제외한 그림형 선화를 생성한다.
5. 원본과 생성물의 부품 수와 연결 관계를 비교한다.
6. 구조 오류만 대상으로 국소 수정 패스를 실행한다.
7. 회색 단계 수와 비백색 면적을 검사한다.
8. 회색이 평면색 기준을 넘으면 이미지 생성 모델을 반복 호출하지 않고 결정적 양자화 후처리를 적용한다.

## 확정된 생성 규칙

### 구조 고정

- 대상명보다 부품 목록과 연결 관계를 먼저 적는다.
- 반복 부품은 총개수만 쓰지 않고 영역별 개수를 적는다. 예: `위 4개, 아래 4개`.
- 복잡한 생물 구조는 각 경로의 시작점, 통과 지점, 끝점을 별도로 적는다.
- 입체 단면은 절개면 수, 절개 방향, 보이는 외피 범위를 먼저 고정한다.
- 원본의 화살표가 물리적 구조가 아니라 설명 표시이면 제거하고, 상태는 위치·각도·간격으로 남긴다.

### 선과 면

- 외곽선은 내부선보다 약간 굵게 한다.
- 대부분의 면은 완전한 흰색으로 둔다.
- 회색은 물·용액·토양·단면처럼 실제 구분이 필요한 영역에만 허용한다.
- 생성 프롬프트의 `균일한 회색`만으로는 그라디언트가 완전히 제거되지 않는다.
- 최종 출력에서는 흰색, 검은색, 필요 시 1~2개의 고정 회색값으로 양자화한다.

### 질감 제한

- 암석·조직·수관처럼 생성 모델이 질감을 자동 추가하는 대상은 내부선 예산을 수치로 제한한다.
- `최소한의 질감`이라는 표현만 사용하지 않는다.
- 표본별 균열선·입자·층리선의 최대 개수를 명시한다.

### 수정 패스

- 전체를 다시 생성하지 않고 잘못된 요소만 수정한다.
- 반복 개수, 불필요한 기호, 특정 점선, 과도한 내부선은 국소 수정 대상으로 지정한다.
- 명암 제거를 위한 생성 모델 반복은 효과가 불안정하므로 두 번 이상 반복하지 않는다.

## 자동 검수 항목

1. 목표 부품 수와 생성 부품 수가 같은가?
2. 각 연결의 시작점과 끝점이 같은가?
3. 좌우·상하 순서와 겹침 순서가 보존됐는가?
4. 문자, 숫자, 기호, 화살표, 지시선이 0개인가?
5. 허용되지 않은 새 부품이 추가되지 않았는가?
6. 반복 요소의 영역별 개수가 정확한가?
7. 회색이 허용 영역 안에만 존재하는가?
8. 평면 회색 대신 그라디언트가 남지 않았는가?

## 현재 성능 판단

- 사진과 컬러 삽화를 깔끔한 흑백 선화로 바꾸는 능력은 실용 단계에 근접했다.
- 실험 기구, 독립 물체, 반복 상태 그림은 비교적 안정적이다.
- 심장, 네프론처럼 복잡한 연결 구조는 아직 사람 또는 프로그램의 구조 검수가 필요하다.
- 첫 생성만으로 95% 일치를 보장할 수는 없다.
- 구조 명세, 국소 수정, 회색 양자화까지 포함하면 실제 문항 자산 제작 흐름으로 사용할 수 있다.

- 도구: `tools/normalize-exam-lineart.py`
- 기본 팔레트: `[0, 96, 176, 224, 255]`
- 흰색 강제 기준: 밝기 240 이상
- 20개 생성물 전체의 회색값을 239~256단계에서 5단계로 축소했다.
- 모든 RGB 채널을 같은 값으로 통일하므로 미세한 색 번짐도 제거된다.

- 결과는 각 배치의 `normalized` 폴더에 저장한다.

사용 예시:

```powershell

python tools/normalize-exam-lineart.py input-folder output-folder --recursive
```

## 추가 검증 운영 방식

- 사례 21번부터는 10건을 한 배치로 삼는다.
- 각 배치마다 `원본 크롭 → 1차 생성 → 3단계 정규화 → 비교판 → 실패 수정 → 규칙 갱신`을 완료한 뒤 다음 배치로 넘어간다.
- 점수는 픽셀 유사도가 아니라 구조 보존, 삭제 대상 제거, 스타일 적합성, 명암 평탄도에 대한 내부 검수 점수다.
- 95점 미만 사례는 실패로 기록하고, 실패 원인 하나 또는 두 개만 대상으로 수정본을 만든다.
- 수정 전 결과를 삭제하지 않고 `revisions/v1`에 보존한다.
