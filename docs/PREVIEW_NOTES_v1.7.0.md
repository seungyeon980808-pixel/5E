## 화면 디자인 — 5E_image

- 프로그램 이름을 **5E_image**로 표시합니다.
- 디자인 규격 파일 `css/design-tokens.css`를 기준으로 위쪽 막대·도구 패널·속성 패널·페이지 탭·아래 기능 줄·푸터·메뉴·대화상자를 한 규격으로 맞췄습니다(`css/graphite-shell.css`).
  - 글자 14 / 12.5 / 11, 높이 40 / 36 / 32 / 28, 패널 안 모든 줄은 16px 시작선·끝선.
  - 버튼은 테두리 없음 · 마우스를 올리면 옅은 면 · 선택되면 회색 면. 아이콘은 한 가족의 선 아이콘.
  - 튀어 오르거나 도는 장식 효과를 뺐습니다. 결과 알림 같은 기능 신호는 고정 표시로 남깁니다.
- 위쪽 막대 순서: 패널 버튼(양 끝 고정) · 5E_image · Pro|Lite · 되돌리기 · 설정·파일·공유·튜토리얼 · 자동 정렬·격자·자유 이동·캡처·기능 검색 · 배율 · ChatGPT·테마·전체화면.
- **기능 검색**: 돋보기 버튼이나 ⌘K/Ctrl+K로 스포트라이트처럼 기능을 찾습니다.
- **패널 레일**: 패널을 접으면 52px 줄이 남습니다(왼쪽 공통 도구 한 열, 오른쪽 섹션 아이콘). 패널 버튼 아이콘은 열림=채운 칸, 접힘=빈 칸.
- **화면 색 세 가지**: 처음은 다크네이비(1.6.x 남색). 테마 버튼을 누를 때마다 다크네이비 → 그라파이트 → 화이트. 환경 설정 > 화면에서도 고를 수 있습니다.
- 문제 신고 게시판과 AI 이미지 변환·튜토리얼·로그인 창도 같은 규격으로 맞췄습니다. Lite 모드 화면은 그대로입니다.
- **다크네이비 색감**(2026-10-17~18): 시안 색 그대로(바탕 #0d1117, 작업대 #0a0e14, 글자·아이콘 #e6edf3/#b1bac4/#7d8590). 선택·실행 버튼은 은은한 버튼(면 #152137 + 1px 선 #6ba4f8). 창 안쪽 테두리·버튼을 같은 규칙으로 정리했습니다(라이브러리·그래프 창·설정·AI 작업대·한글 작업실).
- **위쪽 막대**: 아이콘 밝기를 도구 아이콘과 같게, 켜진 버튼 아래 점을 없앴습니다(면·아이콘 색으로만 표시). 문제 신고 버튼은 라이브러리 위쪽 막대로.
- **슬라이더·숫자칸**: 슬라이더는 2px 선 + 6×16 세로 막대 손잡이. 격자 창은 높이 44에 진하기 값(3/10), 간격 칸 44 + 옆 작은 상하 버튼. 다른 숫자칸의 ▲▼ 상자는 칸 안 꺾쇠(마우스를 올릴 때만).
- **라이브러리 문항 카드**: 썸네일을 문항의 실제 글자·그림에 맞춰 잘라 문항 번호가 카드 맨 위에 오고 그림이 크게 보입니다. 옆 단 세로선이 빠지고, 단 아래에서 잘리던 마지막 줄(보기)이 들어갑니다. 작업대에 넣는 영역은 그대로입니다.

## 5E_ExamPool — 문항 작업실 (다음 게시 예정, 준비 브랜치 `prep/1.7.0/exampool-into-preview`)

- 위쪽 막대 「5E_ExamPool」로 엽니다. 문항 보관함·시험지·문항 카드(왼쪽 라이브러리 · 가운데 카드 · 오른쪽 미리보기|AI).
- **새 문항 창**: 유형 → 자료 구조 2번 클릭으로 평가원 문항 틀(합답형·정답형·짝 고르기·대화형 / 자료 1·2·3개·조건 상자·실험 상자, 글 옆 작은 자료는 어울림 배치).
- **한글 조판 미리보기**: 오른쪽 미리보기 칸이 곧 한글(HWP) 조판. 카드에서 고친 글이 바로 들어가고, 한글에서 고친 글이 카드로 돌아옵니다. 문항별 기준 용지(기본 A4, 기출은 원본 비율 B4), 그림·표는 가운데.
- **기출 「변형」**: 「기출」 탭에서 과학탐구 기출 8,420문항을 과목·단원·연도·본문 단어로 찾고, 「변형」을 누르면 원본 PDF를 AI 없이 편집 가능한 한글 문항으로 바꿔 새 카드로 엽니다(원본은 근거로 연결). 2024~2026 과탐 1,440문항 자동 채점에서 복원 95.7%.
- **AI 출제 대화·검토**와 AI 그림/설명 그래프 만들기(변경안은 「적용」을 눌러야 반영). 근거 검색은 데스크톱 앱·로컬 실행에서만(공개 웹에서는 '근거 미확보'로 표시).
- 시험지 HWPX 내려받기, 5e_hwp로 보내기.
- 공개 프리뷰에서는 저장 이름에 `5e.preview:`를 붙여 정식 사이트 데이터와 분리합니다.
- 변환기 일부는 같은 저자의 기출 탐색기(exam-search, AGPL-3.0) 코드를 `assets/exampool/convert/es/`에 출처·라이선스와 함께 옮겼습니다.

## 기능

- **문제 신고 게시판** <https://5e.ai.kr/bug/>: 로그인 없이 신고, 이미지 3장(붙여넣기·파일·화면 캡처, 이미지별 공개 선택), 글 비밀번호로 수정·삭제·추가 내용, 공감, 관리자 처리 상태·답변·FAQ. 편집기는 이 페이지를 새 탭으로 열기만 합니다.
- **AI 작업대**: 진입 버튼 'AI 이미지/그래프', 작업 목록 '이미지 작업대', 선택한 작업만 지우는 '선택 삭제', 비교 기본값 나란히, 보조선·지시선 기본 '유지'.
- **그래프 편집**: 그래프 창 안 편집 기록(되돌리기), 축 이름·원점·오른쪽 눈금을 그래프 위에서 바로 고치기.
- **화면 로딩**: 라이브러리 미리보기·작업대 불러오기 중 상태와 흐림 해제 표시.
- **아래 기능 줄**: 좌표/함수 생성 → AI 이미지/그래프 → 5E_hwp 순서, 준비 중인 5E_ExamPool 자리. 페이지 탭 폭 고정.
