# 심화234 튜토리얼 단계별 기획·구현 기준

이 문서는 각 단계에서 활성 화면, 목표 동작, 안내 효과의 적용 여부를 확인하기 위한 문서다.

## 용어 기준

| 용어 | 의미 | 상태 |
|---|---|---|
| 대상 강조선 | 클릭해야 할 UI 요소를 파란 테두리로 강조 | 구현됨: `tut-halo` |
| 보조키 안내 배지 | `Ctrl 누른 채` 같은 입력 조건을 파란 캡슐로 표시. 버튼이 아님 | 구현됨: `tut-modkey` / `demo.mod` |
| 유령 커서 | 클릭·드래그 위치와 순서를 시연 | 구현됨: `tut-ghost` / `demo` |
| 작업 위치 가이드선 | 캔버스에서 따라갈 경로를 점선으로 표시 | 구현됨: `tut-guide` / `guide` |
| 목표 형상 가이드 | 완성할 오브젝트의 크기·비율·범위를 실루엣으로 표시 | 신규 구현 필요: `guide.shape` |
| 코치창 | 단계 설명과 진행 버튼을 표시 | 구현됨: `tut-coach` |
| 완료 피드백 | 실제 동작 완료 후 통과 상태 표시 | 구현됨: `pass()` |

## 표기 방법

`있음`은 현재 단계에 정의됨, `없음`은 정의되지 않음, `해당 없음`은 대상 유형상 필요하지 않음, `추가 필요`는 목표 형상 가이드가 필요한 캔버스 단계지만 아직 미구현임.

## 목표 형상 가이드 요구사항

유령 커서가 선을 따라 움직이는 것만으로는 최종 결과의 크기와 비율이 불명확하다. 캔버스 단계에서는 작업 경로와 완성될 결과 실루엣을 함께 표시해야 한다.

- 직선: 방향·길이·정렬
- 사각형·원·삼각형: 최종 크기·비율·범위
- 꺾은선·경사면: 꼭짓점과 연결 순서
- 치수선·화살표: 기준점·방향·화살촉

제안 구조: `guide.path`는 움직임 경로, `guide.shape`는 최종 실루엣을 담당한다. 둘은 동시에 보이고 저장·내보내기에는 포함하지 않는다.

## 성능과 완료 판정

- `wait.click`·`wait.until`·`wait.progress`로 실제 동작을 판정한다.
- 튜토리얼 실행 중에만 80ms 상태 확인과 위치 재계산이 동작한다.
- 종료 시 interval·animation frame·이벤트·오버레이를 정리한다.

## 요청서 문장

**클릭해야 하는 UI 요소에는 대상 강조선을 표시하고, Ctrl·Shift 입력이 필요한 단계에는 보조키 안내 배지를 표시한다. 캔버스 작업에는 작업 위치 가이드선과 목표 형상 가이드를 함께 표시하며, 사용자의 실제 동작은 유령 커서로 시연한다. 단계 설명은 코치창에 표시하고, 성공 시 완료 피드백을 보여준다.**
