# v1.5.1 — 통합 누락을 바로잡은 5E

v1.5.1은 v1.5.0 설치 파일이 주요 병합보다 먼저 만들어져 일부 기능이 빠졌던 문제를 바로잡은 통합 수정판입니다.

## 포함된 기능

- 스마트 누끼와 민감도 조절
- 지연 자르기와 내부 영역 분리
- 심화 튜토리얼 2~4 및 실습 과제
- AI 이미지 변환 `단순 / 보통 / 복잡` 품질 모드
- 최대 5개 동시 변환과 독립 작업 탭
- 온라인 이미지·기출문제·로컬 폴더 통합 검색
- 이미지 불러오기·화면 캡처·AI 창 붙여넣기

## 검증

- 데스크톱 단위 테스트 43개 통과
- 편집기·AI·자르기 전체 Node 테스트 138개 통과
- 개발 Electron 및 패키징된 Windows 실행 파일 스모크 테스트 통과
- 패키지 내부 `app.asar`에서 위 기능의 실제 포함 여부 확인
