AI 이미지 생성 — 작은 보조 창에서 작업대로

AI 기능을 중앙 모달형 이미지 작업대로 다시 만들었습니다. 왼쪽에는 생성 결과와 참고 이미지, 오른쪽에는 대화와 요청 입력을 배치해 결과를 보면서 지시를 이어갑니다.

대화와 생성은 다른 동작입니다

요구사항이 확정되지 않았다면 보내기 버튼으로 대화만 이어갑니다. 실제 그림이 필요할 때만 이미지 생성을 누릅니다. 상투적인 요청문을 자동으로 작성하지 않으며 사용자의 문장이 요청 기록에 그대로 남습니다.

  1. 요청과 참고 자료 정리
  2. 구조와 배치 분석
  3. 이미지 서버 생성 대기
  4. 투명 배경과 편집용 결과 정리

이미지가 도착하면 대화에 완료 안내를 남기고 캔버스로 출력 버튼으로 현재 페이지에 삽입합니다. 이미지 생성 뒤 작업이 잠기던 문제도 turn 종료 확인과 복구 절차로 고쳤습니다.

그림형

문자 없이 구조만

문자·숫자·기호·라벨·지시선·화살표를 만들지 않습니다. 5E에서 정확한 표기를 나중에 붙입니다.

완성형

필요한 표기까지

사용자가 요청한 표기만 포함하고 장식적 효과와 불필요한 명암을 억제합니다.

연결과 모델 선택

  • 로그인하면 자동으로 연결하며 불필요한 연결 중지 조작을 줄였습니다.
  • 로그인 계정, 잔여 한도, 누적 토큰을 한 줄에서 확인합니다.
  • Luna를 기본 권장 모델로 사용하며 다른 모델에는 지연 가능성 안내를 표시합니다.
  • 모델, 추론 수준, Fast 속도 설정을 작업대에서 선택합니다.
  • 작업마다 사용한 입력·출력 토큰과 소요 시간을 대화 하단에 기록합니다.

참고 이미지를 여러 장 쓰고, 영역마다 따로 지시합니다

참고 자료는 이미지 불러오기, 이미지 라이브러리, 기출문제 라이브러리의 세 경로에서 가져옵니다. 파일 탐색기와 화면 영역 캡처도 같은 불러오기 메뉴에 들어갑니다.

  • 여러 이미지를 동시에 선택해 AI 작업대로 전달합니다.
  • 이미지 위를 드래그하면 번호가 붙은 요청 영역이 만들어집니다.
  • 영역별 요청은 접이식 목록에서 언제든 수정하거나 삭제합니다.
  • 참고 이미지뿐 아니라 생성 결과의 특정 영역에도 수정 요청을 답니다.
  • 이미지 비교에서는 좌우 자료를 골라 1대1로 확대 비교합니다.
  • 확대·축소·수정 버튼은 제목 옆에 모아 세로 공간을 줄였습니다.

전송 성능 정리

이미 보낸 이미지는 대화마다 반복 전송하지 않고, 동일 픽셀 자료는 중복 제거합니다. 큰 이미지는 선화 여부에 맞춰 축소·압축하고 여러 자료는 개요·관련 영역·접촉 시트로 제한합니다. 완전히 같은 요청과 입력의 성공 결과는 캐시에서 즉시 다시 엽니다.

자르기 — 도려낸 부분이 사라지지 않습니다

기존 가위는 이미지를 양 끝까지 가르는 데 적합했지만 내부의 특정 부분만 떼어내기 어려웠습니다. 이제 닫힌 영역도 분리할 수 있으며, 결과는 삭제되지 않습니다.

  • 바깥 부분과 도려낸 부분이 각각 독립 이미지 객체가 됩니다.
  • 작업이 끝나면 도려낸 부분만 선택된 상태가 됩니다.
  • 이동·회전·크기·레이어·삭제를 두 조각에 따로 적용합니다.
  • 지연 자르기는 결과를 확인한 뒤 오른쪽 패널에서 확정합니다.
  • 선택 조건, 팝업 조건, undo 동작도 함께 정리했습니다.

스마트 오려내기는 비슷한 색과 연결된 픽셀을 기준으로 대상을 찾습니다. 민감도를 조절하고 미리보기에서 확인한 뒤 분리합니다.

아트보드 — 드래그한 위치가 새 작업 영역이 됩니다

드래그로 영역 지정은 모서리를 늘이는 기능이 아닙니다. 내보내기 범위를 고르듯 캔버스에서 사각형을 끌면 그 좌표와 크기가 새 아트보드가 됩니다.

  • 커서가 닿는 지점과 실제 선택 사각형의 좌표를 맞췄습니다.
  • 선택 중 너비와 높이를 mm로 표시합니다.
  • Enter 또는 크기 팝업 옆의 지정 버튼으로 확정합니다.
  • 객체를 자르지 않고 아트보드 영역만 다시 정의합니다.
  • Ctrl+A 전체 선택, 내보내기 확정, 한국어 자동 줄바꿈도 보강했습니다.

이미지 배경 — 흰 사각형을 실제 투명 영역으로

AI 생성 결과와 외부 이미지의 흰 배경 때문에 다른 도형 위에 올렸을 때 큰 사각형처럼 보이던 문제를 정리했습니다. 캔버스 삽입 전 배경을 분석해 실제 RGBA 투명 이미지로 만듭니다.

  • 미리보기에서는 결과 확인이 쉽도록 흰 판 위에 표시합니다.
  • 캔버스에서는 선 바깥 영역이 실제로 투명해 뒤쪽 도형이 보입니다.
  • 후처리에 실패한 이미지는 성공 캐시에 저장하지 않습니다.
  • 배경 제거 알고리즘 버전을 캐시 키에 넣어 오래된 결과 오염을 막습니다.

이미지·기출문제·AI 기능이 한 줄로 이어집니다

  • 오브젝트 검색은 돋보기 아이콘으로 줄여 격자 왼쪽에 배치했습니다.
  • 기출문항 검색을 기출문제 라이브러리로 통일했습니다.
  • 이미지·기출 라이브러리의 선택 자료를 AI 작업대로 바로 보냅니다.
  • 라이브러리만 닫아도 뒤의 AI 작업대는 그대로 유지됩니다.
  • 복수 선택한 이미지를 한꺼번에 전달할 수 있습니다.
  • 이미지를 불러오면 추가 버튼 없이 참고 이미지 영역에 바로 표시됩니다.
  • 격자 아이콘과 버튼 정렬, 글자 크기와 위계도 통일했습니다.

.5e 프로젝트와 Windows 설치판

프로젝트 저장 확장자를 .5e로 바꿨습니다. 내부는 안전한 JSON 구조를 유지해 기존 저장·불러오기·자동 저장 흐름과 호환됩니다.

Windows 설치판은 웹판과 별개의 편집기가 아닙니다. 같은 편집기와 프로젝트 형식을 Electron에서 열고, AI 연결·창 캡처처럼 데스크톱에서만 가능한 기능을 안전한 preload 경계 뒤에 둡니다.

  • NSIS 설치 파일과 바탕화면 바로가기
  • Photoshop식 시작 로딩 화면
  • GitHub Actions 기반 Windows 패키징
  • 설치 파일과 SHA-256 체크섬 배포 절차
  • 코드 서명 정책과 SmartScreen 안내
  • 웹판 AI 버튼에서 설치판 안내와 GitHub Release 연결

회전·튜토리얼·과학 부품 보강

30° 빠른 회전

PageUp/PageDown의 5° 회전에 더해 Shift+PageUp/Shift+PageDown으로 30°씩 회전합니다. 회전된 객체를 다시 변형할 때 선택 상자와 스마트 가이드가 원래 축으로 튀던 문제도 고쳤습니다.

심화 튜토리얼 2·3·4

저장·검색·라벨러·중앙 불러오기·화면 비우기·감싸기 시연을 실제 작업 흐름으로 연결하고, 읽기 단계에서 오조작해 과정에 갇히는 문제를 막았습니다.

검전기와 MCP

검전기를 정식 장치 부품으로 추가하고 잎 벌어짐과 종횡비를 프로젝트 저장 규칙에 포함했습니다. MCP에는 출처가 검증된 손·학생·우주선 자산과 안전한 부품 생성 규칙을 보강했습니다.

평가원 과학 도식 Engine V2

Engine V2는 단일 프롬프트가 아니라 입력을 분석하고 적합한 경로를 고른 뒤 결과를 평가·교정하는 패키지입니다.

이미지 생성 지연을 줄인 방법

  • 대화 thread와 렌더 thread 분리
  • 렌더마다 짧은 임시 thread 사용
  • 이미지 도구 호출 1회 제한과 자동 재시도 금지
  • 중복 첨부 전송 제거와 참고 이미지 최적화
  • 이미지 도착 뒤 남은 turn 종료와 다음 작업 잠금 해제
  • 취소 후 원격 작업이 겹치지 않도록 single-flight 적용

검증 결과를 숨기지 않습니다

Engine V2.2 동결 최종 24사례 중 22사례가 통과해 91.7%를 기록했습니다. 정확 컴파일 결과는 21/24, 87.5%였습니다. 개발 36사례는 27/36, 75%로 화학·지구과학의 복잡한 수정에 약점이 남았습니다.

성공 결과뿐 아니라 실패 프롬프트, 구조 손실·과도한 회색·편집 범위 초과 같은 실패 유형, 교정 이력과 freeze 해시도 저장했습니다.

알려진 제한

원격 생성 속도

서버 상태에 따라 수십 초에서 수분까지 달라집니다. Luna·낮은 추론·Fast가 권장값이지만 시간을 보장하지 않습니다.

과학적 정확성

참고 이미지 변환 결과는 자동 보장되지 않습니다. 구조·연결·접촉 관계를 생성 뒤 확인해야 합니다.

초고속 경로 범위

엄격한 19개 패턴만 로컬에서 즉시 생성합니다. 표현이나 부품이 달라지면 다른 경로로 전환합니다.

배포와 보안

자동 업데이트와 코드 서명은 아직 없습니다. SmartScreen 경고와 lockfile high severity 경고 1건이 남아 있습니다.

예전 AI 브랜치구형 feat/ai-assist의 Cloudflare Worker와 채팅 UI는 포함하지 않았습니다. v1.5.0은 Windows Desktop의 로컬 Codex 연결을 사용합니다.

업그레이드 안내

  1. 웹판 모듈이 갱신되지 않으면 Ctrl+F5로 새로고침합니다.
  2. Windows판은 기존 5E를 종료한 뒤 새 설치 파일을 실행합니다.
  3. 기존 프로젝트 JSON과 .5e 파일은 그대로 열 수 있습니다.
  4. AI 기능에는 Codex 설치와 로그인이 필요합니다. 일반 편집 기능은 AI 없이 동작합니다.
  5. GitHub Release의 SHA-256 값과 설치 파일 체크섬을 비교할 수 있습니다.
배포 상태현재 Windows 검증 빌드는 v1.5.0-beta.1입니다. 공개 태그와 설치 파일은 최종 배포 절차에서 같은 버전으로 맞춥니다.

v1.5.0은 AI가 그림을 대신 완성하는 판이 아니라, 그림을 가져와 비교하고 부분을 지정해 요청한 뒤 5E에서 끝까지 고칠 수 있게 만든 판입니다.
