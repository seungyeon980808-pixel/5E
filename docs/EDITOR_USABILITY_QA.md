# 일반 편집기 사용성 수정·검증

기준: `fc75e368cec7b5d0b409480ab3804fac25570e14`, `codex/editor-usability` 작업 트리.
범위: 일반 편집기. AI 작업실·변환 알고리즘·계정 화면·공용 Render 서버는 변경하지 않음. 커밋·푸시·배포 없음.

Windows 후속 검증 작업 지시: [실제 Windows 검증 명세](WINDOWS_EDITOR_VERIFICATION.md). 수정본 인수, PowerShell 실행 절차, 수동 시험과 보고 기준을 포함한다.

## 반영한 동작

- 실제 브라우저 copy/cut/paste 이벤트로 객체 복사·잘라내기·붙여넣기. 내부 복사 뒤 외부 이미지/텍스트를 복사하면 최신 시스템 클립보드가 우선한다. 클립보드 쓰기 실패 시 원본 보존, 잠금 객체 제외, 잘못된 기하 데이터 거부.
- 복제 객체·그룹 ID 재발급, 함께 복사한 평면·함수 참조 재연결. 평면은 연결 그래프를 함께 복사하고, 잠긴 그래프를 남겨둔 채 평면만 잘라내지 않는다. 단독 함수 복사는 원본 평면 연결을 떼고 점열을 보존한다. 붙여넣기는 커서/뷰 중앙과 활성 레이어에 삽입한 뒤 선택 도구로 돌아간다.
- transform 모듈의 서로 다른 URL로 생기던 별도 인스턴스를 통일해 커서 좌표를 공유한다.
- 이미지 읽기/해석 중 페이지 변경 취소, 실패 안내. 기존 AI 이미지 삽입 함수와 바이트 보존 정책 재사용.
- 페이지별 Undo/Redo·선택·레이어 보존. 삭제 Undo는 현재 페이지를 유지하고 탭을 복구한다. 복구한 페이지의 새 편집은 오래된 삭제 Redo를 무효화한다. 기록은 파일에 저장하지 않는다.
- Windows Ctrl / Mac Command, Windows Ctrl+Y 추가, 한글 물리 키 대응과 조합 보호. 스냅 안내는 Mac Option을 구분한다.
- 입력 컨트롤·모달의 편집 키 보호. 저장/열기는 일반 입력값을 먼저 확정하고 실행하되 모달·조합 중에는 브라우저 기본 파일 동작까지 막는다.
- 캔버스 클릭 시 키보드 포커스 이동. 창 이탈 시 Space/화살표 홀드·팬 초기화. 메뉴 방향키·Home/End·Escape 복귀.
- 파일 저장 완료 / 다운로드 요청 / 자동 복구용 저장 / 미저장 상태 표시. 취소와 저장 도중 추가 변경은 잘못 완료 표시하지 않는다.

## 하네스

```sh
npm run test:editor
```

Node VM 기반 회귀 테스트는 실제 모듈의 이벤트 처리와 상태 전이를 실행한다. Windows/Mac modifier, IME/SELECT/modal, 클립보드 실패, 관계 ID, 페이지 기록, 지연 이미지 읽기, 저장 취소·동시 편집을 포함한다.

브라우저 하네스는 Playwright 패키지와 Chromium이 필요하다. 프로젝트에 별도 의존성을 추가하지 않았으므로 기존 Playwright 설치를 사용하거나 `PLAYWRIGHT_MODULE`에 패키지 경로를 지정한다. 테스트용 페이지는 이 작업 트리를 제공해야 한다.

```sh
# 포트가 비어 있는지 먼저 확인하고 본인 서버만 실행한다.
python3 -m http.server 19424 --bind 127.0.0.1
# 별도 터미널
npm run test:editor:browser
```

옵션: `EDITOR_QA_URL`(localhost만 허용), `EDITOR_QA_OUT`, `PLAYWRIGHT_MODULE`.
결과: `browser-results.json`, 플랫폼별 trace ZIP·스크린샷·저장/재열기한 `.5e` 파일. 기본 경로는 운영체제 임시 디렉터리 아래 `5e-editor-usability-qa`이며 `EDITOR_QA_OUT`으로 지정할 수 있다.

실제 마우스로 생성·크기조절·이동하고, 복사/잘라내기/붙여넣기·그룹·Undo/Redo·페이지 전환·삭제 복구·모달 차단·메뉴 포커스·저장/재열기·외부 PNG 붙여넣기를 검증한다. 읽기 전용 상태 조회를 단언에 사용하며 그림은 UI로 만든다.

## 검증 결과 및 한계

- 편집기 전용 테스트: **84 통과 / 0 실패**.
- macOS Chromium: 실제 Command 키와 OS 클립보드, 파일 선택·다운로드·재열기 통과.
- Windows 분기: macOS Chromium에서 Win32 플랫폼·Control 이벤트와 ClipboardEvent로 통과. **실제 Windows OS 검증 아님**. Windows 호스트에서 같은 하네스를 실행하면 Control과 OS 클립보드 경로를 네이티브로 실행하도록 구성했다.
- 1440/768/375px 캡처. 기존 좁은 화면 편집기의 가로 넘침은 별도 모바일 재설계 대상으로 남긴다.
- 전체 테스트의 기존 AI 비교 크기·AI 완료 상태 테스트 2건은 출발 커밋을 별도 임시 폴더에 풀어 동일 실패를 재현했다. 이 수정으로 고치거나 테스트를 약화하지 않았다.
- 실제 Render 및 AI 생성은 실행하지 않았다. 파일 저장 피커 취소·실제 디스크 쓰기 완료 분기는 단위 하네스에서, 다운로드/재열기는 실제 브라우저에서 검증했다.

전체 실행: **546개 중 544 통과, 기존 실패 2개**. 독립 기능 검토에서 현재 변경과 84개 전용 테스트·브라우저 결과를 재확인하고 승인했다. Git 공백 검사는 기존 CRLF 파일을 보존하도록 `git -c core.whitespace=cr-at-eol diff --check`로 통과했다.

화면 검토 보완: 긴 복구·다운로드 안내를 짧게 표시하고 전체 설명을 title/접근성 이름에 남겼다. 새 작업·미저장·복구 저장·다운로드·파일 저장의 5개 상태를 양 플랫폼 모드에서 각각 **정확한 375×1000 뷰포트**로 캡처했다. 상태의 좌우 경계와 `scrollWidth <= clientWidth`를 브라우저 하네스에서 검사해 10개 상태 모두 통과했다.

재현 근거: 수정 전 실제 transform 핸들러 실행 결과 복제 그룹은 `['g', 'g']`였으며 Ctrl+X 뒤 객체 수는 `2`로 유지됐다. 이미지 클립보드의 페이지 전환·실패 안내·중복 처리 테스트 3개, 메뉴/단축키 보호와 페이지 기록 테스트는 수정 전 실패를 확인한 뒤 수정했다. 추가 독립 검토에서 발견한 잘못된 객체 기하 데이터와 인스펙터 버튼 포커스의 Cut도 회귀 테스트로 보호한다.

최종 독립 검토: 기능 통합과 화면/CJK 두 검토 모두 **APPROVE**, 남은 차단 항목 없음. 화면 검토 보고서는 QA 출력 폴더의 `visual-review.md`에 보관했다. 검증용 19424 서버는 종료했고 임시 디버그 파일은 작업 트리에서 제거했다.
