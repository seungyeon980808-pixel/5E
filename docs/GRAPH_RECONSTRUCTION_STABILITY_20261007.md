# 그래프 복원 안정화 · 2026-10-07

사용자가 승인한 안정화 작업은 기존 그래프 도구를 유지하면서 원본과 편집 결과를 보존하고, 실제 모델 결과의 관계 오류와 누락을 별도로 평가하는 것이다. 개발 브랜치는 `fix/analyable-function`이다.

## 실행과 결과 보존

- 그래프 복원은 `gpt-6.1-sol` / `medium`을 사용한다. 실패 후 다른 모델로 바꾸거나 자동 재전송하지 않는다.
- 429·인증·연결·시간초과·지원 모델 오류를 구분하고 원문 오류는 로그에 보존한다. 새 복원 실패가 이전 후보를 제거하지 않는다.
- 편집 적용 시 객체를 먼저 저장한다. 이후 글꼴/미리보기 렌더가 지연되어 다른 작업을 선택하더라도 편집한 작업에만 결과를 저장한다.
- 중단 후 이전 그래프가 있으면 복구 안내가 기존 결과 편집을 가리지 않는다.
- 저장 객체의 잘못된 점·눈금·참조·그룹을 삽입 전 차단한다. 임시 편집용 레이어 ID는 결과에 남기지 않는다.

## 관계 검사와 캐시

스키마 검증과 별도로 명시된 눈금 교점, 강한 기준점, 보조선 방향, 계열 참조 및 식 정의역을 검사한다. 심각한 불일치는 자동 삽입과 캐시 수락을 차단하고, 식을 찾지 못한 곡선 등은 검토 항목으로 남긴다. 직선·꺾은선·막대는 정상적인 편집 표현이다.

관계 검사 통과는 원본 전체 재현이나 물리 법칙의 검증을 뜻하지 않는다. 원본 요소 목록과 실제 비교 이미지에 의한 별도 평가가 필요하다. 캐시에는 관찰 프롬프트 외에도 좌표·격자·보조선·화살표·함수 맞춤·관계 검사 버전을 포함한다. 실제 평가에는 코드 해시도 기록해 실행 중 기준 코드가 바뀌는 것을 차단한다.

## 재현 가능한 검증

합성 오류 검증은 실제 모델 호출과 구분한다. 작업대 검사는 Chromium과 WebKit에서 중복 실행, 429, 연결 중단, 늦은 완료 이벤트, 새로고침, 편집 렌더 중 작업 전환을 실행한다. 객체 검사는 잘못된 저장 자료가 렌더·편집·삽입 전에 제어된 오류로 거절되는지 확인한다.

초기 안정화 검증: 복원 워크플로 41건 통과, 오류/품질 단위 검사 통과, 작업대 오류 흐름과 객체 검증의 두 브라우저 통과, 기존 중2 교과서 10개를 두 브라우저에서 편집·저장·재개방한 20건 통과. 전체 단위 검증은 345/346 통과했으며 기존 PNG 압축 바이트 비교 실패 1건은 기준을 바꾸지 않고 남겼다. 이후 추가한 null 눈금 단위 검사 4건도 통과했다.

## 새 원본 평가

새 중2 과학 교과서 10개와 물리 기출 10개를 최초 응답 그대로 평가한다. 원본 PDF, 잘라낸 범위와 SHA256, 요청·응답·실행 모델/effort, 초기 결과와 편집 가능한 `.5e`를 보존한다. 사람의 요소 목록은 평가에만 사용하고 AI 입력에는 넣지 않는다. 실패 사례의 추가 실행은 최대 5개로 제한한다.

교과서는 천재교과서 중학교 과학 2(임성숙, 2022 개정)이며 물리는 2023년 6월·2024년 9월 고2 전국연합학력평가이다. 이 물리 원본은 수능·평가원 기출로 집계하지 않는다. 파동 5개는 같은 교과서 페이지의 서로 다른 패널이므로 결과 해석 시 유형 집중을 표시한다.

웹 인증과 데스크톱 IPC의 완전한 종단 검증은 이 로컬 App Server 어댑터 평가만으로 확인됐다고 보고하지 않는다.

## 실제 평가 결과

제품 기준 커밋 `6a879973`의 프롬프트 v22와 코드 해시를 고정해 실행했다. 20개 모두 실제 요청했으며 최초 편집·저장·재개방 성공은 13/20이었다. 제공자 DNS 장애(`ENOTFOUND chatgpt.com`)와 시간초과 사례 중 5개를 추가 실행해 18/20이 되었다. 총 요청은 25회로 한도를 지켰다. 요청 단계 전 로컬 페이지 로딩에 실패한 4개는 코드 기준을 유지한 채 최초 요청을 별도 폴더에 기록했다.

원본 PNG와 결과 PNG의 수동 비교 판정은 핵심 요소·관계 유지 9개, 수정·검토 필요 7개, 미완료 4개다. 미완료는 높은 소리 파형의 가려진 골 변형, 용해도 단위/눈금 겹침, 제공자 장애로 결과가 없는 물리 2개이다. 목표인 재현 확인 18/20은 달성하지 못했다. 이 9개도 모든 글자 크기·굵기가 원본과 같거나 해석 함수로 복원됐다는 뜻은 아니다.

최종 생성 결과의 계열 표현은 식 1개, 정상 기본 도형 5개, 곡선 점 경로 15개이다. 단순히 네이티브 객체가 생겼다는 이유로 함수 복원 성공으로 보고할 수 없다. 새 원본에서 함수 종류 선택과 식 복원이 여전히 부족하다. 특히 제목이 곡선을 가릴 때의 파형 추론, 닫힌 과정의 함수·직선 분해, 수치 없는 상대 좌표의 함수 후보 선택을 다음 품질 작업으로 남긴다.

분석기가 두 숫자 눈금만으로 원점을 제외한 수치 범위를 만들어 버리는 사례도 발견했다. 2023년 6월 2번은 내부 첫 x좌표가 1.043이고 출력 원점에는 0이 쓰인다. 증류 그래프의 y 최소값은 −22.7이다. 원본의 비례하지 않는 도식에서 인쇄된 원점·눈금 관계와 내부 좌표 의미가 충돌할 수 있으며, 현재 명시 관계 검사는 이 문제를 전부 검출하지 못한다. 관계 검사 통과를 정확한 수치·물리 법칙 검증으로 확장해 보고하지 않는다.

## 평가에서 추가로 고친 오류

- 제공자 연결 장애를 한국어 작업대 메시지와 원문 공급자 로그에서 감지하고 남은 배치 제출을 멈춘다. 외부 글꼴 네트워크 때문에 로컬 화면의 `networkidle`이 끝나지 않던 검증 도구는 실제 작업대 요소 준비를 기다린다.
- 그래프 라벨의 `\\left` / `\\right` 괄호 명령을 문자로 출력하던 그래프 전용 렌더 오류를 수정했다. 괄호 안 분수·한글·단위는 보존한다. 실제 용해도 결과를 AI 재호출 없이 재렌더했고 기존 `.5e`를 두 브라우저에서 열어 no-op 편집과 원본 계획·객체 불변을 확인했다. 단위의 방향·배치와 눈금 겹침은 여전히 미완료다.
- 라벨 렌더 버전도 복원 캐시 키에 넣고 평가 코드 해시에 라벨/수식 렌더 파일을 포함했다.

추가 렌더 회귀 검사는 Chromium/WebKit에서 통과했다. 최종 전체 단위 실행의 347개 중 345개가 통과했고, Playwright 경로 환경 누락으로 실패한 검사 1개는 올바른 경로로 재실행해 통과했다. 합계 346/347이며 남은 1개는 기존 PNG 압축 바이트 비교 문제다. 실패한 실행 로그도 덮어쓰지 않고 보존했다.
