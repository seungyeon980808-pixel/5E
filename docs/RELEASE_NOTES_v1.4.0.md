## 부품 라이브러리 — 밖에서 그림을 가져옵니다

세포 그림처럼 **수치로 정의할 수 없는 것**은 부품으로 못 만듭니다. 그래서 퍼블릭 도메인 도해를 모아 두고, 쓸 때 **흑백 선화로 바꿔 넣는** 창을 만들었습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.4.0/docs/images/release-v1.4.0/09-lineart-levels.svg" alt="선화 위계 4단계" width="700" />

*맨 왼쪽이 원본(컬러). 오른쪽으로 갈수록 지우는 단계가 세집니다 — 색만 벗기기, 작은 조각 정리, 글자·지시선 제거, 큰 구조만.*

**최적 단계는 그림마다 다릅니다.** 증류 장치는 3단계가, 식물 세포는 4단계가 맞았습니다. 원본이 글자를 어떻게 그렸느냐에 따라 갈리기 때문에 자동으로 정하지 않고 고르게 했습니다.

원본(컬러)을 그대로 보관하고 **넣을 때 변환**합니다. 변환기가 나아지면 다시 모으지 않고 전부 다시 뽑을 수 있습니다.

라이선스와 출처를 항목마다 박아 두었습니다. 나중에 "이 그림 어디서 났더라"를 다시 찾지 않아도 되고, 라이선스가 애매한 게 섞이면 그것만 골라 뺄 수 있습니다.

창을 처음 열 때만 목록을 읽습니다. **앱 켜는 시간은 그대로**이고, 그림 1000장을 등록해도 변하지 않습니다.

## 상자가 그림에 맞습니다

자른 조각이 원본 상자를 그대로 물려받아, **작은 조각은 상자의 76%가 빈 공간**이었습니다. 미관 문제가 아니라 빈 곳을 눌러도 그 이미지가 잡히고, 드래그 선택·정렬·내보내기 여백이 모두 어긋나는 문제였습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.4.0/docs/images/release-v1.4.0/15-tight-box.svg" alt="상자를 그림에 맞추기 전후" width="640" />

*같은 조각입니다. 선택 상자(파란 점선)가 보이는 그림에 붙습니다.*

**크기 조절은 그대로 됩니다.** 상자만 줄이고 그림은 원래 자리에 그리는 방식이라, 클릭·이동·회전·크기조절은 전과 똑같이 동작합니다. 실측으로 낭비 76%가 0%가 됐고, 원본과 조각을 합친 그림이 픽셀 단위로 같습니다.

내보내기에 **[내용에 맞춤]** 이 생겼습니다. 지금까지는 아트보드 전체가 나가서 여백을 없애려면 영역을 손수 잡아야 했습니다. 이제 체크 한 번이면 그림에 딱 맞게 나가고, 여백은 mm로 정합니다. 90×60mm 아트보드가 25.9×40mm로 줄어듭니다.

이미 놓아 둔 이미지는 인스펙터의 **[여백 정리]** 나 Ctrl+K → "이미지 여백 정리"로 조입니다.

## 말로 그립니다 — 그리기 도구가 3개에서 7개로

Claude에게 "30도 경사면에 물체 두 개 올려 줘"라고 시키면 열려 있는 5E 화면에 바로 그려지는 기능입니다. 지금까지 그림을 그리는 도구는 **객체 넣기·회로·그래프 셋뿐**이었고, 나머지는 전부 좌표 계산이었습니다. **좌표 산술이 남아 있는 한 어떤 모델도 거기서 틀립니다.**

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.4.0/docs/images/release-v1.4.0/16-mcp-tools.svg" alt="MCP 도구 20개 — 이번에 늘어난 5개" width="700" />

*늘어난 자리는 전부 "손으로 좌표를 계산하던 자리"입니다.*

### 모델에게 mm를 묻지 않습니다

`add_incline_scene`(경사면 장면)에 주는 것은 **경사각과 면 위 위치(0~1)**뿐입니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.4.0/docs/images/release-v1.4.0/17-mcp-incline.svg" alt="주는 것 vs 툴이 계산하는 것" width="700" />

*왼쪽이 부르는 말 전부입니다. 오른쪽의 접촉점·회전각·안팎은 아무도 계산하지 않았습니다.*

블록이 면에 닿는 점, 회전각과 그 **부호**, 법선 방향, 마찰 띠를 면 안쪽에 깔지 바깥쪽에 깔지, 그리는 순서까지 도구가 정합니다. 면 이름은 `경사면`·`수평면` 둘뿐이고, `s=0`이 아래끝 `s=1`이 꼭대기입니다.

선도 숫자로 부르지 않습니다. `dashLength: 1.0`이 아니라 **"기준선"이라는 이름**으로 고르면 규격은 바이블 §17 표에서 옵니다.

### 새로 부를 수 있게 된 것

| 도구 | 하는 일 |
|---|---|
| `add_incline_scene` | 경사면 장면 통째로 — 빗면·블록·마찰 구간·실·용수철·각도호·치수·화살표·패널 이름 |
| `add_dimension` | 치수선 — 방향·뺄 쪽·끝 캡·라벨 자리. 화살표와 글자를 손으로 조립하지 않습니다 |
| `add_part` | 삽화 부품 — 물체를 쥔 손처럼 **앞·뒤 두 조각**으로 갈라 사이에 대상을 끼웁니다 |
| `add_stand_rig` | 스탠드·가로대·레일 — 매다는 것과 얹는 것을 위치 비율로만 지정 |
| `export_image` | 그린 결과를 그림으로 되받습니다 |

기존 도구도 자랐습니다. `add_graph`는 수식 말고 **좌표를 직접 찍는 점 계열(꺾은선)**과 문자 눈금을 받고, `add_circuit`은 사각 폐회로가 아닌 **임의 배선**과 소자 크기 배율을 받습니다.

### 그린 다음 확인하는 눈이 둘

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.4.0/docs/images/release-v1.4.0/18-mcp-verify.svg" alt="export_image 고리와 검산 리포트" width="700" />

**하나는 눈입니다.** `export_image`가 생기면서 호출 순서가 "그린다 → 본다 → 고친다"로 닫혔습니다. 겹침·잘림·라벨 위치는 봐야 압니다.

**하나는 숫자입니다.** 장면 도구는 응답마다 **검산 리포트**를 붙입니다. 요청한 값을 다시 읊는 게 아니라, **만들어진 객체에서 되짚어 재서** 접촉 거리(0.01mm 이내)·되잰 각도·글자 간격을 ✔/⚠로 돌려줍니다. 이미지 판독이 약한 모델도 이 표만 읽고 고칠 수 있습니다.

### 규칙을 문서로 못박았습니다

`tools/mcp-5e/CONVENTIONS.md`에 표준 호출 6단계와 페이지 규약을 적었습니다 — 그림 하나에 페이지 하나, 겹쳐 그리지 않기, 한 그림은 한 번에, 수정은 2회 이내. **저장은 사용자의 Ctrl+S입니다.** Claude가 파일을 덮어쓰지 않고, 들어온 변경은 전부 Ctrl+Z로 되돌아가는 상태를 유지합니다.

`/5e` **슬래시 명령**도 함께 넣었습니다(`tools/mcp-5e/commands/5e.md`를 `~/.claude/commands/`에 복사하고 폴더 경로만 바꿉니다). 선 굵기·점선 종류·라벨 위치 규칙을 요약해 물려주기 때문에, 같은 요청이라도 그림 품질이 눈에 띄게 달라집니다. 설치는 `GUIDE_FOR_TEACHERS.md` 6단계입니다.

앱 쪽도 손봤습니다. **MCP 버튼이 항상 보이고**, 설치가 안 돼 있으면 안내를 띄웁니다. 5E 창을 여러 개 띄워도 **자동 재연결이 다른 창의 연결을 뺏지 않고**, 지금 어느 창에 붙었는지 알려줍니다.
