# 참조 이미지 직접 생성 재현 학습 로그

## 목적

평가원 기출 원본을 이미지 생성 모델에 참조 이미지로 제공하고, MCP 조작이나 벡터 코드 작성 없이 별도의 래스터 도판으로 재현한다. 원본과 생성본을 나란히 비교해 다음 생성 프롬프트와 제작 지침을 갱신한다.

## 고정 조건

- 그래프는 선정하지 않는다.
- 한글·영문·기호·숫자·수식·패널 표식·화살표를 생성 이미지에 넣지 않는다.
- 흰 배경과 검은 선을 기본으로 한다.
- 회색은 물리적 의미가 있는 영역에서만 균일한 평면 농도로 사용한다.
- 95% 이상만 통과로 판정한다.
- 원본과 생성본의 실루엣, 객체 수, 연결 관계, 상대 위치, 선 위계, 회색 사용을 함께 평가한다.
