# 평가원 도판 재현 학습 로그

## 공통 통과 기준

- 원본에서 제거하기로 한 문자·수치·기호·화살표가 남지 않는다.
- 본체, 회로, 그래프, 점선 기준선 등 문제 풀이 구조가 누락되지 않는다.
- 각 요소의 상대 위치·크기·간격이 원본과 시각적으로 95% 이상 일치한다.
- 실선·점선·외곽선의 굵기 위계가 원본과 일치한다.
- 회색은 원본의 재료 구분 영역에만 사용한다.

## 001. 이중 코일과 전류 그래프

원본: `graph_reference/p2_2027_06_11.png`

### 보존 요소

- 하나의 긴 원통형 철심
- 왼쪽 1차 코일과 오른쪽 2차 코일의 분리, 폭, 감김 밀도
- 서로 분리된 두 회로
- 전원 장치의 사각 외곽과 두 단자
- 검류계의 원형 외곽
- 두 저항의 지그재그 형태
- 오른쪽 좌표축, 점선 격자, 상승-정속-하강 꺾은선

### 제거 요소

- 한글 라벨
- 라틴 문자와 수식
- 수치와 단위
- 전류 방향 화살표
- 패널 구분 문자

### 생성 모델 반복에서 확인된 실패

1. 텍스트 제거와 함께 오른쪽 그래프 전체를 누락했다.
2. 장치와 그래프를 원본보다 크게 확대했다.
3. 코일의 감김 수와 간격을 임의로 바꿨다.
4. 모든 선을 같은 굵기로 만들어 인쇄 도판의 위계를 잃었다.

### 확정 제작 지침

- 원본 전체를 하나의 장면으로 보존 대상을 먼저 선언한다.
- `텍스트 제거`와 `구조 재생성`을 동시에 맡기지 않는다.
- 코일처럼 반복 횟수가 의미 있는 구조는 생성 모델에 맡기지 않고 좌표 기반 SVG로 그린다.
- 그래프는 축, 격자, 곡선을 별도 레이어로 분리한다.
- 2회 이상 반복해 동일 구조 오차가 남으면 SVG 직접 추적으로 전환한다.

### SVG 직접 추적 결과

- 캔버스를 원본과 동일한 `974 × 457` 좌표계로 고정했다.
- 철심, 회로, 그래프의 주요 좌표를 원본 픽셀 기준으로 배치했다.
- 생성 과정에서 반복적으로 변형된 1차·2차 코일은 감김 수와 폭을 좌표로 고정했다.
- 문자와 화살표가 있던 자리는 구조선을 임의로 보충하지 않고 흰 여백으로 남겼다.

- 누락 구조: 없음
- 결과: 통과
