# 문항 시트

5E의 **문항 시트**에서 연다. 독립 주소는 `/assets/exampool/sheet/index.html`이다. `?example=1`은 실제 입력과 별도의 저장소를 쓰는 구조 연습 화면이며 예제의 정답은 미설정이다.

## 작업 흐름

1. **새 문항**에서 기출 모양을 고른다. 지문·보기, 두 그림 비교, 실험·장치, 실험·결과표, 그림·자료표, 그림 선지의 6종이다. 답안형과 선지 표현은 별도로 선택한다.
2. A열의 항목을 고정하고 B열부터 문항을 관리한다. 문항유형, 대·중·소단원, 성취기준, 핵심개념, 관리번호, 발문, 자료, 사진, 지문, 선지, 보기 순서다. 아래에는 자료 구성·선지 표현·시험지 번호·정답·배점·출처·해설·출제 의도가 있다. 핵심개념은 쉼표나 줄바꿈으로 여러 개를 입력한다.
3. 자료·사진·표/그림 선지는 **더블클릭 또는 F2**로 구성 편집을 연다. 묶음 안에 과정·표·그림을 추가하고 배치·순서를 조정한다. 표는 실제 셀을 편집하며 병합·머리글·셀 그림·단위·각주를 유지한다. 평소에는 구성 편집을 닫고 시트를 넓게 쓴다.
4. **자료 열람**에서 성취기준·해설, 교과서, 참고자료, 공개 물리 기출 원문을 보고 문항·자료·선지별로 쪽수와 근거를 연결한다.
5. 문항 머리글의 **조판 보기** 또는 **문항 조판**을 누르면 시트 오른쪽의 작은 패널에 실제 RHWP 문서 편집기가 열린다. 문항 안을 클릭해 문단 모양을 조정하고, 글을 선택한 뒤 글자 모양을 조정한다. 표를 선택하면 표 위치와 크기 잠금 도구가 나온다. **상세 조판**에서 전체 도구와 기준 시험지 설정을 펼치고 **크게 보기**로 넓게 편집한다. 기본은 A4·2단이며 B4·A3 및 1단을 선택할 수 있다. 그림을 더블클릭해 글자처럼 취급·어울림·간격·정렬을 정하고 크기는 그림 조절점을 드래그한다.
6. **조판 저장**은 편집 가능한 HWPX 문서를 문항에 보관한다. 먼저 중첩 표의 모든 상위 셀까지 확인해 글의 여백·테두리 넘침, 줄 겹침, 글과 수식·그림의 겹침, 단 너비를 벗어난 표를 검사한다. 문제가 있으면 해당 쪽·행·열과 글을 안내하고 저장을 중단한다. 재열기 후 모든 페이지의 글자 위치·크기·장평·자간, 표 크기·병합, 그림 위치·크기·자르기·어울림도 비교한다. 빈 문단의 삽입 글꼴 등으로 재열기 배치가 달라지면 최종 파일을 다시 표시한다. 이 경우 사용자가 갱신된 모양을 확인한 뒤 저장을 다시 누른다.
7. **HWPX 내려받기**, 또는 5E 안에서 **한글로 보내기**를 사용한다. 저장한 문항 범위를 네이티브로 가져오므로 승인한 문항을 다시 HTML로 변환하지 않는다. 본문은 글·표·그림·수식이 각각 편집 가능하다. 새 시험지는 조판의 용지·단을 적용하고 기존 시험지의 규격이 다르면 안내한다.
8. **엑셀 내려받기·올리기**는 같은 세로 구조를 사용한다. 가져오기 미리보기 후 새 문항 추가 또는 같은 문항 업데이트를 정한다. 오류·취소는 기존 입력을 보존한다.

## 수식과 조판 내용

지문·발문·보기·선지·표 셀에서 `$\frac{1}{2}mv^2$`, `\(v_0\)`, `{{수식:1 over 2}}`처럼 입력한다. 문서 엔진은 LaTeX와 한글 수식 문법을 읽고 편집 가능한 한글 수식 개체로 표시한다. 수식의 실제 너비·높이로 줄을 다시 배치해 글 겹침을 방지한다. 사진으로 변환하지 않는다. 일반 Excel 계산 수식은 실행하지 않는다.

문항의 **내용**은 시트·구성 편집에서 수정하고, 조판 화면에서 서식을 정한다. 조판 화면에서 글·수식·그림 내용까지 바뀌면 데이터 시트와 어긋나므로 저장 전에 안내한다. 데이터를 수정하면 이전 조판의 승인 상태가 무효가 되고 다음 조판을 다시 만들어 확인한다. 해설·정답·출제 의도·근거는 학생용 조판에 넣지 않는다.

표 머리글은 셀 너비에 맞춰 단위와 단어를 줄바꿈하고 전체 머리글 묶음을 가운데 정렬한다. 줄 수에 맞춰 행 높이를 확보한다. 새 문서를 만드는 단계에서 HTML 가져오기가 붙인 표 들여쓰기와 무시된 셀 여백을 보정한다. 실험 상자와 보기의 높이는 내용에 맞춰 늘어나며 표 아래 설명도 상자 안에 줄바꿈한다. 이전 방식으로 저장한 조판은 새 배치로 다시 확인해야 한다. 표 크기는 기본 잠금 상태다. 표 셀을 선택한 뒤 **표 크기 조절**을 켠 경우에만 경계 드래그로 크기를 조절한다. 표 자체는 단 또는 상자 안에서 가운데에 놓이며, 셀을 클릭한 뒤 상단 **표 위치**에서 왼쪽·가운데·오른쪽을 고른다. 일반 표 셀 안 여백은 약 1mm, 실험 상자 좌우 여백은 약 2mm이며 보기 좌우 여백은 6px다. 보기의 제목은 원본처럼 상단 선 중앙의 `<보 기>`이며 제목 뒤에는 선을 그리지 않는다. 테두리는 0.4pt의 가는 검은 선, 항목은 `ㄱ.·ㄴ.·ㄷ.` 표기와 150% 줄 간격을 쓴다. 긴 문장의 이어지는 줄은 실제 글꼴로 측정한 기호 뒤에 맞춘다. 보기 제목·테두리·본문은 편집 가능한 한글 표와 문단으로 유지한다. 중첩 보기에서도 줄 수에 맞춰 셀 높이를 확보한다. 이 서식을 적용할 때 수식 문단의 원래 줄 배치를 함께 보존해 자료 상자 앞에 과도한 빈 공간이 생기지 않도록 한다. 조판 보기에서는 인쇄되지 않는 빨간 보조 테두리를 기본으로 숨긴다. 문항 번호와 첫 지문(지문이 없으면 발문)은 같은 문단에 놓이며 다음 줄은 번호 뒤에 맞춘다. 본문·일반 표 셀에서 커서를 놓고 **Shift+Tab** 또는 **내어쓰기** 버튼을 누르면 그 위치에 다음 줄을 맞춘다. 문단 맨 앞에서 실행하면 내어쓰기를 해제한다. 시트에서 Shift+Tab은 이전 셀 이동으로 유지된다. 중첩 표의 보기 기본 내어쓰기는 생성 단계에서 적용한다. 현재 문서 엔진의 중첩 셀 문단 서식 명령에는 제약이 있어 중첩 셀 안에서 Shift+Tab으로 다시 지정하는 경우 별도 안내가 필요하다.

## 엑셀식 조작

클릭 선택, 방향키 이동, 바로 입력, 더블클릭/F2 편집, Enter·Tab 확정 및 이동, Esc 취소, Alt/Option+Enter 줄바꿈을 지원한다. 드래그·Shift·행/열 머리글로 범위를 선택하고 ⌘/Ctrl+C/V로 Excel TSV를 복사·붙여넣는다. 문항 열이 Z를 넘어도 주소를 표시한다. 검색 중에는 보이는 문항 ID만 수정한다. 새 문항 열은 새 문항·복제로 추가한다.

한 값을 범위에 붙여 채울 수 있으며 여러 셀 적용은 하나의 되돌리기 단위다. 실패 시 부분 수정도 복원한다. 유형·자료 구성·선지 표현은 목록을 검증한다. 자료표의 병합을 가로지르는 붙여넣기와 값이 있는 숨은 셀은 거절한다. 내용 비우기는 그림과 복합 자료를 유지한다. 되돌리기·다시 실행은 버튼과 단축키를 제공한다.

## XLSX와 저장

| 시트 | 내용 |
| --- | --- |
| 문항 | 항목은 행·문항은 열. 단원·관리번호·핵심개념·지문·보기·문장 선지를 편집한다. |
| 구성 | 중첩된 설명·그림·과정·대화·보기·선지의 실제 셀과 이미지 개체. |
| 표 | 실제 표 셀, 병합, 그림, 다단 머리글, 단위와 각주. |
| 자료 | 자료 원문과 연결 쪽수·인용. |

숨김 문항 ID 행, 구성 ID 열과 `_구조` 시트는 문항·그림·표·원문·5E 원본·저장한 조판을 연결한다. 세로 시트에서 수정한 지문·보기·선지는 구성 시트의 이전 값에 덮어쓰이지 않는다. 이전 가로 구조 양식과 단순 문항 양식도 읽는다. 표·그림 선지는 해당 구성·표 시트에서 수정한다. 그림은 지정 그림 칸 또는 표 셀에 넣는다. `0`, 빈칸, `㉠`, `001`, `1.0`을 구분한다.

IndexedDB `5e-exampool-structure`에 자동 저장하며 버전 충돌을 확인한다. 이전 저장소는 지우지 않고 복사와 백업으로 옮긴다. 문항 500개, 구성 80개/문항, 표 30×12, 자료 40개, 개별 입력 파일 5 MB, 전체 묶음 24 MB, XLSX 20 MB·압축 해제 48 MB 제한이다.

## 검수 범위

기존 물리학Ⅰ·Ⅱ 2025학년도 6월·9월·수능 120문항과 사용자가 제공한 2028 수능 통합과학 예시 6쪽의 실험 상자, 복수 결과표, 사진·그림, 병합 머리글, 표 셀 그림, 그림 선지 구조를 참고했다. 제공 자료의 실제 배치에서 모양을 추렸으며 기출의 내용·정답을 새로 생성한 것은 아니다.

관련 회귀 검사 45개를 통과했다. 포함된 문서 엔진으로 분수·첨자, 글자 크기·자간, 표·보기·그림 선지를 조판한 중첩 보기를 포함한 4종의 HWPX 재열기와 네이티브 삽입을 확인했다. 네이티브 삽입 뒤 HWP 저장에서 그림의 바이너리 목록이 누락되는 엔진 문제는 HWPX로 목록을 재구성한 뒤 HWP를 저장하고 그림을 재확인하여 처리한다. 다만 현재 엔진은 HWP와 HWPX 사이에서 일부 표 다음 문단이 약 4 px 이동하는 사례가 있다. HWP 재열기에서도 모든 페이지의 실제 배치를 비교하고 차이가 있으면 다운로드를 중단해 HWPX 저장을 안내한다. 검수된 기본 전달 형식은 HWPX다. 문항 삽입은 하나의 되돌리기 단위다.

이 검수는 포함된 RHWP 엔진과 Safari의 로컬 화면 기준이다. 별도 한컴 한글 앱에서 폰트 대체·줄바꿈까지 일치한다고 보증한 것은 아니다. 복잡한 수식 및 대각선 표 머리글은 최종 조판 화면에서 개별 확인한다. 로컬 변경이며 게시·배포는 포함하지 않는다.

SheetJS CE 0.20.3과 JSZip 3.10.1은 기존 번들 라이브러리를 사용한다. 별도 문서 엔진을 제품에 추가하지 않았다.


## 문항 전용 용지 — 2026-10-14

한 열의 문항을 열면 기준 시험지 한 단 폭의 실제 용지를 사용한다. A4 2단 기준 본문 86mm, 좌우 여백 3mm, 용지 폭 약 92mm다. 높이는 네이티브 글·표·그림·수식 및 마지막 입력 줄에서 계산한다. 기준 출력 높이 267mm와 실제 사용 높이를 표시하며 초과해도 저장한다. 가이드는 문서 밖의 표시로 출력과 배치에 영향을 주지 않는다. 긴 문항은 같은 문항으로 이어지고 입력을 자르거나 글자를 자동 축소하지 않는다.

저장한 조판은 프로필과 실제 용지 규격을 따로 보관한다. 과거 승인 서식은 보존하여 전용 용지로 변환한다. 규격 변경은 재열기 후 표시하고, 명시적 줄바꿈의 줄 높이도 보존한다. 그림 선지·수식·중첩 보기·장문 및 3페이지 문항을 포함한 7종이 네이티브 저장·재열기 배치 검사를 통과했다. 한글에서 바꾼 내용을 시트 항목으로 되돌리는 양방향 편집은 아직 별도 구현이 필요하다.

## 작은 조판 패널과 보기 여백

조판 패널은 기본 500px로 시트 옆에 붙는다. 패널 너비에 맞춘 화면 확대율은 문서의 실제 글꼴·용지 규격을 바꾸지 않는다. 문항 전환과 닫기는 저장 전 조판 변경을 검수하여 원래 문항에 저장한 뒤 진행한다. 시트 내용이 달라지면 **문항 새로고침**을 사용한다. 조판 내용과 시트 내용이 동시에 달라진 경우 덮어쓰지 않고 안내한다.

보기는 실제 글꼴 너비로 줄바꿈하고 첫 줄에 내어쓰기 폭을 중복 예약하지 않는다. 좌우 6px·위 3px·아래 4px를 기본으로 하며 중첩 보기에는 셀 높이 보정 3px를 더한다. `<보 기>` 제목과 테두리, 기호 뒤 내어쓰기를 유지한다. 이전 저장 문서의 혼합 글자 서식·수식·그림이 있는 보기 본문은 원래 조판을 보존한다. 회귀 검사 46개와 네이티브 문항 7종의 재열기, Safari 실제 화면, 작은 화면, 글자 모양 설정 및 규격 변경 중 열 전환을 검수했다.
