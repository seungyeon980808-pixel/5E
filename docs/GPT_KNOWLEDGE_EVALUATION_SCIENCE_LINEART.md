# 평가원식 과학 선화 GPT 지식 패키지

이 문서는 설명·참고 이미지·손그림을 시험 문항용 무라벨 과학 선화로 바꾸는 GPT가 참조하는 핵심 제작 및 검수 기준이다. 행동 규칙은 GPT Instructions가 우선하며, 이 문서는 구조·스타일 판단의 근거로 사용한다.

## 산출물 정의

- 출력물은 흰 배경과 검은 선이 중심인 2D 과학 도식 PNG이다.
- 이미지 내부에는 문자, 숫자, 단위, 수식, 라벨, 로고, 워터마크, 지시선, 화살표를 넣지 않는다.
- 후속 조판 단계에서 라벨을 추가할 수 있도록 본체 주변 여백을 남긴다.
- 기본 모드는 `illustration_only`다. 문제 문장, 선택지, 정답, 해설은 만들지 않는다.

## 변환 우선순위

1. 객체 종류·개수·연결 관계·패널 수·좌우 방향·상대 위치를 보존한다.
2. 물리적으로 중요한 상태(현재/이전/가상), 접촉 관계, 단자 연결, 층 경계, 반복 위치를 보존한다.
3. 색·광택·그림자·배경·문자·라벨은 제거하거나 단순화한다.
4. 같은 개념을 나타내더라도 용기, 부품 수, 연결 방식, 패널 상태가 바뀌면 재현 실패로 본다.

## 선과 명암

- 외곽선은 내부 구조선보다 굵게, 내부선은 단순하게 유지한다.
- 실제 구조·현재 상태는 실선, 이전·가상·보이지 않는 구조는 점선으로 구분한다.
- 회색은 액체·용액, 단면, 핵·세포질, 물리적으로 구분이 필요한 한두 영역에만 사용한다.
- 장식 목적의 회색은 사용하지 않는다. 자연물·지층 장면에서도 회색 면적은 전체 캔버스의 약 10% 이내를 목표로 한다.
- 그라디언트, 반사광, 광택, 그림자, 사진식 연속 명암, 과도한 해칭·점묘는 사용하지 않는다.

## 참조 이미지 분해 절차

1. 본체, 지지대, 가동부, 연결선, 부착물, 반복 부품, 패널을 목록화한다.
2. 각 요소의 개수와 위치(좌/우/상/하/중앙), 크기 관계, 연결 상대를 확인한다.
3. 제거 대상인 문자·수식·화살표·지시선·로고의 좌표 영역을 분리한다.
4. 생성 뒤 원본과 결과의 객체 목록을 대조한다. 객체 종류·개수·연결·상태 중 하나가 달라지면 통과시키지 않는다.

## 분야별 핵심 보존 요소

### 물리

- 경사면·레일·궤도: 시작점, 최저점, 수평 접속점, 경사 방향을 보존한다.
- 도르래·용수철·저울: 축, 줄의 시작·종료 물체, 접촉면, 반복 수와 간격을 보존한다.
- 회로: 소자 모양보다 폐회로, 분기점, 소자 순서, 접점 여부를 우선 보존한다.
- 빛·파동: 화살표는 제거하되 실제 장치, 매질 경계, 광학 부품, 패널별 상태는 보존한다.

### 화학

- 용기 형태, 액체층 수, 관 연결, 분리된 용액 영역, 입자 종류와 상대 배치를 보존한다.
- 빈 용기에는 원본에 없는 액체 면이나 바닥 타원을 추가하지 않는다.

### 생명과학

- 기관·세포·혈관의 주요 덩어리와 포함 관계를 일반 아이콘으로 축약하지 않는다.
- 상태 비교 그림에서는 각 패널의 개체 수와 작은 독립 객체도 보존한다.

### 지구과학

- 지층의 순서, 경계의 연속성, 핵심 지형 실루엣, 천체의 상대 위치와 잘린 구도를 보존한다.
- 자연 사진을 선화로 바꿀 때 배경 장식은 제거하되, 문제 풀이에 필요한 주 실루엣과 반복 객체 수는 유지한다.

## 실패 신호와 수정 원칙

- 텍스트·숫자·화살표·라벨선이 남아 있으면 실패다.
- 원본에 없는 부품, 액체, 선, 물체, 배경 요소를 모델이 보충하면 실패다.
- 좌우 반전, 패널 순서 변경, 연결 위상 변경은 세부 묘사와 무관하게 실패다.
- 같은 구조 오류가 반복되면, 장면 전체 재생성 대신 구성 요소별로 분리해 다시 제작하는 방향을 제안한다.
- 결과가 스타일 조건을 어기면 한 번 수정 생성하되, 수정 과정에서 구조를 임의로 단순화하지 않는다.

## 최종 점검표

1. 문자 없이도 물리적·생물학적 구조가 식별되는가?
2. 객체의 종류, 개수, 연결, 상태, 방향이 입력과 일치하는가?
3. 실선과 점선의 의미가 구분되는가?
4. 회색 영역마다 정보 전달 목적이 있는가?
5. 불필요한 제품 묘사, 광택, 그림자, 장식이 제거되었는가?
6. 나중에 라벨을 넣을 충분한 여백이 있는가?

## 구조 명세 예시

```json
{
  "id": "sample-inclined-plane",
  "subject": "physics",
  "mode": "illustration_only",
  "components": [
    {"id": "inclined_plane", "kind": "inclined plane", "count": 1, "region": "center"},
    {"id": "block", "kind": "rectangular block", "count": 1, "region": "center"}
  ],
  "connections": [
    {"from": "block", "to": "inclined_plane", "kind": "adjacent"}
  ],
  "remove": ["text", "numbers", "symbols", "labels", "leader_lines", "arrows"],
  "style": {"background": "white", "palette": [0, 176, 255], "gradient": false, "shadow": false}
}
```

정확한 JSON 필드·허용값은 별도 업로드된 `IMAGE_CONVERSION_MANIFEST.schema.json`을 따른다.
