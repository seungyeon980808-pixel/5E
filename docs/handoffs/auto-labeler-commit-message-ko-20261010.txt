자동 라벨러 편집·복구 개선 및 이미지 생성 분리

- AI 복원 라벨을 기존 5E 객체로 편집·이동·저장할 수 있도록 개선
- 라벨 선택 후 간단 편집과 아이콘·보조 클릭을 통한 상세 편집 정리
- 지시선 연결·선택 핸들·두 점 생성 완료·텍스트 입력 영역 오류 수정
- 텍스트 초안 입력 시 반복되는 장면·뷰포트·속성 패널 갱신 감소
- 라벨 단위 제거·복원과 교과서 주변 요소·과학 삽화 분류 보완
- 라이브러리 이미지와 크롭을 로그인 후 작업대로 복구하고 창 전환 개선
- 공통 버튼 스타일 정리와 영역 드래그 후 클립보드로 복사하는 빠른 캡처 추가
- 일반 이미지 생성에 RHWP 승인 하네스를 적용하고 기존 라벨 글꼴 유지
- 동일 그림 요청의 RAW PNG를 보존하여 라벨 옵션 변경 시 재생성 방지
- 단위·브라우저 회귀 검사와 기능별 인계 문서 보강
