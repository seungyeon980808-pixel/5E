<!-- release-title: v1.5.0 — 그림을 가져오고, 고치고, 다시 쓰는 5E -->

v1.4.0이 **과학 부품과 그리기 도구를 넓힌 판**이었다면, v1.5.0은 **밖의 그림을 5E 안으로 가져와 고치고 다시 쓰는 작업 흐름**을 완성한 판입니다.

- 이미지·기출문제 라이브러리와 AI 이미지 작업대를 한 흐름으로 묶었습니다.
- 자르기는 삭제가 아니라 **두 객체로 분리**되며, 도려낸 쪽이 바로 선택됩니다.
- 아트보드는 모서리를 늘이는 대신 **드래그한 영역으로 다시 지정**할 수 있습니다.
- 생성 이미지의 흰 배경을 투명하게 정리하고, 스마트 오려내기와 영역별 수정 요청을 더했습니다.
- Windows 설치판과 `.5e` 프로젝트 파일, 심화 튜토리얼, 30° 회전 단축키가 들어왔습니다.
- 평가원 과학 도식 Engine V2와 세 단계 생성 경로를 통합하고, 성공뿐 아니라 실패·교정 이력도 동결했습니다.

`v1.4.0` 이후 병합 커밋을 제외하고도 48개 커밋이 들어갔습니다. 코드와 문서뿐 아니라 이미지 자산 4,431개, 벤치마크·실험 결과 1,270개를 포함해 6,211개 경로가 바뀌었습니다. 아래에는 눈에 보이는 UI뿐 아니라 수집 도구, 객체화, 자동화 계약, 테스트와 배포 기반까지 함께 기록합니다.

*그림을 넣는 곳과 고치는 곳이 분리되어 있지 않습니다. 라이브러리·AI·편집기·내보내기가 같은 프로젝트 안에서 이어집니다.*

## AI 이미지 생성 — 구석의 작은 창에서 작업대로

AI 이미지 기능을 화면 구석의 보조 창이 아니라 중앙 모달형 **이미지 작업대**로 다시 만들었습니다. 왼쪽에는 생성 결과와 참고 이미지, 오른쪽에는 대화와 요청 입력을 놓아 결과를 보면서 지시를 이어갈 수 있습니다.

상단에서는 모델, 추론 수준, 응답 속도를 고릅니다. 기본 권장 모델은 Luna이며 다른 모델을 고르면 시간이 더 걸릴 수 있다는 안내가 표시됩니다. 로그인 계정, 잔여 한도, 누적 토큰도 같은 줄에서 확인합니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/02-ai-workspace.svg" alt="생성 결과와 대화가 나란히 놓인 AI 이미지 작업대" width="820" />

### 대화와 생성은 다른 동작입니다

요구사항이 아직 확정되지 않았다면 보내기 버튼으로 대화만 이어갑니다. 실제 그림이 필요할 때 **이미지 생성**을 누릅니다. 자동으로 상투적인 요청문을 만들어 보내지 않으며, 사용자가 작성한 문장이 그대로 요청 기록에 남습니다.

생성 중에는 다음 단계를 구분해 보여줍니다.

1. 요청과 참고 자료 정리
2. 구조와 배치 분석
3. 이미지 서버 생성 대기
4. 투명 배경과 편집용 결과 정리

이미지가 도착하면 대화에 완료 안내를 남기고, 결과 카드의 **캔버스로 출력** 버튼으로 현재 페이지에 넣습니다. 생성 뒤 작업이 잠겨 다음 요청을 못 보내던 문제도 turn 종료 확인과 복구 절차를 추가해 고쳤습니다.

### 그림형과 완성형

| 모드 | 쓰임 | 기본 규칙 |
|---|---|---|
| **그림형** | 5E에서 라벨을 나중에 붙일 그림 | 문자·숫자·기호·라벨·지시선·화살표를 만들지 않음 |
| **완성형** | 요청한 표기까지 들어간 완성 도판 | 필요한 표기만 포함하고 장식적 요소는 억제 |

그림형의 목적은 AI가 글자를 어설프게 그리게 하는 것이 아니라, 구조가 선명한 그림을 받은 뒤 5E의 텍스트·수식·라벨러로 정확하게 마무리하는 것입니다.

## 참고 이미지를 여러 장 쓰고, 영역마다 따로 지시합니다

참고 자료는 세 경로에서 가져옵니다.

- **이미지 불러오기** — 파일 탐색기 또는 화면 영역 캡처
- **이미지 라이브러리** — 5E 내부 자산
- **기출문제 라이브러리** — 검색한 문항을 한 장 또는 여러 장 선택

여러 이미지를 동시에 선택해 AI 작업대로 보낼 수 있습니다. 각 카드에서 드래그로 영역을 표시하면 번호가 붙고, 아래의 요청 목록에서 문장을 언제든 수정하거나 삭제할 수 있습니다. 생성 결과에도 같은 방식으로 영역 요청을 달 수 있습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/03-reference-regions.svg" alt="여러 참고 이미지에 번호가 붙은 영역 요청을 작성하는 모습" width="820" />

**이미지 비교**에서는 왼쪽과 오른쪽에 놓을 참고·생성 결과를 각각 골라 1대1로 비교합니다. 확대·축소·수정 버튼은 이미지 제목 옆에 모아 세로 공간을 줄였습니다.

전송 성능도 손봤습니다. 이미 보낸 자료는 대화마다 반복 전송하지 않고, 중복 이미지는 제거합니다. 큰 사진은 선화 여부를 판단해 적절히 축소·압축하며, 여러 참고 이미지는 필요한 개요·영역·접촉 시트로 제한합니다. 동일한 요청과 입력의 완성 결과는 캐시에서 즉시 다시 불러옵니다.

## 자르기 — 도려낸 부분이 사라지지 않고 분리됩니다

v1.4.0의 가위는 이미지를 양 끝까지 가르는 데는 적합했지만, 내부의 특정 부분만 도려내기 어려웠습니다. v1.5.0에서는 닫힌 영역도 분리할 수 있고 결과가 사라지지 않습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/04-cut-separate.svg" alt="원본 이미지의 내부 영역을 도려내 두 객체로 분리하는 과정" width="760" />

- 바깥 부분과 도려낸 부분이 각각 독립 이미지 객체가 됩니다.
- 작업이 끝나면 **도려낸 부분만 선택**된 상태가 됩니다.
- 이동·회전·크기 조절·레이어·삭제를 두 조각에 따로 적용할 수 있습니다.
- 지연 자르기에서는 선을 그은 직후가 아니라 오른쪽 패널에서 결과를 확인한 뒤 확정합니다.
- 자르기 모드의 선택·팝업 조건과 undo 동작도 함께 정리했습니다.

스마트 오려내기는 비슷한 색과 연결된 픽셀을 기준으로 대상을 찾습니다. 민감도 슬라이더로 포함 범위를 조절하고 미리보기에서 확인한 뒤 분리합니다.

## 아트보드 — 드래그한 위치가 새 작업 영역이 됩니다

**드래그로 영역 지정**은 아트보드 모서리를 늘이거나 줄이는 기능이 아닙니다. 내보내기 영역을 고르듯 캔버스에서 사각형을 끌면 그 위치와 크기가 바로 새 아트보드가 됩니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/05-artboard-drag.svg" alt="캔버스에서 드래그한 사각형을 새 아트보드로 확정하는 모습" width="760" />

- 커서가 닿는 지점과 실제 선택 사각형의 좌표를 맞췄습니다.
- 선택 중에는 너비와 높이를 표시합니다.
- `Enter`로 확정할 수 있고 크기 표시 옆의 **지정** 버튼으로도 확정합니다.
- 선택한 영역 밖의 객체가 있더라도 아트보드만 다시 정의합니다.
- Ctrl+A 전체 선택, 내보내기 확정 버튼, 한국어 자동 줄바꿈도 함께 다듬었습니다.

내보내기 저장 폴더를 한 번 연결하면 다음 내보내기에도 같은 위치를 사용할 수 있습니다.

## 이미지 배경 — 흰 사각형 대신 편집 가능한 투명 바탕

AI 생성 결과와 외부 이미지는 흰색 배경 때문에 다른 도형 위에 올렸을 때 큰 사각형처럼 보이곤 했습니다. v1.5.0은 결과를 캔버스에 넣기 전에 배경을 분석해 실제 RGBA 투명 이미지로 정리합니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/06-transparent-background.svg" alt="흰 배경 이미지와 투명 배경 이미지의 편집 차이" width="760" />

미리보기에서는 투명 격자가 과하게 드러나지 않도록 흰 판 위에서 결과를 확인합니다. 캔버스에 넣은 뒤에는 뒤쪽 도형과 선이 실제로 비칩니다. 후처리에 실패한 결과를 성공 캐시에 저장하지 않으며, 배경 처리 버전도 캐시 키에 포함합니다.

## 이미지·기출문제·AI 기능이 한 줄로 이어집니다

하단 작업 바를 정리했습니다.

- 오브젝트 검색은 돋보기 아이콘으로 줄여 격자 왼쪽에 배치했습니다.
- `기출문항 검색`은 **기출문제 라이브러리**로 이름을 통일했습니다.
- 이미지 라이브러리와 기출문제 라이브러리에서 선택한 자료를 AI 작업대로 바로 보냅니다.
- 라이브러리 창을 닫아도 뒤의 AI 작업대는 그대로 유지됩니다.
- 복수 선택 자료를 한 번에 넘길 수 있습니다.
- 격자 버튼은 격자임을 알아볼 수 있는 아이콘과 중앙 정렬로 고쳤습니다.

이미지를 불러오면 별도 버튼을 한 번 더 누르지 않아도 바로 참고 이미지 영역에 나타납니다.

## 이미지 라이브러리 — 부품 목록에서 출처가 있는 자료실로

기존 부품 라이브러리를 **이미지 라이브러리 베타**로 확장했습니다. 단순히 미리보기 파일을 나열하는 대신 과목, 형태, 사용 조건, 출처와 가공 이력을 함께 관리합니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/11-image-library.svg" alt="검색 카드와 출처 패널로 구성된 이미지 라이브러리" width="820" />

- 카드 미리보기를 패널 위쪽에 배치하고 다크 모드의 대비를 고쳤습니다.
- 과목·형태·용도 메타데이터를 이용해 이미지와 장치 부품을 함께 찾습니다.
- 선택 자료를 캔버스에 넣거나 AI 참고 이미지로 바로 넘깁니다.
- 한 번에 여러 장을 골라 삽입하거나 참고 자료로 전달합니다.
- 공개 도해는 제목, 저작자·기관, 원본 URL, 라이선스와 가공 이력을 출처 페이지에서 확인합니다.
- 작가·스타일·실험기구별 수집기, 중복 판정, 잘라내기와 선화 정규화 도구를 저장소에 남겼습니다.
- 심화·실습 과제와 아직 품질이 고정되지 않은 라이브러리에는 **베타** 표기를 붙였습니다.

기출문제 3,961개와 분석 atlas 936행도 같은 감사 흐름에 연결했습니다. 다만 “수집되었다”와 “5E 네이티브 부품으로 정확히 재현된다”는 다른 의미이므로, 자동 재현 가능 범위는 별도 감사표로 관리합니다.

## 이미지 객체화 — 픽셀을 다시 고칠 수 있는 도형으로

이미지를 그대로 한 장의 PNG로만 두지 않고, 선·원·사각형·회색 면을 찾아 5E 객체로 변환하는 객체화 기능을 보강했습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/12-objectify.svg" alt="원본 이미지가 선과 원, 사각형 객체로 분리되는 과정" width="820" />

- 안티앨리어싱이 섞인 검정선과 회색선을 구분합니다.
- 가는 직선, 꺾인 선, 원호를 선·폴리라인·곡선으로 추출합니다.
- 채운 원, 원형 링, 회전 타원은 ellipse로 다시 만듭니다.
- 축 정렬·회전 사각형과 사각 링을 인식하고 회전값과 테두리 굵기를 보존합니다.
- 삼각형과 불규칙 윤곽은 폴리곤·곡선으로 안전하게 폴백합니다.
- 밝은 내부 면과 어두운 테두리를 병합해 중복 객체와 회색 유령을 줄입니다.
- 인식이 확실하지 않으면 억지로 의미를 부여하지 않고 원래 윤곽을 보존합니다.

객체화 결과는 선택, 이동, 회전, 채움·선 굵기 변경이 가능한 일반 5E 객체가 됩니다. 모든 그림이 완벽히 벡터화되는 기능은 아니며, 글자·복잡 삽화·겹친 사진은 이미지 상태로 편집하는 편이 안전합니다.

## `.5e` 프로젝트 파일 — 5E 작업임을 파일 이름에서 알 수 있습니다

프로젝트 저장 파일의 기본 확장자를 `.5e`로 바꿨습니다. 내부는 계속 안전한 JSON 구조이므로 기존 저장·불러오기·자동 저장 흐름과 호환됩니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/07-project-desktop.svg" alt="웹과 Windows 설치판이 같은 .5e 프로젝트 파일을 여는 구조" width="760" />

Windows 설치판은 웹판을 별도 제품으로 다시 만든 것이 아닙니다. 같은 편집기와 같은 프로젝트 형식을 Electron 안에서 열고, AI 연결·창 캡처·설치 안내처럼 데스크톱에서만 가능한 기능을 preload 경계 뒤에 둡니다.

- NSIS 설치 파일과 바탕화면 바로가기
- 시작 시 5E 로딩 화면
- GitHub Actions 기반 Windows 패키징
- 설치 파일과 SHA-256 체크섬 배포 절차
- 코드 서명 정책과 SmartScreen 안내

웹판에서 AI 버튼을 누르면 설치판이 필요하다는 안내와 GitHub Release 이동 경로를 보여주며, 나머지 편집 기능은 그대로 사용할 수 있습니다.

큰 기능 사이에서 매일 반복하는 작은 조작도 함께 정리했습니다.

- 수식 객체에 원본 `source`가 없을 때 조용히 손상된 파일을 만들지 않고 오류로 차단합니다.

## 회전·튜토리얼·과학 부품도 함께 보강했습니다

### 30°씩 빠르게 회전

기존 `PageUp`/`PageDown`의 5° 회전에 더해 `Shift+PageUp`/`Shift+PageDown`으로 30°씩 회전합니다. 회전된 객체를 다시 선택하고 변형할 때 선택 상자와 스마트 가이드가 원래 축으로 튀던 문제도 고쳤습니다.

### 심화 튜토리얼 2·3·4

튜토리얼은 설명을 읽는 화면이 아니라 실제 도구를 써서 통과하는 과정입니다. 읽기 단계의 오조작을 막고, 저장·검색·라벨러·중앙 불러오기·화면 비우기·감싸기 시연을 실제 작업 흐름에 맞게 연결했습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/08-tutorial-tools.svg" alt="심화 튜토리얼과 30도 회전, 검전기 부품" width="820" />

### 검전기와 MCP 부품 규칙

검전기를 정식 장치 부품으로 추가하고 잎 벌어짐과 종횡비 보존을 프로젝트 저장 규칙에 넣었습니다. MCP 부품 생성은 사람 손, 우주선, 학생 장면처럼 안전하게 재사용할 수 있는 검증 자산과 출처 정보를 구분합니다.

## MCP 자동화 — 생성에서 저장까지 한 계약으로

외부 Codex 세션과 Python 도구가 5E를 안정적으로 조작하도록 MCP 서버와 브리지를 확장했습니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/14-mcp-workflow.svg" alt="MCP가 객체를 생성하고 그룹화하고 아트보드에 맞춘 뒤 저장하는 흐름" width="820" />

- 여러 객체로 만든 초안을 `group`으로 묶어 한 덩어리처럼 이동·회전합니다.
- `fit_artboard`가 현재 그림의 경계와 지정 여백에 아트보드를 맞춥니다.
- `add_field_region`이 파선 테두리, 기호 격자, 선택적 범례를 가진 균일 자기장 영역을 만듭니다.
- `save_image`가 현재 화면을 인쇄 품질 PNG로 저장합니다.
- 검전기, 안전한 손 부품, 학생 장면, 우주선 외형 같은 감사된 부품 계약을 추가했습니다.
- 프로젝트 저장에서 새로운 장치 속성과 그룹 관계를 보존합니다.
- JavaScript 서버뿐 아니라 Python stdio 클라이언트를 추가했습니다.
- schema validation, 샘플 JSON, MCP smoke test로 잘못된 객체를 편집기에 넣기 전에 차단합니다.

MCP가 임의의 JSON을 캔버스에 밀어 넣는 구조가 아니라, 5E가 이해하는 객체 스키마와 검증 경계를 통과해야만 반영되도록 했습니다.

## 평가원 과학 도식 Engine V2

Engine V2는 단일 프롬프트가 아니라 입력을 분석하고, 적합한 생성 경로를 고르고, 결과를 평가·교정하는 패키지입니다.

<img src="https://raw.githubusercontent.com/seungyeon980808-pixel/5E/v1.5.0/docs/images/release-v1.5.0/09-engine-paths.svg" alt="로컬 벡터, 빠른 장면, 이미지 생성의 세 경로와 속도 범위" width="820" />

| 경로 | 적합한 입력 | 검증된 속도 | 성격 |
|---|---|---:|---|
| 로컬 벡터 | 정확히 등록된 반복 구조 19종 | 약 1ms | 모델 호출 없이 편집 가능한 객체 생성 |
| 빠른 장면 | 참고 이미지 없는 단순 회로·장치·그래프 | 중앙값 약 7.2초 | Luna가 장면 JSON을 만들고 5E가 렌더링 |
| 이미지 생성 | 교과서·기출 참고 이미지, 손그림, 복잡한 삽화 | 보통 수십 초~수분 | 원격 이미지 서버를 사용하며 지연 변동이 큼 |

중요한 한계도 분명히 합니다. **대부분의 교과서 그림이 7초 안에 변환되는 것은 아닙니다.** 빠른 두 경로는 참고 이미지 없이 구조가 명확한 일부 도식에만 적용됩니다. 원본의 형태를 보존해야 하는 변환, 사람·생물 삽화, 복잡한 장치는 여전히 이미지 생성 경로를 사용합니다.

이미지 생성 경로에서는 다음 병목을 줄였습니다.

- 대화 thread와 렌더 thread 분리
- 렌더마다 새 임시 thread 사용
- 이미지 도구 호출 1회 제한, 자동 재시도 금지
- 이미 보낸 첨부의 중복 전송 제거
- 참고 이미지 크기·용량 최적화
- 이미지 도착 뒤 남은 turn을 종료해 다음 작업 잠금 해제
- 실패·취소 뒤 원격 작업이 겹치지 않도록 single-flight 적용

### 검증 결과를 숨기지 않습니다

Engine V2.2의 동결 최종 24사례에서는 22사례가 통과해 **91.7%**를 기록했습니다. 정확 컴파일 결과 기준은 21/24, **87.5%**였습니다. 개발 36사례는 27/36, **75%**였으며 화학·지구과학의 복잡한 수정에서 약점이 남았습니다.

따라서 최종 통과율만 보고 “모든 과학 그림을 안정적으로 고친다”고 표현하지 않습니다. 실패 원인인 구조 손실, 과도한 회색, 편집 범위 초과, 범주 붕괴를 프롬프트와 규칙에 반영하고 실패 프롬프트·교정 이력·freeze 해시를 함께 보존했습니다.

## 알려진 제한

- AI 이미지 생성 속도는 원격 이미지 서버 상태에 따라 크게 달라집니다. Luna·낮은 추론·Fast가 기본 권장값이지만 일정 시간을 보장하지 않습니다.
- 참고 이미지 변환 결과의 과학적 정확성은 자동 보장되지 않습니다. 생성 뒤 구조·연결·접촉 관계를 확인해야 합니다.
- 로컬 초고속 경로는 엄격한 19개 패턴에만 적용됩니다. 표현이나 부품이 달라지면 빠른 장면 또는 이미지 생성으로 넘어갑니다.
- 자동 업데이트는 아직 없습니다. 새 설치 파일을 GitHub Releases에서 받아 갱신합니다.
- 코드 서명이 완료되기 전에는 Windows SmartScreen 경고가 표시될 수 있습니다.
- `npm audit`에는 현재 lockfile 기준 high severity 경고 1건이 남아 있습니다. 자동 breaking 수정은 적용하지 않았습니다.
- 구형 `feat/ai-assist`의 Cloudflare Worker와 채팅 UI는 이번 판에 포함하지 않았습니다. v1.5.0은 Windows Desktop의 로컬 Codex 연결만 사용합니다.

## 업그레이드 안내

1. 웹판은 새로고침 후 모듈이 갱신되지 않으면 `Ctrl+F5`를 누릅니다.
2. Windows판은 기존 5E를 종료하고 새 설치 파일을 실행합니다.
3. 기존 프로젝트 JSON과 `.5e` 파일은 그대로 열 수 있습니다.
4. AI 기능을 사용하려면 Codex 설치와 로그인이 필요합니다. AI를 사용하지 않아도 편집·저장·내보내기는 동작합니다.
5. 설치 파일의 SHA-256 체크섬을 GitHub Release에 적힌 값과 비교할 수 있습니다.

v1.5.0은 AI가 그림을 대신 완성하는 판이 아니라, **그림을 가져와 비교하고, 부분을 지정해 요청하고, 5E에서 끝까지 고칠 수 있게 만든 판**입니다.
