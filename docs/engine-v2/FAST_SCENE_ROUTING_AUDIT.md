# Engine V2 빠른 벡터 경로 라우팅 감사

조사일: 2026-08-09  
대상: `js/ai-engine-router.js`, 기출 3,961장, 수동 분해 아틀라스 936장

## 결론

라우터는 사람·손·생물 삽화·정확한 지도·사진·복잡 차량/제품을 먼저 raster로 보내고, 현재
`ai-scene-fastpath.js`와 `ai-motif-catalog.js`가 표현할 수 있는 반복 도식만 fast-scene으로 보낸다.
빠른 키워드가 같이 있어도 raster 금지 규칙이 항상 먼저 적용된다.

아틀라스의 구조 토큰을 한국어 요청어로 치환한 **라우팅 가능성 대리 측정**에서, 안전한 fast-scene
후보는 기존 625/936장(66.8%)에서 641/936장(68.5%)으로 늘었다. 삽화 위험 blocker를 가진 153장에
각각 `그래프 회로 용수철`이라는 충돌 신호를 함께 넣은 검사에서는 기존 규칙이 23장을 fast-scene으로
잘못 보낼 가능성이 있었지만 수정 규칙은 153장 모두 raster로 보냈다.

이 수치는 이미지 생성 결과의 점수나 통과율이 아니다. 라우터가 어떤 엔진을 먼저 시도할 수 있는지에
대한 정적 후보 비율일 뿐이며, 구조 보존·과학적 정확성·85점 통과 여부는 별도 이미지 평가가 필요하다.

## 3,961장과 936장의 사용 방법

- 전체 3,961장은 `assets/exam-library/manifest.json`과 PNG 전수 검증 결과를 사용했다.
- 이 중 2,955장에는 개념 태그가 있지만, 개념 태그만으로는 그림이 그래프인지 삽화인지 알 수 없다.
  예를 들어 같은 `반사`가 광학 반사와 신경 반사를 모두 가리킬 수 있다. 따라서 3,961장 전체에
  라우팅 통과율을 부여하지 않았다.
- 구조 유형, 부품, 연결, blocker가 사람에 의해 분해된 936장만 정량 라우팅 감사에 사용했다.
- 기존 자산 감사의 `현재 구현만으로 blocker가 모두 사라질 후보` 658/936장(70.3%)과 이 문서의
  641/936장은 다른 값이다. 658장은 구현 존재 여부이고, 641장은 안전 금지 규칙과 실제 요청어
  신호까지 요구한 라우터 후보 수다.

## 변경 전후 잠재 라우팅 범위

아틀라스의 영문 blocker/element id를 exact-match 표로 한국어 구조 요청어로 바꿨다. 예를 들어
`panel_flow → 과정 패널`, `dual_axis → 이중축`, `diagonal_wiring → 대각선 배선`,
`contour_set → 등고선`, `person → 사람`, `map_outline → 정확한 지도 해안선`으로 바꿨다.
substring 매칭은 `photo`와 `phototube`를 혼동하므로 사용하지 않았다.

| 구분 | 변경 전 | 변경 후 | 변화 |
|---|---:|---:|---:|
| 전체 936장 중 안전 fast-scene 후보 | 625 (66.8%) | 641 (68.5%) | +16 |
| 위험 삽화 제외 783장 중 후보 | 625 (79.8%) | 641 (81.9%) | +16 |
| 새로 fast-scene 신호를 얻은 후보 | - | 20 | +20 |
| 모호성이 커 자동 fast에서 빠진 기존 후보 | - | 4 | -4 |

과목별 대리 측정은 다음과 같다.

| 과목 | 아틀라스 | 변경 전 | 변경 후 |
|---|---:|---:|---:|
| 물리 | 483 | 341 (70.6%) | 352 (72.9%) |
| 화학 | 280 | 203 (72.5%) | 200 (71.4%) |
| 생명과학 | 69 | 34 (49.3%) | 33 (47.8%) |
| 지구과학 | 104 | 47 (45.2%) | 56 (53.8%) |

화학과 생명과학에서 각각 3장, 1장이 줄어든 것은 성능 퇴행으로 단정할 수 없다. `사진`, `음식`,
`세포`, 복잡 제품처럼 간단한 선화라고 보장할 수 없는 충돌 요청을 보수적으로 raster로 돌린 결과다.
새로 늘어난 후보 20장은 물리 11장과 지구과학 9장이다. 특히 기존 `추\b`가 한국어 조사 `추를`을
인식하지 못하던 문제, 온도계·스피커, 등고선/등치선 명시가 보완됐다.

## 근거가 있는 fast-scene 규칙

현재 네이티브 컴파일러나 코드 네이티브 motif로 직접 표현할 수 있는 다음 유형만 추가했다.

- 회로: 전원, 저항, 축전기, 코일, 스위치, 직교/대각선 배선
- 역학: 도르래, 용수철, 수레, 블록, 빗면, 진자, 매달린 추, 간단한 충돌 전후
- 광학: 렌즈, 거울, 광원, 스크린, 슬릿, 광선, 간섭/회절 무늬
- 실험 용기: 비커, 플라스크, 시험관, 실린더, 피스톤, U자관, 뷰렛, 깔때기
- 그래프: 일반 좌표 그래프, 이중축, 산점도, 막대/원 그래프, 적정/상평형 곡선
- 반복 배치: 과정 패널, 상태 변화 전후, 나란히 비교
- 지구과학 선형 motif: 등고선, 등치선, 등압선, 등수심선
- 제한적 구조: 가계도, 염색체 배열, 개략/임의 해안선 모식도

`panel_flow` 22건, 이중축 9건, 배선 5건, contour 계열 6건은 코드 네이티브 motif 감사 결과와
직접 연결된다. 정확한 지명이나 실제 지형이 필요한 해안선은 여기에 포함하지 않는다.

## 충돌 및 부정 지시 우선순위

1. 사용자가 `force`를 명시한 경우만 강제 선택을 존중한다.
2. 사람·손·해부·생물 세밀화·정확 지도·사진·복잡 차량/제품을 먼저 raster로 보낸다.
3. 그림형에서 문자나 화살표를 본질적으로 그리는 전류계, 전압계, 검류계, 모터, 트랜지스터,
   막대자석, 저울, 전기력선/자기력선은 fast-scene을 시도하지 않는다.
4. 그 다음에만 지원된 과학 구조 신호를 fast-scene으로 보낸다.
5. 분류되지 않은 요청은 raster fallback을 유지한다.

부정 지시는 출력 대상을 기준으로 해석한다. `사람은 제거하고 도르래만 남겨 줘`는 사람을 출력하지
않으므로 fast-scene이 가능하다. 반대로 `사람을 제거하지 말고`는 이중 부정으로 보고 raster를 유지한다.
`사람 없이 자동차만`도 자동차 규칙 때문에 raster다.

## 회귀 검증

```powershell
node --test tests/test-ai-engine-router.mjs
```

검증 항목은 다음을 포함하며 현재 10/10 통과한다.

- 기출 반복 motif와 지원 장치의 fast-scene 선택
- 사람/손/생물/정확 지도/사진/복잡 제품의 raster 우선
- `무릎 반사 + 그래프`, `눈 구조 + 렌즈` 충돌
- 긍정 제거와 이중 부정 구별
- 그림형 본질 문자/화살표 장치 차단, 완성형 허용
- `손실`, `장기 변화`가 해부 키워드로 잘못 잡히지 않는지 확인
- force와 미분류 fallback의 기존 계약 보존

## 남은 한계

- 936장 대리 요청은 실제 사용자가 쓰는 문장 분포가 아니다.
- fast-scene으로 라우팅된 뒤 Luna가 유효한 scene JSON을 내는 비율과 과학적 정확성은 별도다.
- 그림형은 문자·숫자·기호·화살표 금지 때문에 완성형보다 직접 표현 가능한 장치가 적다.
- 새 지형, 동식물, 해부, 사람 자세, 복잡 차량은 내부 검증 자산이 생기기 전까지 raster가 맞다.
- 처음 보는 구조는 빠른 경로를 낙관적으로 선택하지 않고 raster fallback을 유지한다.
