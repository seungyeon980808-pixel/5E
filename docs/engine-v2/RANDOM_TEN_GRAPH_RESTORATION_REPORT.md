## 자체 기능만으로 부족한 부분과 추가 제안

1. **축 교차 위치와 데이터 최솟값 분리 (`axisAt`) — 우선순위 P0**
   - 8번처럼 축의 표시 최솟값이 50이거나, 축이 데이터 0이 아닌 값에서 교차하는 그래프를 의미 손실 없이 저장하려면 `xAxisAt`, `yAxisAt` 또는 `axisAt:{x,y}`가 필요하다.
   - 현재는 모양을 맞추기 위해 데이터를 내부 0 기준으로 정규화해야 하므로 편집 시 실제 값의 의미가 약해진다.

2. **원본 이미지→수학 좌표 자동 추출 — 우선순위 P0**
   - 이번 10종은 좌표와 라벨을 사람이 판독해 GraphSpec으로 옮겼다. 대량 변환 엔진에는 축/격자 검출, 곡선 벡터화, OCR 라벨 결합, 신뢰도 표시가 필요하다.
   - 신뢰도가 낮은 곡선은 베지어 제어점을 사용자에게 노출해 보정하도록 한다.

3. **픽셀 승인 워크플로 — 우선순위 P1**
   - 원본 crop과 네이티브 렌더를 같은 크기로 겹쳐 차이 영상을 만들고, 축·점·라벨·곡선별 허용 오차를 저장해야 `candidate → verified` 승격을 자동화할 수 있다.

4. **완료된 보강: 계열별 대시 패턴**
   - 9번 때문에 `dashLength`와 `dashGap`을 각 계열에 독립 지정하도록 추가했다. 긴 점선/짧은 점선이 같은 스타일로 뭉개지지 않는다.
