# 평가원 기출 그래프 재현 기능 공백 보고서

기준일: 2026-08-10

## 판정 기준

1. 원본의 패널 수와 배치가 같다.
2. 축 방향·범위·비율, 격자·눈금·화살표·프레임이 같다.
3. 점·꺾임·곡선·평탄 구간·가이드의 수학 위치가 같다.
4. 라벨·분수·세로/가로 조판이 그래프 객체 내부 데이터다.
5. 저장 후 그래프 모달에서 다시 편집할 수 있다.
6. 별도 이미지·text·formula·line 객체를 위에 덧씌워 통과시키지 않는다.

## 현재 네이티브 표현 범위

- 좌표평면, 비대칭 범위, 프레임, 격자, 축별 눈금, 직접 눈금 문자열
- 산점도, 직선·꺾은선, 자동 곡선, 자유 베지어 곡선, 막대, 면적, 원그래프
- 표시점, 수선, 두 점 가이드, 방향 화살표, 축 생략, 범례, 음영 구간
- 지시선, 치수선, 범위 막대
- 축 제목·곡선 라벨·패널 번호의 내부 라벨 저장
- 축 라벨 분수, 평가원식 세로 조판, 가로 조판, 명시적 글자 크기
- 이중 y축과 저장·불러오기 왕복

전체 기출 아틀라스 314개 그래프 패널의 구성요소 어휘와 위 네이티브 경로는
`npm run audit:exam-graphs:strict`에서 통과한다.

## 이번에 확인해 추가한 기능

- 곡선 이름의 `labelRotation`과 점 없는 내부 라벨
- ①–⑤를 별도 텍스트가 아닌 coordplane 내부 라벨로 저장하는 `panelLabelAt`
- 데이터 범위와 무관한 실제 mm 글자 크기 `axisLabelSize`, `tickLabelSize`
- AI GraphSpec에서 기존 5E 베지어 편집 기능으로 연결되는 `curvature`, `handles`
- 지시선·치수선·범위 막대 감사 기준을 별도 덧씌움 객체가 아닌 coordplane 내부 데이터로 교정

## 아직 필요한 기능 제안

### P0. 원본 이미지 → 수학 GraphSpec 추출기

현재 구현은 정확한 GraphSpec을 네이티브 5E 자산으로 바꾸는 컴파일러다. PNG만 넣어 축과
곡선 좌표를 자동 복원하는 단계는 아직 없다. 완전 자동 변환에는 다음 파이프라인이 필요하다.

1. 그래프/패널 박스 검출과 원근·기울기 보정
2. 축 원점·끝점·화살촉·프레임·격자 검출
3. OCR 눈금값으로 픽셀↔수학 좌표 보정
4. 선·점·막대·음영 분리와 계열 연결
5. 직선/꺾은선/단조곡선/베지어 모델 선택 및 오차 최소화
6. 라벨 OCR, 기준점·회전각·가림 영역 복원
7. 낮은 신뢰도 항목만 사람이 고치는 교정 화면

이 기능 없이는 곡선을 사람이 찍은 대표 좌표로 근사하게 되므로 “원본과 완벽히 동일”을 자동으로
보장할 수 없다.

### P1. 그래프 패널 카드

두 패널 전류 그래프처럼 축 바깥까지 감싸는 둥근 회색 배경은 현재 coordplane 자체 속성이 아니다.
`panelCard:{padding, radius, fillLevel, strokeLevel}`을 추가하고 그래프 모달에서 편집 가능하게 해야 한다.

### P1. 색상 원본의 평가원 흑백 변환 규칙

원본의 여러 색 계열을 모두 검정 실선으로 바꾸면 겹치는 계열의 구분이 사라질 수 있다. 색상별로
검정 실선·긴 점선·짧은 점선·선 굵기를 안정적으로 배정하는 `seriesStylePolicy:"kice"`가 필요하다.

### P1. 픽셀 기준 시각 회귀검사

구조 검사는 통과하지만 현재 manifest는 314개 중 후보 fixture 17개, 사람이 원본과 확인해
`verified`로 확정한 fixture는 0개다. 각 패널에 대해 원본 crop, 렌더 PNG, 정렬 overlay,
축/점 위치 오차와 라벨 박스를 저장하고 사람이 승인해야 한다.

## 현재 결론

그래프 구조를 편집 가능한 5E 자산으로 담는 그릇은 갖춰졌다. 남은 핵심 병목은 원본 이미지에서
그 구조와 정확한 수학 좌표를 추출하는 P0 비전 단계와, 314개 전수 시각 승인이다.
