# 5E 평가원 과학 도식 엔진 V2 — 추가 API 없는 속도 개선 보고서

측정일: 2026-08-09  
범위: Codex 로그인/App Server 경로와 5E 내부 벡터 객체만 사용. 별도 Images API 키·추가 과금 경로는 사용하지 않음.

## 결론

신규 도식을 모두 원격 래스터 생성에 맡기면 정상 구간도 대체로 1분 안팎이고, 이미지
서버가 혼잡하거나 취소된 작업이 겹치면 수 분까지 늘어날 수 있다. 이 서버 시간은 5E
코드만으로 제거할 수 없다.

따라서 V2는 다음 네 경로로 나눈다.

1. **동일 요청 캐시** — 이미 성공한 동일 입력은 모델을 다시 부르지 않고 즉시 재사용한다.
2. **zero-round-trip 내부 자산** — 정확히 승인된 지도·삽화·반복 구조·고정 장치 문법은 모델이나
   네트워크를 호출하지 않고 바로 5E 벡터 오브젝트로 컴파일한다.
3. **빠른 편집형 벡터 장면** — 회로, 역학 장치, 광학, 용기·입자, 그래프와 검증된 반복
   모티프는 Luna가 작은 장면 JSON만 만들고 5E가 로컬 객체로 컴파일한다. 이미지 생성
   도구 호출은 0회다.
4. **원격 래스터 fallback** — 검증 자산 밖의 사람·손·생물 삽화·정치/지질 지도·복잡 차량처럼
   현재 내부 객체로 안전하게 표현할 수 없는 경우에만 원격 이미지 생성을 1회 호출한다.

현재 단발 실측에서 빠른 벡터 경로는 **6.9~14.7초**, 건강한 기존 래스터 경로는
**57.2~116.7초**였다. 이어서 현재 `prompt@7/catalog@5`로 9종을 세 번씩 새 스레드에서
실행한 27회 반복 벤치마크는 **27/27 통과**, 전체 중앙값 **7.20초**였다. 동일 요청 캐시는 로컬 조회·미리보기 처리만 남으므로 대기 시간이
사실상 사라진다. zero-round-trip 내부 자산은 19종×3회 **57/57 통과**, match+expand+compile
중앙값 **0.7255ms**였고 모델·imageGeneration·도구 호출이 모두 0회였다. 이 수치는 서로 다른 요청을 섞은 관측 범위이며 서비스 응답 시간을
보장하는 SLA가 아니다.

## 원래 지연의 원인

기존 로그에서 정상 성공 3회는 57.2초, 70.5초, 84.2초였다. 악화 구간 5회는
145.3초, 297.6초, 435.5초, 451.9초, 509.0초였다. 509초 작업에서는 이미지 도구가
한 턴에 세 번 실행되어 88.9초 성공, 340.4초 실패, 45.9초 재성공이 이어졌다.

주요 원인은 다음과 같다.

- 같은 렌더 대화를 계속 재사용해 문맥과 이전 이미지가 누적됨
- 오래된 프롬프트가 결과 자체 점검과 재생성을 허용해 한 요청에서 여러 이미지 호출이 발생
- 취소된 원격 생성이 바로 끝나지 않은 상태에서 다음 작업이 시작되어 서버 작업이 겹침
- 존재하지 않는 저장소 문서를 찾는 도구 호출이 이미지 생성 전에 반복됨
- 참고 이미지가 많은 요청에서 원격 이미지 서버 자체 지연이 크게 변동함

## 적용한 원격 경로 개선

- 렌더마다 짧은 새 임시 스레드 사용; 대화 스레드와 분리
- 검증 규칙을 프롬프트에 직접 내장하고 검색·파일 읽기·추가 질문 금지
- `imagegen` 정확히 1회, 같은 턴 재생성·자가수정 금지
- Luna 기본, 낮은 추론과 priority/Fast 우선; 다른 모델 선택 시 지연 경고
- 필요한 원본·영역 크롭·접촉 시트만 최대 4개 시각 입력으로 제한
- 긴 변/픽셀 수 기반 전송 축소, 선화 PNG 보존, 사진형 캡처 압축
- 성공 결과 exact cache(모드·프롬프트·원본 픽셀·코멘트·모델·엔진 버전 포함)
- 이미지 수신 뒤 원격 턴을 종결하고 서버가 실제 terminal 상태인지 확인한 뒤 다음 작업 허용
- 서버 오류·종료 시 활성 작업에 종결 실패 신호를 보내 UI 잠금 해제
- turn/thread ID가 다른 늦은 토큰·완료 이벤트를 폐기

원격 입력 계획의 6MB 합성 벤치마크는 cold 약 0.1~0.3초, warm 1ms 미만이다. 참고
이미지 준비는 이제 주 병목이 아니며, 남는 지연의 대부분은 원격 이미지 서버다.

## 빠른 벡터 경로

빠른 경로는 이미지 모델을 호출하지 않는다. Luna의 한 번짜리 JSON 응답을 제한된 스키마로
검증한 뒤 기존 5E 객체로 변환한다.

- 지원: 기본 도형·선, 회로, 도르래·용수철, 평가원 장치, 렌즈·거울, 용기·액체·피스톤,
  입자 상자, 그래프, 가계도, 완성형의 제한된 주석
- 내부 반복 모티프: 패널 흐름, 이중 y축, 직교·대각 배선, 등치선 묶음, 근거 제한 학생 3인
  장면과 우주선 쉘, 명시적으로 일반 도식임을 밝힌 해안선 스캐폴드
- 검증 지도 자산: Natural Earth 고정 커밋·SHA-256에서 추출한 세계·태평양·동아시아·한반도
  물리 해안선. 정치 경계·지명·라벨은 포함하지 않음
- 그림형 안전장치: 문자·숫자·라벨·화살촉 제거/차단, 임의 장치 금지, 평탄 회색만 허용
- 좌표 안전장치: 중앙 원점 계약과 보수적인 top-left 좌표 정규화
- 결과: SVG 미리보기와 5E 네이티브 객체를 함께 보존하여 캔버스에서 직접 수정 가능

로컬 컴파일 자체는 장면당 약 0.03~0.15ms다. 실제 6.9~14.7초는 대부분 Luna가 JSON을
만드는 시간이다. 따라서 이 경로의 다음 상한은 명확한 반복 요청을 모델 없이 내부 자산으로
직접 삽입하거나, 성공한 동일 요청을 캐시에서 재사용하는 것이다.

그 직접 삽입 상한도 구현했다. 현재 strict local matcher는 세계·태평양·동아시아·한반도 물리
해안선 단독, 학생 세 명의 착석 대화, 제한 옵션의 단순 평면 우주선 쉘, 패널 흐름·빈 이중축·
고정 배선·값 없는 등치선, 그리고 검증된 고정 회로·도르래/용수철·광학대·용기/입자·S곡선만
승인한다. 19개 고정 문법을 세 번씩 실행한 57회가 모두 결정적 해시와 diagram invariant를
통과했으며 생산 경로 중앙값은 0.7255ms였다. 참고 이미지·완성형·복합 장면·모호한 수량은
이 경로로 보내지 않는다.

별도의 Electron 스모크 검사는 지도 1종과 고정 장치 5종을 실제 AI 패널에서 연속 실행했다.
모든 요청이 SVG/5E 객체로 완료됐고, 메인 프로세스에서 관찰한 `codex:send` 호출은 0회였다.
같은 검사는 새로 패키징한 `release/win-unpacked/5E.exe`에서도 통과했다.

반복 벤치마크는 회로, 도르래·용수철, 렌즈·거울, 용기·입자, 개체군 그래프, 패널 흐름,
이중 축, 등치선, 직교 배선을 각각 3회 실행했다. 모든 실행에서 이미지 생성 호출과 예상 밖
도구 호출은 0회였고, 컴파일 경고·오류도 0건이었다. 최초 탐색에서 실패한 광학 3건과
패널 흐름 3건의 원문 응답·해시를 교정 이력에 보존한 뒤, 프롬프트 계약을 좁혀 두 유형 모두
3/3으로 회귀 통과시켰다.

## 기출 전수 감사와 내부화 우선순위

기출 PNG 3,961개를 모두 파일·매니페스트 기준으로 검사했고, 수동 장치 아틀라스 936개와
현재 116개 템플릿·44개 객체 타입을 대조했다. 현재 구현으로 blocker가 모두 덮일 가능성이
있는 후보는 700/936(74.8%)다. 이는 실제 렌더 통과율이 아니라 **잠재 커버리지**다.

이번에 내부화한 정형 공백은 패널 흐름 22건, 이중 축 9건, 배선 5건, 무라벨 등치선 4건,
평면 지도 해안선 13건과 말풍선 외곽 31건이다. 사람 63건, 차량 28건, 손 19건은 자세와
접촉 관계가 섞여 있어 범용 아이콘 하나로 처리하지 않는다. 메타데이터가 반복성과 안전성을
뒷받침하는 학생 3인 대화 장면 13건, 분리형 우주선 쉘 계열 18건, 잡기 3패널·누르기 1패널만
엄격 자산으로 승격했다. 이 횟수들은 서로 겹칠 수 있어 단순 합산한 통과율로 쓰지 않는다.

## 남는 한계

- 참고 이미지 기반 복합 삽화가 래스터 fallback으로 가면 이미지 서버 지연은 여전히
  수십 초~수 분 변동할 수 있다.
- 빠른 벡터 경로의 스키마/불변식 통과는 과학적 의미가 85점 이상이라는 뜻이 아니다.
  대표 문항과 사람 평가 루브릭을 이용한 구조·과학 정확도 검증이 별도로 필요하다.
- 정확한 지도 중 물리 해안선 4종은 검증 자산을 쓰며, 정치 경계·지질 분포·지명이나 검증되지
  않은 생물 형태·손 접촉 자세는 임의 생성하지 않는다.
- 캐시는 동일 요청의 재사용을 빠르게 할 뿐 새로운 변형을 생성하지 않는다. Shift+생성 또는
  `새 변형`, `다시 생성`, `재생성` 요청은 캐시를 우회한다.
