# Engine V2 기출 도식·내부 자산 전수 조사

조사일: 2026-08-09  
조사 도구: `scripts/engine-v2/audit-exam-motifs.mjs`

## 결론

기출 라이브러리에는 **3,961장**이 있고 모두 정상 PNG로 확인됐다. 이 중 **2,955장(74.6%)**은
개념 태그로 분석할 수 있고, **936장(23.6%)**은 장치·부품·배치 blocker까지 사람이 분해한
아틀라스가 있다.

아틀라스가 처음 만들어졌을 때 완전 재현 가능 판정은 **345/936장(36.9%)**이었다. 그 뒤
추가된 116개 템플릿, 44개 객체 타입, MCP 조립 도구를 현재 코드와 다시 대조하니 과거
blocker 1,035건 중 **673건(65.0%)**은 현재 명시적인 구현이 생겼다. 모든 blocker가 현재
구현으로 덮이는 도판은 **700/936장(74.8%)**이다.

단, 74.8%는 **현재 기능으로 만들 수 있을 것으로 보이는 후보 비율**이지 새로 렌더링해
통과시킨 비율이 아니다. 실제 구조 정확도·비율·스타일 점수는 별도 회귀 재현이 필요하다.

이번 개선에서 패널 흐름, 이중 축, 배선, 무라벨 등치선, 평면 물리 해안선, 근거 제한
말풍선을 내부 벡터로 만들었다. 남은 큰 공백은 사람 63건, 차량 28건, 손 19건처럼 자세와
접촉 관계가 서로 다른 삽화다. 이들은 하나의 범용 아이콘으로 처리하지 않고, 현재는 반복성이
검증된 앉은 학생 3인 장면, 평면 우주선 쉘, 잡기·누르기 손 크롭만 엄격하게 허용한다.

## 기존 자산 창고 현황

- 검색용 부품 매니페스트: 991개
  - 화학 405, 지구 289, 물리 160, 생명 137
- 수집 원본 SVG: 4,374개
- 승인 SVG: 60개
- 수집 기록: 4,316개
- `keep.json`: 139개
- 기출 크롭: `hand_grip`, `hand_press` 2종, 실제 파일 4개
- 모든 매니페스트 참조 파일 존재: 누락 0

검색용 SVG 991개는 “파일이 있다”는 뜻이지 평가원 선화에 바로 적합하다는 뜻은 아니다.
예를 들어 `calorimeter`는 정확한 영문 토큰 후보가 1개 있지만 사람·차량·지도 윤곽은 0개다.
토큰 후보는 반드시 실제 그림을 보고 선 밀도·라벨·라이선스·구조를 검수한 뒤 내부 템플릿으로
승격해야 한다.

## 과거 재현 로그가 말하는 것

| 로그 | 사례 | 95점 이상 통과 | 평균 점수 |
|---|---:|---:|---:|
| 평가원 재현 학습 로그 | 101 | 31 (30.7%) | 91.60 |
| 참조 이미지 직접 생성 로그 | 100 | 59 (59.0%) | 94.03 |

직접 이미지 생성은 평균이 높지만 95점 통과율은 59%에 머문다. 반복 개수, 연결 위상, 작은
구조와 회색 평탄화가 계속 실패했다. 반면 용기·그래프·회로처럼 정형 장치는 현재 내부
템플릿으로 blocker가 많이 해소됐다. 따라서 Engine V2의 기본값은 정형 장치를 내부 벡터
경로로 보내고, 사람·동물·사진형 복합 삽화만 이미지 생성 fallback으로 보내는 것이 맞다.

기출·훈련 이미지도 수정하지 않았다.

## 한계와 다음 검증

- 장치 아틀라스는 전체 3,961장의 23.6%다. 아직 분석하지 않은 3,025장에는 다른 반복
  모티프가 있을 수 있다.
- 700장은 blocker 명칭과 현재 구현을 코드로 대조한 후보치다. 실제 85점 통과나 95% 구조
  일치를 보증하지 않는다.
