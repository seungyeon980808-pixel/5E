# RHWP 시험지 작업 공간 실험

기준: `main` / `e095f281edf650e6e23320aca1b29944e70ef71d` (5E 1.6.3)

현재 작업 브랜치: `perf/rhwp-typing-latency` (최초 실험: `codex/rhwp-exam-workspace`)

5E에서 그림을 만들고 한글 시험지에 넣은 뒤, 시험지 그림을 더블클릭해 **그 자리에서 라벨·지시선만 편집**한다. 선택한 그림 우측 상단의 **수정 → 편집기에서 수정**으로 원래 5E 작업 탭을 연다. AI 작업은 선택 버전, 원본 이미지, 코멘트, 대화 이력까지 이어서 연다. 알한글은 RHWP Studio를 사용하는 macOS 앱이며, 이 프로젝트는 RHWP 웹 SDK와 로컬 Studio를 직접 연결한다.

## 실행

별도 작업 폴더에서 서버를 실행한다.

macOS에서는 작업 폴더의 **`RHWP 시험지 열기.command`**를 더블클릭하면 된다. 로컬 서버의 응답을 확인한 뒤 Safari에서 시험지를 연다. 터미널이 닫혀도 서버는 계속 실행되며, 다시 실행하면 같은 작업 폴더의 서버를 재사용한다. 주소는 기본 `http://127.0.0.1:4188/`로 유지하여 이 주소의 자동 저장을 이어갈 수 있다. 다른 작업 폴더가 같은 포트를 사용 중이면 기존 서버를 재사용하지 않고 안내한다. 서버 로그는 `_work/rhwp/local-preview.log`에 남긴다.

Node.js를 사용할 수 있는 터미널에서는 `npm run exam`으로 같은 실행 경로를 사용한다. 다른 포트가 필요하면 `PORT=4190 npm run exam`을 사용하되, 이전 주소의 자동 저장은 새 주소로 이동하지 않으므로 `.5e`로 저장하여 옮긴다. 브라우저를 열지 않으려면 `npm run exam -- --no-open`을 사용한다.

서버를 터미널에 직접 연결하여 실행하려면 다음 명령을 사용한다.

```sh
PORT=4188 node scripts/preview-local-server.cjs
```

Safari에서 `http://127.0.0.1:4188/?mode=pro&mobile=0`을 연다. `/preview/`에서도 같은 기능을 사용한다. 상단 **시험지** 또는 **파일 → 시험지 작업 공간**으로 문서를 연다. `&exam=1`을 붙이면 시험지부터 표시한다.

Electron에서는 `npm run desktop`으로 이 브랜치의 앱을 실행한다. 그림 보내기는 작성 중인 시험지를 별도 창에서 열며, 그림 더블클릭은 시험지 창에서 라벨 편집을 시작한다. **원본 편집**은 원래 5E 창을 앞으로 가져온다. 설치된 5E 앱을 교체하는 작업은 포함하지 않는다.

## 사용 흐름

1. 5E에서 직접 그림을 만들거나 AI 작업 탭에서 생성 결과를 선택한다. **보내기**를 누른다.
2. 캔버스에서 시험지에 보낼 영역을 드래그하고 **확인**한다. 취소하면 문서에 그림이 들어가지 않는다. 선택 영역으로 픽셀을 내보내되 전체 페이지 원본은 함께 보관한다.
3. 시험지가 표시된다. 본문 또는 표 셀에서 삽입 위치를 클릭한 뒤 두 번째 **확인**을 누른다. 이때 크롭한 PNG가 들어간다. 처음 보낼 때는 위치를 선택하기 전까지 확인이 비활성화된다. 그림은 300 dpi, 최대 폭 80 mm로 들어가며 표에서는 셀 안쪽 폭에 맞추고 행 높이를 늘린다.
4. 문서 그림이나 목록을 한 번 클릭하면 선택하며, 그림과 겹치지 않는 우측 상단 바깥에 **수정 / 설정**이 나타난다. RHWP의 선택틀 한 개와 기존 8개 크기 조절점을 사용하며 가로·세로를 같은 배율로 확대·축소한다. 문서에서 크기를 바꿔도 원본·PNG·크롭 범위는 그대로다. 더블클릭 또는 **수정 → 현재 페이지에서 수정**은 문서와 주변 본문을 부드럽게 확대하고 라벨 편집 화면을 연다. 배경은 고정하고 라벨 내용·위치·글꼴·글자 크기, 지시선 끝점·꺾임점·굵기만 수정한다. **라벨 추가**는 다음 클릭 위치에 놓고, **지시선 추가**는 가리킬 위치와 라벨 위치를 차례로 클릭한다. 그림 상단의 **수정 반영**은 같은 문서 그림을 교체하며, **돌아가기**는 미반영 라벨을 원래 작업 탭에 보관한다.
5. **수정 → 편집기에서 수정**을 누르면 해당 그림의 원래 5E 페이지가 열린다. 원본 전체에 시험지 크롭 범위를 파란 점선으로 표시한다. AI 그림은 원래 작업 탭과 수정 이력도 표시한다. 원래 탭이 없으면 보관한 원본으로 독립된 작업 탭을 복원한다. 편집 중 배지만 그림 상단에 표시한다. 원본 편집의 반영·전환은 기존 상단 **보내기 / 시험지**를 사용하며 그림 위에 같은 동작의 버튼을 중복 배치하지 않는다.
6. 간단한 선·도형·글자는 직접 수정한다. AI 그림은 기존 작업 탭에서 새 버전을 생성하거나 코멘트를 편집한다. 편집 중에도 크롭 핸들 또는 오른쪽 **시험지에 보낼 영역**의 좌표·크기·여백으로 영역을 조정한다. 영역 밖으로 넓히면 원본이나 빈 공간이 보이며 객체의 출력 크기는 유지된다. **영역 다시 드래그**를 명시적으로 눌렀을 때만 기존 범위로 영역 지정 창을 연다. 원본 편집 중 **보내기**는 입력 중인 글자를 확정하고 현재 영역을 기존 그림에 적용한다. **시험지**는 문서 그림을 유지하며 크롭·배치·객체의 미반영 수정을 5E 탭에 남기고 편집 영역 표시를 종료한다. 반영 중에는 두 버튼을 잠시 비활성화한다. 실패하면 오류를 알리고 편집 화면을 유지하여 다시 보낼 수 있다.
7. 같은 탭에서 **보내기**를 다시 누르면 새 그림을 추가하지 않고 기존 그림 한 개를 갱신한다. 크롭 확인 다음에 기존 위치를 유지한다는 안내와 확인 버튼이 표시된다.
8. **파일 → 프로젝트 저장**은 시험지, 전체 편집 탭, 객체, AI 작업, 이전 그림 버전과 **미반영 수정**을 `.5e`에 함께 보관한다. 편집 화면에서도 기본 파일 메뉴 또는 `⌘S` / `Ctrl+S`로 저장한다. **프로젝트 열기**로 다른 세션에서 이어서 수정한다. 문서에는 마지막 반영본이, 편집 탭에는 저장 당시의 수정 중인 원본이 남는다.
9. **한글 저장**으로 HWPX 또는 HWP를 저장한다. 문서 안 PNG에도 현재 원본과 AI 작업 정보가 들어 있어, 이 문서만 다시 열어도 그림을 수정할 수 있다. **선택 그림 PNG**로 개별 그림도 옮길 수 있다. 웹에서는 **그림 원본 열기**, 데스크톱에서는 원래 5E 창의 **파일 → 열기**로 원본 포함 PNG를 연다.

**하나의 작업 탭은 문서 그림 하나에만 대응한다.** 탭 연결과 문서 그림의 식별자는 수정 버전이 바뀌어도 유지한다. 문서에서 연결 그림을 복사하면 새 그림·5E 페이지·AI 작업에 각각 독립된 식별자를 부여한다. 원본과 복사본의 데이터가 섞이지 않는다. 연결된 다른 페이지나 AI 작업으로 이동한 상태에서는 반영을 거부하고 원래 탭에서 반영하도록 안내한다.

5E 작업 기능은 왼쪽 패널에 모으며 RHWP 메뉴는 화면 맨 위에서 시작한다. 왼쪽 **파일** 메뉴에서 **한글 파일 열기…**로 HWP/HWPX를, **프로젝트 열기… (.5e)**로 작업 원본을 연다. 동일한 메뉴에 프로젝트 저장, HWP/HWPX 저장, 선택 그림 PNG 저장을 모았다. 파일 선택 창을 사용자 클릭 안에서 직접 열어 Safari의 사용자 제스처를 유지한다. 취소하면 문서를 그대로 두고, 파일을 선택하면 현재 작업을 자동 저장한 뒤 연다. 실패하면 이전 문서·연결·이름을 복원한다. 문서 영역과 왼쪽 패널에 파일을 드롭하는 경로도 같은 로더를 사용한다.

왼쪽 패널에는 이름과 **파일** 메뉴만 두며 보내기·라벨 편집·원본 편집 버튼을 두지 않는다. 그림 편집기로 돌아가는 버튼은 하단에 있다. RHWP의 embed 모드는 파일 열기·저장을 제거하므로 남은 네이티브 파일 메뉴는 **문서 설정**으로 표시한다. 네이티브 **편집 용지**와 제품 정보 기능은 그대로 유지한다. 좁은 창의 파일 메뉴는 패널 바깥으로 펼쳐지며 화면 안에서 스크롤한다. 키보드 화살표 이동과 Esc 닫기를 지원한다.

문서의 모든 본문·표 그림을 목록에 표시한다. 연결된 그림은 **얇은 왼쪽 파란 테두리**, 현재 선택한 그림은 **전체 테두리**로 표시한다. 목록 이름은 편집 탭 이름과 동기화한다. 연결·미연결 안내 문구는 표시하지 않으며 접근성 이름으로 상태를 제공한다.

**설정**은 글자처럼 취급, 왼쪽·가운데·오른쪽 정렬과 본문 간격을 변경한다. 새 그림은 가운데 정렬, 글자처럼 취급, 위·아래 5pt가 기본이다. 가운데 정렬은 좌우 간격을 0으로 처리하고 해당 입력을 숨긴다. 글자처럼 취급을 끄면 **어울림 사용 / 사용 안 함**이 나타난다. 사용은 `Square`, 사용 안 함은 `TopAndBottom`이며 고급 설정의 빈 공간 채움·글 뒤로·글 앞으로도 보존한다. 글자처럼 취급을 다시 켜도 이전 어울림 선택은 유지된다. 원본 편집에서 변경한 배치 설정은 수정 반영 시 문서에 적용한다. 설정을 건드리지 않은 원본·라벨 편집은 기존 문단의 정렬을 유지한다. 새 그림은 별도 문단에 넣어 주변 문제 본문의 정렬을 바꾸지 않는다. 중첩 표와 머리말·꼬리말의 글자처럼 취급 문단 정렬은 이 빌드의 API 제한으로 RHWP 개체 속성에서 변경한다.

외부 문서의 일반 그림도 한 번 클릭하면 선택한다. **수정 → 편집기에서 수정**은 원본 편집에 등록하며, **현재 페이지에서 수정** 또는 더블클릭은 등록 후 시험지 안 라벨 편집을 시작한다. 이미지 픽셀에 이미 찍힌 글자와 선은 개별 객체로 바뀌지 않으며, 새 라벨·지시선을 추가하거나 원본 편집에서 배경을 정리한다. 그림 하나마다 독립된 편집 탭을 만들며 기존 자르기·회전·배치를 읽어 이어서 편집한다. 원래 도형으로 자동 변환하지 않는다. PNG/JPEG 등은 원본 바이트를 편집 원본에 보관하고 문서 연결 메타데이터는 PNG에 넣는다. ImageBitmap이 읽지 못하는 SVG 등의 형식은 이미지 요소로 다시 디코딩해 PNG로 변환한다. 둘 다 읽지 못하는 형식은 등록을 중단하고 PNG 변환 후 등록하도록 안내한다.

시험지와 편집 중인 작업 탭은 프로젝트 ID별 IndexedDB에 자동 저장한다. 새 시험지와 이전 시험지의 자동 저장이 서로 덮어쓰지 않는다. **자동 저장 이어서**는 이름과 저장 시각이 있는 목록에서 고른다. 저장 트랜잭션 완료 후 저장 완료를 표시한다. `⌘S` / `Ctrl+S`는 편집 중에도 미반영 수정을 포함한 프로젝트 파일을 저장한다.

## 파일과 연결

PNG의 표준 `iTXt` 청크 `5E-Editable-Source`에 다음 데이터를 넣는다.

- 전체 활성 5E 페이지 원본과 이름, 수정 버전 ID
- 하나의 탭·그림을 묶는 고정 연결 ID
- 크롭 범위와 내보내기 옵션
- 화면 배율·선택과 해당 AI 작업 한 개의 이미지·코멘트·대화 이력

원본 한 페이지 전체를 보관하므로 크롭 밖의 개체도 다시 편집할 수 있다. PNG 원본 정보는 코드로 실행하지 않는다. 픽셀·해상도·기존 청크를 유지하고, 다시 저장할 때 이전 원본 청크를 교체한다.

문서 그림의 설명에 `5e-exam:<수정 버전 ID>`를 저장한다. 수정마다 새 버전 ID를 발급하고 이전 원본도 남긴다. RHWP의 되돌리기·다시 실행은 이미지와 설명을 함께 복원하여 해당 버전 원본을 다시 연다. 같은 버전으로 돌아올 때 기존 5E 탭의 실행 취소 기록을 유지하며, 전체 원본을 다른 버전으로 교체한 경우에는 이전 탭의 실행 취소 기록을 초기화한다. 라벨만 반영한 버전은 해당 라벨 ID만 병합하여 배경·다른 라벨의 미반영 수정과 페이지 이력을 보존한다. 같은 라벨이 양쪽에서 바뀌면 덮어쓰지 않고 다시 열도록 안내한다.

한글 문서를 열면 실제 PNG 데이터에서 원본을 복원한다. 외부 편집기로 그림 설명이 지워져도 원본 PNG가 남아 있으면 연결을 재생성한다. 외부 프로그램이 PNG 메타데이터를 제거하거나 이미지를 다시 압축하면 원본 복원이 불가능하므로 `.5e` 프로젝트를 별도로 보관하는 것이 좋다. HWP/HWPX는 현재 삽입된 그림의 원본을, `.5e`는 이전 그림 버전과 미반영 수정도 보관한다.

그림 전용과 시험지 프로젝트 모두 새 `.5e` STORE ZIP을 사용한다. 내부 `format:5e-project`, `version:1`, `kind:drawing|exam`으로 구별한다. 이전 JSON `.5e`·`.json`, ZIP `.5exam`, 원본 포함 PNG도 읽는다. 열기 메뉴와 캔버스·시험지의 드롭 경로가 같은 분기 규칙을 사용한다.

```text
manifest.json       공통 형식·버전·종류·프로젝트 ID·이미지 목록
document.hwpx       시험지 프로젝트의 한글 문서
project.json        반영된 원본/이력과 수정 중인 전체 작업 공간
assets/<index>      원본·AI 참조·결과에서 반복되는 이미지의 바이너리
```

프로젝트 최대 크기는 그림 전용과 시험지 모두 **128 MiB**다. 같은 이미지 data URL은 공통 자산 한 개를 참조하여 중복 저장을 줄인다. 문서 안 PNG에는 현재 원본을 계속 포함하므로 외부 한글 파일에서도 연결을 복원할 수 있다. PNG의 원본 청크 제한은 32 MiB, 원본 포함 PNG 전체는 64 MiB, 그림·수정 이력은 500개다.

열기 전에 ZIP CRC, 형식·버전, 자산 누락, 그림 ID 중복, 모든 원본과 작업 맥락을 검증한다. 문서·원본 복원 실패 시 이전 문서와 작업 공간으로 돌아간다. 저장 중 문서/원본이 바뀌면 캡처를 재시도한다. 실행 중인 AI 요청은 이력과 중단 정보를 보관하고 재열기에서는 중단 상태로 표시한다. 공급자 프로세스를 파일에서 자동 재개하지 않는다.

## 라벨 데이터와 크롭

시험지 편집은 기존 `labeler` 객체 ID·좌표·글꼴·수식·텍스트 런을 그대로 사용한다. 라벨을 제외한 반영본 배경과 같은 라벨 렌더러의 편집 화면을 겹쳐 표시하여 기존 PNG의 라벨이 중복되지 않는다. 라벨만 반영할 때는 원래 작업 탭의 미반영 배경 수정은 시험지에 보내지 않는다. 라벨 수정과 크롭 초안은 프로젝트의 작업 공간에 보관하며, 크롭은 전체 원본을 잘라 버리는 작업이 아닌 표시 영역이다.

같은 라벨이 다른 창에서 바뀌면 반영을 중단하고 시도한 수정을 작업 공간의 선택적 `annotationDrafts`에 별도 보관한다. 닫기와 저장은 계속 사용할 수 있다. 다시 열면 보관 초안과 교체 안내를 표시하며, 사용자가 **적용**해야 현재 라벨을 바꾼다. 이 초안도 `.5e` 저장·재열기에 포함된다. 동일 버전의 라벨 읽기는 변경 알림을 발생시키지 않는다.

화면 좌표는 RHWP의 실제 그림 렌더 위치와 SVG 역변환으로 계산한다. 더블클릭하면 약 280ms 동안 줌과 스크롤을 동시에 보간해 그림과 주변 본문을 같은 배율로 확대하고 그림을 편집 영역 위쪽에 맞춘다. 전환 중에는 기존 페이지 래스터를 재사용하고 끝에서 최종 배율로 다시 그린다. 배경 준비는 확대와 병렬로 진행한다. 모션 줄이기에서는 보간을 생략하며 사용자 조작으로 전환을 중단할 수 있다. 기본 확대는 현재 배율의 1.6배, 최대 200%이며 그림 전체와 비교할 본문·도구줄이 들어가는 화면 공간에 맞춰 제한한다. 이미 더 확대해 둔 화면은 축소하지 않는다. 도구줄은 본문을 가리지 않도록 편집 영역 하단에 놓는다. 적용·닫기는 원래 보기로 돌아가며, 편집 중 사용자가 직접 바꾼 배율은 유지한다. 확대·스크롤·표 셀·회전·반전에 따라 편집 화면도 이동한다. 편집 도구와 원본 크롭 점선은 HWP/PNG에 포함되지 않는다.

그래프 제작 창의 **한글에 넣기**는 만들기/적용과 시험지 보내기를 한 번에 연결한다. 잘못된 함수식은 객체를 만들거나 전송하지 않고 제작 창에서 오류를 표시한다. 새 그래프는 축 이름·끝 라벨을 포함한 영역을 먼저 제안하며 기존 그림을 갱신할 때는 이전 크롭 영역을 표시한다. 영역을 이동·조절하거나 다시 드래그한 뒤 확인하고, 시험지에서 위치를 선택하여 확인한다. 같은 탭에서 재전송하면 기존 그림 한 개를 갱신한다. 그래프 객체와 함수식은 해당 5E 탭 및 `.5e` 프로젝트에 남아 다시 편집할 수 있다.

## 데스크톱 연결

파일 화면의 기본 preload에서 신뢰된 IPC로 크롭 범위·연결·5E 원본·AI 작업을 보낸다. 시험지는 기본 `127.0.0.1:39821`에서 열며 일회성 임의 URL로 데이터를 전달한다. 같은 시험지 창을 재사용하고 작성 중인 문서를 유지한다. 시험지의 **5E에서 그림 보내기**는 원래 5E 창을 앞으로 가져오며, 그 창의 **보내기**에서 영역을 선택한다. 편집 중 새 그림을 받으면 현재 편집을 마친 뒤 보내기 확인을 표시한다. 원래 그림 창의 일반 **파일 → 저장**도 연결된 시험지와 미반영 수정을 포함한 `.5e`를 저장하며, **파일 → 열기**로 시험지 프로젝트를 고르면 시험지 창과 그림 창을 함께 복원한다.

시험지 창은 sandbox, context isolation, 별도 브라우저 파티션을 사용한다. 라벨 읽기·수정·버전 확인은 별도 제한된 요청 ID 기반 IPC를 사용하며 원래 창의 초점이나 활성 탭을 바꾸지 않는다. 전용 preload에는 그림 편집 요청·반영 수신·반영 완료 응답·원래 창으로 돌아가기와 저장용 원본 스냅샷 요청·복원을 노출한다. 원본은 신뢰된 5E 창에서 요청 ID로 연결해 받아온다. AI 실행이나 일반 파일 접근 IPC는 노출하지 않는다. IPC는 시험지 창의 같은 Origin·경로를 가진 최상위 프레임만 허용하고 요청 ID 및 연결을 확인한다. 5E 창은 문서 반영 완료 응답을 받은 뒤 수정 버전 연결을 갱신한다. 시험지 창 닫기·재탐색은 진행 중 연결을 취소한다.

로컬 서버는 제품 정적 파일만 제공하며 외부 Origin, 경로 탈출, 숨김 파일, 저장소·작업 폴더와 심볼릭 링크 외부 파일 접근을 거부한다. 테스트의 `FIVE_E_EXAM_PORT=0`은 임시 포트를 사용한다.

## RHWP 업데이트

현재 로컬 의존성은 `@rhwp/editor` 0.8.7 및 공식 RHWP Studio 파일이다. WASM·기본 글꼴·아이콘을 포함하며 출처·수정 사항·SHA-256과 라이선스를 `vendor/rhwp-studio/`에 보관한다.

임베딩·파일 열기·내보내기·저장 통지는 SDK 공개 API를 사용한다. 그림 삽입·선택·교체·설명·실행 취소는 `js/rhwp-exam-bridge.js`의 Studio 플러그인 컨텍스트를 사용한다. 내부 API가 바뀔 수 있으므로 새 버전을 검증한 뒤 의존성을 함께 갱신한다.

1. 공식 RHWP 릴리스 및 editor SDK 변경 사항을 확인한다.
2. 별도 브랜치에서 SDK와 Studio/WASM 파일을 서로 호환되는 버전으로 교체하고 출처·해시·라이선스를 갱신한다.
3. 아래 브라우저·데스크톱 검증으로 크롭, 본문/표 삽입, 원래 탭 복귀, 그림 교체, 복사 분리, 저장·재열기를 확인한다.
4. 통과한 버전만 병합한다. 검증 없이 실행 중 최신 파일을 받아 교체하지 않는다.

주기적인 릴리스 확인 자동화는 별도 설정 사항이다. 이번 구현은 예약 작업을 생성하지 않는다.

AI 브라우저 검증의 프로젝트 저장은 현재 화면과 같은 **파일 → 프로젝트 저장** 경로를 사용한다. 이전처럼 숨겨진 저장 버튼을 직접 클릭하지 않는다. `EVIDENCE_DIR`를 지정하면 AI 검증의 이미지와 `.5e` 결과를 해당 폴더에 남긴다.
