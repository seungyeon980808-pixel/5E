# 박스 부분 수정의 1픽셀 테두리 처리

2026-10-07 사용자 실행 승인에 따라 추가했다. 전체 스타일 변환 하네스나 생성 모델 설정을 바꾸는 작업이 아니다. 로컬 미커밋 상태이며 배포하지 않았다.

## 처리 계약

- 같은 크기의 PNG는 기존 엄격한 마스크 합성 경로를 유지한다.
- 크기 차이는 가로·세로 각각 최대 1픽셀이다. 오른쪽·아래쪽 테두리 차이만 처리하며 좌표 이동, 전체 리사이즈, 보간은 하지 않는다.
- 후보가 모든 수정 허용 픽셀을 포함해야 한다. 누락된 박스 픽셀을 원본이나 배경으로 대신 채우지 않는다.
- 겹치는 보존 영역의 RGBA가 모두 같아야 하고, 그 영역에 가로·세로 두 방향의 가시적 대비가 있어야 한다. 대비 기준은 premultiplied RGB 채널 차이 64 이상이다. 완전 투명 영역의 숨은 RGB는 정렬 기준으로 쓰지 않으며 바이트 보존 검사는 모든 채널을 포함한다.
- 통과한 후보는 원본 크기의 배열에 같은 정수 좌표로 행별 복사한다. 누락된 비수정 테두리는 원본 바이트가 남고, 초과 테두리는 복사하지 않는다.
- 기존 마스크 합성 → PNG 인코딩 → 재디코딩 경로에서 박스 밖 RGBA 변경 0을 다시 확인한다. 컬러 프로파일 호환 조건과 세션 소유권·취소·선택 변경 검사는 유지한다.
- 결과의 `geometry.kind`는 `same-size` 또는 `verified-border-only`다. 제안 객체에 불변 복사본으로 전달하고, 후자의 경우 비교 창에 테두리 처리 사실을 표시한다. 최종 적용은 기존 명시적 수락 경로만 사용한다.

오류 코드는 `SCOPED_EDIT_DIMENSIONS`, `SCOPED_EDIT_MISSING_ALLOWED_PIXELS`, `SCOPED_EDIT_ALIGNMENT_UNCONFIRMED`이며 UI는 한국어 사유를 표시하고 원본을 유지한다. 일반 RGBA 합성기의 동일 크기 조건은 완화하지 않았다.

정렬 조건은 보수적이다. 실제 좌표가 같더라도 배경·안티앨리어싱 픽셀 값이 달라지면 차단될 수 있다. 이 조건을 시각적 정렬의 일반적인 판별기나 박스 내부 의미 품질 보증으로 설명하지 않는다.

## 검증 결과

- 새 경계 처리와 기존 박스 프롬프트·패널·계측 단위 검사 29/29 통과. 표준 단위 목록에 4개 검사 파일을 등록했다.
- Chromium/WebKit에서 1픽셀 누락 후보의 실제 비교·적용·ZIP 내보내기·캔버스 삽입 2/2 통과. 합성 PNG 바이트가 내보내기와 삽입에서 같다. 모의 응답이며 실제 모델 품질 검사와 구분한다.
- 정렬 불명·모델 실패·범위 부족·비교 취소·늦은 응답·선택 버전 변경·박스 없는 일괄 7/7 통과. 큰 PNG 일괄 원본 보존 1/1 통과.
- 기존 실제 모델 RAW 8장을 고정하여 전후 코드로 재처리했다. 이전 합성 가능 4장과 이후 합성 가능 4장이 동일하며 새로 복구한 출력은 0장이다. 합성 4장의 외부 RGBA 변경은 독립 디코더 검사에서 0이고 이전 합성본과 전체 픽셀이 같다. 크기 불일치 4장은 보존 영역이 함께 바뀌어 정렬 미확인으로 남았다.
- 합성 4장 로컬 PNG 처리 중앙값 233.7 → 234.5ms, 차단 4장 60.6 → 82.5ms. Node 24.21.0, 동일 입력 3회, 순서 교차 계측이다. 당시 AI 응답 36.5–83.8초와 현재 로컬 재처리 시간을 구별한다. 추가 생성은 0회다.
- 전체 단위 검사 549/550 통과. 실패 1건은 기존 PNG 압축 바이트 재현성 검사다. 누락된 js-yaml은 설치된 다른 로컬 워크트리 의존성을 이용해 검사 환경에서 해결했다. 기존 래스터 수정 라우팅 검사 2개는 박스 없는 전체 재생성 차단 정책과 실제 코멘트 검증기로 갱신했다.

로컬 증거 폴더는 기본 작업 폴더의 `_work/box-edit-border-20261007/`다. 전후 코드 사본, 테스트 로그, 고정 입력 해시, 처리 시간과 8장 비교 보고서를 보존했다. 보고서는 Safari에서 표시와 박스 확대를 확인했다. WebKit 자동 기능 검증을 Safari의 실제 제품 기능 검수로 간주하지 않는다.

## 남은 작업

이번 변경으로 실제 생성 성공률·시각 품질·전체 속도 향상을 입증하지 못했다. 새 구 잘림과 위치 오차, 도선 재묘사, 물결선 이동 거리 오차와 주변 획 이동이 남았다. 정확한 이동·복제·삭제를 원본 픽셀 조작으로 처리하는 경로와 이미지 모델에 필요한 구조 생성 경로를 구분하는 방안은 후속 실험이며 이번에는 구현하지 않았다.
