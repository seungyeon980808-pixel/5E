# v1.5.0 초안 — 그림을 가져오고, 고치고, 데스크톱에서 이어 그립니다

> 아직 게시하지 않은 릴리즈 노트 초안입니다. 실제 태그·패키지 버전·배포 방식은 검토 후 확정합니다.

v1.4.0이 **도구 상자를 넓힌 판**이었다면, 이번 판은 그림이 들어오는 길을 넓힙니다.

**기출 그림을 가져와 다시 씁니다.** 이미지 라이브러리가 출처와 함께 그림을 모으고, 평가원 지면에 맞는 선화로 다듬어 캔버스에 넣습니다.
**그림을 5E 안에서 계속 고칩니다.** 들어온 이미지는 평범한 5E 이미지 객체입니다. 자르고, 지우고, 도형과 라벨을 얹고, 기존 방식대로 저장·내보냅니다.
**Windows에서도 같은 5E를 엽니다.** 웹판의 편집기와 파일 형식을 바꾸지 않고, 설치판에는 선택형 AI 이미지 생성/변환 패널만 더했습니다.
**AI가 없어도 5E는 그대로입니다.** Codex가 없거나 로그인하지 않았으면 필요한 설치와 로그인만 안내합니다. 편집·저장·내보내기 기능은 계속 쓸 수 있습니다.

---

## 먼저, 이 판의 이름

**v1.4.0은 이미 GitHub에 정식 공개되어 있습니다.** 따라서 이번 Windows 설치판과 AI 이미지 기능은 다음 기능 릴리즈인 **v1.5.0**으로 묶는 것이 맞습니다.

Windows 설치판을 먼저 제한 공개하고 안정화 여부를 보려면 `v1.5.0-beta.1`을 거친 뒤 `v1.5.0`으로 올립니다. 웹판과 설치판의 숫자는 같은 릴리즈에서 맞춥니다.

`0.1.0`은 데스크톱판을 웹판과 별개 제품·별개 릴리스 주기로 운영할 때만 적합합니다. 현재 구조는 같은 5E 편집기와 같은 프로젝트 형식을 공유하므로 그 방식은 권하지 않습니다.

---

## 밖의 그림이 5E 안으로 들어옵니다

세포·실험 장치처럼 도형 몇 개로 시작하기 어려운 그림은, 원본을 보며 손으로 다시 그리는 데 시간이 많이 듭니다. 이미지 라이브러리는 이런 그림을 **출처와 라이선스 정보까지 붙여** 모아 두고, 필요한 그림을 찾아 캔버스로 보냅니다.

그림을 넣는 순간 끝나는 기능은 아닙니다. 평가원 형태에 가까운 흑백 선화로 변환한 뒤 5E 이미지 객체로 넣습니다. 그래서 기존의 **가위, 지우개, 이동, 회전, 크기 조절, 정렬, 레이어, PNG/SVG 내보내기**가 모두 이어집니다.

원본을 그대로 베끼는 대신, 시험지에서 중요한 구조가 남는 방향을 우선합니다. 작은 글자·색·장식은 줄이고, 나중에 5E의 문자와 도형으로 다시 조판합니다.

---

## Windows 데스크톱판 — 웹판을 바꾸지 않고 옆에 놓았습니다

브라우저에서 쓰던 5E의 화면과 프로젝트 형식은 그대로입니다. Windows 설치판은 같은 `index.html`과 편집 모듈을 열고, 컴퓨터 안에서만 필요한 연결 기능을 안전한 경계 뒤에 둡니다.

프로젝트 JSON, 자동 저장, 페이지, 기존 편집 도구, 이미지 내보내기는 웹판과 같은 방식으로 동작합니다. 설치판을 썼다고 파일이 별도 형식으로 바뀌지 않습니다.

설치판에는 5E 아이콘과 NSIS 설치 파일이 포함됩니다. GitHub Releases에서 설치 파일과 SHA-256 체크섬을 함께 제공합니다.

## 고급 기능 → AI 이미지 생성/변환

AI 기능은 화면을 복잡하게 만들지 않도록 **고급 기능** 안에 넣었습니다.

웹판에서 `AI 이미지 생성/변환`을 누르면 Windows 설치판이 필요하다는 안내만 보입니다. 데스크톱판에서는 같은 버튼이 AI 패널을 엽니다.

### 설명만으로 시작합니다

예를 들어 “흰 배경에 검은 선으로 된 비커와 스탠드”처럼 적으면, 5E가 저장해 둔 평가원 도식 규칙을 요청에 함께 적용합니다. 그림형 모드에서는 **문자, 숫자, 기호, 라벨, 지시선, 화살표를 만들지 않도록** 제한합니다.

그림 안에서 글자를 억지로 생성하는 대신, 결과를 캔버스에 넣고 5E의 텍스트·도형 도구로 마무리하는 쪽이 더 안정적입니다.

### 참고 그림도 함께 보냅니다

기출 크롭, 손그림, 바꾸고 싶은 그림을 붙여 “이 구조를 평가원 선화로 바꿔 줘”라고 요청할 수 있습니다. 생성 결과는 여러 시안으로 보이고, 마음에 드는 시안을 눌러 바로 현재 캔버스에 넣습니다.

한 번 넣은 뒤에는 기존 이미지 객체와 같습니다. 생성 결과에 다시 수정 요청을 보내거나, 5E에서 라벨·화살표·도형을 직접 더할 수 있습니다.

### 대화는 이어집니다

패널을 닫거나 앱을 다시 열어도 최근 대화의 연결 정보를 보관해 다음 요청을 이어 갑니다. 새 그림으로 시작하고 싶으면 새 대화를 누르면 됩니다. 생성 중에는 중단할 수 있습니다.

## Codex가 없을 때는 막히지 않게

AI 이미지 기능은 사용자의 ChatGPT/Codex 로그인과 로컬 Codex 설치가 필요합니다.

| 상태 | 5E가 하는 일 |
|---|---|
| Codex를 찾지 못함 | 설치 또는 연결이 필요하다고 안내 |
| 로그인하지 않음 | 기존 Codex 로그인 흐름을 열 수 있게 안내 |
| 연결 실패 | 실패 상태를 표시하고 다시 연결할 수 있게 함 |
| AI를 쓰지 않음 | 편집·저장·내보내기는 평소처럼 계속 사용 |

5E는 계정 비밀번호나 인증 토큰을 저장하지 않습니다. AI를 생성 요청한 때에만 설명과 첨부 그림이 사용자의 로컬 Codex App Server를 거쳐 해당 계정의 AI 서비스로 전달됩니다.

---

## 검증한 것

- 웹판 버튼은 설치 안내만 표시하는지
- 데스크톱판 버튼은 AI 패널을 여는지
- Codex 로그인 상태 확인과 App Server 시작·종료가 되는지
- 실제 이미지 생성 결과가 미리보기에 도착하는지
- 미리보기의 삽입 버튼으로 SVG 캔버스에 이미지 객체가 추가되는지
- 기존 단위 테스트와 데스크톱 UI 스모크 테스트가 통과하는지
- 설치 파일을 실제로 설치한 뒤 실행할 수 있는지

---

## 이번 판에서 아직 아닌 것

- AI 결과의 과학적 정확성·기출과의 완전한 일치는 자동 보장하지 않습니다. 생성 뒤 교사가 확인하고 5E에서 마무리해야 합니다.
- AI 이미지 기능은 ChatGPT/Codex 계정의 사용 가능 모델과 권한에 따라 달라집니다.
- 무료 GitHub 배포본은 코드 서명 승인 전까지 Windows SmartScreen 경고가 보일 수 있습니다. 공개 AGPL-3.0 프로젝트로서 무료 OSS 코드 서명 신청을 준비합니다.
- 자동 업데이트는 아직 넣지 않았습니다. 새 판은 GitHub Releases에서 설치 파일을 받아 갱신합니다.

## 현재 검증 빌드와 배포 전 결정할 것

로컬 Windows 검증 빌드는 `v1.5.0-beta.1`로 통일합니다. 원래 V2의 36개 개발 사례와 24개 동결 최종 사례에 대한 85점 루브릭 검증이 끝나기 전에는 `v1.5.0` 정식판으로 표시하지 않습니다.

1. GitHub Release 설명에 Codex 설치·로그인·AI 데이터 전송 안내를 어느 정도까지 앞에 둘지
2. SignPath Foundation 무료 OSS 서명 신청을 진행할지
3. 전체 V2 검증을 마친 뒤 `v1.5.0` 정식판으로 승격할지

공개할 때는 패키지 버전, 화면 표기, GitHub 태그와 릴리즈 파일명을 같은 버전으로 맞춥니다.
