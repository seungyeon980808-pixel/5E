## 목표

문항은 엑셀과 같은 데이터 시트에서 관리한다. 선택한 문항은 실제 시험지 규격으로 렌더링하고, 글·표·그림의 조판을 사용자가 만족할 때까지 편집한 후 한글로 전달한다. 한글에서 최종 서식을 처음 잡아야 하는 흐름은 목표에 맞지 않는다.

## 데이터 시트

- 항목은 행, 문항은 열이다. A열에 항목 이름을 고정하고 B열부터 문항을 나란히 관리한다.
- 기본 항목 순서는 문항유형, 대단원, 중단원, 소단원, 성취기준, 핵심개념, 문항관리번호, 발문, 자료, 사진, 지문, 선지, 보기이다.
- 핵심개념은 한 문항에 여러 개를 연결할 수 있다.
- 문항관리번호와 시험지에 인쇄하는 문항 번호를 구분한다.
- 선지·보기 등 여러 값을 가진 항목은 하위 행으로 펼쳐 입력할 수 있게 한다.
- 시트의 항목 순서는 관리 순서다. 시험지에 인쇄하는 구성 순서와 동일하게 강제하지 않는다.
- 평소에는 시트를 넓게 사용한다. 문항 머리글을 누르면 해당 문항의 미리보기를 연다.
- 셀 선택, F2/더블클릭 편집, 방향키 이동, Enter/Tab 확정, Esc 취소, 범위 복사·붙여넣기, 되돌리기 조작을 유지한다.
- 내려받은 XLSX도 세로 항목 구조를 제공한다. 표의 실제 셀, 그림 개체, 자료 연결, 조판 설정은 왕복 후에도 유지해야 한다.

## 문항 시작과 유형

처음에는 기출 문항 모양을 선택하고, 그 틀에 자료와 내용을 채운다. 선택 후에도 다음 세 요소를 독립적으로 변경할 수 있게 한다.

1. 자료 제시 방식: 일반 자료, 실험·탐구, 대화 등. 과정·결과·가설·결론과 같은 하위 구성을 포함한다.
2. 답 선택 방식: 정답형, 합답형, 서술형.
3. 선지 표현 방식: 글·수식, 보기 조합, 대응표, 그림·그래프.

사진·표는 개수뿐 아니라 상위 자료, 표시 순서, 나란히 배치, 글과의 어울림, 표 셀 안 배치까지 저장한다. ‘실험형’을 고른다는 이유로 항상 표와 그림을 강제로 하나씩 추가하지 않는다.

## 조판 편집

- 기본 시험지는 A4·2단이다. 다른 용지·단 설정도 선택할 수 있다.
- 기출 모양을 적용한 후 미리보기의 글·그림을 직접 선택해 수정한다.
- 글: 글꼴, 글자 크기, 자간, 장평, 줄 간격, 문단 간격, 정렬, 들여쓰기.
- 그림: 너비·높이, 비율 유지, 글자처럼 취급, 어울림, 정렬·위치, 글과의 상하좌우 간격.
- 표: 행 높이·열 너비, 병합, 셀 여백, 테두리, 셀 글의 정렬, 셀 안 그림.
- 보기·선지: 상자 여백과 제목, 번호 정렬, 가로·세로 배치, 항목 사이 간격. 사용자가 제공한 원본처럼 `<보 기>`를 상단 테두리 중앙에 배치하고 제목 자리에서 선을 끊는다. 가는 검은 테두리와 `ㄱ.·ㄴ.·ㄷ.` 표기, 기호 뒤 본문에 맞춘 내어쓰기를 기본으로 한다.
- 문항 단위 미리보기와 여러 문항을 배치한 시험지 전체 미리보기를 제공한다. 전체 미리보기에서 단·쪽 나눔과 자료 잘림을 확인한다.
- 공통 조판 설정을 다른 문항에 적용하되 개별 문항의 예외 설정을 보존한다.

## 한글 전달과 완료 조건

글·표·그림은 각각 편집 가능한 한글 요소로 유지한다. 문항 전체를 한 장의 그림으로 고정하는 것은 선택한 기본 방식이 아니다.

미리보기와 전달 결과는 동일한 조판 원본을 사용해야 한다. 화면용 HTML을 따로 배치한 뒤 한글로 보낼 때 다시 조판하는 방식만으로 완료라고 보고하지 않는다.

검수 항목은 내용·그림·표 구조 외에 글자 서식, 줄바꿈, 그림 크기·어울림·간격, 셀 크기·여백, 단·쪽 경계다. 저장한 HWP/HWPX를 다시 열어 확인한다. 글꼴 대체나 용지·단 너비 차이가 있으면 차이를 표시하고 완료 상태와 구분한다. 외부 한컴 한글의 실제 표시를 검수하지 않았다면 외부 한글에서도 완전히 동일하다고 보고하지 않는다.

자료나 글을 수정하면 기존 조판 확인 상태를 무효화한다. 이전 조판 초안은 보관하고 다시 확인해야 한다. 정답·해설 등 교사용 정보는 학생용 문항에 섞지 않는다.

## 현재 구현과 확인된 차이

- 항목은 행·문항은 열인 세로 시트와 같은 구조의 XLSX를 구현했다.
- 문항 머리글은 실제 RHWP 조판을 열며 저장한 HWPX 문항 범위를 네이티브로 시험지에 넣는다.
- 글·표·수식·그림의 내용과 조판 재열기 배치를 검수하며, 저장 파일의 배치가 달라지면 최종 모양을 다시 표시한다.
- 좁은 머리글의 단위 줄바꿈·행 높이·셀 여백을 반영하고 표의 불필요한 들여쓰기를 없앴다. 실험 상자의 각주 넘침과 중첩 셀의 글 겹침을 검사하며 문제가 있는 조판은 저장·전달하지 않는다.
- 그림 크기·어울림과 글자·문단 모양은 실제 문서 편집기에서 조절한다. 공통 서식의 여러 문항 일괄 적용은 아직 별도 기능으로 제공하지 않는다.
- HWP에서는 일부 표 다음 문단이 HWPX보다 약 4 px 이동하는 엔진 차이가 확인됐다. 차이가 있는 HWP 출력은 중단하고 HWPX를 안내한다.
- 보기 제목을 상단 선 중앙에 놓고 0.4pt 테두리, 150% 줄 간격과 실제 기호 너비에 맞춘 내어쓰기를 적용했다. 중첩 보기 셀도 글과 테두리를 편집 가능하게 유지하며 HWPX 재열기를 검수했다.
- 중첩 셀의 문단 서식을 직접 변경하는 문서 엔진 명령은 아직 제약이 있다. 기본 보기 내어쓰기는 HWPX 문단 서식으로 적용한다.
- 외부 한컴 한글 앱의 폰트 대체·줄바꿈 검수는 남아 있다.

## 남은 확인 사항

사용자는 LaTeX 또는 한글 수식 문법으로 입력하고 완성된 수식 모양을 확인하는 방식을 선택했다. 수식은 한글 수식 개체로 보관한다. 현재 구현은 `$...$`, `\(...\)`, `{{수식:...}}` 입력을 실제 문서 엔진의 수식 개체로 변환하며 분수·첨자를 검수했다. 행렬 등 복잡한 식의 범용 입력 품질은 개별 검수가 필요하다.
