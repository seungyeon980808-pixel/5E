# 5E v1.7.2 — 그림 생성 새 엔진 · 2027 수능 기출

> **초안·출시 전** — 아직 내놓지 않은 판의 노트입니다. 내용과 숫자는 출시 직전에 다시 확인합니다.

**AI 이미지 생성이 기출 그림을 보고 그리는 새 엔진으로 바뀌었습니다.**

설명을 넣으면 비슷한 평가원·학평 기출 그림 3장을 찾아 참고하고, 흑백 시험지 선화로 그린 뒤, 그림 안에 남은 설명 문장을 지워서 돌려줍니다. 무엇이 고장 나도 「실패」로 끝나지 않고 다음 길로 이어 가도록 다졌습니다. 라이브러리에는 2027학년도 수능 과학탐구 8과목이 들어왔습니다.

[웹에서 시작하기](https://www.5e.ai.kr/) · [README](../README.md) · [문제 신고](https://www.5e.ai.kr/bug/)

## 하이라이트

- **그림 생성 새 엔진** — 요청을 장면으로 풀고 → 비슷한 기출 그림 3장을 찾아 → 그것을 참고해 그리고 → 그림 안 설명 문장을 지우고 → 흑백으로 맞춥니다. (가)(나)처럼 장면이 둘이면 그림도 두 장으로 나옵니다.
- **실패로 끝나지 않음** — AI가 늦거나 거절해도, 기출 그림 서버가 답하지 않아도, 다른 모델·다른 후보·참고 그림 없이 그리기·지금까지의 생성 방식 순서로 이어 가서 그림을 내놓습니다. 앞 결과와 입력은 지우지 않습니다.
- **막히면 할 일로 데려감** — 로그인이 안 돼 있으면 로그인 창을 띄우고, 로그인하면 같은 요청으로 이어서 만듭니다. 인터넷이 끊기면 그렇게 알려 주고, 다시 연결되면 이어서 만듭니다.
- **2027학년도 수능 기출** — 라이브러리 평가원에 2027학년도 대학수학능력시험 과학탐구 8과목(물리학Ⅰ·Ⅱ, 화학Ⅰ·Ⅱ, 생명과학Ⅰ·Ⅱ, 지구과학Ⅰ·Ⅱ) 160문항을 더했습니다. 검색·미리보기·변형(시험지에 넣기)이 다른 기출과 같게 됩니다.
- **그래프는 지금 그대로** — AI 그래프 생성은 지금처럼 「고칠 수 있는 그래프」입니다.
- **첫 화면은 그대로 빠름** — 새 엔진과 기출 그림 목록(약 7MB)은 처음 쓸 때만 불러옵니다. 시작 시간과 첫 화면은 1.7.1과 같습니다.

| | 1.7.1 | 1.7.2 |
|---|---|---|
| AI 이미지 생성 | 설명만 보고 그림 | 비슷한 기출 그림 3장을 참고해 그림 |
| 그림 안 설명 문장 | 남을 수 있음 | 그린 뒤 지움 |
| 생성 중 고장 | 「변환에 실패했습니다」로 끝날 수 있음 | 다음 길로 이어서 그림을 냄 |
| 로그인 없음·인터넷 끊김 | 오류로 끝남 | 로그인 창으로 / 연결되면 이어서 |
| AI 그래프 생성 | 고칠 수 있는 그래프 | 같음 |
| 라이브러리 평가원 수능 | 2026학년도까지 | 2027학년도 과탐 8과목 더함 |

## 그림 생성

**AI 이미지 → 생성**에서 설명으로 그림을 만들 때 새 엔진이 돕니다(설치판).

1. 요청을 장면으로 풉니다. (가)(나)처럼 장면이 나뉘면 장면마다 따로 그립니다.
2. 기출 그림 목록에서 비슷한 그림 3장을 고릅니다. 목록은 설치판 안에 들어 있고, 그림은 그림 서버에서 받습니다.
3. 고른 그림을 참고해 그립니다.
4. 그림 안에 들어간 설명 문장을 찾아 지웁니다.
5. 흑백 시험지 선화로 맞춥니다.

- 진행 중에는 지금 있는 진행 글이 「비슷한 기출 그림 3장을 찾고 있습니다」 「그림을 그리고 있습니다」처럼 단계마다 바뀝니다. 새 창은 없습니다.
- 결과는 지금과 같은 자리(결과 카드 → 캔버스 넣기·PNG·복사·한글로 보내기)에 들어갑니다. 캔버스에 넣은 그림은 어떤 기출을 참고했는지 함께 기억하고, 작업을 저장했다 다시 열어도 남습니다.
- 레퍼런스 그림을 직접 넣은 생성은 넣은 그림을 그대로 쓰는 지금 방식으로 만듭니다.
- 웹에서는 지금 생성 방식 그대로입니다. 새 엔진은 설치판에서 먼저 씁니다.

## 실패로 끝나지 않게

새 엔진이 어디서 막혀도 다음 길로 넘어갑니다.

| 이런 때 | 이렇게 이어 갑니다 |
|---|---|
| AI가 늦거나 잠깐 거절함 | 다시 시도 → 다른 모델로 → 그래도 안 되면 지금까지의 생성 방식으로 |
| AI가 4분 동안 답이 없음 | 그 차례를 끊고 다른 모델로(끝없이 기다리지 않음) |
| 비슷한 기출을 고르는 AI가 실패함 | 요청 낱말로 대강 분류해 참고 그림을 고름 |
| 기출 그림 서버가 답하지 않거나 그림이 너무 큼 | 그 그림만 건너뛰고 다른 후보로, 없으면 참고 그림 없이 그림 |
| 로그인이 없거나 도중에 끊김 | AI를 더 부르지 않고 로그인 창을 띄움 → 로그인하면 같은 요청으로 이어서 |
| 인터넷이 끊김 | 「인터넷 연결을 확인해 주세요」 → 연결되면 한 번 이어서 |
| 새 엔진 파일을 받지 못함 | 이번에는 지금 생성 방식으로, 다음번에는 다시 받아 새 엔진으로 |
| 취소 | 그 차례만 멈춤. 다음 생성은 새로 시작 |

## 그래프

- **AI 그래프 → 대화로 만들기**는 지금 그대로 「고칠 수 있는 그래프」를 만듭니다. 바뀐 것이 없습니다.

## 라이브러리

- **평가원 → 2027학년도 대학수학능력시험**에 과학탐구 8과목 160문항을 더했습니다. 과목·단원 이름표로 찾을 수 있고, 미리보기·형광 표시·변형(시험지에 넣기)이 다른 기출과 같게 됩니다.
- 2027 수능 문항의 단원 이름표는 문항 내용으로 자동으로 붙였습니다. 어긋난 곳은 [문제 신고](https://www.5e.ai.kr/bug/)로 알려 주세요.

## 고친 것

- 5E_exam 문항 카드: 자료 칸 둘 중 앞 칸을 지우면 남은 칸이 「(나)」로 남던 것 — 이제 (가)로 다시 매깁니다.
- Windows 설치판
  - 5E가 이미 떠 있을 때 `.5e`를 두 번 누르면 다른 폴더 기준으로 파일을 찾던 것. 대소문자만 다른 같은 파일은 한 번만 엽니다.
  - OneDrive·백신이 파일을 잡고 있으면 출제 자동 저장이 실패하던 것 — 잠깐 기다렸다 다시 저장합니다.
  - Windows에서 만든 ZIP으로 기호 팔레트를 가져오면 폴더 구분을 잘못 읽던 것.
- 참고 기출 그림은 크기·종류를 확인한 뒤에만 씁니다.
- 함께 든 소프트웨어(수식 글꼴 등)의 라이선스 고지를 채웠습니다.

## 설치

<!-- 출시 직전 실제 파일 이름으로 확인할 것 -->
| | 파일 |
|---|---|
| Windows | `5E-1.7.2-windows-x64.exe` |
| Mac · 애플 실리콘 | `5E-1.7.2-macos-arm64.dmg` (또는 `.zip`) |
| Mac · 인텔 | `5E-1.7.2-macos-x64.dmg` (또는 `.zip`) |

설치 파일은 아직 정식 코드 서명·공증을 받지 않았습니다.
- Windows: 「PC 보호」 창이 뜨면 **추가 정보 → 실행**.
- Mac: 처음 열 때 「Apple이 확인할 수 없습니다」가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 맨 아래 **그래도 열기**를 누릅니다.

내려받은 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다. 설치판의 사용자 자료 폴더는 1.7.1과 같아서, 덮어 설치해도 작업이 그대로 남습니다.

## 알아 두실 것

- 새 그림 엔진은 설치판에서 됩니다. 웹은 지금 생성 방식 그대로입니다.
- 참고할 기출 그림은 그림 서버에서 받으므로 인터넷이 필요합니다. 받지 못하면 참고 그림 없이 그립니다.
- 새 엔진은 그림 한 장에 1~2분쯤 걸리고(참고 그림 찾기와 설명 지우기가 더해짐), AI를 여러 번 부르므로 이용 한도를 조금 더 씁니다.
- AI 기능은 로그인한 ChatGPT 계정의 기능과 이용 한도 안에서 실행됩니다.
- 넓은 화면(PC) 기준입니다. 좁은 화면과 모바일은 다음 버전에서 다룹니다.

## 검사

<!-- 출시 직전 전체 화면 검사 결과로 아래 줄을 확인해 고칠 것 -->

- 새 엔진과 기출 그림 목록·수식 글꼴이 첫 화면에 실리지 않는지 지키는 검사를 더했습니다.
