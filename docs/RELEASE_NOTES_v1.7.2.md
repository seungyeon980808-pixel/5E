# 5E v1.7.2 — 말로 그리는 새 그림 엔진 · 2027 수능 기출

> **초안·출시 전** — 아직 내놓지 않은 판의 노트입니다. 내용과 숫자는 출시 직전에 다시 확인합니다.

**AI 이미지가 「말로 그리는」 새 엔진으로 바뀌었습니다.**

AI와 대화로 그림 구성을 정한 뒤 「이대로 그리기」를 누르면, 비슷한 평가원·학평 기출 그림 3장을 찾아 참고해 흑백 시험지 그림으로 그립니다. 그린 그림은 말로 고치고, 글자를 편집할 수 있는 라벨로 살릴 수 있습니다. 교과서 그림 변환은 원본과 대조해 빠진 곳이 적은 쪽을 고르고, 무엇이 고장 나도 「실패」로 끝나지 않게 다졌습니다. 라이브러리에는 2027학년도 수능 과학탐구 8과목이 들어왔습니다.

[웹에서 시작하기](https://www.5e.ai.kr/) · [README](https://github.com/seungyeon980808-pixel/5E#readme) · [둘러보기](https://www.5e.ai.kr/page) · [문제 신고](https://www.5e.ai.kr/bug/)

## 하이라이트

- **말로 그리기** — 대화로 무엇을 그릴지 정하고 「이대로 그리기」. 비슷한 기출 그림 3장을 참고해 흑백 시험지 선화로 그립니다.
- **말로 고치기** — 결과를 보고 「이 그림 고치기」로 고칠 곳만 말하면 그 부분만 고쳐 다시 그립니다.
- **라벨 살리기** — 그림 안 글자를 편집할 수 있는 5E 라벨로 바꿉니다. 지시선이 그림과 겹쳐 깨끗이 지워지지 않으면 저절로 다시 그려 정리합니다.
- **평가원 글자 표기** — 수치와 단위는 바로 선 글자로 붙여 쓰고(3m, 60kg, 30°), 물리량 기호는 기울여 씁니다(*m*, *v*, *θ*). 아래 첨자는 바로 선 글자입니다.
- **교과서 그림 변환이 더 정확해짐** — 지울 것(글자·지시선·확대 표시)과 남길 것(구획·화살표·과학 관계)을 구체적으로 지시하고, 두 장을 그려 원본과 대조해 더 맞는 쪽을 고릅니다. 끝내 다른 곳은 「원본과 다를 수 있는 곳」으로 알려 줍니다.
- **AI 연결을 한눈에** — 오른쪽 위 「AI」를 누르면 계정·남은 한도·로그인·로그아웃을 보는 작은 카드가 뜹니다. Codex가 없으면 설치 안내로 데려갑니다.
- **2027학년도 수능 기출** — 라이브러리 평가원에 과학탐구 8과목 160문항을 더했습니다.

| | 1.7.1 | 1.7.2 |
|---|---|---|
| AI 이미지 생성 | 설명 한 줄로 바로 그림 | 대화로 구성을 정하고 기출 3장을 참고해 그림 |
| 그린 뒤 고치기 | 처음부터 다시 | 「이 그림 고치기」로 말한 곳만 |
| 그림 속 글자 | 기울임·띄어쓰기가 들쭉날쭉 | 평가원 표기(수치+단위 바로 선 글자·붙여 씀) |
| 교과서 그림 변환 | 한 장 그림 | 두 장 그려 원본과 대조해 고름 |
| 생성 중 고장 | 「실패」로 끝날 수 있음 | 다음 길로 이어서 그림을 냄 |
| 로그인 | 들어갈 길이 없었음 | 「AI」 카드 → GPT 로그인 |
| 라이브러리 평가원 수능 | 2026학년도까지 | 2027학년도 과탐 8과목 더함 |

## 그림 생성 (AI 이미지 → 생성)

1. 아래 입력칸에 그리고 싶은 것을 쓰고 Enter로 대화합니다. AI가 그림 구성을 정리해 줍니다.
2. 「이대로 그리기」(⌘Enter / Ctrl+Enter)를 누르면 그립니다. 대화 없이 바로 그려도 됩니다.
3. 엔진은 요청을 장면으로 풀고 → 비슷한 기출 그림 3장을 고르고 → 참고해 그리고 → 흑백으로 맞춥니다.

- AI가 답을 쓰는 동안에는 점과 「생각하는 중 → 그림 구성을 짜는 중」 같은 단계 글, 흐른 시간이 보입니다.
- 결과 카드에서 **이 그림 고치기 · 확정하고 라벨 살리기 · 라벨 빼기 · 선 진하게 · 각도 바꾸기 · 새로 그리기**를 고를 수 있습니다.
- 그림 안에 (가)(나)(다) 같은 패널 이름은 그리지 않습니다(문항에서 붙임).
- 그리는 중에는 「그리기 멈추기」, 작업 목록에서는 「멈추고 삭제」로 언제든 끝낼 수 있습니다. 같은 작업을 여러 번 고치다 먹통이 되던 것을 고쳤습니다.
- 결과를 보고 나갔다 들어와도, 손대지 않은 보기 설정(나란히 보기 등)은 바뀌지 않습니다.
- 그림 한 장은 보통 40초~1분 30초 걸립니다.

## 이미지 변환 (교과서·기출 그림)

- **교과서 그림**: 글자·지시선·괄호선·확대 표시 원과 잇는 선·말풍선·안내 캐릭터는 지우고, 물체 안 구획·흐름 화살표·치수선·과학 관계는 남깁니다. 같은 요청으로 두 장을 함께 그려 원본에서 뽑은 「지켜야 할 목록」과 대조해 더 맞는 쪽을 고릅니다. 시간은 한 장과 거의 같고, AI 이용 한도는 조금 더 씁니다.
- 두 장 모두 원본과 다른 곳이 남으면 결과를 쓰게 두고 「원본과 다를 수 있는 곳」을 대화 기록에 적어 둡니다.
- **기출 그림**: 지금처럼 한 장을 그립니다.
- 그리기 시작할 때 예전 진행 상자가 잠깐 비치던 것을 없앴습니다.

## 라벨 살리기

- 그림 속 글자를 읽어 편집할 수 있는 라벨로 올리고, 그림의 글자와 지시선을 지웁니다.
- 지시선이 그림과 겹쳐 깨끗이 지우지 못하면 「30~40초쯤 더 걸려요」 안내와 함께 지시선만 지운 그림을 다시 그려 씁니다. 다른 일을 하고 있으면 끝났을 때 작업 목록에 「새 결과」로 알립니다.
- 수치+단위는 붙여 쓰고(2 m → 2m), 바로 선 글자로 맞춥니다.

## AI 연결 (설치판)

- 오른쪽 위 **「AI」** 점: 초록 = 연결됨, 빈 점 = 로그인 필요, 노랑 = Codex 없음.
- 누르면 작은 카드가 뜹니다.
  - 연결됨: 계정·요금제·5시간/이번 주 남은 한도, 「다른 계정으로 로그인」, 「로그아웃」(한 번 확인).
  - 로그인 필요: 「GPT 로그인」 → 브라우저에서 ChatGPT 계정으로 로그인하면 돌아와 바로 이어서 씁니다. 기다리는 동안 「브라우저 창 다시 열기」「취소」.
  - Codex 없음: 「Codex 설치 페이지 열기」, 「설치했어요 · 다시 찾기」.
- 로그인이 필요한 기능을 쓰면 같은 로그인 창을 띄우고, 로그인하면 하던 일을 이어 갑니다.
- Mac에서 Finder로 열면 Codex를 찾지 못하던 것을 고쳤습니다(설치 위치를 직접 찾음).

## 라이브러리 · 시험지

- **평가원 → 2027학년도 대학수학능력시험**에 과학탐구 8과목(물리학Ⅰ·Ⅱ, 화학Ⅰ·Ⅱ, 생명과학Ⅰ·Ⅱ, 지구과학Ⅰ·Ⅱ) 160문항을 더했습니다. 검색·미리보기·형광 표시·변형(시험지에 넣기)이 다른 기출과 같게 됩니다. 단원 이름표는 문항 내용으로 자동으로 붙였습니다.
- 기출 정답을 문항과 나눠 두고 정답 선지를 형광으로 표시합니다(화면 표시만, 내보내기에는 안 들어감).
- 시험지 한 회를 통째로 볼 수 있습니다.
- 조판 편집 잠금은 사용자가 고친 것이 있을 때만 걸립니다.

## 그래프

- 글자 칸을 끌 때 틀이 어긋나던 결함을 고쳤습니다.
- AI 그래프 생성은 지금처럼 「고칠 수 있는 그래프」입니다.

## 그 밖에 고친 것

- 시작 화면: 큰 「5E」가 선으로 그려지는 효과, 한 줄 소개 「과학 평가문항 제작 플랫폼」.
- 그림 AI가 가끔 바탕이 투명한 그림을 주어 어두운 화면·한글에서 검게 보이던 것 — 흰 바탕으로 맞춥니다.
- 5E_exam 문항 카드: 자료 칸 둘 중 앞 칸을 지우면 남은 칸이 「(나)」로 남던 것 — (가)로 다시 매깁니다.
- Windows 설치판: 이미 떠 있을 때 `.5e`를 두 번 누르면 다른 폴더 기준으로 찾던 것, OneDrive·백신이 파일을 잡고 있으면 자동 저장이 실패하던 것, Windows ZIP의 폴더 구분을 잘못 읽던 것.
- 옛한글 글꼴을 바꾸고 함께 든 소프트웨어(글꼴·수식 글꼴 등)의 라이선스 고지를 채웠습니다.

## 설치

<!-- 출시 직전 실제 파일 이름으로 확인할 것 -->
| | 파일 |
|---|---|
| Windows | `5E-1.7.2-windows-x64.exe` |
| Mac · 애플 실리콘 | `5E-1.7.2-macos-arm64.dmg` (또는 `.zip`) |
| Mac · 인텔 | `5E-1.7.2-macos-x64.dmg` (또는 `.zip`) |

설치 파일은 아직 정식 코드 서명·공증을 받지 않았습니다.
- Windows: 「PC 보호」 창이 뜨면 **추가 정보 → 실행**.
- Mac: 처음 열 때 「Apple이 확인할 수 없습니다」가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 맨 아래 **그래도 열기**를 누릅니다.

AI 기능을 쓰려면 OpenAI Codex가 설치되어 있어야 합니다. 없으면 오른쪽 위 「AI」 카드가 설치 페이지로 안내합니다.

내려받은 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다. 설치판의 사용자 자료 폴더는 1.7.1과 같아서, 덮어 설치해도 작업이 그대로 남습니다.

## 알아 두실 것

- 새 그림 엔진은 설치판에서 됩니다. 웹은 지금 생성 방식 그대로입니다.
- 참고할 기출 그림은 그림 서버에서 받으므로 인터넷이 필요합니다. 받지 못하면 참고 그림 없이 그립니다.
- AI 기능은 로그인한 ChatGPT 계정의 기능과 이용 한도 안에서 실행됩니다. 교과서 변환은 두 장을 그리므로 한도를 조금 더 씁니다.
- 넓은 화면(PC) 기준입니다. 좁은 화면과 모바일은 다음 버전에서 다룹니다.
