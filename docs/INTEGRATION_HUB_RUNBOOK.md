# 통합 허브 실행 및 확인

2026-09-12 통합 작업 브랜치는 `codex/integration-hub`입니다. 원본 작업 폴더와 main은 그대로 보존합니다. 이 문서는 로컬 통합 후보의 실행 방법이며 배포 또는 설치 완료를 뜻하지 않습니다.

## 실행 코드 확인

통합 허브 폴더 `5E-integration-hub`에서 다음을 확인합니다.

```sh
git branch --show-current
git rev-parse HEAD
```

첫 출력은 `codex/integration-hub`여야 합니다. 최종 커밋과 검사 결과는 함께 제공되는 통합 보고서에 기록합니다.

## Mac / Windows 데스크톱

의존성이 준비된 허브 폴더에서 실행합니다.

```sh
npm run desktop
```

현재 설치된 다른 5E 앱 대신 위 명령으로 시작해야 허브의 코드를 실행합니다. Windows 설치 파일 생성 명령은 `npm run package:win`, Mac은 `npm run package:mac`입니다. 두 명령은 `FIVE_E_PDF_PACK_SOURCE`에 지정한 최근 3개 학년도 자료팩의 해시를 먼저 검증하고 앱 리소스에 포함합니다. 자료팩이 없거나 해시가 다르면 패키징을 중단합니다. 이번 통합 작업은 패키지 배포·설치를 수행하지 않습니다.

개발 앱에서 자료팩까지 확인하려면 `FIVE_E_BUNDLED_PDF_PACK_SOURCE`를 자료팩 폴더로 지정하고 `npm run desktop`을 실행합니다. 이번에 검증한 로컬 원본 위치는 통합 보고서에 기록합니다. 배포 파일은 이 개인 경로를 사용하지 않고 앱 내부 리소스를 읽습니다.

## 브라우저 편집기

```sh
python3 -m http.server 19440 --bind 127.0.0.1
```

Windows에서는 Python 환경에 따라 `py -m http.server 19440 --bind 127.0.0.1`을 사용할 수 있습니다. 브라우저에서 `http://127.0.0.1:19440/`을 엽니다. 반드시 허브 폴더에서 서버를 실행합니다. 정적 편집기의 AI 기능은 데스크톱 안내를 표시하며, 인증 웹 실험의 실행 방법은 `experiments/web-codex-auth/README.md`를 따릅니다.

## 확인할 동작

- AI 작업실에서 이미지를 넣기 전에도 선 굵기 원본 / +1px / +2px를 선택할 수 있습니다.
- 이미지 하나는 작업 하나에 대응합니다. 미완 작업을 다시 열면 입력과 결과를 복구하며, 중단된 생성 요청은 자동 재전송하지 않습니다. 표시된 재시도로 이어갑니다.
- 여러 작업의 결과를 한 폴더에 저장합니다. 기본은 작업별 선택 결과이며 전체 버전도 선택할 수 있습니다. 같은 이름은 번호를 붙여 보존합니다. 폴더 API가 없는 브라우저는 ZIP 다운로드를 요청하며 실제 다운로드 완료는 브라우저에서 확인합니다.
- 배경·색상·선 굵기는 미리보기와 저장·삽입·모아 저장에 같은 처리 규칙을 적용합니다.
- 설치 안내 전에 직접 파일 쓰기가 완료되어야 합니다. 다운로드 방식이면 파일 존재를 확인한 뒤 계속 진행하며 취소하면 편집기를 유지합니다.
- 라이브러리에 기출 예시 7개가 기본 포함됩니다. 과목·연도 정보를 유지하며 다운로드용 앱에는 검증된 최근 3개 학년도 72개 PDF·288쪽 자료팩을 별도 앱 리소스로 포함하는 경로를 제공합니다. 모든 연도의 기출을 포함한다는 의미는 아닙니다.
