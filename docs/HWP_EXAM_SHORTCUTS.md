# 시험지 편집 단축키

2026-10-13 · 사용자가 승인한 추천 묶음: 글자·문단 서식 및 표 편집.

한컴 한글의 Windows 키 조합을 기준으로 현재 시험지 편집 영역에 연결했다. 기존 네이티브 서식·검색·삽입 기능과 실행 취소를 사용하며, 그림 편집기나 팔레트 설정 입력창에는 적용하지 않는다.

| 기능 | 키 |
| --- | --- |
| 모양 복사·적용 | Alt+C — 원본에서 복사한 뒤 대상 글자/셀을 선택하여 다시 입력 |
| 자간 줄이기 / 늘리기 | Alt+Shift+N / W |
| 장평 줄이기 / 늘리기 | Alt+Shift+J / K |
| 글씨 크게 / 작게 | Alt+Shift+E / R |
| 굵게 / 밑줄 / 기울임 | Ctrl+B / U / I |
| 위 첨자 / 아래 첨자 | Alt+Shift+P / S |
| 글자 모양 / 문단 모양 | Alt+L / T |
| 줄 간격 줄이기 / 늘리기 | Alt+Shift+A / Z |
| 왼쪽 / 가운데 / 오른쪽 / 양쪽 정렬 | Ctrl+Shift+L / C / R / M |
| 빠른 내어쓰기 | 본문 Shift+Tab, 표 셀 안 Ctrl+Shift+Tab |
| 첫 줄 들여쓰기 / 내어쓰기 (한 글자) | Ctrl+F6 / Ctrl+F5, Ctrl+Shift+I / O |
| 왼쪽 여백 늘이기 / 줄이기 (1pt) | Ctrl+Alt+F6 / F5, Ctrl+Shift+G / E |
| 오른쪽 여백 늘이기 / 줄이기 (1pt) | Ctrl+Alt+F7 / F8, Ctrl+Shift+D / F |
| 양쪽 여백 늘이기 / 줄이기 (1pt) | Ctrl+F8 / F7 |
| 한 수준 증가 / 감소 (개요·문단 번호) | Ctrl+숫자패드 − / + |
| 강제 줄바꿈 / 본문 쪽 나누기 | Shift+Enter / Ctrl+Enter |
| 문자표 / 찾아 바꾸기 | Ctrl+F10 / Ctrl+H |
| 표 / 수식 / 그림 삽입 | Ctrl+N → T / M / I |
| 셀 선택 / 범위 확장 | 표 안 F5 / Shift+F5 |
| 다음 셀 / 이전 셀 | Tab / Shift+Tab |
| 행 추가 / 삭제 | 표 안 Ctrl+Enter / Ctrl+Backspace |
| 셀 합치기 / 나누기 | 셀 선택 후 M / S |
| 셀 높이 / 너비 맞추기 | 여러 셀 선택 후 H / W |
| 선택한 셀 크기 | 셀 선택 후 Shift+방향키 |
| 줄·칸 전체 크기 | 셀 선택 후 Ctrl+방향키 |
| 표 크기를 유지하며 줄·칸 크기 | 셀 선택 후 Alt+방향키 |
| 표 빠져나오기 | Shift+Esc |

`Ctrl+N → T`는 Ctrl+N을 누르고 손을 뗀 뒤 2초 이내에 T를 누른다. Esc, 포커스 이동, 한글 조합 시작, 문서 교체로 대기가 취소된다. 수식과 그림에는 Ctrl+Alt+M / I도 제공한다. 기존 Ctrl+1~9 팔레트 실행은 유지한다.

Mac에서 Alt는 Option이며, 한글 고유 조합은 Control로 입력한다. 굵게·밑줄·기울임 등은 Command도 지원한다. 문자표에는 Option+F10이라는 기존 대체 키도 있으며, 키보드 설정에 따라 Fn이 필요하다. Command+N처럼 브라우저가 처리하는 조합에는 Control 조합을 사용한다.

표 크기 유지 조절은 선택 범위 바깥의 인접 줄·칸으로 크기를 보상한다. 이웃이 없거나 최소 크기를 넘는 축소, 보호된 셀을 포함한 변경은 전체 작업을 차단한다. 병합 셀의 줄·칸 수를 반영하여 크기를 계산한다. 기존 셀 내부 커서에서 Ctrl+방향키로 해당 셀을 조절하는 기능도 유지한다.

## 문단 들여쓰기·여백 (2026-10-14)

[한컴 한글 단축키 일람](https://help.hancom.com/hoffice130/ko-KR/Hwp/view/toolbar/shortcut%28table%29.htm)의 문단 속성 단축키를 추가했다. 단계 크기는 한컴 도움말 설명을 따른다: 첫 줄 들여쓰기·내어쓰기는 커서 위치 글자 크기만큼(한 글자), 여백은 1pt씩 바뀐다. 누를 때마다 누적되며, 여백은 0pt 아래로 줄이지 않는다. 본문·표 셀·머리말/꼬리말·각주에서 사용하며 실행 취소 한 번으로 되돌린다. 여러 문단을 선택하면 한글처럼 문단마다 자기 값에서 늘거나 줄어들고, 선택은 유지되어 연달아 누를 수 있다.

- 한 수준 증가·감소는 문단 번호·글머리표 문단에서 수준 번호(1~7수준)를 바꾸고, 개요 문단에서는 기존 개요 스타일 명령을 사용한다. 둘 다 아닌 문단에서는 안내만 표시한다.
- Mac에서는 Control 조합으로 입력한다. macOS 기본 설정에서 Control+F5~F8은 시스템의 키보드 탐색 단축키로 쓰일 수 있으므로 Control+Shift+I/O/G/E/D/F 대체 키를 사용한다. Command+Shift 조합은 브라우저에 그대로 둔다. 숫자 키패드가 없는 키보드에서는 수준 단축키 대신 도구 모음의 수준 버튼을 사용한다.
- Chromium/WebKit에서 실제 키 입력으로 각 단축키의 값 변화, 실행 취소·다시 실행, 0pt 여백 유지, 표 셀 첫 줄 들여쓰기, 문단 번호 수준 변경을 검증했다.

## 검증

- Chromium 및 WebKit에서 실제 키 입력으로 자간·장평·글씨 크기·굵게·밑줄·기울임·첨자·문단 정렬·줄 간격의 값 변경과 실행 취소/다시 실행을 확인했다.
- Alt+C 모양 복사, 커서만 있는 글자 모양 대화상자, 본문/셀 내어쓰기, 강제 줄바꿈, 쪽 나누기, 문자표, 찾아 바꾸기, 두 단계 표·수식·그림 삽입을 확인했다.
- 표 셀 이동·선택·범위 확장·행 추가/삭제·합치기/나누기·높이/너비 맞춤·세 가지 크기 조절·표 탈출을 확인했다. 실제 HWP/HWPX 파일을 호스트 파일 메뉴로 다시 열어 크기 유지도 확인했다.
- 보호 셀, 한글 IME의 조합 중 단축키 및 셀 블록 H/W의 조합 문자 잔류, 문서 이름 입력창, Esc 대기 취소를 확인했다.
- 전체 단위 검사 1,379개 통과, 실패 0개, 기존 제외 1개. 기존 입력·Esc·셀 크기·팔레트 기능 회귀 검사 및 루트/preview 리소스 검사 통과.

기준: [한컴 한글 공식 단축키 일람](https://help.hancom.com/hoffice130/ko-KR/Hwp/view/toolbar/shortcut%28table%29.htm). 구현은 고정된 RHWP Studio 엔진의 기능 범위를 따른다.
