# 5E 조판 팔레트

사용자는 기출·교과서 자료에서 그림과 문항 내용을 준비하고 한글 시험지로 편집하는 과학교사다. 별도 hwpPalette에서 하던 문항 조판을 5E의 rhwp 작업 공간으로 옮겨, 그림 편집·조각 채우기·문서 편집을 이어서 수행하는 것이 이 기능의 목적이다.

사용자가 지정한 기준은 5E `b2f85a00`이며 기존 작업을 보호하기 위해 독립 Git 브랜치와 워크트리를 사용한다. 원본 hwpPalette의 동작과 데이터 형식을 확인하고 기존 문항·조각을 재사용해야 한다. ExamPool의 교육과정·성취기준 검토 및 기출 검색 연결은 이번 이식 다음 단계의 목적이며, 이 팔레트가 문항 내용의 타당성을 자동으로 보증하지는 않는다.

핵심 작업은 문항 틀 선택과 빈칸 채우기, 마크다운·엑셀에서 한글 문단·표 생성, 사진·기호·서식 삽입, 문서 조각 저장과 재사용이다. 성공 조건은 편집 가능한 HWP/HWPX 결과, 기존 5E 그림 작업 복귀, 저장 후 재열기, 조판 오류와 실행 취소에서 원본 문서 보존이다.

이 화면은 기존 5E 작업 공간의 확장이다. 새로운 브랜드나 레이아웃 세계를 선택하는 작업이 아니다. 왼쪽 232px 도구 영역과 기존 밝음/어둠 테마, 파란 동작 색, 시스템 한글 UI 글꼴을 따른다. 팔레트를 즉시 사용할 수 있게 두고, 물감 관리 내용은 오른쪽 창고에서 찾는다. 작은 화면의 창고는 전체 화면으로 전환한다. 본문을 가리는 새 하단 행은 만들지 않으며 변경 알림은 기존 푸터의 작은 배지를 사용한다.

현재 엔진의 지원 범위와 검증 자료는 `../HWPPALETTE_RHWP_PORT.md`에 기록한다. 원본 기능과 완전히 동일하게 처리할 수 없는 편집 위치를 성공으로 표시해서는 안 된다.
