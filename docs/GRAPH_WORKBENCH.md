# 그래프 복원 작업대

AI 변환 작업대의 `이미지 변환 / 그래프 복원` 탭을 사용한다. 중복 진입점인 고급 도구의 `원본 그래프 가져오기` 버튼은 제거했다. 그래프의 결과는 `coordplane`과 `funcgraph`로 구성한 5E 편집 객체다.

그래프 편집의 표시·영역 항목은 작은 선택 목록으로 표시하며, 선택한 항목의 설정만 펼친다. 같은 항목을 다시 누르면 접힌다. 강조 영역은 미리보기의 손잡이로 조절하고 정밀 좌표는 별도 펼침 안에 둔다. 복원 그래프의 화살표 여백·격자 돌출도 기존 고급 옵션으로 조절한다. 서로 연결된 격자 형태의 보조선만 돌출 조절에 함께 반응하며, 개별 투영선·글자·곡선 기준점은 유지한다. 축 전체 폭이 간격으로 저장된 옛 복원 파일에는 눈금에서 추정한 편집 간격을 표시하지만, 수정 없이 적용하면 저장된 객체를 변경하지 않는다.

## 사용자 흐름

1. 라이브러리에서 원본을 선택하고 AI 변환으로 보내면서 `그래프 복원`을 선택한다. AI 변환 작업대의 `그래프 복원` 탭에서 파일, 드래그, 붙여넣기로 원본을 추가할 수도 있다.
2. 복원하기를 누른다. 모델은 `gpt-6.1-sol`, 추론은 `medium`으로 고정한다. 해당 모델·추론을 공급자 목록에서 확인하지 못하면 실행을 중단하며 다른 모델로 대체하지 않는다.
3. 기존 원본·수정본·나란히·겹쳐 비교 화면에서 확인한다. 겹쳐 비교의 경계를 좌우로 드래그하고, 두 그림을 함께 확대·이동할 수 있다.
4. 결과를 더블클릭하거나 `그래프 세부 편집`을 눌러 기존 그래프 편집기에서 축, 눈금, 곡선, 점, 보조선, 표기, 영역 등을 수정한다. 취소하면 페이지와 결과는 변경되지 않는다. 적용 시 결과 저장을 확인한다.
5. 코멘트 또는 대화로 요청을 정리하고 다시 복원하면 새 버전으로 남긴다. 원본과 현재 편집 결과를 별도 이미지로 전달한다. 표현 참고는 데이터·좌표 원본과 구분해서 전달한다.
6. `캔버스에 삽입`은 그래프 객체를 넣는다. 이후 기존 그래프 편집, 이동, 실행 취소·다시 실행, 5E 문서 저장을 사용한다. 결과 파일 저장은 SVG이며 일괄 결과 저장에도 같은 SVG를 제공한다.

작업 이력, 선택 버전, 코멘트, 복구, 취소, 재시도 및 여러 작업 선택 후 실행은 기존 작업대의 상태 관리와 대기열을 사용한다. 결과가 있는 작업에서 변환 종류를 바꾸면 원본을 복사한 새 작업을 만들어 기존 결과를 보존한다.

2026-10-08 진입점 정리: 중복 버튼 생성과 `main.js`의 초기화 연결을 제거했다. 제품 진입은 기존 AI 변환과 라이브러리 전송을 사용한다. 작업대 회귀 검사는 공통 AI 변환 버튼과 그래프 복원 탭으로 진입하도록 변경했다. 라이브러리 전송 11개, Chromium·WebKit의 작업대 및 안정성 검사가 통과했다. 합성 공급자 응답을 사용했으며 신규 실제 AI 호출은 0회다. 증거는 `.omo/evidence/graph-unified-entry-20261008/`에 보존한다.

## 라이브러리 목적 선택과 로컬 실사용 연결 (2026-10-06)

라이브러리 작업대 배정은 한 장도 `이미지 변환` 또는 `그래프 복원`을 명시적으로 선택하고 보내며, 고른 목적을 각 독립 작업에 전달한다. 기존 PDF·부품 라이브러리 경로도 같은 선택으로 연결한다. 현재 작업에 참고를 추가하는 경로는 기존 작업 종류를 유지한다. 종류가 없는 외부 전송은 이미지 변환으로 초기화하며 현재 선택된 작업 종류를 상속하지 않는다.

작업 목록의 각 행에는 종류를 표시하고 공유 목록과 임시저장·복구에 보존한다. 원본이 들어 있는 작업에서 다른 종류로 전환하면 원본만 복사한 별도 작업을 만들고 원래 결과·대화는 기존 작업에 보존한다. 빈 작업은 목적을 지정해 재사용하므로 불필요한 빈 이웃 작업을 만들지 않는다.

새 작업의 기본 모델·추론은 Sol 6.1 / medium이다. 그래프 작업은 표시·저장·실제 요청 모두 이 설정으로 고정하고 설정 패널에 표시한다. 기존 이미지 작업의 명시적인 모델 선택은 유지한다. 공급자에 고정 모델이 없으면 경고를 표시하며 다른 모델로 몰래 대체하지 않는다.

Safari의 기존 연결 차단은 웹 런타임의 모델 목록에 Sol 6.1이 없어서 발생했다. 로컬 미리보기 서버는 `LOCAL_CODEX_BINARY`를 지정했을 때만 이 컴퓨터의 인증된 Codex App Server를 사용하는 선택적 개발 연결을 제공한다. 웹 배포 런타임을 업데이트하거나 로그인 정보를 복사한 것은 아니다. 로컬 개발 연결은 127.0.0.1에만 바인딩하고 Host·Origin·X-5E-Request 검사를 유지하며 브라우저 세션 토큰을 전송하지 않는다. 각 작업의 이벤트와 요청을 분리하고 중복 실행·자동 재시도를 차단한다. 그래프는 기존 도구 비활성화 JSON-scene 프로필을 사용한다.

Node 24.21.0 전체 단위 333/334 통과(기존 PNG 바이트 재현 실패 1개 유지). 라이브러리 전송 브라우저 11/11 통과, Chromium·WebKit 그래프 작업대 회귀 통과. 실제 Safari에서 기존 작업과 종류 표시·연결됨·고정 모델을 확인했다. 별도 새 브라우저에서 실제 로컬 HTTP→App Server 요청 1회로 Sol 6.1 / medium 적용, 그래프 결과 더블클릭 편집 및 coordplane/funcgraph 네이티브 삽입을 확인했다. 이 검증에서 이미지 생성 요청은 실행하지 않았다. 근거는 `.omo/evidence/graph-routing-20261006/`이다.
