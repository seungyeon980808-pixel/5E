# 단진자 원본 윤곽

2026학년도 6월 모평 물리학Ⅱ 8번의 PDF 내 삽화(xref 60, 638×987)를 기준으로 한다. 원본은 비트맵이므로 픽셀 셀의 경계를 합쳐 같은 회색값의 SVG 경로로 저장했다. 회색 평균화나 곡선 단순화는 적용하지 않는다.

`preview/js/pendulum-reference.js`는 추적 데이터, `preview/js/render/pendulum-source.js`는 실제 장치 렌더러다. 실행 중 원본 PNG나 외부 추적 라이브러리는 필요하지 않다. 고정부, 기둥 단면, 눈금판, 받침, 추와 기본 기호는 원본 윤곽을 사용한다. 길이와 각도를 바꾼 실·보조선은 겹친 다른 물체의 픽셀을 끌고 가지 않도록 독립된 선으로 표시한다.

## 좌표와 가림

- 원본 지지점 (378.12, 146), 받침 기준 (378.12, 899), 추 중심 (432, 744), 추 반지름 25.5 px.
- 원본 실은 추 중심과 미세하게 어긋난 부착점을 가진다. 위치 계산과 핸들 역변환에 같은 편심을 사용한다.
- 기준 점선은 불투명한 눈금판 뒤에, 실제 실은 눈금판 앞에 놓인다.
- 원본의 67.78/4.85/5.76은 자세를 맞추는 초기 그림 조건이다. 원문에 없는 물리량을 측정값으로 확정한 것이 아니다.
- 숨긴 기호가 고정부나 실 조각에 남지 않도록 각 요소의 가림과 경계에서 원래 겹친 픽셀을 분리한다.
- 실 길이를 늘려 기둥 밖으로 나가는 경우 내보내기 범위도 함께 늘린다. 반사된 기준 추의 중심과 점선 끝은 같은 좌표 모델을 사용한다.

## 검증과 한계

원본과 실제 장치 렌더러를 같은 원점·자세·638×987 크기에 정렬하고 흰 배경에서 비교한다. 비백색 영역은 회색값 245 미만, 차이 픽셀은 회색값 차이 16 초과로 정의한다. 고정부와 받침의 비교 영역은 픽셀 차이가 0이다. 전체 영역은 아직 100% 동일하지 않으므로 보고서의 실제 측정값을 사용한다.

실제 5E에서 추 위치와 크기 핸들, 되돌리기, 두 페이지 프로젝트 재열기, 작은 추·긴 실·음수 각도의 PNG 출력을 확인한다. OS 저장 대화상자의 동작까지 검증한 것으로 표현하지 않는다.

원본 및 산출물: 작업 루트의 `outputs/pendulum-source-trace-20261004/`. 재현 스크립트: `work/pendulum-source-trace-20261004/trace_parts.py`, `export.cjs`, `compare.py`. 원본 PDF는 `outputs/physics-three-year-review-20261003/pdf/p2_2026_06.pdf` 2쪽이다.

이 윤곽 추적은 현재 스탠드 단진자 한 종에 적용됐다. 다른 장치의 이전 근사 도형을 원본 추적 완료로 분류하지 않는다.
