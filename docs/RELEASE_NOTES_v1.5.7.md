# v1.5.7 — PDF 교과서 검색·크롭 및 AI 그래프 통합

웹앱과 Windows 데스크톱 앱이 동일한 코드 기준으로 동작하도록 통합하고, 데스크톱에서 로컬 교과서 PDF를 텍스트로 검색해 필요한 장면을 AI 편집으로 넘기는 흐름을 추가했습니다.

## 주요 변경 사항

- 로컬 폴더의 PDF 본문을 페이지 단위로 인식하고 검색어 유사도 순으로 정렬
- 왼쪽의 큰 PDF 페이지 화면과 오른쪽의 텍스트 검색 결과 목록으로 작업 공간 재구성
- 선택한 페이지에서 영역을 크롭해 AI 참고 이미지로 전달
- 여러 AI 작업을 병렬 탭으로 관리하고 로컬 MCP 상태를 확인하는 기능 추가
- 시험용 그래프를 네이티브 벡터 장면으로 생성하는 파이프라인과 검증 도구 추가
- 웹 배포와 Windows 설치본이 같은 병합 커밋과 버전 식별자를 사용하도록 릴리스 절차 정리
