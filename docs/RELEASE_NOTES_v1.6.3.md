# 5E 1.6.3 — 로컬 검수 완료, 공개 전 후보

- 라이브러리를 열면 PDF 목록을 먼저 표시하고, 본문 검색 자료는 뒤에서 준비합니다.
- 저장된 목록을 바로 표시한 뒤 최신 자료를 확인합니다. 손상된 목록은 정상 조회로 복구합니다.
- 검색 준비 상태를 안내하고 입력한 검색어를 보존합니다. 준비 후 자동으로 다시 검색하며, 파일명 검색도 계속 사용할 수 있습니다.
- 검색 자료가 도착하거나 목록이 갱신돼도 진행 중인 크롭의 페이지·확대·영역을 보존합니다.
- 일반 `.5e`·`.json` 프로젝트가 128 MiB를 넘으면 읽기 전에 안내하고 현재 작업을 보존합니다.

## 실제 측정

같은 Mac·Chromium에서 첫 방문과 재방문을 각각 5회 측정한 목록 표시 시간입니다. 1.6.2는 같은 날 앞선 실행, 1.6.3은 최종 소스의 새 실행입니다. 회선과 공용 CDN 상태는 통제하지 않았습니다.

| 목록 표시 | 1.6.2 중앙값 | 1.6.3 중앙값 | 1.6.3 최댓값 |
|---|---:|---:|---:|
| 첫 방문 | 8.508초 | 0.107초 | 0.127초 |
| 재방문 | 0.845초 | 0.140초 | 0.197초 |

본문 검색 준비와 대용량 PDF 원본 다운로드 시간은 남아 있습니다. 이번 측정에서 본문 검색 준비 중앙값은 첫 방문 8.136초, 재방문 0.736초입니다. 실제 교과서 316쪽은 0.365초에 크롭을 시작할 수 있었고 원본 전환은 20.053초, 기출 PDF는 각각 0.326초·3.039초였습니다. 원본 전환 때 화면 위치 변화와 페이지 오류는 없었습니다.

## 검사와 공개 상태

기본 검사 336개 통과. 브라우저 41개 묶음을 실행했으며, 기존 AI 경과시간 표시 검사 1건의 첫 실행 시간초과는 코드 변경 없는 단독 재검으로 통과했습니다. 새 라이브러리 검사, 실제 프로젝트 저장·재열기·PNG 출력, 기존 크롭, 화면 반응 검사를 확인했습니다. 상세 기록은 `docs/STABILITY_FOLLOWUP_OPERATIONS.md`에 있습니다.

현재 공개 버전은 1.6.2입니다. 이 후보는 `feature/1.6.3/library-startup`에 보존했으며 main 병합·push·태그·배포는 진행하지 않았습니다. 설치판·실계정 AI 검증은 이번 범위에 포함하지 않습니다.
