# 5E v1.6.3

[5E 웹에서 사용하기](https://www.5e.ai.kr/)

- **라이브러리 목록을 바로 표시합니다.** 저장된 목록을 먼저 보여주고 최신 자료와 본문 검색을 뒤에서 준비합니다.
- 검색 준비 상태를 안내하고, 입력한 검색어와 진행 중인 크롭의 페이지·확대·영역을 보존합니다.
- 128 MiB를 넘는 일반 프로젝트 파일은 읽기 전에 안내해 현재 작업을 보호합니다.
- **서버 운영 환경을 보강했습니다.** 서버를 상시 가동하는 유료 환경으로 전환해 로그인 시 서버 기동 대기를 줄이고, 여러 사용자의 동시 접속에 대응할 CPU 자원을 확충했습니다.

로컬 첫 방문 목록 표시 중앙값은 **8.508초 → 0.107초**로 줄었습니다(각 5회 측정). 본문 검색 준비와 큰 PDF 원본 다운로드에는 별도 시간이 필요합니다.

웹 버전 업데이트입니다. Windows·macOS 설치판은 검증 전까지 제공하지 않습니다. 기존 Preview·모바일·고정 1.6.0 주소는 유지합니다.
