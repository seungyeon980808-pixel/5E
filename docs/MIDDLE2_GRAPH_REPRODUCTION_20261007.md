# 중2 과학 교과서 그래프 요소 보존 검증

작업 브랜치: `fix/analyable-function`. 제품 경로는 `preview/`이며 안정판 렌더러는 변경하지 않았다.

## 변경

- 박스 테두리와 내부 좌표축을 분리한다. 중앙 시간축이 있는 파동 그래프도 프레임 전체 격자를 유지한다.
- 원본의 얇은 회색 선 격자, 네 변 테두리, 기존 보조선의 반복 점선 패턴을 측정한다. 근거가 부족하면 추가·삭제하지 않는다.
- 규칙적인 격자는 기존 격자 기능으로 옮긴다. 확정 데이터·물리 함수 후보·마커·제어점·연결 라벨이 있는 데이터 선은 제거하지 않는다. 부분 기준선의 실제 끝점과 개별 회색/점선 스타일은 보존한다.
- 축 생략이 있는 그림도 표시 좌표로 복원한다. 생략된 실제 수치와 기울기는 추정하지 않는다.
- 단위 없는 관찰 사인 곡선은 명시적 sinusoid 후보일 때만 상대 식으로 변환한다. 극값·교점·밀집 내부 표본 검증을 유지하며 원래 물리 법칙으로 확정하지 않는다.
- 원본 이미지 안의 normalized 사각형·다각형 배경은 그래프 테두리를 넘어도 허용한다. 눈금 보정 뒤에도 유지한다. 원본 이미지 밖/원본 문맥 없음/data 좌표 영역/밴드의 기존 제한은 유지한다.
- 실선의 점선 길이/간격 0이 숨은 입력 검증을 실패시켜 적용을 막던 오류를 수정한다. 기존 ② 함수 입력 및 편집 항목을 사용한다.
- `graph-observation-v22-preserve-elements`는 축·격자·제목·말풍선·진폭 화살표 등 요소 목록을 확인하도록 한다.

새 regular grid 설정과 확정 데이터 로그축의 조합은 `LOG_GRID`로 차단한다. 임의 간격이 10의 거듭제곱 간격으로 조용히 바뀌는 일을 막기 위한 제한이다. 해당 로그축 격자는 실제 위치의 개별 normalized guide로 표현한다. 기존 로그축 기능은 유지한다.

## 실행 근거

공식 천재교과서 『중학교 과학 2』(임성숙 외, 2022 개정)의 기존 10개 원본을 사용했다. 원본 SHA256은 대조했고 이미지 바이트는 수정하지 않았다.

- 기존 응답 5개를 재사용했다.
- 누락 제목 2개, 말풍선 3개는 Sol 6.1 / medium으로 각각 1회 새 인식했다. 총 AI 호출 5회이며 새로 처음 보는 표본 10개 평가가 아니다.
- 녹는점/질량 응답의 `100 g 로산`, `150 g 로산`은 원문과 대조하여 `로르산`으로 텍스트만 보완했다. 변경 전 응답은 보존하고 `reference-text-review.json`에 별도 기록했다. 곡선 좌표 수동 보정은 없다.
- 새 녹는점/질량 응답은 원본 말풍선이 테두리를 넘어 첫 native 생성에서 실패했다. 영역 처리 수정 후 **동일 응답**으로 재현·편집 검증을 통과했다. 최초 생성 성공으로 소급 집계하지 않는다.
- 결과/비교/편집 파일: `outputs/middle2-reproduction-20261007/`. 제목/말풍선 재인식의 원시 응답·모델 요청·개별 최초 검증 기록도 그 아래에 보존했다.

`tools/replay-middle2-reproduction.cjs`는 제품 검증·매퍼·렌더러를 호출하고 실제 편집 모달에서 무변경 적용, 라벨 수정, 사인 식 수정, `.5e` 저장/재열기를 확인한다. 계열 칩은 함수 하위 탭의 필터된 목록으로 검사한다. `tools/report-middle2-reproduction.py`는 실제 PNG와 편집 파일로 비교 페이지를 만든다.

## 결과와 한계

- 10개 생성·편집·저장/재열기 × Chromium/WebKit: **20/20 통과**.
- 소리 그래프 중앙축, source-confirmed 격자선, `0.5+0.375*sin(5*pi*x)`의 기존 함수 입력칸 편집을 확인했다.
- 원본 격자/테두리 실제 10개 검사, 박스/로그/마커/강조영역 렌더 회귀, 편집 모달 검사, 기존 물리 관계 5개 × 2 브라우저도 통과했다.
- 전체 단위 검사 **343/344 통과**. 유일한 실패는 기존 rights-clear PNG fixture의 압축 바이트 차이다. 변경 전 HEAD의 시험·생성기·fixture만 별도 임시 경로로 추출해 실행해도 동일 실패였다. 이번 변경으로 숨기거나 fixture를 교체하지 않았다.
- 읽기 전용 검토 후 확정 데이터 보호·제어 곡선 보호·회색 격자 보존·잘못된 JSON 안전 검증·로그 격자 검증·원본 경계 배경 보존을 회귀 검사했다.

이는 요소 보존과 편집 기능 검증이며 모든 원본과의 완전한 시각 일치를 뜻하지 않는다. 현재 흑백 출력이며 글꼴·일부 글자 크기/회전·말풍선 모서리에는 차이가 남는다. 용해도 실측/생물 개념 곡선은 관찰 자유곡선으로 유지했으며 '해석적으로 표현 불가능'으로 집계하지 않는다. 직선·꺾은선은 정상 기본 도형 결과다.
