# v1.6.0 — 라이브러리와 AI 이미지 변환 작업대

v1.6.0은 기출·교과서 PDF에서 필요한 그림을 찾고, 시험지에 넣을 선화로 바꾸는 과정을 한 화면으로 연결한 후보 버전입니다. 라이브러리에서 여러 PDF를 연속으로 읽고 크롭한 뒤 AI 작업대로 보낼 수 있습니다. AI 결과는 점·영역 코멘트로 수정하고, 원본과 비교하거나 물체별 이미지로 나누어 캔버스에 넣을 수 있습니다. 작업 복구와 저장 상태 표시도 보완했습니다.

## 한눈에 보기

- **라이브러리** — 그림·부품·PDF를 함께 찾고, 검색한 PDF 전체를 읽으며 여러 영역을 자릅니다.
- **AI 이미지 변환** — 교과서 사진을 평가원식 흑백 선화로 변환하고, 점·영역 코멘트로 부분 수정을 요청합니다.
- **비교와 마무리** — 원본과 결과를 겹쳐 비교하고, 배경 제거와 물체별 분리를 거쳐 캔버스에 넣습니다.
- **여러 작업 관리** — 원본을 한 작업에 모으거나 나누고, 선택한 작업을 함께 실행하며 작업별 경과 시간을 확인합니다.
- **편집과 복구** — Lite·Pro 전환, 페이지별 실행 취소, 새 작업 전 복구 보관을 보완했습니다.
- **웹 AI 연결** — 미리보기에서 ChatGPT 계정으로 연결합니다. 서버가 제공하는 모델과 지원 설정을 선택할 수 있습니다.

## 라이브러리·PDF

- 그림·부품·PDF를 한 라이브러리에서 찾고 캔버스나 AI 작업대로 보냅니다. (`0e5beb1a`, `902a0bca`)
- 검색한 PDF도 전체 문서를 연속으로 읽습니다. 스크롤이나 페이지 이동 후 필요한 영역을 자를 수 있습니다. (`db6013aa`, `2e83efad`, `6c17a758`)
- 빠르게 페이지를 넘겨도 늦게 도착한 이전 페이지가 현재 크롭 대상을 덮어쓰지 않도록 수정했습니다. (`3e37281c`, `db8c76eb`, `74133990`)
- 여러 PDF에서 자른 그림을 모아 영역을 다시 조정합니다. 함께 쓸 그림과 개별 작업대로 보낼 그림을 지정할 수 있습니다. (`1134a7c2`, `158e687c`, `fe4d9a12`)
- 작업대 전달이 확인된 크롭만 보관함에서 정리합니다. 전달에 실패한 그림은 남겨 다시 시도할 수 있습니다. (`67446130`)
- 학년도 범위로 검색할 수 있습니다. PDF 파일명의 연도 인식도 보완했습니다. (`ecee5a97`, `c43cac93`, `d76ec33c`)
- 공개 Google Drive 자료를 연결하고 미리보기를 제공합니다. 카드는 단계적으로 불러옵니다. 미리보기 라이브러리의 ‘5E 공유 자료’ 트리에는 PDF 422개가 표시됩니다(2026-09-29 기준). (`fd75e8a8`, `8bce22d5`, `857914e6`, `eab15748`)
- PDF 가져오기에 실패하거나 같은 파일을 다시 가져올 때 사용량이 잘못 쌓이던 문제를 수정했습니다. (`3e37281c`)
- 문항을 선택하면 크롭 화면을 먼저 열고 준비 상태를 표시합니다. (`a007c88d`, `6c17a758`)

## AI 이미지 변환 작업대

- 참고 그림을 시험용 선화로 변환합니다. 결과에 점·영역 코멘트를 남겨 수정 후보를 확인하고 적용할 수 있습니다. (`f5170d86`, `6867de46`)
- 여러 원본을 한 작업에 넣거나 별도 작업으로 나눕니다. 선택한 여러 작업을 묶어 실행할 수 있습니다. (`529e7919`, `77b54780`, `b0ff073e`)
- 배경 제거·무채색·선 굵기 설정을 미리보기와 캔버스 삽입에 일관되게 적용합니다. (`b8c34160`, `8300f5a5`, `a72d68de`)
- 생성한 그림을 자동 감지·격자·직접 지정으로 나눕니다. 나눈 이미지를 개별 편집하고 캔버스에 넣을 수 있습니다. (`e2d7ef7a`, `ec7276e1`, `b0ff073e`)
- 수정 전후를 나란히 보거나 경계선을 움직여 겹쳐 비교합니다. 크기가 다른 이미지도 비율을 유지하며 공통 화면에 표시합니다. (`0c4282c6`, `fc1e2d55`, `74133990`)
- 투명 배경 표시와 후처리 결과가 서로 다르게 보이던 문제를 수정했습니다. (`a72d68de`, `fc1e2d55`, `74133990`)
- 생성 중 다른 작업이나 페이지로 이동해도 결과는 실행을 시작한 작업에 연결됩니다. (`16a6b97a`, `b0ff073e`)
- 작업별 실행 시간과 대기 상태를 표시합니다. 실패해도 입력과 코멘트를 유지합니다. (`0c4282c6`, `74133990`, `4d3fb77c`)
- 비어 있는 첫 작업대는 라이브러리에서 보낸 그림에 재사용합니다. (`67446130`)

## 캔버스·그리기·그래프

- 라벨러에 확대경을 추가했습니다. 최대 다섯 시작점을 연결하고 선과 글자 사이 간격을 조절할 수 있습니다. (`82c2c09e`)
- 패널을 열고 닫을 때 캔버스 위치가 흔들리던 문제와 드래그 선택 표시를 수정했습니다. (`3ba659a0`, `0f134a52`, `8715e5ac`)
- 캔버스 위치 고정 방식을 선택합니다. 기본값은 기준 좌표 고정입니다. (`1ea36224`, `4d3fb77c`)
- 직각 표시와 묶은 함수 그래프의 선택 테두리를 맞추고, 짧은 회로 부품의 크기 변경을 보완했습니다. (`315850ed`, `47210848`, `21b8c010`, `3c973d23`)
- 불연속 함수의 구간을 보존합니다. 복잡한 함수는 정의역을 줄이도록 안내합니다. (`edfbc76e`)
- 겹친 끝점이나 잘못된 치수 때문에 도형이 비정상적으로 커지는 경우를 줄였습니다. (`50864505`, `62322a36`)

## Lite·Pro와 작업 복구

- Lite에서도 메인 캔버스를 중심으로 자주 쓰는 도구와 선택 대상 편집 기능을 사용합니다. (`641b7463`, `9f22fb5d`)
- 모드를 바꿀 때 현재 작업을 이어갈지 새 작업으로 시작할지 선택합니다. (`9f22fb5d`)
- 새 작업 전에 기존 도면을 복구용으로 보관합니다. 이후 자동 저장이 복구 내용을 덮어쓰지 않도록 수정했습니다. (`d7f5060b`, `5c1f90c7`, `3e62c46d`)
- 페이지별 실행 취소 기록을 유지합니다. 닫은 AI 작업이 뒤늦게 복원되는 문제도 수정했습니다. (`d7f5060b`, `c4fad9ed`)
- AI 작업대와 모드 전환 대화상자의 키보드 포커스 이동을 보완했습니다. (`5c599996`, `949d5bdc`)

## 저장·내보내기

- 지원 환경에서 저장 위치 선택창을 바로 엽니다. 기본 파일명에는 날짜와 시간이 들어갑니다. (`8637066e`, `27912d7b`)
- 파일 저장, 다운로드 요청, 자동 복구 저장의 상태를 구분해 표시합니다. (`37ddcc52`, `74133990`)
- PNG·SVG의 겹침 순서를 맞췄습니다. 내용 맞춤 저장에서 화살표와 장식선 끝이 잘리던 문제도 보완했습니다. (`50864505`, `18576869`)
- 여러 AI 결과를 내보낼 때 설정을 일관되게 적용합니다. ZIP의 한글 파일명과 Windows 파일명 길이 처리를 보완했습니다. (`424ce198`, `bd64f758`, `ae8a50a1`)
- 웹에서 Mac·Windows용 실행형 프로젝트를 내려받는 기능을 추가했습니다. **운영체제별 실행은 아직 검증하지 않았습니다.** (`0121076c`, `af619e84`; 서버 `eafd95f3`)

## 웹 AI 연결

- 웹 편집기에서 ChatGPT 계정을 연결합니다. 인증 창을 닫아도 연결을 유지합니다. (`a7b1c119`, `5505e514`; 서버 `5e5158d7`)
- 로그인 코드와 인증 창을 나란히 표시합니다. Safari의 창 크기와 재시도 안내를 보완했습니다. (`988a6882`, `71f7624f`; 서버 `2d17bbd8`, `9ca87b56`)
- AI 작업을 보기 전용 또는 편집 가능한 복사본으로 공유하고, 만든 링크를 중지할 수 있습니다. (`dc346876`, `da182b07`; 서버 `71670c2c`)
- 서버가 제공하는 모델 목록과 지원 설정을 표시합니다. 선택한 모델·사고 수준·속도를 실제 요청에 전달합니다. (`3403a42e`; 서버 `556c2b32`)
- 모델을 바꿀 때 호환되지 않는 설정은 기본값으로 바꿉니다. 실패하면 인증 정보를 제거한 상세 오류를 확인하고 복사할 수 있습니다. (`4d3fb77c`, `3403a42e`)
- 서버의 Codex 0.158.0에서 GPT-6 Sol·Luna를 모델 목록으로 제공합니다. **실제 로그인 계정으로 이 서버에서 이미지를 생성하는 흐름은 미검증입니다.** (서버 `5eb98d76`)

## 데스크톱

- Intel·Apple Silicon Mac용 패키지 구성과 macOS 창·Dock·재실행 동작을 추가했습니다. **공개 배포된 Mac 설치판은 아닙니다.** (`b4c1cd25`)
- 전체화면 동작과 운영체제별 단축키 안내를 보완했습니다. (`cd504b36`, `58215ff6`, `ae5dca46`)
- 작업대별 요청과 결과를 분리했습니다. **Windows 실기 검증은 보류 중입니다.** (`b0ff073e`)

## 안정성·성능

- 큰 이미지가 있는 작업에서 저장 상태를 확인할 때 반복 복사를 줄였습니다. (`74133990`)
- 정상 PNG의 해상도 메타데이터를 오류로 거부하던 문제를 수정했습니다. (`5a70fb2d`)
- 개인 오브젝트의 이름과 분류를 문자 그대로 표시합니다. 프로젝트와 로컬 입력의 검증도 보강했습니다. (`59457c31`, `4db68c6a`, `d7f5060b`)
- 같은 AI 실패가 여러 번 표시되는 경우를 줄였습니다. (`3403a42e`)

## 알려진 제한

- 물체별 분리는 **래스터 이미지 분리**입니다. 내부 선을 벡터로 바꾸지 않습니다. 맞닿거나 겹친 물체는 함께 분리될 수 있습니다.
- AI 출력은 원본 구도나 과학적 표현을 항상 그대로 보존하지 않습니다. 시험지에 넣기 전에 원본과 결과를 비교하세요.
- 웹 서버 연결은 이미지 생성·수정에 한정됩니다. 대화·자동 분석·검수·벡터 생성은 지원 범위가 아닙니다.
- 웹 AI 서버는 시험 운영 중입니다. 서버 재시작·재배포 또는 30분 동안 요청이 없으면 다시 로그인해야 합니다. 여러 작업의 동시 실행이 동시 사용자 수용량을 보장하지는 않습니다.
- 공유 링크는 최대 1시간 동안 임시 보관됩니다. 서버 재시작 시 더 일찍 사라질 수 있습니다. 편집 권한은 받는 사람의 복사본에 적용됩니다.
- 자료가 라이브러리에 표시된다는 사실이 이용 권리 확인을 뜻하지 않습니다. 권리 미확인 샘플은 후보 배포에서 제거했습니다.
- Windows 서명·실기 검증, 실계정 AI 검증, macOS 서명·공증은 완료로 안내할 수 없는 상태입니다. 1.6.0 공식 설치 파일도 아직 게시되지 않았습니다.

## 업데이트 전에

작업 중인 프로젝트를 파일로 저장하고 별도로 백업하세요. 웹·데스크톱, 브라우저, 정식 웹·미리보기의 저장 공간은 서로 다를 수 있습니다. 자동 복구만으로 작업을 옮기지 말고 저장한 프로젝트 파일을 사용하세요. AI 기능은 연결 상태와 로그인한 계정의 기능·이용 한도에 영향을 받습니다. AI 연결 없이도 일반 그리기와 편집은 사용할 수 있습니다.
