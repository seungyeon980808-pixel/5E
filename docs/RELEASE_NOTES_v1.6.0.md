# v1.6.0 — Lite 작업 화면 개편과 이미지 편집 안정성 개선

> **게시 전 초안 · HOLD**: 아래 내용은 1.6.0 후보의 변경 사항입니다. 1.6.0 설치 파일과 정식 GitHub Release는 아직 게시되지 않았습니다. 현재 공개 설치판은 [v1.5.8](https://github.com/seungyeon980808-pixel/5E/releases/tag/v1.5.8)입니다.

v1.6.0은 Lite에서 그림을 찾고 편집하는 흐름을 다시 정리하고, 작업 전환·PDF 크롭·AI 이미지 결과 적용·저장의 안정성을 높인 후보 버전입니다. Pro에서 익숙한 캔버스 중심 구성을 Lite에서도 사용할 수 있도록 손봤습니다.

## 주요 변경 사항

- **Lite 작업 화면 개편** — 메인 캔버스를 중심으로 도구와 속성 영역을 정리했습니다. Pro와 Lite를 바꿀 때 현재 작업을 이어가거나 새 작업을 시작할 수 있습니다.
- **작업 복구 보강** — 새 작업으로 넘어가기 전 도면을 복구할 수 있도록 보관하고, 이후 자동 저장이 복구 내용을 덮어쓰던 문제를 수정했습니다.
- **AI 이미지 작업 안정화** — 이미지 변환과 선택 영역 수정의 실행 흐름을 합쳤습니다. 생성 중 페이지나 작업을 바꿔도 결과가 다른 대상에 들어가지 않도록 하고, 결과 분리 옵션을 바꿨을 때 이전 결과가 재사용되지 않도록 했습니다.
- **PDF 크롭 수정** — 검색 결과에서 다른 페이지로 이동한 뒤에도 표시 중인 페이지의 영역을 자를 수 있도록 크롭 대상과 페이지 상태를 맞췄습니다.
- **편집과 내보내기 개선** — 페이지별 실행 취소·다시 실행, 프로젝트 불러오기 검증, PNG·SVG의 객체 겹침 순서와 내용 맞춤 저장 영역을 보강했습니다.

## 조금 더 자세히

### 라이브러리와 AI 이미지

PDF 검색 결과에서 페이지를 넘긴 뒤 크롭이 처음 페이지로 돌아가거나 더 이상 동작하지 않던 문제를 수정했습니다. PDF 가져오기가 실패하거나 같은 파일을 다시 가져올 때 사용 한도가 잘못 늘어나던 문제도 다뤘습니다.

AI 변환 요청을 준비하는 동안 연속 클릭이나 작업 전환으로 잘못된 요청이 시작되지 않도록 작업 대상을 고정했습니다. 결과를 적용할 때는 요청을 시작한 페이지와 작업을 확인합니다. 닫힌 작업의 지연된 복구, 마지막 탭을 닫은 뒤 남는 작업 화면, PNG 해상도 메타데이터가 있는 정상 이미지의 처리도 보강했습니다.

이 항목은 **후보 코드의 동작**을 설명합니다. 실제 로그인 계정과 연결한 AI 서비스의 모든 경로가 검증됐다는 뜻은 아닙니다.

### 캔버스와 그래프

직각 표시와 묶은 함수 그래프의 선택 영역, 짧은 회로 부품의 크기 변경, 끝점 편집 중 임시 표시를 수정했습니다. 잘못된 크기 입력이나 겹친 끝점으로 도형의 크기가 비정상적으로 커지지 않도록 했습니다. 함수의 불연속 지점과 면적 구간을 다듬고, 눈금이나 함수 샘플이 지나치게 많을 때의 작업량을 제한했습니다.

### 저장과 접근성

PNG·SVG 출력에서 텍스트와 도형의 겹침 순서를 편집 화면과 맞췄습니다. 화살표와 장식선의 끝부분이 내용 맞춤 저장에서 잘리지 않도록 출력 영역을 계산합니다. 모드 전환 대화상자의 키보드 포커스 이동과 개인 오브젝트 이름·분류의 안전한 표시도 개선했습니다.

## 업데이트 전 알아둘 점

작업 중인 프로젝트는 파일로 저장하고 백업한 뒤 업데이트하세요. 웹·데스크톱 및 브라우저별 저장 공간은 서로 다를 수 있습니다. AI 이미지 기능은 로컬 Codex 연결과 로그인한 계정의 이용 가능 상태에 영향을 받습니다.

최종 지원 운영체제와 다운로드 파일, 서명·공증 여부, 실제 계정으로 진행한 AI 흐름, 배포 SHA와 체크섬은 아직 확정되지 않았습니다. 확인된 파일만 정식 릴리즈에 첨부하고 이 문단을 실제 지원 환경·알려진 제한으로 교체합니다. 자세한 상태는 [릴리즈 보류 기록](RELEASE_HOLD.md)에 있습니다.
