# 이미지 변환 모드 실사용 검증 보고서

## 결론

모드 선택 UI, 명시적 출력 방식, 최대 5개 동시 변환, 독립 작업 탭, 3단계 흑백 후처리, 복잡 모드 2차 교정, 설명만으로 만드는 교과서형 선화까지 구현·실행했다. 기능 회귀 테스트 43개와 데스크톱 스모크 테스트는 통과했다.

다만 “평가원 그림과 거의 동일”이라는 품질 기준에서 심장 단면은 90점으로 95점 게이트를 통과하지 못했다. 복잡 모드가 보통보다 나았지만, 생성 모델이 원본을 전형적인 심장 형태로 일반화했다. 이 결과는 자동 채택하지 않는 것이 맞다.

## 그림별 판정

### 단일 암석

- 단순: 생성 모델을 거치지 않아 외곽 형태가 바뀌지 않았다. 타이트한 크롭에서는 가장 실용적이다.
- 보통·복잡: 불필요한 조판은 잘 지웠으나 암석 외곽과 공동 배치를 새로 해석했다. 더 오래 걸렸지만 품질은 낮아졌다.

### 가열·응축 장치

- 단순: 원본 형태는 보존했지만 원본 선 질감도 함께 남아 후처리가 더 필요하다.
- 보통: 용기·배출구·받는 비커·액체·가열부의 관계와 세 방울을 명확히 표현해 95점으로 통과했다.
- 복잡: 구조는 유지했지만 두 번째 패스의 시간 증가에 비해 보통보다 명확한 이득이 없었다.

### 심장 단면

- 단순: 본체 형태를 재해석하지 않았지만 본체에 걸친 지시선과 흐름 화살표가 남아 부적합하다.
- 보통: 조판 제거와 선화 스타일은 좋지만 원본의 비대칭 방·실 경계와 혈관 접속 일부가 일반화됐다.
- 복잡: 가장 깔끔하고 구조 검사가 한 번 더 수행됐으나, 원본 고유 형상 대신 전형적 심장 단면으로 수렴했다. 하드 게이트 실패다.

## 모드 선택 기준

1. 독립 객체 1~2개이고 크롭 안에 라벨·화살표·본문이 본체와 겹치지 않으면 `단순`.
2. 부품 3~12개, 하나의 장치, 분기 2개 이하이면 `보통`.
3. 해부도, 분기 3개 이상, 다중 패널, 교차 배관·회로, 반복 객체 12개 초과이면 `복잡`.
4. 형태 보존과 삭제가 충돌하면 단순은 형태를 우선하고 사용자가 5E에서 잔여 조판선을 지운다.
5. 복잡 결과는 객체·연결 대응표를 확인하기 전 자동 확정하지 않는다.

## 설명 기반 생성 검증

“스탠드·클램프·온도 센서·물이 든 비커·핫플레이트·전원선”의 폐쇄 목록만으로 교과서형 선화를 생성했다. 33.6초가 걸렸고 문자·라벨·화살표 없이 부품과 접촉 관계가 명확했다. 다만 전원선 종단처럼 설명의 위치 관계가 애매하면 모델이 합리적으로 보충하므로, 정확한 장치에서는 시작점과 끝점을 문장에 함께 적어야 한다.
