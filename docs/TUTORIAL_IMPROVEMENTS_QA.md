## 3. 실제 재현한 문제와 수정

| 재현한 문제 | 수정 |
|---|---|
| Space 팬 안내 중 Space가 다음 단계로 이동 | Space를 튜토리얼 전역 진행 키로 가로채지 않고 앱 팬 조작에 전달 |
| Esc 취소 안내대로 누르면 코스 자체가 종료 | 앱 취소를 우선하고 튜토리얼 종료는 명시적인 `그만` 버튼 사용 |
| Mac에서도 Ctrl 명령 표시, 각도 스냅 키도 Ctrl로 안내 | 명령은 Command(⌘), Mac 스냅은 Option(⌥)로 분리 표시. Windows는 Ctrl 유지 |
| 텍스트 확정 안내가 실제 Enter 동작과 반대 | Enter 확정/Esc 취소로 통일. 입력창과 하단 힌트도 같은 문구로 수정 |
| Command+Enter를 줄바꿈이라고 설명했으나 실제 Mac 입력에서 확인되지 않음 | 검증되지 않은 줄바꿈 약속 제거. 텍스트 키 처리 구현 자체는 변경하지 않음 |
| 선택하지 않은 도형의 첫 드래그는 이동 대신 선택만 됨 | 먼저 클릭해 선택한 다음 다시 잡아 드래그하는 순서로 안내 |
| Shift를 먼저 누르고 이미 선택한 도형을 잡으면 선택이 풀려 이동하지 않음 | 생성 코스의 이동 스냅 2단계는 `마우스로 먼저 잡은 뒤 Shift`로 안내. 도형 생성·크기 제한과 구분 |
| 기본 선 굵기 0.2mm가 기존 비교값 0.4mm와 달라, 변경 없이 통과 | 단계 진입 시 실제 값을 저장하고 이후 값 변경을 판정 |
| 생성·삭제·클립보드·Redo·페이지·파일 실습 누락 | `편집과 저장` 12단계 추가. 준비 5 + 기초 조작 13 + 편집과 저장 12 = 30단계 |
| 삭제 성공을 엉뚱한 기존 도형 삭제나 페이지 변경으로 오판할 위험 | 방금 그린 사각형 ID와 연습 페이지에 한정해 판정 |
| 저장/열기 취소나 불충분한 클립보드 판정으로 성공을 잘못 표시할 위험 | 클립보드와 파일 단계는 실제 결과를 확인하고 사용자가 `다음`으로 진행. 자동 성공을 주장하지 않음 |
| 자동 실습 버튼 재클릭·빠른 단계 전환·이전 실행 콜백의 간섭 위험 | 실행/방문 토큰, 전환 타이머 정리, 자동 실행 중복 방지, 재실행 단계 보호 |
| 설정 메뉴를 빠르게 누르면 환경 설정 클릭이 다음 단계의 대기 등록보다 먼저 발생 | 클릭뿐 아니라 실제 열린 메뉴/환경 설정의 가시성을 확인하여 이미 수행한 조작을 인식 |
| 큰 배율에서 코치 창이 슬라이더를 가리거나 버튼이 화면 밖으로 나감 | 대상 위·아래 여유 공간으로 높이를 제한하고 스크롤 및 하단 버튼 고정 적용 |
| 캔버스 코치의 고정 280px 폭이 좁은 오른쪽 패널 밖으로 나옴 | 실제 패널 사각형에 맞춘 위치·폭·높이로 도킹, 긴 버튼 줄바꿈 |

`js/text-editor.js`는 안내 문자열 2곳만, `js/tool-hint.js`는 선택·회전·텍스트 설명과 키 표시 분할만 변경했다. 도형 편집, 클립보드, 파일 저장 및 변환 알고리즘은 변경하지 않았다.

### 생성 코스 및 마지막 보완 검사

- `오브젝트 생성, 스냅, 라벨링` 16단계를 수행했다: 직선, 텍스트 Enter 확정, 삼각형, 바닥 스냅, 정사각형, 물리량 라벨, 빗면 스냅, 전체 선택, 그룹화, 그룹 이동, 마치기.
- Option을 누른 직선 생성, Esc로 도구 조작 취소 후 튜토리얼 유지, 마우스로 잡은 뒤 Shift를 누르는 이동 스냅을 실제로 확인했다.
- 생성 코스 중 확인된 설명을 수정한 뒤 새로고침하여 Enter 안내, 입력창/하단 힌트, 수정한 Shift 문구를 다시 확인했다.
- 이전, 건너뛰고 다음, 중도 그만, 재시작, 연습 페이지 남기기/이번 실행 페이지 지우기를 확인했다. 마지막 검사용 페이지 삭제 후 기존 7개 페이지가 유지됐다.
- 마지막 준비 단계 판정 수정 후 새로고침하여 빠른 메뉴 진입을 다시 실행했다. 클릭을 놓치지 않고 4/5 슬라이더 단계로 진행했다. 배율 복원, 설정 닫기, 본 실습 진입도 재확인했다.
- 기초 전체 실행 이후 변경되지 않은 후속 25단계의 결과를 활용하고, 이후 변경한 준비 단계 및 표시/배치를 새로 검사했다. 마지막 문구 수정마다 전체 20코스를 반복 실행했다는 뜻은 아니다.
