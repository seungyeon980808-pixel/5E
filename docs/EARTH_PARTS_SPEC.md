> 근거: `docs/SURVEY_earth_20260731.md` §5(우선순위 Top 5) + 시안 검토.
> 원칙: **새 객체 타입을 만들지 않는다.** 전선·등치선·산점은 본질이 선·곡선·점이라
> 기존 타입의 옵션으로 두면 "마우스로 찝어 구부리기"가 공짜로 따라온다.
> 새 타입으로 만들면 꼭짓점 핸들·픽·복사·저장·스타일 배선을 전부 새로 깔아야 한다.

## 0. 전제 작업 — 닫힌 곡선의 꼭짓점 핸들

**무엇이 없었나**: 열린 polyline·curve만 점마다 핸들이 생기고, **닫힌** 것은
크기조절 상자로만 떨어졌다. 등치선의 폐곡선 링, 지질 단면의 닫힌 영역은
상자 스케일만으로는 모양을 못 고친다.

**어떻게 고쳤나** (기존 동작 무손실, 더하기만):

| 파일 | 변경 |
|---|---|
| `js/render/scene.js` renderHandles | 닫힌 polyline·curve에 크기조절 상자 **위에** 꼭짓점 핸들을 함께 얹는다 |
| `js/transform.js` | 분기 기준을 `닫힘 여부` → **`핸들 이름이 p<번호>인가`**로 바꿨다. 상자 핸들(n/s/e/w/모서리)은 그대로 branch-A로 간다 |

실측 검증: 닫힌 곡선 선택 시 꼭짓점 5 + 상자 8 = 13핸들.
`p2` 드래그 → 2번 점만 이동. `se` 드래그 → 5점 전부 스케일(기존 동작 유지).

## 1. 암상 무늬 채움 (`fillStyle` 4종 추가)

`js/render/fill.js` `makeFillPattern()`. 기존 4종(solid·dots·cross·hatch)에 추가:

| 값 | 무엇 | 타일 구성 |
|---|---|---|
| `brick` | 벽돌(석회암) | 가로 줄눈 2 + 세로 줄눈을 한 칸씩 엇갈려 |
| `vees` | v (화산암·응회암) | 엇갈린 작은 v 2개 |
| `plus` | + (심성암) | 엇갈린 십자 2개 |
| `hlines` | 가로줄(셰일·이암) | 층리 수평선 2개 |

인스펙터 이름은 무늬 모양이 아니라 **암석 이름**으로 적는다 — 교사가 고를 때 보는 것이 암석이다.
`obj.fillTile`(간격)은 기존과 같이 동작하고, 기호 크기도 간격에 비례한다.

## 2. 전선 기호 (`curve.frontKind`)

곡선의 옵션. 경로를 `getPointAtLength`로 훑어 기호를 반복해 얹는다 —
**꼭짓점을 끌어 곡선을 구부리면 기호가 자동으로 따라온다.**

| 필드 | 뜻 |
|---|---|
| `frontKind` | `cold`(삼각) · `warm`(반원) · `stationary`(삼각·반원이 **반대쪽**에 번갈아) · `occluded`(삼각·반원이 **같은 쪽**에 번갈아) |
| `frontGap` | 기호 간격(mm). 기본 7 |
| `frontSize` | 기호 크기(mm). 없으면 간격의 0.34배 |
| `flipSide` | 기호가 붙는 쪽을 뒤집는다 |

반원의 sweep 플래그는 붙는 쪽의 외적 부호로 정한다 — 고정값으로 두면
곡선이 반대로 휠 때 반원이 선 안쪽으로 말린다.

---

## 3. 등치선 값 라벨 (`curve.inlineLabel`)

등압선·등고선·등수심선의 관례: **선을 끊고 그 자리에 값이 앉는다.**

| 필드 | 뜻 |
|---|---|
| `inlineLabel` | 값 문자열(예: `1000`) |
| `inlineLabelT` | 곡선 위 위치 0~1. 기본 0.5 |
| `inlineLabelSize` | 글자 크기(mm). 없으면 선 굵기 기반 자동 |

**경로를 실제로 자르지 않는다.** 바탕색 사각형을 깔아 선을 가린다 —
자르면 곡선을 구부릴 때마다 다시 잘라야 하고 도형이 둘로 갈라진다.
글자는 그 지점의 접선 방향으로 눕히되, 기울기가 ±90°를 넘으면 180° 돌려 뒤집히지 않게 한다.

> **다발 만들기**: 링 하나를 만들어 값만 바꿔 복사·붙여넣기 한다.
> 전용 생성기는 넣지 않았다(복사가 더 빠르고, 실제 등치선은 간격이 균일하지 않다).

## 4. 축척 막대 (`line.lineMode:"scaleBar"`)

치수선(`lengthArrow`)의 형제. 화살촉이 없고 라벨이 **막대 위**에 놓인다(지도 관례).

| `scaleBarVariant` | 모양 |
|---|---|
| `bars` | 양 끝 세로 바 (기본) |
| `alt` | 흑백 교차 — 절반을 검게 칠한 막대 |
| `simple` | 선만 |

라벨은 `dimensionLabel`/`dimensionLabelSize`를 **그대로 재사용**한다 —
치수선이 이미 쓰는 필드라 인스펙터·복사·스타일 붙여넣기 배선이 공짜로 따라온다.
인스펙터에서 같은 버튼을 다시 누르면 모양이 순환한다(다른 선 모드와 같은 규약).

---

## 5. 산점 (`polyline.markerOnly`)

H-R도·은하 분포처럼 점이 수십~수백 개인 자료. 그래프 모달의 '표시점'은
낱개 클릭이라 감당하지 못했다.

| 필드 | 뜻 |
|---|---|
| `markerOnly` | 잇는 선 없이 점만 찍는다 |
| `markerSize` | 점 지름(mm). 없으면 선 굵기의 4배 |
| `markerOpen` | 속 빈 원(○) — 두 자료를 구분할 때 |

폴리라인의 옵션으로 둔 이유: 점 배열을 이미 갖고 있어 **점마다 핸들이 붙는다** —
자료점 하나를 집어 옮기는 것까지 공짜다.
픽(`js/pick.js`)은 선이 아니라 **점 자체**를 기준으로 판정한다 — 선 기준으로 두면
점 없는 허공을 눌러도 선택돼 뒤의 객체를 고를 수 없다.

---

## 6. 한글 세로쓰기 (`text.textOrient:"vertical"`)

기출 그래프의 세로축 이름 표기. **회전(눕히기)과 다른 물건이다** — 글자는 똑바로 선 채
한 자씩 아래로 쌓인다. 줄 간격은 가로쓰기(1.4배)보다 촘촘한 **1.05배** —
가로 줄 간격을 그대로 쓰면 축 이름이 아니라 낱글자 여러 개로 보인다.
줄바꿈은 무시하고 글자 단위로 쌓는다(세로 축 이름은 한 기둥이 원칙).

## 7. 팔레트 — 과목 선택 '지구과학'

옵션만 만들어 두면 **교사는 그 기능이 있는지 알 수 없다.** 인스펙터를 열어 곡선을
고른 뒤에야 나타나기 때문이다. 그래서 왼쪽 패널에 실제 부품으로 올린다.

| 파트 | 부품 | 만들어지는 것 |
|---|---|---|
| 지질학 | 석회암·화산암·심성암·셰일 층 | `rect` + 해당 `fillStyle` (드래그) |
| 지질학 | 부정합면 | 굵은 `curve` (클릭 배치) |
| 해양학 | 등수심선 | `curve` + `inlineLabel` |
| 해양학 | 축척 막대 | `line` + `lineMode:"scaleBar"` |
| 기상학 | 한랭·온난·정체·폐색 전선 | `curve` + `frontKind` |
| 기상학 | 등압선 | `curve` + `inlineLabel` |
| 천문학 | 산점 / 산점(속 빈 원) | `polyline` + `markerOnly`(+`markerOpen`) |
| 표시·주석 | (기존 공용 부품) | 중괄호·범례·축 생략 |

배선에서 고친 것 두 가지 — **둘 다 없으면 팔레트를 눌러도 옵션이 안 붙는다**:

1. **클릭배치 경로에 병합이 없었다.** 드래그 도형은 `tools.js makeShape` 안에서
   `_symbolProps` 를 얹지만, 선·꺾은선·곡선은 commit이
   `tools/click-placement.js` 에 있어 값을 못 봤다 → `commitClickShape` 에서
   `getSymbolProps()` 를 읽어 얹는다(line·polyline·curve 한정).
2. **맨 도형(rect/ellipse/triangle)에도 병합이 없었다.** kind 를 고르는 부품
   (광학·기구·입체·화학·생명)만 병합 지점이 있었다 → `makeShape` 반환 직전에 추가.

곁들여 **`setActiveTool` 이 `_symbolProps` 를 비우게** 했다. 곡선이 심볼 도구가 되면서
"한랭 전선을 고른 뒤 C 키로 맨 곡선을 그리면 옛 필드가 따라붙는" 사고가 가능해졌기
때문이다. `armSymbol` 은 `setActiveTool` **뒤에** 값을 넣으므로 정상 경로는 영향이 없다.

아이콘은 `js/tool-icons.js` 에 손으로 그렸다. 렌더러 축소본을 쓰면 암상 무늬 넷이
전부 '빈 상자'로 보인다 — 채움 패턴은 `render()` 가 만드는 `<defs>` 에 사는데
아이콘에는 그 defs 가 없기 때문이다.

## 8. 이 세션에서 만들지 않은 것

- **지도 배경**(`map_outline`, 14장) — 파라미터로 못 그린다. 크롭 또는 SVG 자산 조달을
  사용자가 결정해야 한다(`docs/PARTS_PIPELINE.md` 경로).
- **막대그래프·이중 y축·일점쇄선** — 같은 날 **다른 세션이 이미 구현**했다
  (`js/graph/graph-modal.js` 막대 계열, `coordplane.js` y2축, `core.js` dashPattern).
- **등치선 '다발' 생성기** — 링 하나를 만들어 값만 바꿔 복사·붙여넣기 한다(§3).
