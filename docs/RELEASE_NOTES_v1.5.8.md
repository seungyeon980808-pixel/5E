# v1.5.8 — PDF 교과서 검색·크롭 및 AI 그래프 통합

v1.5.0이 외부 그림을 5E로 가져와 자르고 고쳐 쓰는 작업 흐름을 만든 판이었다면, v1.5.8은 그 흐름을 **교과서 PDF 검색에서 필요한 장면 선택, 크롭, AI 편집까지** 확장한 누적 통합판입니다.

이번 판에는 v1.5.0 이후 여러 브랜치에서 진행된 AI 품질 모드, 병렬 작업 탭, 로컬 자료 검색, 지연 자르기 복구, 네이티브 시험 그래프와 배포 안정화 작업을 현재 `main` 기준으로 다시 모았습니다. 웹앱과 Windows 설치판은 동일한 병합 커밋을 사용하며, 데스크톱에서만 가능한 로컬 폴더·AI 연결 기능을 제외하면 편집 동작도 같은 코드를 사용합니다.

---

## 가장 큰 변화 — 교과서 PDF를 텍스트로 찾고 그림만 골라 씁니다

로컬 이미지·PDF 폴더를 연결하면 PDF.js가 문서의 본문을 페이지별로 분석합니다. 검색어를 입력하면 파일명만 찾는 것이 아니라 실제 페이지 텍스트를 기준으로 관련도를 계산하고, 유사도가 높은 페이지부터 보여줍니다.

검색 작업 공간은 교과서 그림을 중심으로 다시 구성했습니다.

- 왼쪽에는 선택한 PDF 페이지를 가능한 크게 표시합니다.
- 오른쪽에는 페이지 번호, 유사도와 본문 일부로 구성된 텍스트 결과 목록을 둡니다.
- 결과를 클릭하면 해당 페이지가 왼쪽 큰 화면에 열립니다.
- 검색 결과에 작은 PDF 미리보기를 반복해서 표시하지 않아 본문 목록을 더 빠르게 훑을 수 있습니다.
- 선택한 페이지에서 **영역 크롭**을 누르고 필요한 그림만 드래그해 지정할 수 있습니다.
- 지정한 영역은 실제 화면에 렌더링된 이미지 좌표를 기준으로 잘라 AI 참고 이미지에 전달합니다.

웹에서는 브라우저의 폴더 선택 권한으로, Windows 설치판에서는 데스크톱 브리지로 같은 검색 화면을 사용합니다. PDF 본문과 원본 파일은 외부 검색 서버로 올리지 않고 기기 안에서 분석합니다.

### PDF 검색의 한계

- 현재 검색은 PDF에 포함된 텍스트 레이어를 사용합니다. 스캔 이미지로만 구성된 PDF는 OCR을 거치지 않으므로 본문 검색 결과가 없을 수 있습니다.
- 암호화됐거나 손상된 PDF, 브라우저가 읽을 수 없는 특수 형식은 분석되지 않을 수 있습니다.
- 웹 브라우저는 보안 정책상 새 세션에서 로컬 폴더 권한을 다시 요청할 수 있습니다.
- 큰 교과서는 처음 연결할 때 페이지 분석 시간이 필요하지만, 분석 중인 페이지 수와 진행 상태를 표시합니다.

## 크롭한 교과서 장면을 AI 편집으로 바로 넘깁니다

PDF 페이지 전체를 참고 자료로 보내는 대신 시험에 사용할 그림 부분만 선택할 수 있습니다. 선택 바깥은 어둡게 표시되고, 확정하면 선택 영역만 참고 이미지 카드로 만들어집니다.

- 크롭 사각형과 실제 결과가 어긋나지 않도록 `<img>`의 렌더링 경계를 기준으로 좌표를 정규화했습니다.
- 1280×720 작업 화면에서도 참고 카드와 하단 조작부가 잘리지 않도록 미리보기 높이를 조정했습니다.
- 잘라낸 이미지의 출처 파일명과 페이지 번호를 참고 정보로 유지합니다.
- 크롭 결과는 기존 AI 참고 이미지·영역 코멘트·비교 작업 흐름에서 그대로 사용할 수 있습니다.
- PNG 밀도 메타데이터 유틸리티의 모듈 내보내기를 정리해 데스크톱 MCP 브리지가 안정적으로 시작되도록 수정했습니다.

AI 생성 결과는 자동 정답이 아닙니다. 교과서 그림을 변형한 뒤에는 구조, 연결 관계, 화살표 방향, 단위와 과학적 의미를 사용자가 다시 확인해야 합니다.

## AI 작업 — 품질 모드와 병렬 탭

v1.5.0 이후 AI 이미지 작업대에는 요청 복잡도와 작업 수를 직접 관리하는 기능이 쌓였습니다.

### 단순·보통·복잡 품질 모드

- **단순**은 구조가 명확하고 빠르게 처리할 수 있는 요청에 사용합니다.
- **보통**은 일반적인 교과서 그림 변환의 기본값입니다.
- **복잡**은 참고 구조 보존과 교정 단계를 더 엄격하게 적용합니다.
- 그림형과 완성형의 출력 규칙을 분리하고, 그림형에서는 불필요한 글자·숫자·라벨 생성을 억제합니다.

### 최대 5개의 독립 작업 탭

- AI 작업을 최대 5개 탭에서 동시에 진행할 수 있습니다.
- 각 탭은 요청, 진행 상태, 결과와 취소 대상을 독립적으로 관리합니다.
- 한 탭의 늦은 토큰 사용량 갱신이나 이미지 이벤트가 다른 탭의 결과를 덮지 않도록 이벤트를 작업별로 연결합니다.
- 이미지가 완성된 뒤 해당 렌더 작업만 종료하고 다음 요청이 잠기지 않도록 복구 절차를 보강했습니다.

온라인 이미지, 기출문제, 로컬 이미지·PDF 검색은 같은 참고 자료 선택 창으로 이어집니다. 라이브러리를 닫아도 AI 작업대와 기존 참고 이미지는 유지됩니다.

## 시험 그래프 — 이미지가 아니라 다시 편집 가능한 5E 객체로

산점도, 꺾은선, 막대, 원그래프와 여러 평가원식 보조 표기를 네이티브 5E 장면으로 생성하는 그래프 파이프라인을 추가했습니다. 결과를 한 장의 래스터 이미지로 고정하지 않고 좌표평면, 곡선, 점, 막대, 라벨과 보조선을 각각 편집 가능한 객체로 보존합니다.

지원 범위에는 다음 요소가 포함됩니다.

- 다중 곡선과 직접 라벨, 표시점, 산점도
- 막대그래프, 원그래프, 면적 채움과 음영 구간
- 격자, 눈금, 축 제목, 축 생략 표시와 이중 y축
- 수선·가이드 점선, 범위 막대, 치수선과 지시선
- 다중 패널 번호, 회전 라벨과 분수형 축 표기
- 정밀 곡선의 베지어 제어점과 재편집용 수학 좌표

자동 감사에서는 기출 그래프 **275개 그림의 314개 패널**을 분류했고, 구조 커버리지와 구조 충실도 검사를 통과했습니다. 별도 네이티브 그래프 테스트는 34/34가 통과했습니다.

다만 이 수치는 모든 그래프가 사람의 픽셀 단위 비교 승인을 마쳤다는 뜻은 아닙니다. 자동 구조 검증과 실제 원본 대조는 구분해서 관리하며, 시각 fixture 승인이 없는 항목은 계속 검토 대상입니다.

## 편집기와 데스크톱 안정화

기능 통합 과정에서 화면에는 보이지 않거나 이전 캐시 때문에 도달할 수 없던 기능도 복원했습니다.

- 왼쪽 도구 패널의 `자르기 / 지연 자르기 / 지우개` 선택 팝오버 복원
- 지연 자르기 모드 탭, 확정 패널과 `Ctrl+E` 단축키 연결 복구
- `tools.js`, `cut-tool.js`, `tool-hint.js`와 공통 CSS 캐시 키 정렬
- 기존 설치 사용자 프로필에서도 최신 모듈이 로드되도록 캐시 무효화 보강
- 도구 패널과 5E 앱 아이콘 복원
- 로컬 MCP 서버 중복 실행을 방지하고 상태 확인용 health 경로 추가
- 개발용 레거시 배치 실행 파일을 정리하고 현재 실행 경로를 단일화

## 웹앱과 Windows 설치판을 같은 기준으로 배포합니다

과거에는 GitHub Pages의 코드와 Windows Release 설치본이 서로 다른 브랜치 또는 버전을 가리켜, 한쪽에서 고친 문제가 다른 쪽에 남는 일이 있었습니다. v1.5.8에서는 다음 기준으로 정리했습니다.

- GitHub Pages와 Windows 설치본 모두 `main`의 동일한 병합 커밋에서 생성합니다.
- `package.json`, lockfile, 화면 하단 버전, 데스크톱 로그와 설치 파일명을 하나의 릴리스 번호로 맞춥니다.
- Windows 패키징은 `--publish never`로 로컬 빌드의 암묵적 업로드를 막고, 태그 전용 워크플로만 Release를 게시합니다.
- CI가 단위 테스트를 통과한 뒤에만 NSIS 설치 파일과 `SHA256SUMS.txt`를 만듭니다.
- Node.js 20 Windows CI에서 PDF.js가 브라우저 렌더링 타입을 요구하던 테스트 초기화 문제를 보완했습니다.

`v1.5.7` 태그에서는 마지막 항목이 발견되어 공식 GitHub Release가 만들어지지 않았습니다. 태그를 덮어쓰지 않고 수정 커밋을 추가한 `v1.5.8`을 새로 발행했습니다.

## 업그레이드 안내

1. 웹판은 새로고침합니다. 이전 모듈이 남아 있으면 `Ctrl+F5`로 강력 새로고침합니다.
2. Windows판은 실행 중인 5E를 종료한 뒤 `5E Setup 1.5.8.exe`를 설치합니다.
3. 기존 `.5e` 프로젝트 파일은 그대로 열 수 있습니다.
4. AI 기능을 사용하려면 데스크톱판과 Codex 로그인이 필요합니다. 편집·저장·내보내기와 웹 로컬 폴더 검색은 AI 없이도 사용할 수 있습니다.
5. 설치 파일의 SHA-256은 `04d30dacf9b3dd8e63889872527f69a95a96106dc7d4e709ab933dd55de65487`입니다.

v1.5.8은 단순히 PDF를 열어 보는 판이 아니라, **교과서에서 필요한 내용을 검색하고, 큰 화면에서 확인하고, 시험에 쓸 부분만 잘라 AI와 5E 편집기로 이어 가는 판**입니다.
