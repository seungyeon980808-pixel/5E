# 5E v1.6.1

- 정식 1.6 버전의 소스와 실행 경로를 정리했습니다.
- PDF 페이지를 넘길 때 불필요한 이전 페이지 이미지가 캐시에 남는 문제를 수정했습니다.
- 배포 전 검사를 통과한 동일 파일만 배포하도록 검증 절차를 추가했습니다.
- 화면에서 확인하는 소스 커밋을 실제 배포 파일의 출처와 맞췄습니다.

기존 편집·AI 작업 방식은 유지하며, 1.7.0 프리뷰와 기존 1.6.0 고정 주소는 보존합니다. 설치판의 서명·실기기 검증 등 기존 출시 보류 항목은 유지합니다.
