# 과학 도식 PNG 검수 명세 v1

## 지위와 적용 범위
- 2026-09-07 사용자 승인: 흰 배경 PNG, 구조 보존, 원본의 검정 표면색 복제 금지, 독립 검수 후 명확한 오류에만 교정 최대 1회.
- **평가원 공식 제작 규정이 아니라 5E 제품의 내부 명세**다. 공식 문제지 도판은 표현 사례의 근거이며 전체 평가원 스타일을 대표하지 않는다.
- 대상은 diagram+raster. complete/asset/SVG 엔진과 OCR·객체화·조판은 별도다. PNG 후처리·투명화·팔레트 양자화는 하지 않는다.
- 생성 1회 + 독립 검수. 명확히 실패하면 교정 생성 1회 + 독립 재검수. 판단 불가·전송 오류를 이유로 무한 반복하지 않는다.

## 충돌 해결 순서
1. 원본에서 보이는 과학적 구조와 사용자가 확정한 내용.
2. 입력별 보존 목록: 객체 종류·개수·안팎·연결·액체 점유 영역·상태·잘린 구도.
3. 아래 유형별 표현 규칙.
4. 장식 제거와 출력 형식.
- 장식 제거를 이유로 작은 객체·액체 경계·관·도선을 삭제하지 않는다.
- '검정 제거'는 물체 표면의 큰 검정 채움에 적용한다. 구조 윤곽선·의미 있는 점·그림자 자체가 과학적 대상인 경우는 삭제하지 않는다.
- 과거 지침의 모든 화살표 삭제·그림자 무조건 삭제·고정 회색 면적 상한은 입력의 의미와 충돌하면 보편적 규칙으로 사용하지 않는다. 주석 지시선은 제거하되 실제 경계·관·도선은 보존한다.

## 입력별 보존 목록
생성자는 같은 요청 안에서 목록을 정리한다. 별도 질문·파일 탐색·OCR 파이프라인을 추가하지 않는다.
- 대상과 유형: 실험 장치 / 용기·액체 / 회로·경로 / 생물 구조 / 자연물 / 기타.
- 객체: 보이는 종류, 영역별 개수, 서로 구별되는 작은 독립 요소.
- 공간: A 안에 B, A 바깥에 액체, 겹침·접촉·이격, 부분 잘림.
- 연결: 시작·중간 접속·끝점. 익숙한 실험의 일반적인 형태로 추측하지 않는다.
- 상태: 층 수와 순서, 액체가 차지하는 용기 및 높이, 빈 영역, 패널별 차이.
- 불확실성: 원본 해상도·가림 때문에 판정할 수 없는 항목은 불확실로 남긴다.

## 검수 방식
- 별도 문맥의 검수자에게 원본, 후보 결과, 사용자 요청과 명세를 전달한다. 생성자의 '완성됐다'는 설명은 합격 근거가 아니다.
- 필수 구조 항목: 객체 종류/개수, 연결/접촉, 포함/겹침, 액체층/상태, 상대배치/패널, 추가/누락.
- 필수 표현 항목: 불필요한 검정 면, 회색의 정보 역할, 질감/광택, 불필요한 문자/주석, 가독성.
- 각 항목은 pass/fail/uncertain 및 관찰 근거를 갖는다. 점수 평균으로 구조 오류를 상쇄하지 않는다.
- pass: 필수 항목 모두 확인되어 통과. fail: 구체적인 오류를 원본과 대조하여 확인. uncertain: 자료 부족·상충·불완전 응답으로 확정 불가.
- 올바른 JSON 모양만으로 그림을 합격시키지 않는다. 빈 점검표·누락 항목·잘못된 상태·서술과 판정의 모순은 보수적으로 확인 필요.
- 교정은 오류 목록에 한정하지만 다른 부분이 유지된다고 보장하지 않는다. 결과 전체를 다시 원본과 대조한다.
- 초안과 교정본은 둘 다 보존. 최신 결과가 자동으로 더 좋은 결과인 것은 아니다.

## 결정적 검사와 한계
- PNG 형식·크기·알파·RGB 채널 편차는 코드로 측정한다. 이미지 픽셀을 수정하지 않는다.
- 픽셀 통계는 액체의 위치·세포 종류·과학적 의미를 판정하지 못한다.
- 검정 픽셀 비율만으로 선과 검정 면을 구별하지 못한다. 가장자리 비백색만으로 배경 불량을 확정하지 않는다(잘린 물체가 가장자리에 닿을 수 있음).
- 완전한 R=G=B와 순백색 픽셀 계약은 생성 모델만으로 보장하지 않는다. 실제 측정값과 육안 품질을 별도로 보고한다.
- '자동 검수 통과'는 AI가 수행한 검사 결과이며 사람 검토·공식 승인 또는 무오류 보증이 아니다.

## 회귀 사례와 평가 계획
1. 시험관: 뚜껑·층 수·층 순서·비율, 색의 회색 치환과 회색 손실 확인.
2. 증류: 바깥 용기의 원래 액체 영역과 안쪽 용기를 구별. 검정 가열판을 검정 면으로 복제하지 않음.
3. 혈관: 원본 크롭 그대로 사용, 작은 독립 혈소판 수·세포 종류·잘린 구도 유지, 조직 질감 억제.
- 위 3건은 알려진 오류 회귀용이다. 이후 처음 보는 실제 입력을 별도 평가해야 일반화 가능성을 논할 수 있다.
- 모델 비교: Sol medium 생성/Sol high 검수와 Luna medium 생성/Sol high 검수를 동일 입력·동일 지침에서 비교. 첫 생성 시간, 검수 시간, 추가 생성 수, 오류 탐지/누락, 최종 채택 시간 기록.
- 중단·실패 시간을 누락한 속도 향상 주장을 금지. 아직 3입력에서 최고 조합이나 평균 절감률을 확정하지 않는다.

## 코멘트 수정의 추가 계약 (2026-09-07)
- 별도 변경 금지 표시는 제공하지 않는다. 지정한 변경 외 구조·객체·연결·액체·위치·선 의미 보존이 기본이다.
- 생성 요청에는 원본과 선택 후보 버전의 점/영역 코멘트만 포함한다. 과거 후보 코멘트를 새 요청에 자동 재적용하지 않는다.
- 독립 검수에 원본·새 후보·수정 전 선택 버전을 구분해서 전달한다. 수정 전 버전은 비교 기준이지 추가 객체/패널이 아니다.
- 필수 gate에 request-scope(요청 반영·요청 외 보존)를 추가하여 총 8개다. 누락된 이전 7-gate 보고서는 자동 pass로 재사용하지 않는다.
- 사용자가 명시한 의도적 개수/위치/연결 변경은 허용하되 요청 밖 변경은 실패로 판단한다. 코멘트별 독립 완료 배지가 아니라 요청 단위 검수이며 실제 정확도는 별도 실사용 검증 대상이다.
