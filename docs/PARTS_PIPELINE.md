# 삽화 부품 만드는 법 — 그리지 말고 기출에서 오려라 (2026-07-31)

## 왜

손·사람·차량 같은 삽화는 **그려서는 안 된다.** 2026-07-31 세션에서 손을 직접 그려 봤고,
결과는 폐기됐다. 대신 확인한 사실:

> **기출 원본 PDF 안에 같은 그림이 600dpi 로 박혀 있다.**
> `assets/exam-library/images/*.png`(가로 979px)는 화면용 축소본이라 손 하나가 70px 이지만,
> `32_exam_pool/PDF/*.pdf` 의 원본은 같은 손이 **430px** 이다.

시험지에 실제로 인쇄되는 손은 **가로 6.1mm**다. 600dpi 원본을 그 크기로 넣으면 약 580dpi —
인쇄용으로 넉넉하다. 저작권은 정리된 사안이다(평가원 기출 · 비상업 · 교육).

## 세 단계

### ① PDF에서 도판 뽑기

```
python tools/pdf-figure-extract.py p1_2025_06            # 회차 전체
python tools/pdf-figure-extract.py p1_2025_06 --page 3   # 그 페이지만
python tools/pdf-figure-extract.py --list                # 있는 회차 보기
```

`_work/pdf-figures/<회차>/p<페이지>_<이름>.png` 로 나오고, `index.json` 에 픽셀·인쇄 mm·dpi 가 적힌다.
어느 그림이 몇 번 문항인지는 `assets/exam-library/images/` 의 축소본과 **가로세로 비율**로 맞춘다.

### ② 부품만 오려내기

```
python tools/cutout-part.py _work/pdf-figures/p1_2025_06/p3_Im1.png \
    --id hand_grip --name "쥔 손" --keywords "손,쥔 손,hand,grip" \
    --box 165:276:315:386 --erase 308:276:316:293 \
    --seal left --split 0.68 --dpi 600
```

여기서 하는 일이 셋인데, 셋 다 이유가 있다:

1. **바깥만 투명, 안쪽은 불투명.** 흰색을 전부 투명으로 만들면 뒤의 선이 손을 뚫고 보인다.
   테두리에서 시작하는 홍수 채우기로 *바깥에 이어진* 흰색만 지운다. 손가락 사이 틈처럼
   바깥과 통하는 곳은 저절로 투명해져 뒤가 비친다 — 원본과 같은 동작이다.
2. **잘린 면 봉하기(`--seal`).** 손목처럼 그림이 화면 밖으로 이어지는 쪽은 윤곽이 열려 있어
   바깥 흰색이 손 안까지 샌다. 그 면에 임시 벽을 세우고 채운 뒤 벽은 남기지 않는다.
   (안 하면 손 전체가 투명해진다 — 실제로 한 번 그렇게 됐다.)
3. **앞/뒤 두 조각(`--split`).** 물체를 쥔 그림은 한 장으로는 안 된다. 손바닥은 물체 뒤,
   손가락은 물체 앞에 있어야 쥔 것으로 보인다. 쥐는 선에서 잘라 둔다.

결과는 `assets/exam-parts/` 에 PNG 로, 치수·출처는 `manifest.json` 에 적힌다.

### ③ 그림에 넣기

```
add_part { part:"hand_grip", gripAt:{x:0,y:0}, w:12,
           between:[{ type:"rect", x:0, y:-4, w:8, h:8, fillLevel:255, labelInner:"m" }] }
```

- `gripAt` 에 **쥐는 물체의 모서리 좌표**를 주면 쥐는 선이 거기 맞는다(세로는 중심 정렬).
- `between` 에 준 객체가 뒤 조각과 앞 조각 **사이에** 들어간다 — 그리는 순서가 곧 앞뒤다.
- 크기를 안 주면 **기출 인쇄 크기 그대로**다. 시험지 도판은 작다. 키우기 전에 원본 크기를 먼저 본다.
- `part` 없이 `add_part {}` 를 부르면 쓸 수 있는 부품 목록이 온다.
