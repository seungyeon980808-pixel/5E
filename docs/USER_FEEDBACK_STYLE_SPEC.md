- 현재 생성 품질·모델·공통 변환 조건을 품질 개선 명목으로 변경하지 않는다. 다음 작업은 속도 개선 방법 조사와 영역 지정 수정·변경 부분 비교에 한정한다.
- U-010 | 사용자 절대 요구: “변경하라고 지시하지 않은 영역은 절대 수정해서는 안된다는 것입니다.”
- 구현 수용 조건: 수정 전 이미지를 불변 기준으로 두고, 사용자가 명시적으로 허용한 영역 밖의 디코딩된 RGBA 픽셀은 완전히 동일해야 한다. 캔버스 크기·좌표·투명도도 유지한다. 유사도 점수나 육안상 동일함으로 대체하지 않는다. PNG 압축 바이트 전체 동일함과는 구분한다.
- 프롬프트만으로 이 보존을 보장했다고 주장하지 않는다. 허용 영역 밖의 변화가 있거나 영역이 불명확하면 결과를 자동 반영하지 않는 fail-closed 경계가 필요하다. 임의 영역 확장·전체 재배치·전역 명암/배경/해상도 변경 금지.
- 부분 수정에서만 허용 영역 내부를 교체하고 외부는 원본 픽셀을 유지하는 합성 방식은 구현 후보다. 기존 전체 변환 PNG 후처리 금지와 구분해야 하며, 아직 이 예외를 구현하거나 사용자 승인된 구현 방식으로 간주하지 않는다.
- 변경 부분 비교는 수정 전/후 및 실제 변화 영역을 사용자가 확인하는 기능이다. 사용자 요청 밖의 변경을 자동 승인하는 기능이 아니다.
- 현재 상태: 요구사항 기록 완료. 영역 밖 픽셀 보존 강제·비교 UI·속도 개선 코드는 아직 구현하지 않음.
