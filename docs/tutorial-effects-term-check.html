요청서에 바로 쓸 수 있는 통합 문장

“클릭해야 하는 UI 요소에는 대상 강조선을 표시하고, Ctrl·Shift 입력이 필요한 단계에는 보조키 안내 배지를 표시한다. 캔버스 작업에는 작업 위치 가이드선과 목표 형상 가이드를 함께 표시하며, 사용자의 실제 동작은 유령 커서로 한 번 시연한다. 단계 설명과 진행 버튼은 코치창에 표시하고, 성공 시 완료 피드백을 보여준다.”

이 문서에서 “버튼”은 실제로 클릭하는 UI 컨트롤에만 사용하고, 파란 캡슐형 안내는 “배지”, 파란 점선 경로는 “가이드선”, 결과물의 반투명 윤곽은 “목표 형상 가이드”로 구분한다.

정적 비교용 모형입니다. 실제 구현의 대응명은 js/tutorial.js와 js/tutorial-courses.js에 정의되어 있습니다.
