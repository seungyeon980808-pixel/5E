# 원본 이미지 수동 분할

AI 이미지 변환 화면의 원본 쪽 `이미지 분할`을 엽니다. 분할할 원본을 선택한 뒤 사각형을 드래그하거나 자유 그리기로 닫힌 영역을 그립니다. 여러 영역에 이름을 붙이고 불필요한 영역을 삭제한 뒤 `새 작업으로 분할`을 누릅니다. 자유 그리기는 손을 떼면 마지막 점과 시작점을 연결합니다.

- 원본 해상도의 정수 픽셀 경계로 PNG를 추출합니다. 원본을 확대하거나 다시 생성하지 않습니다.
- 자유 그리기 바깥은 투명하게 보존합니다. 사각형 내부는 원본 RGBA 픽셀을 그대로 사용합니다.
- 영역마다 새 이미지 작업을 추가하며 원본 작업·이전 결과·코멘트·요청·표시 설정은 남깁니다.
- 기출/일반 이미지 선택은 자식 작업에도 전달합니다.
- 원본 작업 ID·원본 이미지 ID·해상도·영역 좌표를 자식 이미지의 source 메타데이터에 기록합니다.
- 기존 문서 그림 연결은 원본에 유지합니다. 자식에 같은 연결을 복제하지 않습니다.
- 원본에 인쇄된 글자는 픽셀 그대로 남습니다. 편집 라벨이나 원본 좌표의 OCR 후보를 자식에 겹쳐 붙이지 않습니다.
- 취소·Esc는 새 작업을 만들지 않습니다. 읽기 전용, 진행 중 변환, 그래프 복원 화면에서는 분할을 비활성화합니다.

한 번에 최대 32영역을 추가할 수 있습니다. 원본과 선택 영역 합계는 각각 4천만 픽셀 이하이며 너무 큰 영역은 나눠 작업합니다. 처음 버전은 개별 원본 이미지를 대상으로 합니다. 연결된 전체 원본을 다시 생성하거나 기존 문서 그림을 자동 교체하지 않습니다.
