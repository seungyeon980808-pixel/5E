# 이미지 변환 복잡도 모드 명세

## 절대 규칙

모드와 관계없이 원본의 주 객체 종류, 개수, 외곽 실루엣, 연결, 접촉, 겹침, 좌우·상하 순서와 상대 비율을 바꾸지 않는다. 같은 개념의 다른 물체나 표준 장치로 대체하지 않는다. 문자, 숫자, 라벨, 지시선, 화살표, 로고와 조판 배경은 출력 대상이 아니다.

## 사용자가 고르는 두 축

- 복잡도: `단순 / 보통 / 복잡`
- 출력 방식: `교과서 선화 / 5E 에셋`

두 축은 자동 전환하지 않는다. 교과서 선화는 이미지 결과이고, 5E 에셋은 현재 지원하는 장치만 편집 가능한 벡터 객체로 만든다. 말로 설명해 생성할 때도 사용자가 출력 방식을 직접 고른다.

## 단순 - 정밀 1회 변환

- 대상: 여백까지 타이트하게 자른 독립 물체 1개 또는 서로 붙은 물체 1~2개, 분기·교차·패널이 없는 그림.
- 처리: 원본 외곽·내부 경계·구멍·접촉점·반복 세부를 고정한 뒤 고품질 이미지 생성을 1회 수행하고 3단계 흑백 후처리를 적용한다. 거친 로컬 윤곽 추출 결과를 최종 출력으로 사용하지 않는다.
- 예상 시간: 약 20~50초. 이미지 생성 호출 1회.
- 적합 예: 암석 표본, 단일 비커, 단일 렌즈, 라벨이 없는 독립 실험 기구.
- 부적합: 본문·카드·화살표가 본체와 붙은 크롭, 해부도, 손이 포함된 사진, 여러 용기, 분기 회로.
- 안전 규칙: 삭제와 형태 보존이 충돌하면 형태를 우선한다. 남은 조판선은 5E에서 지우며, 주 객체 일부를 임의 삭제하지 않는다.
- 질감 규칙: 사진의 흐림·노이즈를 내부 구조로 발명하지 않는다. 내부선은 식별에 필요한 대표 경계만 남기고 원본 사진보다 성기게 정돈한다.

## 보통 - 구조 목록 1회 생성

- 대상: 3~12개 부품, 하나의 연결 장치, 용기·지지대·센서·액체 경계처럼 연결 순서가 짧은 그림.
- 처리: 객체 폐쇄 목록, 부품 수, 연결, 접촉, 빈 내부 영역을 먼저 고정한 뒤 이미지 생성 1회와 3단계 흑백 후처리를 수행한다.
- 예상 시간: 약 30~60초. 네트워크와 모델 상태에 따라 달라진다.
- 적합 예: 가열 장치, 증류·응축 장치, 저울과 눈금실린더, 간단한 회로, 두 상태 비교.
- 복잡으로 올리는 조건: 분기점 3개 이상, 패널 3개 이상, 반복 객체 12개 초과, 가림 순서가 3단 이상, 해부학적 내부 경계.

## 복잡 - 생성 + 구조 교정

- 대상: 심장·네프론·혈관망·기관계, 복합 배관·회로, 다중 패널, 정확한 분기와 절단면이 필요한 그림.
- 처리: 1차 생성 뒤 원본과 직전 결과를 함께 넣어 틀린 구조만 고치는 교정 패스 1회를 자동 수행한다. 최종 이미지는 3단계 팔레트로 고정한다.
- 예상 시간: 약 1~2분 이상. 이미지 생성 호출 2회.
- 통과 조건: 객체 종류·개수·연결·접촉·상태 중 하나라도 원본과 다르면 95점 통과를 금지한다. 미관이 좋아도 일반적인 해부 아이콘으로 바뀌면 실패다.
- 현재 제한: 생성 모델은 심장처럼 익숙한 대상을 원본 대신 전형적 형태로 일반화할 수 있다. 따라서 복잡 결과는 프로그램이 자동 확정하지 않고 원본 비교 후 사용한다.

## 동시 변환과 작업 탭

- 여러 장 변환: 각 참고 이미지를 독립 작업으로 만들고 최대 5개를 동시에 처리한다. 단순과 보통은 각 1회 생성, 복잡은 각 이미지마다 2회 패스를 수행한다. 10장을 등록하면 5장씩 두 묶음으로 자동 진행한다.
- 작업 탭: 탭마다 참고 이미지, 생성 결과, 대화, 요청문, 복잡도, 출력 방식을 분리한다. 여러 레퍼런스를 한 작업에 묶어 구체적으로 수정할 때 사용한다.
- 동시 변환은 많은 교과서 크롭을 같은 규칙으로 바꾸는 용도이고, 탭은 서로 다른 레퍼런스·수정 이력을 섞지 않는 용도다.

## 말로 설명해 생성

참고 이미지가 없으면 명사 한두 개를 아이콘으로 축약하지 않는다. 사용자의 설명을 `폐쇄 객체 목록 → 위치 → 연결 → 접촉 → 빈 영역 → 상태` 순으로 시각화하고, 교과서 삽화 수준의 부품 경계를 그린다. 교과서 선화와 5E 에셋은 사용자가 선택하며 자동 전환하지 않는다.

## 이미지 입력 및 검색 구조

- `이미지 불러오기`: 사용자가 고른 개별 이미지 파일을 현재 AI 작업의 참고 이미지로 추가한다.
- `이미지 검색…`: 하나의 검색 화면에서 `온라인 이미지 / 기출문제 / 로컬 폴더`를 전환한다. 로컬 폴더는 사용자가 OS 폴더 선택 창에서 직접 연결한 폴더만 읽는다.
- `화면 캡처`: 화면 영역을 캡처해 현재 AI 작업의 참고 이미지로 추가한다.
- AI 창이 열린 동안 텍스트 입력란 바깥에 이미지 클립보드를 붙여 넣으면 참고 이미지로 추가한다. AI 창이 닫혀 있으면 기존처럼 캔버스에 붙여 넣는다.
- 로컬 폴더 검색은 연결한 폴더와 하위 폴더의 이미지 파일명·상대 경로를 대상으로 한다. PDF 열기·페이지 검색은 이 흐름에 포함하지 않는다.
- 로컬 원본은 프로그램 라이브러리로 복사하지 않는다. 사용자가 선택한 파일만 변환 요청 시 읽는다.
