# 5E 1.6.0 웹 사용 가이드

기준: 정식 웹 1.6.0 · 안내 갱신: 2026-09-30

[웹에서 열기](https://www.5e.ai.kr/) · [전체 기능과 변경 내용](RELEASE_NOTES_v1.6.0.md) · [README](../README.md)

1.6.0은 웹으로 먼저 출시했습니다. Windows·Mac용 1.6.0 설치판과 로컬 PDF 폴더 연결은 준비 중입니다. 기존 설치판 v1.5.8에는 이 가이드의 라이브러리·AI 이미지 변환 작업대가 포함되지 않습니다.

## 먼저 준비하기

- 웹브라우저에서 [5e.ai.kr](https://www.5e.ai.kr/)을 엽니다.
- PDF 자료 불러오기와 AI 변환에는 인터넷 연결이 필요합니다. AI 기능은 로그인한 ChatGPT 계정의 기능과 이용 한도를 따릅니다.
- 이전 버전에서 작업 중이라면 먼저 프로젝트 파일로 저장하세요. 브라우저·웹·설치판의 자동 저장 공간은 서로 다릅니다.
- 기존 작업은 `.5e` 프로젝트 파일로 보관합니다. 이전 `.json` 프로젝트도 열 수 있습니다.

## 1. PDF에서 필요한 그림 자르기

1. 캔버스 아래의 **라이브러리**를 엽니다.
2. 검색창에 자료 이름이나 본문 검색어를 넣습니다. 웹의 기본 제공 자료는 공개 Google Drive 폴더에서 불러옵니다.
3. PDF를 열고, 검색 일치 위치 또는 쪽 이동으로 필요한 그림을 찾습니다.
4. 그림을 포함하는 영역을 드래그로 자릅니다. 미리보기에서 위치와 크기를 확인한 뒤 크롭 보관함에 추가합니다.
5. 보관함에서 보낼 그림을 고르고 **작업대에 넣기**를 누릅니다. 여러 그림을 함께 참고할 한 작업으로 묶거나, 이미지마다 별도 작업으로 나눌 수 있습니다.

한 쪽에서 여러 영역을 자르거나, 여러 PDF에서 그림을 모을 수 있습니다. 전송에 실패한 그림은 보관함에 남으므로 상태를 확인하고 다시 보냅니다.

키보드로 자르려면 Enter로 첫 영역을 만들고, 화살표로 이동합니다. Shift+화살표는 크기 조절, Shift+Enter는 다음 영역 만들기입니다. 크롭 화면의 안내에 따라 Enter·Space로 추가합니다.

## 2. 로그인하고 AI로 선화 변환하기

1. **AI 이미지 변환**에서 작업의 원본을 확인합니다. 원본 여러 장을 넣었다면 원본·표현 참고의 역할과 순서를 확인합니다.
2. ChatGPT 계정으로 기기 로그인을 시작합니다. **1. 인증 코드 복사**를 누르고, **2. OpenAI 인증하기 →**에서 코드를 붙여 넣어 인증합니다.
3. 사용할 모델·사고 수준·속도를 고릅니다. 목록과 설정은 계정 및 연결된 서버에서 제공하는 범위에 따라 달라집니다.
4. 필요한 요청을 입력하고 **변환**을 누릅니다. 그림을 넣는 것만으로 변환이 시작되지는 않습니다.
5. 완료된 PNG를 원본과 비교합니다. 물체 수, 배치, 비율, 연결 관계와 과학적 표현을 확인합니다.

여러 작업을 골라 동시에 실행할 수 있습니다. 작업별 경과 시간과 대기 상태를 확인하세요. 예시 이미지의 변환 시간과 품질은 다른 모델·원본·서버 상황에서 달라질 수 있습니다.

## 3. 원본과 비교하고 필요한 부분 고치기

- **나란히 보기**는 원본과 결과를 좌우에 놓습니다.
- **겹쳐 보기**는 경계선을 움직여 같은 위치의 원본과 결과를 비교합니다.
- 고칠 부분에 점이나 영역 코멘트를 남기고 부분 수정을 요청합니다.
- 수정 후보를 원래 결과와 비교한 뒤 적용하거나 버립니다. 적용 전에 지정한 수정 영역이 의도한 부분을 포함하는지 확인하세요.

AI가 원본의 과학적 표현을 항상 정확하게 유지하지는 않습니다. 시험지에 사용하기 전에 원본과 결과를 확인합니다.

## 4. 배경·색·선 굵기와 물체별 분리

| 설정 | 사용 방법 |
|---|---|
| 배경 | 원본 유지, 외부 배경 제거, 모든 흰색 제거 중에서 선택합니다. 모든 흰색 제거는 그림 내부의 흰 영역도 투명하게 만듭니다. |
| 색상 | 원본 색상 또는 무채색을 선택합니다. |
| 선 굵기 | 원본, +1px, +2px 중에서 선택하고 미리보기를 확인합니다. |
| 객체 분리 | 자동 감지, 격자 기준 또는 직접 지정으로 나눈 영역을 확인하고 조정합니다. |

이 후처리는 브라우저에서 수행합니다. 설정을 바꾸는 것만으로 AI를 다시 호출하지 않습니다.

물체별 분리는 투명 PNG로 나누는 이미지 분리입니다. 내부 선을 벡터로 바꾸는 기능은 아닙니다. 맞닿거나 겹친 물체는 함께 나뉠 수 있으므로 분리 영역을 확인하세요.

## 5. 캔버스에 넣고 라벨 붙이기

1. 처리 결과를 확인하고 **캔버스에 삽입**을 누릅니다.
2. 캔버스에서 이미지의 위치와 크기를 조정합니다.
3. 라벨러로 지시선과 (가)(나)(다) 같은 표기를 붙입니다. 확대경을 이용해 지시선 시작점을 정확하게 정할 수 있습니다.
4. 그림과 라벨이 겹치거나 잘리지 않는지 확인합니다.

## 6. 프로젝트 저장과 시험지용 이미지 내보내기

| 목적 | 저장할 것 |
|---|---|
| 나중에 이어서 편집 | `.5e` 프로젝트 파일 |
| 시험지·학습지에 그림 넣기 | PNG 또는 SVG |
| 여러 결과를 한꺼번에 보관 | ZIP 내보내기 |

PNG·SVG 내보내기와 프로젝트 저장은 서로 다른 기능입니다. 내보낸 이미지와 별도로 프로젝트 파일을 저장해 두세요. AI 결과는 PNG 이미지이므로 SVG로 내보내도 그 이미지 내부의 선이 자동으로 편집 가능한 벡터가 되지는 않습니다.

브라우저에 따라 저장 위치 선택창 또는 다운로드로 저장됩니다. 저장 후 실제 파일이 생성됐는지 확인합니다.

## 자동 저장 실패와 복구

**자동 저장에 실패했습니다**가 나오면 창을 닫기 전에 프로젝트 파일로 즉시 저장합니다. 자동 저장은 다시 시도하지만, 복구할 수 있는 범위는 마지막으로 저장에 성공한 내용까지입니다.

다음에 **작업 복구** 창이 열리면 보관된 작업을 골라 복구합니다. Esc나 창 바깥을 눌러 닫는 것은 **나중에 결정**입니다. 새로 시작은 해당 버튼을 직접 눌러 선택합니다.

## 동료에게 작업 공유하기

작업 공유 링크는 보기 전용 또는 편집 가능한 복사본으로 만들 수 있습니다. 복사본을 받은 사람이 수정해도 원래 작업은 바뀌지 않습니다.

- 링크는 최대 1시간 동안 유지되며, 서버가 다시 시작되면 더 일찍 사라질 수 있습니다.
- 만료된 링크는 브라우저에 남은 작업에서 새로 만들어 전달합니다. 재로그인으로 이전 링크가 복원되지는 않습니다.
- **공유 중지**로 링크를 중지할 수 있습니다. 장기 보관과 전달에는 프로젝트 파일을 사용하세요.

## 문제가 생겼을 때

| 증상 | 다음 조치 |
|---|---|
| 인증 팝업이 차단됨 | 해당 사이트의 팝업을 허용하고 **2. OpenAI 인증하기 →**를 다시 누릅니다. |
| 로그인 시간이 만료되거나 연결이 끊김 | **다시 로그인**에서 새 코드로 인증합니다. |
| 변환 실패 | 남아 있는 원본·요청·코멘트를 확인하고 **로그 보기**에서 원인을 확인합니다. 재실행은 직접 선택합니다. |
| 원하는 모델이 목록에 없음 | **모델 목록 새로고침** 후 사용 가능한 모델을 고릅니다. |
| 제공 자료 연결 실패 | 네트워크를 확인하고 **다시 시도**를 누릅니다. |
| 자동 분리가 원하는 영역과 다름 | 격자 기준 또는 직접 지정으로 분리 영역을 조정합니다. |

상세한 연결·데이터 안내는 [README의 데이터 안내](../README.md#user-content-내-데이터는-어디로-가나요)와 문제 해결 부분을 참고하세요. 교과서·기출 자료는 각 저작권자의 이용 조건을 따릅니다.
