# 엑셀과 한글을 하나의 문항으로 관리

2026-10-14 사용자 요청: 데이터 시트와 한글 문항이 거의 한몸처럼 작동해야 한다. 사용자가 범위를 명확히 했다: 한글로 출력하면 작업이 끝나며, 외부 한글 수정의 시트 역반영은 현재 필수 범위가 아니다.

## 현재 확인된 동작

시트의 문항 구조와 내용을 편집 가능한 한글 문서로 조판하고, 실제 한글 엔진으로 렌더링한다. 조판 저장 시 원래 글·수식·그림과 일치하는지 확인하며, HWPX로 재열기한 문서의 배치와도 비교한다. 현재 한글 조판 화면에서 본문 내용을 바꾸면 시트 내용과 달라졌다는 이유로 저장을 차단한다. 따라서 양방향 내용 편집은 아직 완성된 상태가 아니다.

## 확정한 구현 방향

같은 문항 ID 아래에 내용·구조·조판 서식을 함께 보관한다. 사용자의 추가 설명에 따라 도구 안의 시트와 한글 문항 화면 모두에서 내용을 수정하는 것을 목표로 한다. 외부 한글 파일의 수정 내용을 되가져오는 기능과는 별개의 요구다. 사용자가 만족한 문항을 편집 가능한 한글 파일로 내보낸 뒤에는 역반영을 요구하지 않는다.

- 시트의 발문·자료·보기·선지를 바꾸면 해당 문항의 렌더링을 갱신한다. 기존 조판 서식을 유지할 수 있는 부분과 다시 배치해야 하는 부분을 구분한다.
- 문항 내용은 시트와 도구 안의 한글 문항 화면 양쪽에서 수정할 수 있도록 연결한다. 글꼴·자간·내어쓰기·표·그림 배치 등 조판도 문항 화면에서 조정한다. 표 안의 자료, 보기, 그림 선지처럼 구조가 있는 항목도 대응 위치를 명확히 유지한다. 현재 한글 화면의 내용 변경 저장을 차단하는 동작은 이 목표를 구현한 것이 아니다.
- 글꼴·크기·자간·내어쓰기·표 여백·그림 배치 같은 조판 설정은 같은 문항에 저장한다. 시트 내용 편집 때문에 사용자가 승인한 서식을 무조건 초기화하지 않는다.
- XLSX 왕복 시 문항 ID와 구조 및 조판 정보를 잃지 않도록 검증한다. HWPX는 같은 문항에서 만들어지는 편집 가능한 출력이다.
- 변경 전 내용과 승인한 조판을 보존한다. 두 화면의 변경이 충돌하거나 문항 구조를 판별하지 못하면 덮어쓰지 않고 사용자가 확인할 수 있게 한다.
- 갱신된 배치는 글 겹침·셀 및 단 너비 넘침·출력 재열기 차이를 검사한다. 검사에 실패한 모양을 승인된 조판으로 저장하지 않는다.

## 우선 작업: 문항 한 개를 위한 좁은 한글 용지

사용자는 전체 시험지를 모두 출력하여 완성된 시험지로 보는 기능을 후순위로 지정했다. 우선 한글 문서의 실제 용지 좌우 너비를 줄여 한 문항만 편집하고 렌더링한다. 확대율만 바꾸거나 A4 화면을 잘라 보이는 방식으로 대체하지 않는다.

- 문항의 본문 폭은 기준 시험지 한 단의 폭과 같게 한다. 현재 A4 2단, 좌우 여백 15mm, 단 간격 8mm 기준으로 한 단은 86mm다. 예를 들어 좁은 용지에 좌우 3mm 여백을 두면 용지 폭은 92mm가 된다. 이 규격을 실제 문항 용지에 적용하고 HWPX 재열기로 검수했다.
- 한 문항 용지는 1단으로 구성한다. 글자 크기를 축소하지 않고 같은 본문 폭에서 글·표·수식·그림의 배치를 확인한다.
- 한 문항은 시트의 한 열과 연결한다. 문항 ID와 열의 대응은 용지 높이 또는 실제 페이지 수에 따라 바뀌지 않는다.
- 고정된 높이의 한 페이지로 내용을 제한하지 않는다. 문항 편집 영역은 내용에 따라 높이가 늘어나고 세로로 스크롤하며, 지문·표·그림·보기·선지를 같은 문항으로 유지한다.
- 기준 시험지 한 단의 출력 가능 높이를 가이드로 표시한다. 이를 넘으면 출력 기준 높이 초과를 안내하고 사용자가 분량이나 배치를 조정한다. 자동 글자 축소, 내용 잘라내기 또는 데이터 삭제로 한 페이지에 맞추지 않는다.
- 기준 시험지 규격과 문항 편집용 용지 규격을 구분하여 보관한다. 나중에 전체 시험지에 넣을 때 같은 단 폭을 사용해 줄바꿈과 문항 배치를 유지하도록 검수한다.
- 사용자 선택은 문항 단위로 제한하고, 문항 화면과 시트의 항목 대응 정보를 유지한다. 자유로운 한글 새 문서 전체를 즉시 시트 구조로 변환하는 기능은 현재 우선 작업에 포함하지 않는다.

기존 저장 검수는 A4·B4·A3 원본 용지만 허용하므로, 좁은 용지를 구현할 때 용지 생성·프로필 변경·저장·재열기 검수·문항 전달의 규격 처리도 함께 수정해야 한다. 단순히 화면의 종이 폭만 줄여 저장이 실패하거나 줄바꿈이 달라지는 상태로 끝내서는 안 된다.

## 현재 제외한 범위와 향후 확장

외부 한글에서 내용을 수정한 HWPX를 다시 올려 시트로 반영하는 기능과, 외부 Excel·한글 앱 간 실시간 동기화는 현재 범위에서 제외한다. 출력된 한글의 글·표·그림은 편집 가능한 상태를 유지한다. 전체 시험지 조립과 완성 시험지 보기는 후순위다.

향후 역반영을 검토할 수 있도록 문항 ID 및 발문·자료·보기·선지의 구성 ID와 구조 정보는 원본에서 유지한다. 다만 한글에서 문단을 합치거나 표를 재구성하면 원래 항목과의 대응이 모호해질 수 있으므로, 모든 자유 편집을 자동으로 되가져올 수 있다고 보장하지 않는다. 현 단계의 우선순위는 출력 전 조판 안정성과 XLSX 왕복 시 구조·내용·조판 정보의 보존이다.

2026-10-14 20:26 KST: 실행 환경 복구 후 좁은 문항 용지, 자동 높이, 출력 높이 가이드, 높이 초과 안내 및 초과 문항 저장을 구현했다. 문항 ID와 한 열의 연결을 유지한다. 렌더러의 과도한 단일 캔버스 크기를 피하려고 실제 용지 높이 1200mm를 넘는 문항은 다음 페이지로 이어지지만 내용과 문항 ID는 그대로 유지한다. 한 페이지 분량으로 입력을 제한하지 않는다.

기준 시험지 프로필과 실제 문항 용지·1단·높이를 각각 보관하고 XLSX 왕복에서도 유지한다. 이전 버전의 승인한 조판은 HTML로 다시 만들지 않고 네이티브 문서를 변환하여 글꼴·자간·표·수식·그림을 보존한다. 규격을 바꾸면 엔진의 메모리에 남은 표 배치 때문에 겹치는 문제가 있어, 새 규격을 화면 밖에서 재열기·검수한 뒤 표시한다. HWPX 저장 시 명시적 줄바꿈의 줄 높이 정보도 보존하여 발문과 그림 선지가 겹치지 않게 한다.

## 시트 옆 조판 패널 — 2026-10-14

전체 화면 대화상자를 시트 오른쪽의 500px 패널로 바꿨다. 일반 화면에서는 한글의 메뉴·리본·눈금자를 접고 문항 용지가 패널 너비를 채우도록 화면 확대율만 맞춘다. 실제 용지 폭·글자 크기·HWPX 배치는 이 화면 조절로 바뀌지 않는다. 좁은 화면에서는 시트 아래에 패널을 배치한다. `상세 조판`으로 전체 도구와 기준 시험지 설정을 펼치고, `크게 보기`로 넓게 편집할 수 있다.

문항 안을 클릭하면 문단·내어쓰기 도구가 나타난다. 글자 모양은 글을 드래그하여 선택한 뒤 사용할 수 있고, 표를 선택한 경우 표 위치·크기 조절 잠금 도구를 표시한다. 기본 표 잠금과 저장 전 배치·재열기 검수는 유지한다.

보기 본문은 네이티브 글꼴의 실제 글자 너비로 줄을 정하고, 이어지는 줄에만 ㄱ. 등의 기호 너비를 제외한다. 본문 좌우 6px, 위 3px, 아래 4px를 기본으로 하며 마지막 줄 아래에 불필요한 한 줄 간격을 추가하지 않는다. 중첩 보기는 엔진의 상위 셀 높이 계산을 고려해 3px를 더 확보한다. 제목·가느다란 테두리·내어쓰기는 유지한다. 저장 버전 9·10의 문서도 기존 문서에서 보기 부분만 정리하며, 혼합 글자 서식·보기 안의 수식·그림이 있는 문단은 원래 조판을 유지한다. 새 저장 버전은 11이다.

문항을 바꾸거나 패널을 닫을 때 저장 전 조판 변경을 먼저 검수하여 원래 문항 ID에 저장한다. 빠르게 열을 바꾸면 마지막 선택을 표시하고, 진행 중인 용지 규격 변경이 끝난 뒤 저장·전환한다. 시트 내용을 편집하면 자동 재생성 대신 `문항 새로고침`을 표시한다. 저장 전 조판과 시트 내용이 동시에 변경되면 덮어쓰지 않고 안내한다. 한글 화면의 내용 변경을 시트 항목으로 역반영하는 기능은 여전히 남은 작업이다.
