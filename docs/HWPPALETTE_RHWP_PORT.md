Windows 한글 COM 제어를 rhwp의 실제 한글 문서 API로 바꾸었다. 원본 HWP 조각과 서식·기호·문법 데이터를 함께 제공한다. HTML로 시험지를 흉내 내는 방식이 아니며, 결과는 HWP/HWPX의 편집 가능한 문단·표·수식·그림이다. 원래 5E의 그림 원본 편집과 프로젝트 저장 흐름을 사용한다.

## 사용 순서

1. 시험지를 열면 왼쪽에 조판 팔레트가 표시된다.
2. 기본 학교/수능 팔레트의 문항 틀을 눌러 빈칸을 채우거나, 마크다운/문항 엑셀을 변환한다.
3. 자주 쓰는 문자·서식·조각은 물감 창고에 등록하고 팔레트로 끌어 놓는다.
4. 기존 시험지를 재사용하려면 문서 해체에서 문단·표를 저장한다. 조각의 `\이름\` / `\`는 빈칸이고, 양식의 `\본문\`는 작성 시작 위치다.
5. 각주·미주는 팔레트 설정의 **도구**에서 넣는다. 삭제할 때는 해당 각주·미주 안에 커서를 놓고 **각주·미주 삭제**를 누른다. 머리말·꼬리말은 rhwp에서 편집 모드로 들어간 뒤 같은 팔레트를 사용한다.
6. 그림은 5E 원본 편집 흐름 또는 팔레트의 사진 연결을 사용한다. 프로젝트 `.5e`와 한글 `.hwp` / `.hwpx` 저장은 기존 파일 메뉴를 사용한다.

구버전 자료는 **기존 설정 가져오기**에서 `config.json`, `library.json`과 참조하는 HWP/HWPX 조각을 함께 선택하거나, 이 파일들을 포함한 ZIP으로 가져온다. 칩은 별도 **칩 가져오기**를 사용한다. 이전 프로그램의 사진 폴더 경로는 브라우저가 임의로 읽을 수 없으므로 **사진 폴더 연결**에서 다시 고른다. 연결한 그림은 이 브라우저에 보관하며 원본 폴더 변경은 다시 연결해야 반영된다.

## 구현과 보존

- `catalog.js`: 원본 카탈로그와 기본 조판·엑셀 메타데이터.
- `parser.js`: 원본 순서·슬롯·꾸러미·서식 토큰 문법; 5E 수식 토큰 추가.
- `model.js`: 팔레트·라이브러리, 기존 설정 변환, 칩, 직렬 저장·복구.
- `native.js`: 본문·셀·머리말·꼬리말·각주·미주 문서 조작, 리소스 포함 조각 가져오기, 원자적 취소.
- `subdocuments.js`: 머리말·꼬리말·각주·미주를 분리한 HWPX에서 편집한 뒤 원래 영역으로 복원; 문서 핸들을 교체해도 native 취소 기록의 소유권 유지.
- `hwpx-import.js`: native 문단 가져오기가 거절하는 각주·번호 문단의 글꼴·서식·그림 리소스 병합과 참조 재배치.
- `rhwp-exam-bridge.js` / `rhwp-exam-workspace.js`: 머리말·꼬리말 그림의 파일 열기, 목록, 원본 데이터, 그림 교체와 5E 편집 연결.
- `workbook.js`: OOXML XLSX/XLSM 읽기·쓰기와 기존 템플릿 연결.
- `image.js`: 물리 크기와 로컬 OpenCV 변환.
- `ui.js` / `hwp-palette.css`: 기존 시험지 패널에 붙는 팔레트와 창고.

비동기로 파일이나 그림을 준비하는 동안 문서가 바뀌면 위치 토큰을 확인하고 삽입을 중단한다. 조판 중 오류는 문서 스냅샷으로 되돌린다. 칩·설정 가져오기는 원본 파일을 수정하지 않는다. 라이브러리의 꾸러미에서 참조하는 조각은 삭제를 막는다. 중첩 문단 서식은 원본 문단을 HWPX로 준비해 리소스를 가져오고, 본문 내용과 머리말·용지 설정을 보존하여 적용한다. 머리말의 직렬화 순서와 native 컨트롤 순서가 다른 경우 실제 native 인덱스를 사용한다. 일부 중첩 그림의 화면 경로가 생략되는 경우 native 원본 리소스 키와 HWPX 전체 셀 경로를 대응한다.

머리말·꼬리말과 각주·미주 조판은 준비된 분리 문서에서 완료하고 native 파서로 다시 검증한 뒤 반영한다. 일반 타이핑은 기존 native 편집 경로를 유지한다. 스냅샷은 각 문서 핸들과 함께 보관하고, 기록에서 빠진 이전 핸들만 해제한다. 파일 열기 실패는 기존 기록을 유지하고, 새 문서·정상 파일 열기는 이전 기록을 정리한다. 그림은 글줄/셀 안에 삽입하여 종이 좌상단에 떠서 잘리는 문제를 막는다.

## 남아 있는 엔진 경계와 기준 소스의 검사 불일치

이전 버전에서 남았던 머리말·꼬리말의 표·그림·수식과 각주·미주 편집 제한을 해소했다. 영역을 구분하여 편집하므로 본문을 잘못 수정하지 않는다. Windows 한글 프로그램 외부 제어와 Excel 매크로의 브라우저 내부 실행은 제공하지 않으며, Excel 매크로는 파일로 보존한다. 임의의 모든 HWP 버전·개체가 Windows 한글과 동일하게 렌더링된다는 보장은 아니다. 각주 내부 표·수식의 저장 구조도 검사하지만, 현재 rhwp의 해당 개체 화면 렌더링은 별도 엔진 검증 범위다. 위 기능 대응과 검증 결과는 실제 이식·검사한 범위를 나타낸다.

기존 `workspace`, `inline`, `menu-focus` 브라우저 검사 일부는 `#exam-workspace-open` 버튼을 찾는다. 지정된 **기준 커밋 b2f85a00에서 이미 이 버튼이 없고** 닫기 뒤 초점은 `#exam-send`로 옮긴다. 이식 때문에 버튼을 제거한 것이 아니다. 해당 검사는 실패로 기록하며 통과 수에 포함하지 않는다. 원본 소스의 동작을 바꾸어 검사에 맞추지는 않았다.

출처와 라이선스는 `assets/hwp-palette/NOTICE.md`, `vendor/fflate/PROVENANCE.json`, `vendor/opencv/PROVENANCE.json`과 각 LICENSE를 따른다.
