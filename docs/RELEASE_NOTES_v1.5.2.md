# v1.5.2 — 지연 자르기 UI 복원

지연 자르기의 처리 엔진과 단축키는 포함되어 있었지만, 통합 과정에서 왼쪽 도구막대의 선택 팝오버가 이전 마크업으로 덮여 화면에서 기능을 찾을 수 없던 문제를 수정했습니다.

## 수정 사항

- 왼쪽 자르기 버튼에 `자르기 / 지연 자르기 / 지우개` 선택 팝오버 복원
- `지연 자르기` 선택 시 모드 탭과 오른쪽 `자르기 확정` 패널 표시
- `Ctrl+E` 지연 자르기 단축키 유지
- 화면에서 지연 자르기까지 실제로 도달할 수 있는 회귀 테스트 추가
