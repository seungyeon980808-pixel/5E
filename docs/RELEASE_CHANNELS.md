## 단일 기준 파일

루트 `release-channels.json`이 채널별 버전과 주소를 정의합니다. `package.json`은 현재 루트 소스로 빌드하는 패키지의 버전입니다. `channels.windows`는 **이미 발행된 설치판**의 기록이므로 현재 package 버전과 달라도 됩니다.

채널 선언, README, 화면, package-lock 불일치는 `npm run check:release`로 탐지합니다. 파일별 `?v=`는 캐시 키이며 제품 버전과 무조건 같아야 하는 값이 아닙니다. 이번 변경에서는 검증 없이 전체 캐시 키를 일괄 치환하지 않습니다.
