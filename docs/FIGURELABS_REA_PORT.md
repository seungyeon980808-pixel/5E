## 구현된 사용자 동선

편집기 하단 **도식 만들기** → 세 가지 종류 중 선택한다.

| 종류 | 입력 | 실제 동작 |
|---|---|---|
| 일러스트 | 물체·위치·모양을 한 줄로, PNG/JPEG/WebP 참고 이미지 0~4장 | 짧은 설명을 별도의 AI 작업 공간에 전달. 생성 시 시험용 표현·차원 일관성을 내부 보강한다. 참고 없이 생성 가능하며 요청한 글자·기호를 포함한다. 자동 실행하지 않는다. |
| 흐름도 | 줄바꿈 또는 화살표로 나눈 2~12개 과정 | 가로/세로 배치, 글자 줄바꿈, 연결 화살표. 표준 rect/line 객체로 삽입한다. |
| 데이터 그래프 | 엑셀 두 열, CSV, 탭/세미콜론/공백 표 | 숫자 범위에 맞춘 좌표평면, 측정점, 선택적 연결선. 표준 coordplane/optics/polyline 객체로 삽입한다. |

흐름도·그래프에는 시험지 흑백·학습지 회색·굵은 선 프리셋을 제공한다. 일러스트는 평가원식 표현을 자동 보강하므로 스타일 선택을 요구하지 않는다. 흐름도·그래프는 실제 렌더러로 미리 본 뒤 삽입하며, 기존 객체·페이지 크기를 보존하고 한 번의 undo 이력으로 묶는다. 그룹 해제 후 기존 속성창에서 개별 수정할 수 있다. 기존 프로젝트 저장과 PNG/SVG 내보내기를 그대로 쓴다.

## 실제 공급자 생성 검수 (2026-10-18 10:32 KST 수정 후)

실제 검수에서 발견해 수정한 경로:

- 한 줄 생성 PNG에 기존 배경 제거·색 변환을 적용하지 않고 공급자 원본을 보존한다. 프로필은 후보 스냅샷에도 남긴다.
- 결과 선택 뒤에도 짧은 입력창을 유지하며 박스 코멘트 없이 다음 수정 문장을 제출할 수 있다.
- 원본이 없는 신규 생성도 렌더러 시스템 지시에서 명시적으로 허용한다.
- 흰 배경 설명만으로 투명 PNG가 생성된 사례가 있어, 내부 실행 지시에 `transparent_background: false` 도구 인수까지 명시했다. 재생성 세 장과 물리 수정본 모두 투명 픽셀 0개다. 이는 이번 표본의 관측 결과이며 미래 생성의 보장은 아니다.

## 2026-10-18 통합 생성 탭과 설명 그래프

AI 이미지 변환에 `이미지 변환 / 그림 만들기 / 그래프 복원 / 그래프 만들기`를 제공한다. 기존 brief 작업은 image-create로 복구하며 네 작업의 입력·결과를 분리한다. 생성 화면은 원본 없이 결과를 넓게 표시한다.

설명 그래프는 Figure Labs 호출 없이 기존 5E JSON 전송과 네이티브 그래프 엔진을 연결했다. 설명·이전 plan·현재 수동 편집 객체의 해시를 요청에 묶고 이미지 첨부 없이 JSON을 한 번 요청한다. 계약 검증 후 편집 객체로 렌더링한다. 정성 그래프는 숫자 없는 비율 도식, 수식과 데이터는 정량 그래프다. 원형/3D 그래프는 지원 범위 밖이며 빈 계열 결과는 오류로 처리한다. 설명 생성 작업의 일괄 실행은 막고 개별 만들기 버튼을 안내한다.

실제 로컬 Codex 연결로 그래프 8회, 그림 1회를 생성했다. 정성·수식·막대 생성과 수정, 세부 편집의 수식·범위·축 이름, 캔버스 삽입과 복구를 확인했다. 검수 중 숫자 눈금 작성 규칙, 막대 이름 중복, 축 제목 여백을 보강했다. Node 24 단위/회귀 134개 및 전송 워크플로 46개 통과. 실제 Safari 화면·탭·푸터를 확인했다. 작은 모바일 폭은 이번 검수에 포함하지 않았다. 결과의 과학 조건은 교사 검수가 필요하며 평가원 공식 검증을 의미하지 않는다. 커밋·푸시·배포 없음.
